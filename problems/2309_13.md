## 문제 요약
선분 AB를 지름으로 하는 반원의 호 위에 두 점 C, D. AB의 중점 O에 대하여 선분 AD, CO가 점 E에서 만나고 CE = 4, ED = 3√2, ∠CEA = 3π/4. AC × CD는?

## 풀이
1. ∠CED = π − 3π/4 = π/4, ∠OED = 3π/4, ∠AEO = ∠CED = π/4(맞꼭지각).
2. **[L071]** 삼각형 CED: CD² = 16 + 18 − 2·4·3√2·cos(π/4) = 10 → CD = √10.
3. **[L071]** 반지름 r, OE = r − 4. 삼각형 OED: r² = (r − 4)² + 18 + 6(r − 4) → r = 5, OE = 1.
4. **[L071]** 삼각형 AOE: 25 = AE² + 1 − √2·AE → AE = 4√2.
5. **[L071]** 삼각형 AEC(∠AEC = 3π/4): AC² = 32 + 16 + 2·4√2·4·(√2/2) = 80 → AC = 4√5.
6. AC × CD = 4√5·√10 = 20√2.

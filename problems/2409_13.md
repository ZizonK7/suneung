## 문제 요약
f(x) = −x³/3 − ax² − bx (x < 0), x³/3 + ax² − bx (x ≥ 0)가 (−∞, −1]에서 감소, [−1, ∞)에서 증가할 때 a + b의 최댓값 M, 최솟값 m. M − m은?

## 풀이
1. **[L089]** f′(−1) = −1 + 2a − b = 0 → b = 2a − 1. x < 0에서 f′ = −(x + 1)(x + 2a − 1).
2. x < −1에서 f′ ≤ 0 → a ≤ 1. −1 < x < 0에서 f′ ≥ 0 → 2a − 1 ≤ 0 → a ≤ 1/2.
3. **[L054]** x ≥ 0에서 x² + 2ax − 2a + 1 ≥ 0: a ≥ 0이면 x = 0에서 1 − 2a ≥ 0, a < 0이면 꼭짓점 −a에서 −a² − 2a + 1 ≥ 0 → a ≥ −1 − √2.
4. a ∈ [−1 − √2, 1/2], a + b = 3a − 1 ∈ [−4 − 3√2, 1/2] → M − m = 9/2 + 3√2.

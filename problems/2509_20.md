## 문제 요약
[0, 2π]에서 f(x) = sinx − 1 (0 ≤ x < π), −√2 sinx − 1 (π ≤ x ≤ 2π). 0 ≤ t ≤ 2π인 t에 대하여 x에 대한 방정식 f(x) = f(t)의 서로 다른 실근의 개수가 3이 되는 모든 t의 합이 (q/p)π일 때 p + q는? (p, q 서로소 자연수)

## 풀이
1. **[L064]** k = f(t)로 두고, f(x) = k의 실근이 3개인 k를 먼저 찾은 뒤 f(t) = k인 t를 모두 모은다.
2. **[L013]** 조각별로 본다. [0, π)에서 sinx − 1은 −1(x = 0)에서 0(x = π/2)까지 올랐다가 −1로 내려가지만 x = π는 빠진다. [π, 2π]에서 −√2 sinx − 1은 −1(x = π)에서 √2 − 1(x = 3π/2)까지 올랐다가 −1(x = 2π)로 내려간다.
3. **[L014]** 개수가 달라지는 k는 극값 높이와 끝값뿐이다.
   - k = −1: x = 0, π, 2π → 3개.
   - −1 < k < 0: 2 + 2 = 4개. k = 0: x = π/2와 sinx = −1/√2인 5π/4, 7π/4 → 3개.
   - 0 < k < √2 − 1: 2개, k = √2 − 1: 1개.
4. f(t) = −1인 t: 0, π, 2π. f(t) = 0인 t: π/2, 5π/4, 7π/4. 합 = 3π + 7π/2 = 13π/2 → p + q = 2 + 13 = 15.

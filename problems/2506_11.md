## 문제 요약
최고차항 계수 1이고 f(0) = 0인 삼차함수 f가 lim_{x→a} {f(x) − 1}/(x − a) = 3을 만족한다. 곡선 y = f(x) 위의 점 (a, f(a))에서의 접선의 y절편이 4일 때 f(1)은? (a는 상수)

## 풀이
1. **[L002]** 분모 → 0이므로 분자 → 0: f(a) = 1.
2. **[L044]** 그러면 극한은 차분몫이라 f′(a) = 3.
3. 접선 y = 3(x − a) + 1의 y절편 1 − 3a = 4 → a = −1.
4. f(x) = x³ + px² + qx: f(−1) = −1 + p − q = 1, f′(−1) = 3 − 2p + q = 3 → p = −2, q = −4.
5. f(1) = 1 − 2 − 4 = −5.

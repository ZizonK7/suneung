## 문제 요약
최고차항 계수 1, f′(0) = f′(2) = 0인 삼차 f, 양수 p. g(x) = f(x) − f(0) (x ≤ 0), f(x + p) − f(p) (x > 0). ㄱ. p = 1이면 g′(1) = 0 ㄴ. g가 미분가능한 p는 1개 ㄷ. p ≥ 2이면 ∫_{−1}^1 g ≥ 0.

## 풀이
1. f′ = 3x(x − 2), f = x³ − 3x² + c. g는 x ≤ 0에서 x³ − 3x².
2. ㄱ: g′(1) = f′(1 + p) = f′(2) = 0. 참.
3. **[L040]** ㄴ: x = 0에서 양쪽 값은 모두 0으로 연속. 기울기 f′(0) = 0 = f′(p) → p = 2 하나. 참.
4. **[L103]** ㄷ: p = 2이면 x > 0에서 g = f(x + 2) − f(2) = x³ + 3x²이고 g(−x) = −g(x)인 홀함수 → ∫_{−1}^1 g = 0.
5. p ≥ 2이면 [1, ∞)에서 f′가 증가하므로 f(x + p) − f(p) = ∫_p^{p+x} f′ ≥ ∫_2^{2+x} f′ = f(x + 2) − f(2). 오른쪽 적분은 p = 2일 때가 최소 → ∫_{−1}^1 g ≥ 0. 참.

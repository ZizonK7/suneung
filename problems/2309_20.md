## 문제 요약
k<0. f(x) = x³ + x² − x, g(x) = 4|x| + k의 교점이 2개일 때 둘러싸인 넓이 S, 30S는?

## 풀이
1. x≥0: x³ + x² − 5x = k. 극소 x=1에서 −3. x<0: x³ + x² + 3x = k, 증가함수라 k<0이면 근 1개. [L013]
2. 총 2개 → x≥0 쪽에서 접해야 함 → k = −3. [L014]
3. 음수 쪽 근: (x+1)(x²+3) = 0 → x = −1. 양수 쪽: f − g = (x−1)²(x+3). [L015]
4. S = ∫_{−1}^{0}(x³+x²+3x+3)dx + ∫_{0}^{1}(x³+x²−5x+3)dx = 19/12 + 13/12 = 8/3 → 80.

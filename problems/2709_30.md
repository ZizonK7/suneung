## 문제 요약
f(x) = 2^{2x + (1/2)cos πx}의 역함수 g는 양의 실수 전체에서 연속인 도함수를 갖는다. (1/4)∫_{f(1)}^{f(3)} g(x)dx + ∫_{f(0)}^{f(2)} 2^{4g(x)}g′(x)/x dx = (q/p)√2일 때 p + q는? (p, q는 서로소인 자연수)

## 풀이
1. f′ = f·ln2·(2 − (π/2)sin πx) > 0이라 f는 증가. f(0) = 2^{1/2}, f(1) = 2^{3/2}, f(2) = 2^{9/2}, f(3) = 2^{11/2}.
2. **[L051]** ∫_{f(1)}^{f(3)} g = 3f(3) − f(1) − ∫_1^3 f(t)dt = 3·2^{11/2} − 2^{3/2} − ∫_1^3 f(t)dt.
3. **[L115]** 둘째 적분은 g(x) = t로 치환(x = f(t), g′dx = dt): ∫_0^2 2^{4t}/f(t) dt = ∫_0^2 2^{2t − (1/2)cos πt} dt.
4. **[L059]** cos π(s + 1) = −cos πs → f(s + 1) = 2^{2s + 2 − (1/2)cos πs} = 4·2^{2s − (1/2)cos πs}.
5. **[N6C3]** ∫_1^3 f(t)dt에 t = s + 1을 넣으면 4∫_0^2 2^{2s − (1/2)cos πs} ds. 1/4을 곱하면 3의 적분과 같아 지워진다.
6. 합 = (1/4)(3·2^{11/2} − 2^{3/2}) = (1/4)(96√2 − 2√2) = (47/2)√2 → p + q = 49.
7. 검산: 역함수를 수치로 구해 두 적분을 직접 계산, 33.2340… = 47√2/2 일치.

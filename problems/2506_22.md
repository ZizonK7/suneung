## 문제 요약
a₂ = −a₁. n ≥ 2에서 √n이 자연수이고 a_n > 0이면 a_{n+1} = a_n − √n·a_{√n}, 그 외에는 a_{n+1} = a_n + 1. a₁₅ = 1이 되는 모든 a₁의 곱은?

## 풀이
1. a₁ = t로 둔다. 2 ≤ n ≤ 14에서 갈림이 생기는 첨자는 n = 4, 9뿐. 나머지는 +1.
2. **[NC3]** a₄ = 2 − t. n = 4에서 갈래: a₄ > 0 (t < 2)이면 a₅ = a₄ − 2a₂ = t + 2, 아니면 a₅ = 3 − t. a₉ = a₅ + 4.
3. n = 9에서 갈래(a₃ = 1 − t): a₉ > 0이면 a₁₀ = a₉ − 3(1 − t), 아니면 a₉ + 1. 끝 조건 a₁₀ = a₁₅ − 5 = −4.
   - t < 2, t > −6: 4t + 3 = −4 → t = −7/4 ✓
   - t ≤ −6: t + 7 = −4 → t = −11 ✓
   - 2 ≤ t < 7: 2t + 4 = −4 → t = −4 ✗
   - t ≥ 7: 8 − t = −4 → t = 12 ✓
4. 곱 = (−7/4)(−11)(12) = 231 (직접 반복 계산으로 확인).

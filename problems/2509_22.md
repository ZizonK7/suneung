## 문제 요약
a₁ = k > 0. (가) a₂a₃ < 0. (나) (a_{n+1} − a_n + 2k/3)(a_{n+1} + k·a_n) = 0. a₅ = 0이 되는 모든 k에 대해 k²의 합은?

## 풀이
1. **[NC3]** (나)는 매 단계 a_{n+1} = a_n − 2k/3 또는 a_{n+1} = −k·a_n의 두 갈래다. 수형도로 따라간다.
2. a₂ = k/3 또는 −k². (가)로 가지치기: a₂ = k/3이면 a₃ = −k/3 또는 −k²/3 (둘 다 음수 ✓). a₂ = −k²이면 a₃ = k³만 가능.
3. 끝에서 거꾸로: a₅ = 0 ⇔ a₄ = 2k/3 또는 a₄ = 0.
   - a₃ = −k/3 → a₄ = −k 또는 k²/3. k²/3 = 2k/3 → k = 2.
   - a₃ = −k²/3 → a₄ = −k²/3 − 2k/3(음수) 또는 k³/3. k³/3 = 2k/3 → k² = 2.
   - a₃ = k³ → a₄ = k³ − 2k/3 또는 −k⁴. k³ − 2k/3 = 0 → k² = 2/3, k³ − 2k/3 = 2k/3 → k² = 4/3.
4. k²의 합 = 4 + 2 + 2/3 + 4/3 = 8 (sympy로 16갈래 전수 확인).

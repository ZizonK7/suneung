## 문제 요약
사각형 ABCD가 한 원에 내접하고 AB = 5, AC = 3√5, AD = 7, ∠BAC = ∠CAD일 때 이 원의 반지름의 길이는?

## 풀이
1. **[L028]** BC와 CD는 같은 원주각 θ = ∠BAC = ∠CAD에 대한 현이므로 BC = CD = 2R·sinθ.
2. **[L071]** 삼각형 ABC, ACD에서 코사인법칙: BC² = 25 + 45 − 30√5·cosθ, CD² = 49 + 45 − 42√5·cosθ. 두 식이 같으므로 12√5·cosθ = 24 → cosθ = 2/√5, sinθ = 1/√5.
3. BC² = 70 − 60 = 10, BC = √10.
4. **[L028]** R = BC/(2sinθ) = √10·√5/2 = 5√2/2.

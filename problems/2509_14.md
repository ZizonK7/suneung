## 문제 요약
자연수 n에 대하여 곡선 y = 2ˣ 위의 두 점 Aₙ, Bₙ이 (가) 직선 AₙBₙ의 기울기는 3, (나) AₙBₙ = n√10을 만족시킨다. 중심이 직선 y = x 위에 있고 Aₙ, Bₙ을 지나는 원이 곡선 y = log₂x와 만나는 두 점의 x좌표 중 큰 값을 xₙ이라 할 때, x₁ + x₂ + x₃은?

## 풀이
1. **[L077]** 중심이 y = x 위인 원은 y = x에 대해 대칭이다. Aₙ, Bₙ을 y = x에 대칭이동한 점은 원 위에 있고 y = log₂x 위에 있다. 그래서 두 교점의 x좌표는 Aₙ, Bₙ의 y좌표다.
2. **[L092]** Aₙ(p, 2ᵖ), Bₙ(q, 2^q), p < q. 기울기 3인 직선 위 길이 n√10 → q − p = n, 2^q − 2ᵖ = 3n.
3. 2ᵖ(2ⁿ − 1) = 3n → xₙ = 2^q = 2ⁿ·3n/(2ⁿ − 1).
4. x₁ = 6, x₂ = 8, x₃ = 72/7 → 합 170/7.

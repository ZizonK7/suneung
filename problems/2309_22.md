## 문제 요약
최고차항 계수 1인 삼차 f가 x = 3에서 극댓값 8. g(x) = f(x) (x ≥ t), −f(x) + 2f(t) (x < t). g(x) = 0의 서로 다른 실근 개수 h(t)가 불연속인 t가 두 개일 때 f(8)은?

## 풀이
1. **[L015]** f(x) − 8은 x = 3에서 중근 → f(x) = (x − 3)²(x − k) + 8. 3이 극대이므로 다른 극점 m = (2k + 3)/3 > 3, 즉 k > 3.
2. **[L064]** g = 0 ⇔ (x ≥ t에서 f(x) = 0) 또는 (x < t에서 f(x) = 2f(t)). 왼쪽 부분은 y = f (x < t)와 수평선 y = 2f(t)의 교점.
3. f의 음수 쪽 근 r에서: t < r이면 2개, t = r이면 1개, t > r이면 (극솟값이 충분히 크면) 0개 → 불연속 1개는 항상 있다.
4. **[L093]** 나머지 불연속은 t > 3에서 2f(t)가 극댓값 8 이하, 즉 f(t) ≤ 4가 될 때 생긴다. 극솟값 f(m) < 4이면 f(t) ≤ 4인 t 구간의 양 끝에서 개수가 바뀌어 불연속이 3개 이상.
5. **[L014]** 정확히 2개 → 극솟값 = 4. 그러면 t = m에서만 f(x) = 8의 근 x = 3이 생겨 h(m) = 1, 주변은 0인 고립 불연속.
6. f(m) = −4(k − 3)³/27 + 8 = 4 → (k − 3)³ = 27 → k = 6. f(8) = 25·2 + 8 = 58.
   - 확인: k = 6일 때 수치로 h(t) 불연속은 t = r ≈ 1.64와 t = 5 두 개.

## 문제 요약
삼차함수 f에 대하여 곡선 y = f(x) 위의 점 (0, 0)에서의 접선과 곡선 y = xf(x) 위의 점 (1, 2)에서의 접선이 일치할 때 f′(2)의 값은?

## 풀이
1. 점 (1, 2)가 y = xf(x) 위에 있으므로 f(1) = 2. f(0) = 0.
2. 두 접선이 같으므로 y = xf(x)의 (1, 2)에서의 접선은 원점을 지난다. 기울기는 2/1 = 2이고, 이것이 (0, 0)에서 y = f(x)의 접선 기울기이므로 f′(0) = 2.
3. **[L068]** (xf(x))′ = f(x) + xf′(x) → x = 1에서 2 + f′(1) = 2 → f′(1) = 0.
4. f(x) = ax³ + bx² + 2x에서 a + b + 2 = 2, 3a + 2b + 2 = 0 → a = −2, b = 2. f′(x) = −6x² + 4x + 2, f′(2) = −14.

## 풀이
1. **[L064]** 3x⁴ − 4x³ − 12x² = −k로 상수를 분리한다. f(x) = 3x⁴ − 4x³ − 12x², f′(x) = 12x(x + 1)(x − 2).
2. 극값 f(−1) = −5(극소), f(0) = 0(극대), f(2) = −32(극소). 수평선 y = −k와 네 점에서 만나려면 −5 < −k < 0 → 0 < k < 5. 자연수 k = 1, 2, 3, 4로 4개.

## 문제 요약
자연수 k에 대해 a₁ = k이고, 모든 자연수 n에 대해 a_{n+1} = a_n + 2n − k (a_n ≤ 0), a_n − 2n − k (a_n > 0)이다. a₃ × a₄ × a₅ × a₆ < 0이 되도록 하는 모든 k의 값의 합은?

## 풀이
1. **[L107]** a₁ = k > 0 → a₂ = −2 → a₃ = 2 − k. 여기서부터 k에 따라 갈래를 친다.
2. k = 1: a₃ = 1 > 0 → a₄ = −6, a₅ = 1, a₆ = −10. 곱 > 0. 제외. k = 2: a₃ = 0이라 곱 = 0. 제외.
3. k ≥ 3: a₃ < 0 → a₄ = 8 − 2k.
   - k = 3: a₄ = 2 > 0 → a₅ = −9, a₆ = −2. 부호 −, +, −, − → 곱 < 0. 성립.
   - k = 4: a₄ = 0. 제외.
   - k ≥ 5: a₄ < 0 → a₅ = 16 − 3k. k = 5이면 a₅ = 1 > 0, a₆ = −14 → 부호 −, −, +, − → 성립. k ≥ 6이면 a₅ < 0, a₆ = 26 − 4k: k = 6에서 a₆ = 2 > 0 → 성립, k ≥ 7에서 넷 다 음수 → 곱 > 0.
4. k = 3, 5, 6 → 합 14. 검산: k = 1~199 전수 확인.

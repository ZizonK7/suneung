## 문제 요약
최고차항의 계수가 6인 이차함수 f, f(0) = 0, ∫_0^2 f = 4. ㄱ. ∫_0^2 |f| = 6 ㄴ. g(1) = 0인 일차함수 g에 대해 ∫_0^2 (f + g) = 4 ㄷ. k > 6인 각 k에 대해 ∫_0^2 (f + h) = 4, ∫_0^2 |f + h| = k인 일차함수 h가 존재. 옳은 것은?

## 풀이
1. f = 6x² + bx, ∫_0^2 f = 16 + 2b = 4 → b = −6, f = 6x(x − 1).
2. **[L078]** ㄱ: 근 1에서 나눠 ∫_0^1 (6x − 6x²) + ∫_1^2 (6x² − 6x) = 1 + 5 = 6. 참.
3. **[NB4]** ㄴ: g = c(x − 1)은 구간 [0, 2]의 중점 1에 대해 점대칭 → ∫_0^2 g = 0. 참.
4. ㄷ: 같은 이유로 ∫_0^2 h = 0 ⇔ h = c(x − 1). f + h = (x − 1)(6x + c). c ≥ 0이면 [0, 2]에서 근은 1뿐 → ∫|f + h| = −∫_0^1 + ∫_1^2 = 6 + c. c = k − 6 > 0으로 잡으면 된다. 참.
5. 검산(sympy/scipy): b = −6, ㄱ = 6, ㄴ = 4, c = 0, 1, 6, 12, 100에서 ∫|f + h| = 6, 7, 12, 18, 106. 답 ⑤.

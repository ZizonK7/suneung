## 문제 요약
최고차항 계수 9인 삼차함수 f가 (가) lim_{x→0} sin(π·f(x))/x = 0, (나) f의 극댓값과 극솟값의 곱이 5를 만족한다. g(x)는 0 ≤ x < 1에서 g(x) = f(x)이고 모든 실수 x에서 g(x + 1) = g(x)이다. g가 실수 전체에서 연속일 때 ∫_0^5 x·g(x)dx = q/p(서로소인 자연수), p + q는?

## 풀이
1. **[L002]** 분모 x → 0이고 극한이 수렴하므로 sin(π·f(0)) = 0 → f(0)은 정수.
2. **[L044]** 그러면 sin(πf(x))/x = {sin(πf(x)) − sin(πf(0))}/(x − 0)의 극한은 x = 0에서 sin(πf(x))의 미분계수 π·cos(πf(0))·f′(0)이다. cos(πf(0)) = ±1이므로 f′(0) = 0.
3. **[L040]** g가 x = 1에서 연속 → 좌극한 f(1) = g(1) = g(0) = f(0). f(x) = 9x³ + ax² + c(f′(0) = 0)에 넣으면 9 + a = 0, a = −9.
4. **[L060]** f′(x) = 27x² − 18x = 9x(3x − 2): 극점 x = 0, 2/3. f(0) = c, f(2/3) = c − 4/3. c(c − 4/3) = 5 → c = 3 또는 −5/3. f(0)이 정수이므로 c = 3, f(x) = 9x³ − 9x² + 3.
5. **[N4C1]** k번째 주기에서 x = t + k로 옮기면 ∫_0^5 x·g(x)dx = Σ_{k=0}^{4} ∫_0^1 (t + k)f(t)dt = 5∫_0^1 t·f(t)dt + 10∫_0^1 f(t)dt.
6. ∫_0^1 t·f = 9/5 − 9/4 + 3/2 = 21/20, ∫_0^1 f = 9/4 − 3 + 3 = 9/4. 합 21/4 + 90/4 = 111/4 → p + q = 115.

## 문제 요약
양수 a, Σ{(a − 3n)/n + (an + 6)/(n + a)}가 S로 수렴할 때 a + S는?

## 풀이
1. **[L083]** 일반항 → −3 + a = 0 → a = 3.
2. 일반항 = 3/n − 3/(n + 3) → **[L016]** S = 3(1 + 1/2 + 1/3) = 11/2.
3. a + S = 17/2.

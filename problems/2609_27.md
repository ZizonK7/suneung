## 문제 요약
f′ > 0, f(x³ + x)의 역함수 g. f(2) = 1, f′(2) = 8g′(1) − 1일 때 g(1) + g′(1)은?

## 풀이
1. **[L082]** f(x³ + x) = 1 = f(2) → x³ + x = 2 → x = 1 → g(1) = 1.
2. g′(1) = 1/{f′(2)·4}. f′(2) = 2/f′(2) − 1 → f′(2) = 1(양수) → g′(1) = 1/4.
3. 5/4.

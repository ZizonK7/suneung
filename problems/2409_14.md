## 문제 요약
자연수 a, b에 대해 f(x) = 2^{x+a} + b (x ≤ −8), −3^{x−3} + 8 (x > −8). 집합 {f(x) | x ≤ k}의 원소 중 정수인 것의 개수가 2가 되도록 하는 모든 실수 k의 값의 범위가 3 ≤ k < 4일 때 a + b는?

## 풀이
1. **[L123]** 왼쪽 조각은 증가: 치역 S₁ = (b, b + 2^{a−8}]. 오른쪽 조각은 감소: x ∈ (−8, k]의 치역은 [8 − 3^{k−3}, 8 − 3^{−11}), 정수는 8 − 3^{k−3} 이상 7 이하.
2. **[L014]** 범위의 끝 k = 3은 오른쪽 조각의 값이 정수 7에 닿는 순간이다. k < 3에서는 오른쪽 조각에 정수가 없어 개수 = |S₁ ∩ ℤ| ≠ 2. k = 4에서는 5, 6, 7이 들어와 3개 이상.
3. 3 ≤ k < 3 + log₃2: 오른쪽 정수는 {7}, 개수 2 → S₁에 7이 아닌 정수가 있다. S₁ ∩ ℤ가 비면 개수 1이라 안 된다.
4. **[L176]** 3 + log₃2 ≤ k < 4에서 6이 새로 들어오는데 개수가 2로 그대로이므로 6은 이미 S₁에 있어야 하고, S₁ ∩ ℤ ⊆ {6, 7}. 3번과 합치면 6 ∈ S₁. {6, 7}이면 k < 3에서 개수 2가 되어 모순 → S₁ ∩ ℤ = {6}.
5. S₁의 가장 작은 정수는 b + 1 = 6 → b = 5, b + 2^{a−8} ∈ [6, 7) → 2^{a−8} ∈ [1, 2) → a = 8. a + b = 13.
6. 검산: a, b = 1~19 전수 탐색에서 (8, 5)만 범위 3 ≤ k < 4를 준다.

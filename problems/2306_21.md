## 문제 요약
4 log₆₄(3/(4n + 16))이 정수가 되는 1000 이하 자연수 n의 합은?

## 풀이
1. (2/3)log₂(3/(4(n + 4))) = −m (정수) → 4(n + 4) = 3·2^{3m/2}. [L085]
2. m은 짝수 2j → n + 4 = 3·2^{3j−2}, j = 1, 2, 3 → n = 2, 44, 380 (j = 4는 1000 초과).
3. 합 426.

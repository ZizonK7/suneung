## 문제 요약
이계도함수를 갖는 f와 상수 a, b. (가) f⁵ + f³ + ax + b = ln(x² + x + 5/2), (나) f(−3)f(3) < 0, f′(2) > 0. a·e^b는?

## 풀이
1. G(x) = ln(x² + x + 5/2) − ax − b로 두면 f⁵ + f³ = G. (나)와 사잇값 정리로 f(c) = 0인 c ∈ (−3, 3)이 있다.
2. **[L098]** 양변 미분: (5f⁴ + 3f²)f′ = G′. 한 번 더: (20f³ + 6f)f′² + (5f⁴ + 3f²)f″ = G″. x = c에서 f = 0 → G(c) = G′(c) = G″(c) = 0.
3. (ln q)″ = −2(x + 2)(x − 1)/q² (q = x² + x + 5/2) → c = −2 또는 1. a = (2c + 1)/q(c) → c = −2이면 a = −2/3, c = 1이면 a = 2/3.
4. f′(2) > 0 ⇔ G′(2) = 10/17 − a > 0 (5f⁴ + 3f² ≥ 0) → a = 2/3은 탈락. a = −2/3, c = −2.
5. b = ln(9/2) − ac = ln(9/2) − 4/3. a·e^b = −(2/3)(9/2)e^{−4/3} = −3e^{−4/3}.

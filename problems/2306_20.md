## 문제 요약
최고차항 계수 2인 이차함수 f에 대하여 g(x) = ∫_x^{x+1} |f(t)|dt는 x = 1과 x = 4에서 극소이다. f(0)의 값은?

## 풀이
1. **[L069]** g′(x) = |f(x + 1)| − |f(x)|.
2. **[L053]** x = 1, 4에서 극소이므로 g′(1) = g′(4) = 0이고 g′의 부호가 −에서 +로 바뀐다. |f(2)| = |f(1)|, |f(5)| = |f(4)|.
3. **[L035]** |f(a)| = |f(a + 1)|은 f(a) = f(a + 1)(축이 x = a + 1/2) 또는 f(a) = −f(a + 1)이다. 축은 하나뿐이라 두 점 모두 같은 값일 수는 없다. 한쪽만 같은 값인 경우(f = 2x² − 6x − 14, 2x² − 18x + 22)는 그 점에서 극소가 되지 않는다.
4. 따라서 f(1) + f(2) = 0, f(4) + f(5) = 0. h(x) = f(x) + f(x + 1)은 최고차항 계수 4인 이차식이고 근이 1, 4 → h = 4(x − 1)(x − 4) = 4x² − 20x + 16.
5. f = 2x² + bx + c이면 h = 4x² + (2b + 4)x + (b + 2c + 2) → b = −12, c = 13. f(0) = 13.
6. 확인: f(1) = 3 > 0 > f(2) = −3이라 x = 1 근처에서 g′ = −h, x = 4 근처에서 f(4) = −3 < 0 < f(5) = 3이라 g′ = h. 둘 다 −에서 +로 바뀐다(수치 검산 일치).

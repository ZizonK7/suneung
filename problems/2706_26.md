## 풀이
1. **[L034]** sin x = √3/2 (0 < x < π)의 두 근은 x = π/2에 대해 대칭인 π/3, 2π/3. 접선의 기울기는 cos(π/3) = 1/2, cos(2π/3) = −1/2.
2. **[L124]** tanθ = |(1/2 − (−1/2))/(1 + (1/2)(−1/2))| = 1/(3/4) = 4/3.

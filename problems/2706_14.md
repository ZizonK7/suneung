## 문제 요약
양수 a, 자연수 b. 0 ≤ x ≤ 2에서 (cos bπx − 1/2)(a cos bπx + (a + 2)/2) = 0의 서로 다른 실근이 15개일 때 a + b는?

## 풀이
1. θ = bπx는 [0, 2bπ], 곧 b주기를 돈다.
2. **[L020]** cos θ = 1/2: 주기마다 2개 → 2b개.
3. cos θ = −1/2 − 1/a < −1/2. 이 값이 −1보다 작으면 0개, (−1, −1/2)이면 2b개, −1이면 주기마다 1개 → b개.
4. 2b, 4b는 짝수라 15가 안 된다 → 2b + b = 15, b = 5, −1/2 − 1/a = −1 → a = 2.
5. a + b = 7.

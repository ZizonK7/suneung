## 문제 요약
f(x) = sin(ax + b + sin x), 1 ≤ a ≤ 2. (가) f(0) = 0, f(2π) = 2πa + b. (나) f′(0) = f′(t)인 최소 양수 t는 4π. (0, 4π)에서 극대인 x의 개수 n, 가장 작은 값 α₁. nα₁ − ab = (q/p)π, p + q는?

## 풀이
1. **[L086]** f(2π) = sin(2πa + b) = 2πa + b → 2πa + b = 0. f(0) = sin b = 0 → b = mπ → a ∈ {1, 3/2, 2}.
2. **[L087]** a = 1, 2이면 f의 주기가 2π라 f′(2π) = f′(0) → 최소 t ≤ 2π로 어긋난다. a = 3/2, b = −3π: f = −sin(3x/2 + sin x). f′(t) = f′(0) = −5/2는 cos t = 1, cos(3t/2 + sin t) = 1일 때뿐 → t = 4π ✓.
3. **[L023]** u = 3x/2 + sin x는 증가(u′ = 3/2 + cos x > 0). f = −sin u의 극대는 u = 3π/2, 7π/2, 11π/2 → n = 3, α₁ = π(u(π) = 3π/2).
4. nα₁ − ab = 3π + 9π/2 = 15π/2 → 17.

## 문제 요약
자연수 n에 대해 f(x) = |3^{x+2} − n| (x < 0), |log₂(x + 4) − n| (x ≥ 0). 실수 t에 대해 방정식 f(x) = t의 서로 다른 실근의 개수를 g(t)라 할 때, g(t)의 최댓값이 4가 되도록 하는 모든 자연수 n의 합은?

## 풀이
1. **[L032]** x < 0과 x ≥ 0으로 나눠 각 조각과 수평선 y = t의 교점을 따로 세고 더한다.
   - x < 0: 3^{x+2}의 치역은 (0, 9). n < 9이면 |3^{x+2} − n|은 0까지 내려갔다가 다시 올라가 t ∈ (0, min(n, 9 − n))에서 교점 2개. n ≥ 9이면 단조라 교점은 많아야 1개.
   - x ≥ 0: log₂(x + 4)의 치역은 [2, ∞). n > 2이면 x = 0에서 값 n − 2로 시작해 0까지 내려갔다 올라가므로 t ∈ (0, n − 2]에서 교점 2개. n ≤ 2이면 많아야 1개.
2. **[L137]** 각 조각의 교점은 많아야 2개이므로 g의 최댓값이 4이려면 두 조각이 동시에 2개가 되는 t가 있어야 한다. 3 ≤ n ≤ 8이면 두 구간 (0, min(n, 9 − n))과 (0, n − 2]가 겹친다(둘 다 0 근처를 포함).
3. n = 3, …, 8 → 합 33. 검산: n = 1~39, t를 촘촘히 훑어 최댓값 4인 n이 3~8임을 확인.

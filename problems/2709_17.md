## 문제 요약
최고차항 1인 이차함수 f. 모든 a에 대해 lim_{x→a} (2x+1)f(x) / {f(x) + f(x−t)}가 존재하는 양수 t의 집합이 {t | t ≥ 3/2}. f(2)는?

## 풀이
1. f = (x − m)² + n이라 하자. **[L043]** D_t = f(x) + f(x − t)는 최솟값 t²/2 + 2n.
   n ≥ 0이면 모든 t > 0이 되므로 n < 0이다.
2. t > t₀ = 2√(−n)이면 D_t > 0이라 극한이 늘 존재한다. 집합이 [3/2, ∞)이므로 t₀ = 3/2 → n = −9/16.
3. **[L042, L002]** t = t₀에서 D_t는 x = m + 3/4에서 중근을 갖는다.
   분자 (2x + 1)f(x)도 거기서 중근이어야 하는데, f의 근은 m ± 3/4(단근)이다. 그래서 m + 3/4 = −1/2 → m = −5/4.
4. f(2) = (13/4)² − 9/16 = 10.

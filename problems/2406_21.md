## 문제 요약
실수 t에 대하여 두 곡선 y = t − log₂x와 y = 2^{x−t}가 만나는 점의 x좌표를 f(t)라 하자. 명제 ㄱ, ㄴ, ㄷ이 참이면 각각 A = 100, B = 10, C = 1, 거짓이면 0으로 정할 때 A + B + C는? (A + B + C ≠ 0)
ㄱ. f(1) = 1이고 f(2) = 2이다. ㄴ. t가 증가하면 f(t)도 증가한다. ㄷ. 모든 양의 실수 t에 대하여 f(t) ≥ t이다.

## 풀이
1. **[N3D2]** x에 대해 y = t − log₂x는 감소, y = 2^{x−t}는 증가하므로 교점은 하나다. 차 D(x) = (t − log₂x) − 2^{x−t}는 감소하므로 어떤 점 c에서 D(c) > 0이면 교점은 c보다 오른쪽, D(c) < 0이면 왼쪽이다.
2. ㄱ: t = 1, x = 1에서 1 − 0 = 2⁰ = 1, t = 2, x = 2에서 2 − 1 = 2⁰ = 1. 참.
3. ㄴ: t가 커지면 감소 곡선은 위로, 증가 곡선은 오른쪽(아래)으로 움직인다. 옛 교점 x = f(t)에서 D > 0이 되므로 새 교점은 오른쪽이다. 참.
4. ㄷ: x = t에서 D(t) = t − log₂t − 1. f(t) ≥ t ⇔ D(t) ≥ 0 ⇔ log₂t ≤ t − 1.
5. **[N3D3]** y = log₂t는 위로 볼록이고 y = t − 1과 t = 1, 2에서 만나므로 1 < t < 2에서 log₂t > t − 1. 예: t = 1.5에서 f(1.5) ≈ 1.449 < 1.5. 거짓.
6. A + B + C = 100 + 10 + 0 = 110. 이분법으로 f(t)를 수치 계산해 확인했다.

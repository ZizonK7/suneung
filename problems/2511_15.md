## 문제 요약
g(x) = x³ + ax² + 15x + 7 (x ≤ 0), f(x) (x > 0, 최고차항 계수가 음수인 이차함수), a ≠ 3√5. (가) g는 미분가능. (나) g′(x)g′(x − 4) = 0의 서로 다른 실근이 4개. g(−2) + g(2)는?

## 풀이
1. **[L040]** x = 0에서 값과 기울기 일치: f(0) = 7, f′(0) = 15 → f = px² + 15x + 7 (p < 0). x > 0에서 g′ = 0인 점은 x₀ = −15/(2p) > 0 하나.
2. x ≤ 0에서 3x² + 2ax + 15 = 0: 두 근의 곱 5 > 0이므로 음근은 a > 3√5일 때 두 개(r₁ < r₂ < 0), 아니면 없다.
3. **[L003]** g′(x)g′(x − 4) = 0의 근 = Z ∪ (Z + 4) (Z = g′의 근 집합). Z = {x₀}이면 2개뿐이므로 Z = {r₁, r₂, x₀}이고, 6개에서 2개가 겹쳐야 한다 → r₂ = r₁ + 4, x₀ = r₂ + 4.
4. r₁(r₁ + 4) = 5 → r₁ = −5, r₂ = −1 → a = 9 (근의 합 −6 = −2a/3), x₀ = 3 → p = −5/2.
5. g(−2) = −8 + 36 − 30 + 7 = 5, g(2) = −10 + 30 + 7 = 27. 합 32.

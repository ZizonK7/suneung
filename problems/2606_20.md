## 문제 요약
0 ≤ x < 4에서 f(x) = −x² + 4x, f(x + 4) = f(x). f(f(x)) = f(x)의 0 이상 실근을 작은 순서로 a_n. 빈칸 (가)·(나)·(다)의 값 p, q, r에 대해 p + q + r은?

## 풀이
1. **[L076]** u = f(x)로 두면 f(u) = u. f의 치역이 [0, 4]이고 f(4) = 0이므로 f(u) = u의 근은 u = 0, 3 → f(x) = 0 또는 f(x) = 3.
2. 0 ≤ x < 4에서 f = 0 → x = 0, f = 3 → x = 1, 3. (가) = 1.
3. **[NA5]** 주기 4이므로 한 주기의 근 3개에 4씩 더해진다 → a_{3n−2}, a_{3n−1}, a_{3n}은 첫째항 0, 1, 3, 공차 4. (나) = 4.
4. a_20 = a_{3·7−1} = 1 + 24 = 25, a_21 = 3 + 24 = 27, a_22 = a_{3·8−2} = 0 + 28 = 28 → (다) = 80.
5. p + q + r = 1 + 4 + 80 = 85.

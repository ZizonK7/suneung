## 문제 요약
f(x) = x − 1/2 (x < 0), −x² + 3 (x ≥ 0)에 대하여 함수 (f(x) + a)²이 실수 전체에서 연속일 때 상수 a의 값은?

## 풀이
1. **[L040]** 각 조각은 연속이므로 x = 0에서 좌극한과 함숫값만 맞추면 된다: (a − 1/2)² = (3 + a)².
2. **[L035]** f + a는 x = 0에서 −1/2 + a에서 3 + a로 뛰므로 두 값은 같을 수 없고 부호만 반대: (a − 1/2) + (3 + a) = 0 → a = −5/4.

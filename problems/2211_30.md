## 문제 요약
증가하고 미분가능한 f. (가) f(1) = 1, ∫_1^2 f = 5/4. (나) g = f⁻¹, x ≥ 1에서 g(2x) = 2f(x). ∫_1^8 x f′(x)dx = q/p일 때 p + q는?

## 풀이
1. **[L111]** ∫_1^8 xf′ = 8f(8) − f(1) − ∫_1^8 f.
2. (나) ⇔ f(2f(x)) = 2x. x = 1 → f(2) = 2, x = 2 → f(4) = 4, x = 4 → f(8) = 8.
3. **[L077]** (나)는 점 (x, y)가 그래프 위면 (2y, 2x)도 그래프 위라는 뜻. [2, 4]의 그래프는 [1, 2]의 그래프를 y = x에 대해 대칭이동해 2배 확대한 것 → ∫_2^4 f = 4∫_1^2 g. 마찬가지로 ∫_4^8 f = 4∫_2^4 g.
4. **[L051]** ∫_1^2 g = 2·2 − 1·1 − 5/4 = 7/4 → ∫_2^4 f = 7. ∫_2^4 g = 4·4 − 2·2 − 7 = 5 → ∫_4^8 f = 20.
5. ∫_1^8 f = 5/4 + 7 + 20 = 113/4. 답 64 − 1 − 113/4 = 139/4 → 143.

## 문제 요약
f(x) = x² + 6x + 12. 모든 실수 a에서 lim_{x→a} x²/[{f(x)}² − k(x + 2)f(x)]가 존재하는 정수 k의 개수는?

## 풀이
1. 분모 = f(x)·{f(x) − k(x + 2)}. f = (x + 3)² + 3 > 0이라 근이 없다.
2. **[L002]** 분모의 근은 분자 x²의 근, 즉 0뿐이어야 하고 중복도도 2 이하. h(x) = f(x) − k(x + 2) = x² + (6 − k)x + 12 − 2k.
3. h가 실근이 없을 때: D = k² − 4k − 12 = (k − 6)(k + 2) < 0 → k = −1, …, 5 (7개).
4. h가 0을 근으로 가질 때: 12 − 2k = 0 → k = 6, h = x²(0의 중근). 극한 = 1/f(0)으로 존재.
5. 모두 8개.

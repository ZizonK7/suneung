## 문제 요약
실수 전체에서 연속인 f(x)가 모든 x에 대하여 f(x) ≥ 0이고, x < 0일 때 f(x) = −4xe^{4x²}. 모든 양수 t에 대하여 f(x) = t의 서로 다른 실근은 2개이고, 작은 근을 g(t), 큰 근을 h(t)라 하자. 모든 양수 t에 대하여 2g(t) + h(t) = k (k는 상수). ∫_0^7 f(x)dx = e⁴ − 1일 때 f(9)/f(8)은?

## 풀이
1. **[N6E2]** x < 0에서 f′ = −4e^{4x²}(1 + 8x²) < 0 → f는 ∞에서 0으로 감소, 모든 t > 0을 한 번씩 갖는다. 그래서 g(t) < 0이 그 근이고, x ≥ 0 부분이 모든 t > 0을 정확히 한 번씩 가져야 한다. f(0) = 0, f ≥ 0이므로 x ≥ 0에서 양수인 부분은 증가해 (0, ∞)를 덮고, 양수 값을 갖지 않는 구간은 f = 0이다.
2. **[L077]** h = k − 2g: (g, t)가 그래프 위면 (k − 2g, t)도 그래프 위다. g < 0 ↔ h > k이므로 x > k에서 f(x) = f((k − x)/2) = 2(x − k)e^{(x−k)²}이고, [0, k]에서는 h가 오지 않으므로 f = 0이다.
3. **[L115]** ∫_0^7 f = ∫_k^7 2(x − k)e^{(x−k)²}dx = e^{(7−k)²} − 1 = e⁴ − 1 → k = 5 (k < 7).
4. f(9)/f(8) = 8e^{16}/(6e⁹) = (4/3)e⁷.

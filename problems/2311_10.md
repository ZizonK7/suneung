## 문제 요약
y = x³ + x², y = −x² + k와 y축으로 둘러싸인 넓이 A, 두 곡선과 x = 2로 둘러싸인 넓이 B. A = B일 때 k는? (4 < k < 5)

## 풀이
1. **[L078]** 교점 x = α (0 < α < 2). A = ∫_0^α {(−x² + k) − (x³ + x²)}dx, B = ∫_α^2 {(x³ + x²) − (−x² + k)}dx.
2. A = B → A − B = ∫_0^2 (−x³ − 2x² + k)dx = 0. 교점 α를 구할 필요가 없다.
3. −4 − 16/3 + 2k = 0 → k = 14/3.

## 문제 요약
원점에서 출발한 P, Q의 속도 v₁ = t² − 6t + 5, v₂ = 2t − 7. 거리 f(t)가 [0, a] 증가, [a, b] 감소, [b, ∞) 증가. t = a부터 b까지 Q가 움직인 거리는?

## 풀이
1. **[L067]** 위치는 속도의 정적분: x_P = t³/3 − 3t² + 5t, x_Q = t² − 7t.
2. **[L096]** x_P − x_Q = t³/3 − 4t² + 12t = (t/3)(t − 6)² ≥ 0 → f(t) = x_P − x_Q. f′ = v₁ − v₂ = (t − 2)(t − 6) → a = 2, b = 6.
3. **[L067]** Q가 움직인 거리 = ∫_2^6 |2t − 7|dt, t = 7/2에서 나눔: 9/4 + 25/4 = 17/2.

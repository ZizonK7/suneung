## 문제 요약
최고차항의 계수가 1인 삼차함수 f에 대하여 g(x) = f(x − 3) × lim_{h→0+} {|f(x + h)| − |f(x − h)|}/h. (가) g는 실수 전체에서 연속. (나) g(x) = 0은 서로 다른 네 실근 α₁, α₂, α₃, α₄를 갖고 α₁ + α₂ + α₃ + α₄ = 7. f(5)는?

## 풀이
1. **[L132]** 극한 D(x) = lim {|f(x + h)| − |f(x)|}/h + lim {|f(x)| − |f(x − h)|}/h는 |f|의 우미분계수와 좌미분계수의 합이다. f(x) ≠ 0이면 D = 2·(|f|)′. 단순근 c에서는 우·좌미분계수가 |f′(c)|, −|f′(c)|라 D(c) = 0이고, c 양쪽에서 D는 −2|f′(c)|에서 2|f′(c)|로 뛴다. 중근·삼중근에서는 D가 연속이고 0이다.
2. **[L091]** D가 끊기는 점은 f의 단순근뿐이다. 곱 g가 연속이려면 그 점에서 다른 인수 f(x − 3)이 0이어야 한다. 곧 f의 단순근 c마다 c − 3도 f의 근이다.
3. 단순근이 셋이면 가장 작은 근 r₁에서 r₁ − 3도 근이 되어 모순. 단순근 하나와 허근 둘이어도 모순. 삼중근 f = (x − a)³이면 g의 근은 a, a + 3 두 개뿐이라 (나)에 맞지 않는다. 따라서 f = (x − a)²(x − a − 3)(단순근 a + 3, a + 3 − 3 = a는 근).
4. g의 근: f(x − 3) = 0에서 a + 3, a + 6. D = 0에서 f의 근 a, a + 3과 f′ = 3(x − a)(x − a − 2)의 근 a + 2. 모으면 {a, a + 2, a + 3, a + 6}, 네 개. 합 4a + 11 = 7 → a = −1.
5. f = (x + 1)²(x − 2), f(5) = 36 × 3 = 108. 수치로 g의 연속성과 근 {−1, 1, 2, 5}를 확인했다.

## 문제 요약
닫힌구간 [0, 2π]에서 정의된 f(x) = a·cos bx + 3이 x = π/3에서 최댓값 13을 갖도록 하는 두 자연수 a, b의 순서쌍 (a, b)에 대하여 a + b의 최솟값은?

## 풀이
1. **[N6A1]** a > 0이고 x = 0에서 cos 0 = 1이므로 [0, 2π]에서 f의 최댓값은 a + 3이다. a + 3 = 13 → a = 10.
2. 최댓값을 x = π/3에서 가지려면 cos(bπ/3) = 1 → bπ/3 = 2kπ → b = 6k(k는 자연수).
3. b의 최솟값 6 → a + b = 16.

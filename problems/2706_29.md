## 문제 요약
모든 항이 정수인 등차수열 {a_n}과 모든 항이 양수인 등비수열 {b_n}이 (가) a₁ = b₁, a₄ = b₂, (나) 어떤 자연수 k에 대해 a_k = b₃을 만족한다. Σ_{n=1}^∞ b_n이 수렴할 때 |Σ_{n=1}^∞ b_n cos(a_nπ)|의 최솟값을 m이라 하면 10m은?

## 풀이
1. b_n = b·rⁿ⁻¹(b > 0). 양수항 등비급수가 수렴하므로 0 < r < 1.
2. **[L072]** a₄ − a₁ = 3d = b(r − 1), a_k − a₁ = (k − 1)d = b(r² − 1). 나누면 (k − 1)/3 = r + 1 → r = (k − 4)/3. 0 < r < 1이고 k가 자연수이므로 k = 5(r = 1/3) 또는 k = 6(r = 2/3).
3. 정수 조건: r = 1/3이면 d = −2b/9, r = 2/3이면 d = −b/9. a₁ = b도 정수이므로 b = 9m(m 자연수), 각각 d = −2m, d = −m.
4. **[L159]** cos(a_nπ) = (−1)^{a_n}. 공차가 짝수면 모든 a_n의 홀짝이 같아 |합| = b/(1 − r), 공차가 홀수면 홀짝이 번갈아 |합| = b/(1 + r).
   - r = 1/3: d 항상 짝수 → 9m/(2/3) = 27m/2 ≥ 27/2.
   - r = 2/3: m 홀수면 9m/(5/3) = 27m/5, m 짝수면 27m. 최소는 m = 1에서 27/5.
5. m = 27/5 → 10m = 54.

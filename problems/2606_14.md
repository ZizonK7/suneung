## 문제 요약
AB = 2√7인 삼각형 ABC에서 P는 BC의 중점, Q는 BC를 5 : 1로 내분하는 점. AQ = 3√2, sin(∠QAP) : sin(∠APQ) = √2 : 3일 때 삼각형 ABC의 외접원의 넓이는?

## 풀이
1. **[L028]** 삼각형 APQ에서 사인의 비는 대변의 비: PQ : AQ = √2 : 3 → PQ = 2.
2. BP = BC/2, BQ = 5BC/6이므로 PQ = BC/3 → BC = 6, BQ = 5.
3. **[L071]** 삼각형 ABQ의 세 변 2√7, 5, 3√2로 cos B = (28 + 25 − 18)/(2·2√7·5) = √7/4, sin B = 3/4.
4. **[L071]** 삼각형 ABC에서 AC² = 28 + 36 − 2·2√7·6·(√7/4) = 22.
5. **[L028]** 2R = AC/sin B = 4√22/3 → R² = 88/9, 넓이 88π/9.

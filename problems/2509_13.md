## 문제 요약
f(x) = −x² − 2x + 6 (x < 0), −x² + 2x + 6 (x ≥ 0). y = f(x)가 x축과 만나는 두 점을 P, Q(P의 x좌표 음수), 상수 k(k > 4)에 대해 직선 x = k가 x축과 만나는 점을 R이라 한다. 곡선과 선분 PQ로 둘러싸인 넓이 A, 곡선과 직선 x = k 및 선분 QR로 둘러싸인 넓이 B. A = 2B일 때 k는?

## 풀이
1. **[L077]** f(−x) = f(x)이므로 두 식은 y축 대칭이다. Q = 1 + √7, P = −(1 + √7)이고 A = 2∫_0^Q f.
2. **[L121]** Q < x에서 f < 0이므로 B = −∫_Q^k f. A = 2B ⇔ 2∫_0^Q f = −2∫_Q^k f ⇔ ∫_0^k f = 0. Q의 무리수 값은 쓰지 않는다.
3. ∫_0^k (−x² + 2x + 6)dx = −k³/3 + k² + 6k = 0 → k² − 3k − 18 = 0 → k = 6 (k > 4).

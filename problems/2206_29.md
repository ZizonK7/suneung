## 문제 요약
t > 2e에서 f(x) = t(ln x)² − x²이 x = k에서 극대일 때 k = g(t). g(α) = e²일 때 α{g′(α)}² = q/p, p + q는?

## 풀이
1. **[L060]** f′ = 2(t ln x − x²)/x = 0 → t ln k = k², 즉 t = k²/ln k. (t ln x − x²는 증가 후 감소하므로 큰 근이 극대점.)
2. **[L082]** g는 T(k) = k²/ln k의 역함수. g(α) = e² ⇔ α = T(e²) = e⁴/2. 이때 e²에서 t ln x − x²의 기울기 e²/2 − 2e² < 0이라 큰 근(극대) ✓.
3. T′(k) = (2k ln k − k)/(ln k)² → T′(e²) = 3e²/4 → g′(α) = 4/(3e²).
4. α{g′(α)}² = (e⁴/2)(16/(9e⁴)) = 8/9 → 17.

## 문제 요약
두 곡선 y = 16^x, y = 2^x와 점 A(64, 2⁶⁴). A를 지나 x축에 평행한 직선이 y = 16^x와 만나는 점 P₁, P₁을 지나 y축에 평행한 직선이 y = 2^x와 만나는 점 Q₁. Q₁에서 같은 과정으로 P₂, Q₂를 얻고 이를 반복해 n번째에 얻은 두 점 Pₙ, Qₙ에서 Qₙ의 x좌표를 xₙ이라 한다. xₙ < 1/k를 만족하는 n의 최솟값이 6이 되도록 하는 자연수 k의 개수는?

## 풀이
1. **[L063]** 16^x = 2^{4x}로 밑을 2로 통일한다.
2. **[N5D2]** 한 번의 계단 이동을 식으로 쓴다. x좌표 s인 점(y = 2^s)에서 수평 이동하면 y = 16^x 위에서 x = s/4, 수직 이동하면 Q의 x좌표도 s/4. 따라서 x₁ = 64/4 = 16, xₙ₊₁ = xₙ/4, xₙ = 64·(1/4)ⁿ: 16, 4, 1, 1/4, 1/16, 1/64, ….
3. **[N5D3]** xₙ은 감소하므로 조건을 처음 만족하는 n이 6이려면 x₆ < 1/k ≤ x₅, 곧 1/64 < 1/k ≤ 1/16 → 16 ≤ k < 64.
4. k의 개수는 48.

## 문제 요약
수직선 위를 움직이는 두 점 P, Q의 시각 t(t ≥ 0)에서의 위치가 x₁ = t² + t − 6, x₂ = −t³ + 7t². 두 점의 위치가 같아지는 순간 P, Q의 가속도를 각각 p, q라 할 때 p − q는?

## 풀이
1. **[L096]** 상대위치 x₁ − x₂ = t³ − 6t² + t − 6 = (t − 6)(t² + 1). t ≥ 0에서 0이 되는 시각은 t = 6뿐이다.
2. 가속도: x₁″ = 2, x₂″ = −6t + 14. t = 6에서 p = 2, q = −22.
3. p − q = 24.

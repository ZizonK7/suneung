## 문제 요약
실수 전체에서 연속인 f가 모든 실수 x에 대해 {f(x)}³ − {f(x)}² − x²f(x) + x² = 0을 만족한다. f의 최댓값이 1, 최솟값이 0일 때 f(−4/3) + f(0) + f(1/2)는?

## 풀이
1. **[N7D1]** f에 대한 식으로 보고 인수분해: f²(f − 1) − x²(f − 1) = (f − 1)(f − x)(f + x) = 0. 각 x에서 f(x)는 1, x, −x 중 하나다.
2. **[L022]** f가 연속이므로 한 가지에서 다른 가지로는 두 가지가 만나는 점(x = 0, x = ±1)에서만 옮겨 갈 수 있다.
3. 최솟값 0: f(x) = 0이 되는 것은 x = 0에서 f = x 또는 −x를 고를 때뿐이므로 f(0) = 0. 최댓값 1이므로 f ≤ 1이고 f ≥ 0이다.
4. 0 ≤ f ≤ 1과 연속성에서 |x| ≤ 1이면 f = |x|, |x| ≥ 1이면 f = 1. 즉 f = min(|x|, 1).
5. f(−4/3) + f(0) + f(1/2) = 1 + 0 + 1/2 = 3/2.

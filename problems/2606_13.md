## 문제 요약
f(x) = 3x² − 7x + 2와 직선 y = x/3 − 2/3. 곡선 y = f(x), 직선, y축으로 둘러싸인 영역 A, 곡선과 직선으로 둘러싸인 영역 B, 곡선과 직선 및 x = k(k > 2)로 둘러싸인 영역 C에 대해 (A의 넓이) + (C의 넓이) = (B의 넓이)일 때 k는?

## 풀이
1. f(x) − (x/3 − 2/3) = 3x² − (22/3)x + 8/3 = (1/3)(9x − 4)(x − 2). 교점 x = 4/9, 2. 차는 [0, 4/9]와 [2, k]에서 양(A, C), [4/9, 2]에서 음(B).
2. **[L121]** A + C = B는 부호 있는 정적분 ∫_0^k {f(x) − (x/3 − 2/3)}dx = 0과 같다. 0부터 적분하므로 상수항이 없다.
3. k³ − (11/3)k² + (8/3)k = 0 → k(3k − 8)(k − 1) = 0. k > 2이므로 k = 8/3.

## 문제 요약
a > 0, b, 실수 전체에서 연속인 f. (가) {f(x)}² + 2f(x) = a cos³πx·e^{sin²πx} + b, (나) f(0) = f(2) + 1. a × b는?
(사용자가 D007 피드백에서 L019의 출처로 짚은 문항이라 랜덤 추출 없이 정리했다.)

## 풀이
1. G(x) = a cos³πx·e^{sin²πx} + b + 1이라 하면 {f(x) + 1}² = G(x) ≥ 0이다. G는 주기 2이므로 G(0) = G(2).
2. (나)에서 f(0) + 1 = f(2) + 2이다. 두 값의 제곱이 같고 값은 다르므로 f(0) + 1 = 1/2, f(2) + 1 = −1/2 → G(0) = a + b + 1 = 1/4.
3. **[L022]** f + 1은 연속이고 0과 2 사이에서 부호가 바뀌므로 0을 지난다. 그 점에서 G = 0이다.
4. **[L019]** G ≥ 0이고 G = 0인 점이 있으므로 G의 최솟값은 0이다.
   c = cos πx라 하면 c³e^{1 − c²}의 도함수는 c²(3 − 2c²)e^{1 − c²} ≥ 0이라 [−1, 1]에서 증가한다. 최솟값은 c = −1에서 −a다.
   → −a + b + 1 = 0.
5. a + b = −3/4, b − a = −1 → a = 1/8, b = −7/8. a × b = −7/64.

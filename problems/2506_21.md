## 문제 요약
최고차항 계수 1인 사차함수 f. (가) f′(a) ≤ 0인 실수 a의 최댓값은 2. (나) {x | f(x) = k}의 원소가 3개 이상인 k의 최솟값은 8/3. f(0) = 0, f′(1) = 0일 때 f(3)은?

## 풀이
1. **[L089]** (가)에서 f′(2) = 0이고 x > 2에서 f′ > 0. f′(1) = 0과 함께 f′ = 4(x − 1)(x − 2)(x − c), c ≤ 2.
2. **[L055]** c = 1 또는 c = 2이면 중근에서 f′의 부호가 안 바뀌어 극소가 하나뿐 → 수평선과 교점이 2개 이하. 버린다. 그러므로 극소 둘, 극대 하나인 W 모양.
3. **[L064]** 교점이 3개 이상인 k의 최솟값 = 두 극솟값 중 큰 값 = 8/3.
4. f(x) = ∫₀ˣ f′ 으로 f(1) = 1 − 10c/3, f(2) = −8c/3, f(c) = −c⁴/3 + 2c³ − 4c².
   - 1 < c < 2: 극소는 x = 1, 2. f(1) = 8/3 또는 f(2) = 8/3이면 c = −1/2, −1로 범위 밖.
   - c < 1: 극소는 x = c, 2. f(c) = 8/3은 c⁴ − 6c³ + 12c² + 8 = 0이라 실근 없음. f(2) = 8/3 → c = −1, 이때 f(−1) = −19/3 < 8/3 ✓.
5. f = x⁴ − (8/3)x³ − 2x² + 8x, f(3) = 81 − 72 − 18 + 24 = 15.

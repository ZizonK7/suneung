## 문제 요약
∠A > π/2인 삼각형 ABC, A에서 BC에 내린 수선의 발 H. AB : AC = √2 : 1, AH = 2, 외접원 넓이 50π일 때 BH는?

## 풀이
1. 외접원 넓이 50π → R = 5√2.
2. **[L028]** AC = 2R·sin B이고, 직각삼각형 ABH에서 sin B = AH/AB = 2/AB. → AB·AC = 2R·2 = 20√2.
3. AB = √2·AC → √2·AC² = 20√2 → AC² = 20, AB² = 40.
4. BH = √(AB² − AH²) = √36 = 6.

## 문제 요약
최고차항 계수 1인 삼차 f가 모든 정수 k에 대해 2k − 8 ≤ {f(k + 2) − f(k)}/2 ≤ 4k² + 14k를 만족할 때 f′(3)은?

## 풀이
1. f(x) = x³ + ax² + bx + c이면 Q(k) = {f(k + 2) − f(k)}/2 = 3k² + (6 + 2a)k + (4 + 2a + b), 이차식.
2. **[NG4]** 위 경계 − 아래 경계 = 4k² + 12k + 8 = 4(k + 1)(k + 2). k = −1, −2에서 두 경계가 같으므로 Q(−1) = −10, Q(−2) = −12.
3. Q(k) = 3k² + pk + q에 대입 → p = 11, q = −2. 확인: Q − (2k − 8) = 3(k + 1)(k + 2) ≥ 0, (4k² + 14k) − Q = (k + 1)(k + 2) ≥ 0 (정수에서 성립).
4. 6 + 2a = 11 → a = 5/2, 4 + 2a + b = −2 → b = −11. f′(3) = 27 + 6a + b = 31.

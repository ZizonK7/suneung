## 문제 요약
실수 전체에서 미분가능한 f가 모든 실수 x에 대해 f(x) + f((1/2)sin x) = sin x를 만족할 때 f′(π)는?

## 풀이
1. **[L145]** 양변을 미분: f′(x) + f′((1/2)sin x)·(1/2)cos x = cos x.
2. x = π를 넣으면 속값 (1/2)sin π = 0이라 f′(π) − (1/2)f′(0) = −1. f′(0)이 필요하다.
3. x = 0은 속값이 자기 자신(0)인 점: f′(0) + (1/2)f′(0) = 1 → f′(0) = 2/3.
4. f′(π) = −1 + 1/3 = −2/3.

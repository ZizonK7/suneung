## 문제 요약
x = −ln4에서 x = 1까지 곡선 y = ½(|e^x − 1| − e^{|x|} + 1)의 길이는?

## 풀이
1. x ≥ 0이면 y = 0 → 길이 1.
2. x < 0이면 y = 1 − (e^x + e^{−x})/2, 1 + y′² = {(e^x + e^{−x})/2}². [L075]
3. ∫_{−ln4}^{0} (e^x + e^{−x})/2 dx = (4 − 1/4)/2 = 15/8. 합 23/8.

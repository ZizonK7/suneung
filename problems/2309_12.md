## 문제 요약
y = x + t와 y = x²의 교점 A(x > 0), B. A를 지나는 수평선과 포물선의 다른 교점 C, B에서 AC에 내린 수선의 발 H. lim_{t→0+} (AH − CH)/t는?

## 풀이
1. **[L073]** 교점을 α > 0, β라 하면 α + β = 1, αβ = −t. C(−α, α²), H(β, α²)이다.
2. CH = β + α = 1(상수), AH = α − β = √(1 + 4t).
3. **[L044]** (√(1 + 4t) − 1)/t → (√(1 + 4t))′ at t = 0 = 2. (유리화해도 4/(√(1 + 4t) + 1) → 2.)

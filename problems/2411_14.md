## 문제 요약
두 자연수 a, b에 대하여 f(x) = 2x³ − 6x + 1 (x ≤ 2), a(x − 2)(x − b) + 9 (x > 2). y = f(x)와 y = t의 교점 개수를 g(t)라 할 때, g(k) + lim_{t→k−} g(t) + lim_{t→k+} g(t) = 9를 만족시키는 실수 k의 개수가 1이 되도록 하는 순서쌍 (a, b)에 대하여 a + b의 최댓값은?

## 풀이
1. **[L032]** 조각별로 센다. x ≤ 2 조각: 극대 f(−1) = 5, 극소 f(1) = −3, f(2) = 5 → 개수 L(t)는 t < −3에서 1, t = −3에서 2, −3 < t < 5에서 3, t = 5에서 2, t > 5에서 0.
   x > 2 조각: x → 2+에서 9. b ≤ 2이면 증가해서 R(t) = 0 (t ≤ 9), 1 (t > 9). b > 2이면 꼭짓점 x = (b + 2)/2에서 최솟값 m = 9 − a(b − 2)²/4 → R(t) = 0 (t < m), 1 (t = m), 2 (m < t < 9), 1 (t ≥ 9).
2. **[L166]** g = L + R가 3인 열린 구간이 있으면 그 안의 모든 k가 조건(3 + 3 + 3 = 9)을 만족해 k가 무수히 많다. 그런 구간이 없어야 한다.
   - b ≤ 2: (−3, 5)에서 g = 3 → 불가.
   - b > 2, m > −3: (−3, min(m, 5))에서 g = 3 → 불가. m < −3: (m, −3)에서 g = 1 + 2 = 3 → 불가.
3. **[L014]** 남는 것은 꼭짓점 높이가 극솟값과 같은 m = −3뿐이다. 이때 g = 1 (t < −3), 3 (t = −3), 5 (−3 < t < 5), 4 (t = 5), 2 (5 < t < 9), 1 (t ≥ 9). 합이 9인 k는 −3(1 + 3 + 5)뿐이다(k = 5는 11, k = 9는 4).
4. a(b − 2)² = 48 → (b − 2, a) = (1, 48), (2, 12), (4, 3). a + b의 최댓값 48 + 3 = 51.

## 문제 요약
곡선 y = log₁₆(8x + 2) 위의 점 A(a, b), 곡선 y = 4^{x−1} − ½ 위의 제1사분면 점 B. A를 y = x에 대해 대칭이동한 점이 직선 OB 위에 있고 AB의 중점이 (77/8, 133/8)일 때 a × b = q/p, p + q는?

## 풀이
1. **[L077]** A′(b, a)는 곡선 x = log₁₆(8y + 2), 즉 y = (16^x − 2)/8 위에 있다. 이 곡선을 원점 기준 2배 하면 y/2 = (16^{x/2} − 2)/8 → y = 4^{x}/4 − ½ = 4^{x−1} − ½.
2. 그래서 직선 OB 위의 A′에 대해 B = 2A′ = (2b, 2a).
3. 중점: a + 2b = 77/4, b + 2a = 133/4 → a = 63/4, b = 7/4.
4. ab = 441/16 → 457.

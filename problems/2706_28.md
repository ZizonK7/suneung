## 문제 요약
y = t가 y = e^{2x} − e^{−x} + 1, y = e^{2x}와 만나는 점 P, Q. P를 지나는 수직선과 y = e^{2x}의 교점 y좌표 f(t), Q를 지나는 수직선과 y = e^{2x} − e^{−x} + 1의 교점 y좌표 g(t). lim_{t→1} (9f′(t) − 4g′(t))/(t − 1)은?

## 풀이
1. Q의 x좌표 q: e^{2q} = t → e^{−q} = t^{−1/2}. g(t) = t − t^{−1/2} + 1 → g′(1) = 3/2, g″(1) = −3/4.
2. **[L049]** P의 x좌표 p는 t로 직접 못 쓰므로 p를 거친다. e^{2p} − e^{−p} + 1 = t에서 f(t) = e^{2p} = t + e^{−p} − 1, f′ = 1 − e^{−p}·p′.
3. **[L082]** p(t)는 h(x) = e^{2x} − e^{−x} + 1의 역함수. t = 1 ↔ p = 0, p′(1) = 1/h′(0) = 1/3. → f′(1) = 2/3.
4. 9f′(1) − 4g′(1) = 6 − 6 = 0.
5. **[L044]** 극한 = 9f″(1) − 4g″(1). p″ = −h″(p)·p′³ → p″(1) = −3/27 = −1/9. f″ = e^{−p}p′² − e^{−p}p″ → f″(1) = 1/9 + 1/9 = 2/9.
6. 9·(2/9) − 4·(−3/4) = 2 + 3 = 5.

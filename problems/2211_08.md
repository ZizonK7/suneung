## 풀이
x² − 5x = x → x = 0, 6. 0 ≤ x ≤ 6에서 직선이 위에 있으므로 넓이는 ∫_0^6 (6x − x²)dx = 36. [L078]
∫_0^k (6x − x²)dx = 3k² − k³/3 = 18 → k³ − 9k² + 54 = 0 → (k − 3)(k² − 6k − 18) = 0, 0 < k < 6에서 k = 3. (6x − x²이 x = 3에 대해 대칭이라 바로 3으로 볼 수도 있다.)

## 문제 요약
실수 전체에서 미분가능한 f의 도함수가 f′(x) = −x + e^{1−x²}. 양수 t에 대하여 곡선 y = f(x) 위의 점 (t, f(t))에서의 접선과 곡선 y = f(x) 및 y축으로 둘러싸인 부분의 넓이를 g(t)라 할 때, g(1) + g′(1)은?

## 풀이
1. **[L100]** f″(x) = −1 − 2xe^{1−x²} < 0 (x > 0). f′가 [0, t]에서 감소하므로 f′(x) − f′(t) > 0 (x < t) → 0 ≤ x < t에서 접선이 곡선보다 위에 있다. 절댓값 없이 쓸 수 있다.
2. **[L128]** g(t) = ∫_0^t {f′(t)(x − t) + f(t) − f(x)}dx = −t²f′(t)/2 + tf(t) − ∫_0^t f(x)dx.
   미분하면 g′(t) = −t²f″(t)/2 − tf′(t) + f(t) + tf′(t) − f(t) = −t²f″(t)/2 → g′(1) = −f″(1)/2 = 3/2.
3. **[L111]** f(1) − ∫_0^1 f = ∫_0^1 xf′(x)dx = ∫_0^1 (−x² + xe^{1−x²})dx = −1/3 + (e − 1)/2. f′(1) = 0이므로 g(1) = e/2 − 5/6.
4. g(1) + g′(1) = e/2 − 5/6 + 3/2 = e/2 + 2/3.

## 문제 요약
삼차함수 f가 모든 x에서 xf(x) − f(x) = 3x⁴ − 3x를 만족할 때 ∫_{−2}^{2} f(x)dx는?

## 풀이
1. **[L125]** (x − 1)f(x) = 3x(x − 1)(x² + x + 1) → x ≠ 1에서 f(x) = 3x³ + 3x² + 3x, 다항식이므로 실수 전체에서 같다.
2. **[L103]** [−2, 2]에서 홀수차항의 적분은 0 → ∫_{−2}^{2} 3x² dx = 16.

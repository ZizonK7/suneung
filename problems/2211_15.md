## 문제 요약
두 점 O₁, O₂를 각각 중심으로 하고 반지름이 O₁O₂인 두 원 C₁, C₂. C₁ 위의 서로 다른 세 점 A, B, C와 C₂ 위의 점 D가 있고, A, O₁, O₂와 C, O₂, D가 각각 한 직선 위에 있다. ∠BO₁A = θ₁, ∠O₂O₁C = θ₂, ∠O₁O₂D = θ₃. AB : O₁D = 1 : 2√2, θ₃ = θ₁ + θ₂일 때 AB : CD를 구하는 과정(빈칸 채우기). 과정에서 ∠CO₁B = θ₁, 삼각형 O₁O₂B ≡ O₂O₁D, AB = k, BO₂ = O₁D = 2√2k를 얻고, AO₂ = (가), ∠BO₂A = θ₁/2에서 cos(θ₁/2) = (나), 삼각형 O₂BC에서 BC = k, BO₂ = 2√2k, ∠CO₂B = θ₁/2로 코사인법칙을 써 O₂C = (다), AB : CD = k : ((가)/2 + (다)). (가), (다)를 f(k), g(k), (나)를 p라 할 때 f(p)·g(p)는?

## 풀이
1. **[N4D2]** 반지름이 O₁O₂이므로 O₂는 C₁ 위에 있고, A, O₁, O₂가 한 직선 위에 있으니 AO₂는 C₁의 지름이다. 따라서 ∠ABO₂ = π/2.
2. 피타고라스: AO₂ = √(k² + 8k²) = 3k → (가) f(k) = 3k.
3. **[L114]** ∠BO₂A는 호 AB의 원주각, ∠BO₁A = θ₁은 중심각이므로 θ₁/2. 직각삼각형 ABO₂에서 cos(θ₁/2) = BO₂/AO₂ = 2√2/3 → (나) p = 2√2/3.
4. **[L071]** O₂C = x: k² = 8k² + x² − 2·2√2k·x·(2√2/3) → 3x² − 16kx + 21k² = 0 → x = 3k 또는 7k/3. C ≠ A이므로 지름보다 짧은 현 O₂C < 3k → (다) g(k) = 7k/3.
5. f(p)·g(p) = 3p·(7p/3) = 7p² = 56/9.

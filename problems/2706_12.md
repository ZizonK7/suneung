## 문제 요약
공비가 양수인 등비수열 {aₙ}이 2a₁(a₁ + a₃) = 5a₂(a₁ + a₂) = 20을 만족할 때 a₁ × a₆의 값은?

## 풀이
1. 공비 r > 0: a₁²(1 + r²) = 10, a₁²·r(1 + r) = 4.
2. **[L030]** 두 식을 나눠 a₁²을 지운다: (1 + r²)/{r(1 + r)} = 5/2 → 3r² + 5r − 2 = 0 → (3r − 1)(r + 2) = 0 → r = 1/3.
3. a₁² = 4/{(1/3)(4/3)} = 9. a₁ × a₆ = a₁²·r⁵ = 9/243 = 1/27.

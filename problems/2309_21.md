## 문제 요약
y = 2^x 위 P(a, 2^a), Q(b, 2^b) (0 < a < b), PQ 기울기 m. P를 지나는 기울기 −m 직선이 x축, y축과 A, B에서, Q를 지나는 기울기 −m 직선이 x축과 C에서 만남. AB = 4PB, CQ = 3AB일 때 90(a + b)는?

## 풀이
1. **[NA2]** B, P, A가 한 직선 위 → 길이 비 = x좌표 차의 비. B의 x = 0, P의 x = a → A의 x = 4a. P에서 A까지 가로 3a, 세로 2^a → m = 2^a/(3a).
2. **[NA2]** 두 직선이 평행 → CQ = 3AB이면 가로 거리도 3배: Q에서 C까지 가로 12a. 세로 2^b = m·12a = 4·2^a → b = a + 2.
3. PQ 기울기 m = (2^b − 2^a)/(b − a) = 3·2^a/2. 2^a/(3a) = 3·2^a/2 → a = 2/9, b = 20/9.
4. 90(a + b) = 90·22/9 = 220.

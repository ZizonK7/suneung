## 문제 요약
f(x) = (x − 1)(x − 2)와 최고차항 계수 1인 사차함수 g가 모든 실수 a에 대해 lim_{x→a} g(x)|f(x)|/f(x)와 lim_{x→a} |g(x) − f(x)|/g(x)의 값이 모두 존재한다. g(−1)은?

## 풀이
1. **[L091]** |f|/f는 단순근 1, 2의 양쪽에서 ±1로 뒤집힌다. 첫 극한이 존재하려면 g(1) = g(2) = 0. g = f·h, h는 최고차항 계수 1인 이차식.
2. **[L002]** g(a) = 0인데 f(a) ≠ 0이면 둘째 극한의 분자 → |f(a)| ≠ 0, 분모 → 0이라 발산. 따라서 g의 근은 1, 2뿐이다.
3. **[L116]** 공통 인수 f를 뽑으면 |g − f|/g = (|f|/f)·|h − 1|/h.
4. h(1) = 0이면 x → 1에서 |h − 1|/h가 발산하므로 h(1) ≠ 0(h(2)도 같다). 그러면 **[L091]** |f|/f가 뒤집히므로 |h(1) − 1|/h(1) = 0, 즉 h(1) = 1, h(2) = 1.
5. h − 1 = (x − 1)(x − 2) → h = x² − 3x + 3(판별식 < 0이라 다른 근이 없음, 2와 부합). g(−1) = (−2)(−3)(7) = 42.

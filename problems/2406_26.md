## 풀이
1. **[L064]** f(x) = x² − 5x + 2ln x (x > 0)와 수평선 y = t의 교점으로 센다. f′ = (2x − 1)(x − 2)/x → x = 1/2에서 극대 −9/4 − 2ln2, x = 2에서 극소 −6 + 2ln2. x → 0⁺에서 −∞, x → ∞에서 ∞.
2. **[L014]** 교점이 2개인 것은 수평선이 극댓값이나 극솟값 높이에 닿을 때뿐이다. 합 (−9/4 − 2ln2) + (−6 + 2ln2) = −33/4.

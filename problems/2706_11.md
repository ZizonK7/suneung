## 문제 요약
일차함수 f, lim_{x→a} f(x + 2)/{x(f(x) − 3)}가 a = 0에서 존재, a = 3에서 존재하지 않는다. f(4)는?

## 풀이
1. a = 3에서 존재하지 않으려면 분모 → 0, 분자 ≠ 0: f(3) = 3.
2. **[L002]** a = 0에서 분모 → 0이므로 분자 → 0: f(2) = 0 (f(0) = 3이면 f가 상수가 되어 일차함수가 아님).
3. f(x) = 3x − 6 → f(4) = 6.

## 문제 요약
양수 a에 대하여 x ≥ −1에서 f(x) = −x² + 6x (−1 ≤ x < 6), a·log₄(x − 5) (x ≥ 6). t ≥ 0에 대하여 닫힌구간 [t − 1, t + 1]에서 f의 최댓값을 g(t)라 할 때, [0, ∞)에서 g의 최솟값이 5가 되도록 하는 a의 최솟값은?

## 풀이
1. f는 [−1, 3]에서 증가(최댓값 f(3) = 9), [3, 6)에서 감소해 0으로 가고, x ≥ 6에서 a·log₄(x − 5)는 0부터 증가한다.
2. **[N5D1]** 구간 [t − 1, t + 1]이 꼭짓점 x = 3을 품는지로 나눈다. 2 ≤ t ≤ 4이면 g(t) = 9.
3. **[L123]** 0 ≤ t < 2이면 구간 전체가 증가 구간이라 g(t) = f(t + 1), 최솟값은 g(0) = f(1) = 5. 4 < t ≤ 5이면 구간 전체가 감소 구간(t + 1 ≤ 6)이라 g(t) = f(t − 1) ≥ f(4) = 8.
4. **[L130]** t ≥ 5이면 g(t) = max{f(t − 1), a·log₄(t − 4)}로 감소하는 식과 증가하는 식의 큰 쪽이다. 최솟값은 두 식의 교점 높이다. f(t − 1) = 5가 되는 t = 6에서 a·log₄2 = a/2 ≥ 5이면 교점 높이가 5 이상이다.
5. 따라서 a ≥ 10, a의 최솟값은 10. 수치로 a = 9.9에서 최솟값 4.975, a = 10에서 5임을 확인.

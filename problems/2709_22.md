## 문제 요약
a > 1, 직사각형 ABCD. (가) y = a^x, y = 2x² − (7/2)x + 3이 모두 A, B를 지난다. (나) y = log_a(x − 1/4) − 1/4, y = 2x² − (15/2)x + 15/2가 모두 C, D를 지난다. a³ = q/p일 때 p + q는?

## 풀이
(2709는 정답표가 없어 직접 풀고 네 점을 대입해 검산했다.)
1. **[L077]** 로그 곡선은 y = a^x를 y = x에 대해 대칭이동한 뒤 (1/4, −1/4)만큼 평행이동한 것이다. 둘째 포물선은 첫째 포물선을 (1, −1)만큼 평행이동한 것이다.
2. **[L007]** D = A + (1, −1), C = B + (1, −1)로 놓으면 C, D는 저절로 둘째 포물선 위에 있다. 이 점이 로그 곡선 위에도 있으려면, A를 대칭이동·평행이동한 점 (y_A + 1/4, x_A − 1/4)가 A + (1, −1)과 같아야 한다 → y_A = x_A + 3/4. B도 같다.
3. A, B는 직선 y = x + 3/4와 첫째 포물선의 교점: 8x² − 18x + 9 = 0 → x = 3/4, 3/2 → A(3/4, 3/2), B(3/2, 9/4). AB의 기울기 1, AD 방향 (1, −1)이라 직사각형이다.
4. a^{3/4} = 3/2 → a³ = 81/16 → 97.

## 문제 요약
최고차항 1인 삼차함수 f, k ≥ 0. g = 2x − k (x ≤ k), f(x) (x > k). (가) g는 증가하고 미분가능.
(나) 모든 x에 대해 ∫_0^x g{|t(t−1)| + t(t−1)}dt ≥ 0이고 ∫_3^x g{|(t−1)(t+2)| − (t−1)(t+2)}dt ≥ 0. g(k+1)의 최솟값은?

## 풀이
1. **[L038]** 첫 가중치는 t < 0 또는 t > 1에서만 2t(t−1) > 0, 둘째는 −2 < t < 1에서만 −2(t−1)(t+2) > 0.
2. **[L039]**
   - 첫 조건: t > 1에서 g ≥ 0, t < 0에서 g ≤ 0.
   - 둘째 조건(아래끝 3, 살아 있는 구간 (−2, 1)): 1 바로 왼쪽에서 g ≤ 0.
   - 증가·연속 → g(1) = 0.
3. k < 1이면 g(1) = f(1) = 0인데, f(k) = k ≥ 0이고 증가하므로 모순이다. 그래서 k ≥ 1이고, 2 − k = 0 → k = 2.
4. **[L040]** f(2) = 2, f′(2) = 2 → f = u³ + au² + 2u + 2 (u = x − 2).
5. **[L041]** u > 0에서 3u² + 2au + 2 ≥ 0 → a ≥ −√6. g(3) = f(3) = 5 + a ≥ 5 − √6.

## 문제 요약
닫힌구간 [0, 12]에서 f(x) = cos(πx/6), g(x) = −3cos(πx/6) − 1. 곡선 y = f(x)와 직선 y = k가 만나는 두 점의 x좌표 α₁, α₂에 대해 |α₁ − α₂| = 8이다. 곡선 y = g(x)와 y = k가 만나는 두 점의 x좌표 β₁, β₂에 대해 |β₁ − β₂|는? (−1 < k < 1)

## 풀이
1. **[L034]** [0, 12]는 cos(πx/6)의 한 주기이고 그래프는 x = 6에 대해 대칭이다. 수평선과의 두 교점은 α₁ + α₂ = 12, |α₁ − α₂| = 8 → α = 2, 10, k = cos(π/3) = 1/2.
2. g(x) = 1/2 ⇔ cos(πx/6) = −1/2 → πx/6 = 2π/3, 4π/3 → x = 4, 8(역시 x = 6 대칭).
3. |β₁ − β₂| = 4.

## 문제 요약
두 정수 α, β(α > β)에 대하여 모든 자연수 n에서 a_n = α·sin(nπ/2) + β·cos(nπ/2)이고 a₁a₂a₃a₄ = 4인 수열 {a_n}이 있다. {a_n}과 b₁ > 0인 등비수열 {b_n}에 대하여 Σa_{4n−2}b_n = Σa_{4n−3}b_{2n} = 6일 때 b₁b₃ = q/p, p + q는?

## 풀이
1. **[L059]** a₁ = α, a₂ = −β, a₃ = −α, a₄ = β이고 주기 4. a₁a₂a₃a₄ = α²β² = 4 → |αβ| = 2. a_{4n−2} = −β, a_{4n−3} = α로 일정하다.
2. **[L168]** b_n = b·rⁿ⁻¹(b > 0, |r| < 1). b_{2n}은 첫째항 br, 공비 r² → −βb/(1 − r) = 6, αbr/(1 − r²) = 6.
3. 1 − r > 0, b > 0이므로 β < 0. 두 식을 나누면 αr = −β(1 + r).
4. 후보 (α, β) = (1, −2), (2, −1), (−1, −2): 앞의 둘은 r = −2, r = 1로 수렴 조건에 어긋나고, (−1, −2)에서 −r = 2 + 2r → r = −2/3.
5. 2b/(5/3) = 6 → b = 5. b₁b₃ = b²r² = 100/9 → 109.

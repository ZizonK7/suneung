## 문제 요약
a_2 = −4, 공차 d ≠ 0인 등차수열 a_n, b_n = a_n + a_{n+1}. A = {a_1, …, a_5}, B = {b_1, …, b_5}. n(A ∩ B) = 3인 모든 수열에 대해 a_20의 합은?

## 풀이
1. **[L072]** a_2 기준으로 쓴다: a_n = −4 + (n − 2)d. b_n = 2a_n + d = −8 + (2n − 3)d.
2. A = {−4 + md | m = −1, …, 3}, B = {−8 + jd | j = −1, 1, 3, 5, 7}.
3. **[NG5]** −4 + md = −8 + jd ⇔ (j − m)d = 4. d가 하나로 정해지므로 공통 원소는 j − m = c (c = 4/d)가 같은 쌍만.
4. c별 쌍의 수: c = 2 → (−1,1), (1,3), (3,5) 3개. c = 4 → (−1,3), (1,5), (3,7) 3개. c = −2, 6은 2개, 홀수 c는 2개 이하.
5. d = 2 → a_20 = −4 + 36 = 32, d = 1 → a_20 = 14. 합 46.

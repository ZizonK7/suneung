## 문제 요약
양수 a에 대해 {x | −a/2 < x ≤ a, x ≠ a/2}에서 정의된 f(x) = tan(πx/a). 원점 O를 지나는 직선이 y = f(x)의 그래프와 A(제3사분면), B(제1사분면)에서 만난다. A를 지나고 x축에 평행한 직선이 그래프와 만나는 점 중 A가 아닌 점을 C라 하자(오른쪽 가지 위). 삼각형 ABC가 정삼각형일 때 넓이는?

## 풀이
1. **[L034]** 가운데 가지는 O에 대해 점대칭이므로 O를 지나는 직선과의 두 교점은 A(−p, −q), B(p, q). C는 A를 주기 a만큼 옮긴 점 C(a − p, −q), AC = a.
2. **[L126]** 정삼각형의 꼭짓점 B에서 밑변 AC에 내린 수선의 발은 AC의 중점 → p = (−p + a − p)/2 → a = 4p.
3. q = tan(πp/a) = tan(π/4) = 1. 높이 2q = 2 = (√3/2)a → a = 4/√3.
4. 넓이 = (√3/4)a² = (√3/4)(16/3) = 4√3/3.

## 문제 요약
연속함수 f가 n − 1 ≤ x < n에서 |f(x)| = |6(x − n + 1)(x − n)|. (0, 4)에서 g(x) = ∫_0^x f − ∫_x^4 f가 x = 2에서 최솟값 0을 가질 때 ∫_{1/2}^4 f(x)dx는?

## 풀이
1. **[NB2]** f는 연속이고 정수 사이에서 0이 아니므로 구간 [k − 1, k]마다 f = ±6(x − k + 1)(x − k)로 부호가 하나다. 각 구간의 적분은 ±1(아래로 볼록이면 −1). 구간 k의 적분을 s_k = ±1로 둔다.
2. **[L069]** g(x) = 2∫_0^x f − ∫_0^4 f, g′(x) = 2f(x).
3. **[L053]** x = 2에서 최소 → f가 2에서 −에서 +로 바뀐다: s_2 = −1, s_3 = +1.
4. g(2) = 0: s_1 + s_2 = s_3 + s_4 → s_1 − s_4 = 2 → s_1 = 1, s_4 = −1. 이때 ∫_0^x f는 0 → 1 → 0 → 1 → 0으로 움직여 g ≥ 0 ✓.
5. ∫_0^4 f = 0, ∫_0^{1/2} f = 1/2(구간 1의 절반, 대칭) → ∫_{1/2}^4 f = −1/2.

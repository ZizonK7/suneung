## 문제 요약
a_{n+1} = 1/a_n (n 홀수), 8a_n (n 짝수), a_12 = 1/2일 때 a_1 + a_4는?

## 풀이
a_2 = 1/a_1, a_3 = 8/a_1, a_4 = a_1/8, a_5 = a_1 → 주기 4. a_12 = a_4 = a_1/8 = 1/2 → a_1 = 4. 합 9/2. [L018]
(역추적 a_12 → a_11 = 2 → a_10 = 1/4 → a_9 = 4 → a_8 = 1/2로도 주기가 보인다.)

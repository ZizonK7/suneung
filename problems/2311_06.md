## 문제 요약
f(x) = 2x³ − 9x² + ax + 5가 x = 1에서 극대, x = b에서 극소일 때 a + b는?

## 풀이
f′(x) = 6x² − 18x + a, f′(1) = 0 → a = 12. f′(x) = 6(x − 1)(x − 2)이므로 x = 1에서 + → −(극대), x = 2에서 − → +(극소) → b = 2. a + b = 14. [L060]

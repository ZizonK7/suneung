## 문제 요약
A₁B₁ = 4, A₁D₁ = 1인 직사각형 A₁B₁C₁D₁의 두 대각선의 교점을 E₁이라 한다. A₂D₁ = D₁E₁, ∠A₂D₁E₁ = π/2이고 선분 D₁C₁과 선분 A₂E₁이 만나도록 A₂를, B₂C₁ = C₁E₁, ∠B₂C₁E₁ = π/2이고 선분 D₁C₁과 선분 B₂E₁이 만나도록 B₂를 잡아 두 삼각형 A₂D₁E₁, B₂C₁E₁을 색칠한 그림이 R₁. R₁에서 A₂B₂ : A₂D₂ = 4 : 1이고 선분 D₂C₂가 두 선분 A₂E₁, B₂E₁과 만나지 않도록 직사각형 A₂B₂C₂D₂를 그리고 같은 방법으로 색칠한 그림이 R₂. 이를 반복한 Rₙ의 색칠 넓이 Sₙ에 대해 lim Sₙ은?

## 풀이
1. A₁ = (0, 0), D₁ = (0, 1), E₁ = (2, 1/2). D₁E₁ = (2, −1/2)을 90° 돌리면 A₂ = D₁ + (1/2, 2) = (1/2, 3), 대칭으로 B₂ = (7/2, 3).
2. 두 직각이등변삼각형의 넓이는 각각 ½·D₁E₁² = 17/8 → S₁ = 17/4.
3. **[L047]** A₂B₂ = 3이 다음 직사각형의 가로이므로 닮음비 3/4, 넓이 공비 9/16.
4. lim Sₙ = (17/4)/(1 − 9/16) = 68/7.

## 문제 요약
0, 1, 2가 적힌 공 3개에서 복원추출 5번, 평균 X̄. Σ_{k=1}^{10} k²·P(X̄ = k/5) = a, 6a는?

## 풀이
1. X̄ = S/5 → P(X̄ = k/5) = P(S = k). [L011]
2. Σ_{k=1}^{10} k² P(S=k) = E(S²) (k=0 항은 0). [L010]
3. 한 번: 평균 1, 분산 5/3 − 1 = 2/3. S: 평균 5, 분산 10/3.
4. E(S²) = 10/3 + 25 = 85/3 → 6a = 170. [L012]

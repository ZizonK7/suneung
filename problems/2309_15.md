## 문제 요약
수열 {a_n}이 (가) 모든 자연수 k에 대해 a_{4k} = r^k (0 < |r| < 1인 상수), (나) a₁ < 0이고 a_{n+1} = a_n + 3 (|a_n| < 5), −a_n/2 (|a_n| ≥ 5)를 만족한다. |a_m| ≥ 5인 100 이하의 자연수 m의 개수를 p라 할 때 p + a₁은?

## 풀이
1. **[L018]** a₄ = r에서 네 항 돌린다. |r| < 1 → a₅ = r + 3 ∈ (2, 4) → a₆ = r + 6 ≥ 5 → a₇ = −(r + 6)/2 ∈ (−7/2, −5/2) → a₈ = −r/2.
2. a₈ = r²이므로 r² = −r/2 → r = −1/2. 그러면 a₈ = 1/4 = r²이고, 같은 과정이 a_{4k} = r^k마다 되풀이되어 (가)가 모든 k에서 성립한다(|r^k| < 1이라 갈래가 같다).
3. **[L107]** a₄ = −1/2에서 거꾸로 올라가며 직전 항 후보를 적고 갈래의 범위 조건으로 거른다.
   - a₃: a₃ + 3 = −1/2 → a₃ = −7/2 (|a₃| < 5 ✓), −a₃/2 = −1/2 → a₃ = 1 (|a₃| ≥ 5 ✗). a₃ = −7/2.
   - a₂: a₂ + 3 = −7/2 → −13/2 (✗), −a₂/2 = −7/2 → a₂ = 7 (✓).
   - a₁: a₁ + 3 = 7 → 4 (a₁ < 0 ✗), −a₁/2 = 7 → a₁ = −14 (✓).
4. |a_m| ≥ 5인 m: 1, 2와 m = 4k + 2 (k = 1, …, 24, 6 ~ 98). p = 26.
5. p + a₁ = 26 − 14 = 12. 분수 계산으로 a₁ ~ a₁₀₀을 전개해 확인.

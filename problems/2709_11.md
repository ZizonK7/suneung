## 문제 요약
다항함수 f가 모든 x에서 ∫_{−1}^{x} f(t)dt = xf(x) − 2x³ − 3x² + 6을 만족할 때 f(0)은?

## 풀이
1. **[L069]** 양변 미분: f = f + xf′ − 6x² − 6x → f′ = 6x + 6 → f = 3x² + 6x + C.
2. **[L026]** x = −1을 넣으면 0 = −f(−1) + 5 → f(−1) = 5 → C − 3 = 5, C = 8.
3. f(0) = 8. (sympy로 원식 대입 확인)

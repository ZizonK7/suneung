## 문제 요약
AB = 3, BC = √13, AD × CD = 9, ∠BAC = π/3인 사각형 ABCD. S₂ = (5/6)S₁일 때 R/sin(∠ADC)는? (R은 삼각형 ACD의 외접원의 반지름)

## 풀이
1. **[L071]** 13 = 9 + AC² − 3AC → AC = 4.
2. S₁ = ½·3·4·sin(π/3) = 3√3 → S₂ = 5√3/2.
3. **[L070]** S₂ = ½·(AD × CD)·sin D = (9/2)sin D → sin D = 5√3/9.
4. **[L028]** AC = 2R·sin D → R = 4/(2 sin D) = 18/(5√3).
5. R/sin D = (18/(5√3))·(9/(5√3)) = 162/75 = 54/25.

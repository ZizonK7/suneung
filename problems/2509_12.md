## 문제 요약
{a_n}은 등차수열, b_n = Σ_{k=1}^{n} (−1)^{k+1} a_k. b₂ = −2, b₃ + b₇ = 0일 때 b₁ + … + b₉는?

## 풀이
1. **[L072]** 공차를 d라 하면 a_{2m−1} − a_{2m} = −d. 두 항씩 묶는다.
   - b_{2m} = −md, b_{2m+1} = −md + a_{2m+1} = a₁ + md.
2. b₂ = −d = −2 → d = 2.
3. b₃ + b₇ = (a₁ + d) + (a₁ + 3d) = 2a₁ + 8 = 0 → a₁ = −4.
4. 홀수 번째: b₁, b₃, …, b₉ = −4, −2, 0, 2, 4 → 합 0. 짝수 번째: b₂, …, b₈ = −2, −4, −6, −8 → 합 −20.
5. 합 = −20.

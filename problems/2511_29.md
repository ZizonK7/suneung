## 문제 요약
등비수열 {a_n}이 Σ_{n=1}^∞ (|a_n| + a_n) = 40/3, Σ_{n=1}^∞ (|a_n| − a_n) = 20/3을 만족한다. lim_{n→∞} Σ_{k=1}^{2n} (−1)^{k(k+1)/2}·a_{m+k} > 1/700을 만족하는 모든 자연수 m의 값의 합은?

## 풀이
1. **[L038]** |a| + a는 양수 항만, |a| − a는 음수 항만 남긴다. 양수 항의 합 20/3, 음수 항의 합 −10/3. 둘 다 있으므로 공비 r < 0이고, 합이 양수 쪽이 커서 a₁ > 0.
2. **[L134]** r < 0이면 홀수항(양수)과 짝수항(음수)은 각각 공비 r²인 등비급수이고, 짝수항 합/홀수항 합 = r. r = (−10/3)/(20/3) = −1/2, a₁/(1 − 1/4) = 20/3 → a₁ = 5. a_n = 5(−1/2)^{n−1}.
3. **[L136]** (−1)^{k(k+1)/2}는 k = 1, 2, 3, 4에서 −, −, +, +로 주기 4. 한 주기를 묶으면 공비 r⁴인 등비급수이므로 Σ s_k r^{k−1} = (−1 − r + r² + r³)/(1 − r⁴) = (−3/8)/(15/16) = −2/5.
4. 극한값 = −(2/5)a_{m+1} = −2(−1/2)^m. 양수이려면 m 홀수, 2/2^m > 1/700 → 2^m < 1400 → m ≤ 10. m = 1, 3, 5, 7, 9, 합 25.

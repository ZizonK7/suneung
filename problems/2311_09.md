## 문제 요약
f(x) = a − √3 tan 2x가 [−π/6, b]에서 최댓값 7, 최솟값 3일 때 a × b는?

## 풀이
1. tan 2x는 −π/4 < x < π/4에서 증가 → f는 감소. 최솟값이 존재하므로 b < π/4.
2. 감소함수이므로 최댓값은 왼쪽 끝, 최솟값은 오른쪽 끝. f(−π/6) = a + √3·√3 = a + 3 = 7 → a = 4.
3. f(b) = 4 − √3 tan 2b = 3 → tan 2b = 1/√3 → b = π/12.
4. a × b = π/3.

## 문제 요약
상수항이 0인 삼차함수 f. (가) ∫_p^{p+3}|f(x)|dx ≠ |∫_p^{p+3}f(x)dx|가 되도록 하는 모든 실수 p의 값의 범위는 0 < p < 3. (나) ∫_0^3|f(x) + q|dx ≠ |∫_0^3{f(x) + q}dx|가 되도록 하는 모든 실수 q의 값의 범위는 0 < q < 1. f(6)은? (① 18 ② 21 ③ 24 ④ 27 ⑤ 30)

## 풀이
1. **[N3D5]** ∫|F| ≠ |∫F| ⇔ 구간 안에서 F의 부호가 바뀐다(부호가 일정하면 등호).
2. (가) 길이 3인 구간 (p, p + 3)이 부호가 바뀌는 점을 품는 p가 정확히 (0, 3)이다. 부호가 바뀌는 점 c마다 (c − 3, c)가 p의 범위에 들어가므로 그런 점은 x = 3 하나뿐이다. f(0) = 0인데 0에서는 부호가 바뀌지 않으므로 0은 중근. f = cx²(x − 3).
3. **[L064]** (나) f + q가 (0, 3)에서 부호를 바꾸려면 수평선 y = −q가 [0, 3]의 그래프를 뚫고 지나야 한다. f(0) = f(3) = 0, 극값 f(2) = −4c. c > 0이면 범위는 −4c < −q < 0, 곧 0 < q < 4c(q = 4c는 접하기만 한다). c < 0이면 q < 0이 되어 맞지 않는다. 4c = 1 → c = 1/4.
4. f(6) = (1/4) × 36 × 3 = 27 → ④. 수치 적분으로 (가)의 p 범위를 확인했다.

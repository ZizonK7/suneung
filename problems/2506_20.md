## 문제 요약
5 이하의 자연수 a, b. (0, 2π)에서 y = a sin x + b의 그래프가 x = π, y = 1, y = 3과 만나는 점의 집합 A, B, C. n(A ∪ B ∪ C) = 3인 (a, b)에 대해 a + b의 최댓값 M, 최솟값 m. M × m은?

## 풀이
1. A = {(π, b)} 한 점.
2. **[L064]** 수평선 y = c와의 교점 수(열린구간 (0, 2π)): c = b ± a(최댓값·최솟값)이면 1개, c = b이면 x = π 하나뿐(끝점 0, 2π 제외)으로 1개, b − a < c < b + a이고 c ≠ b이면 2개, 범위 밖이면 0개.
3. **[NH1]** c = b이면 그 교점이 바로 A와 같은 점이다. 그래서 b = 1, b = 3인 경우를 따로 나눈다.
   - b = 1: B = A. C가 2개여야 → 1 + a > 3 → a ≥ 3. a + b ∈ {4, 5, 6}.
   - b = 3: C = A. B가 2개여야 → 3 − a < 1 → a ≥ 3. a + b ∈ {6, 7, 8}.
   - b = 2: B, C가 각각 1개(a = 1)일 때만 3개 → a + b = 3.
   - b = 4: a = 2(B 0개, C 2개) → 6. b = 5: a = 3(B 0개, C 2개) → 8.
4. M = 8, m = 3 → M × m = 24.

## 문제 요약
a > 1, 곡선 y = a^x − 2 위 제1사분면의 점 A를 지나는 y축 평행선이 x축과 만나는 점 B, 점근선 y = −2와 만나는 점 C. AB = BC이고 삼각형 AOC 넓이 8일 때 a × OB는?

## 풀이
1. A의 x좌표 p. B = (p, 0), C = (p, −2). AB = a^p − 2 = BC = 2 → a^p = 4.
2. **[L008]** AC는 세로 선분(길이 4)이고 O에서 직선 x = p까지 거리 p → 넓이 = ½·4·p = 8 → p = 4.
3. **[L063]** a⁴ = 4 = 2² → a = 2^{1/2}. a × OB = 2^{1/2}·2² = 2^{5/2}.

## 문제 요약
−1 ≤ t ≤ 1. (sin(πx/2) − t)(cos(πx/2) − t) = 0의 근 중 0 ≤ x < 4에서 최솟값 α(t), 최댓값 β(t). ㄱ. t < 0이면 α + β = 5. ㄴ. β(t) − α(t) = β(0) − α(0)인 t의 집합은 [0, √2/2]. ㄷ. α(t₁) = α(t₂), t₂ − t₁ = 1/2이면 t₁t₂ = 1/3.

## 풀이
1. θ = πx/2 ∈ [0, 2π). s = arcsin|t|, c = arccos|t|로 두면 **[NA9]** s + c = π/2.
2. **[L034]** 근은 대칭으로 짝지어진다: sin θ = t > 0이면 θ = s, π − s; cos θ = t > 0이면 θ = c, 2π − c (t < 0이면 각각 π + s, 2π − s와 π − c, π + c).
3. ㄱ: t < 0이면 α ↔ θ = π − c, β ↔ θ = 2π − s. α + β = (2/π)(3π − (s + c)) = 6 − 1 = 5. t = −1도 2 + 3 = 5. 참.
4. ㄴ: β(0) − α(0) = 3 − 0 = 3. t > 0: β ↔ 2π − c. s ≤ c (t ≤ √2/2)이면 α ↔ s, β − α = 4 − (2/π)(s + c) = 3. s > c이면 4 − 4c/π = 3 → c = π/4로 모순. t < 0이면 β − α = 2 + (2/π)(c − s) < 3. 집합은 [0, √2/2]. 참.
5. ㄷ: t > 0에서 α = (2/π)min(s, c) ≤ 1/2, t < 0에서 α ∈ (1, 2]. 같은 α는 t₁ < t₂ 둘 다 양수이고 arcsin t₁ = arccos t₂, 즉 t₁² + t₂² = 1. t₂ − t₁ = 1/2 → 2t₁t₂ = 3/4 → t₁t₂ = 3/8. 거짓.

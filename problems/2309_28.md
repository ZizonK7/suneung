## 문제 요약
반지름 1, 중심각 π/2인 부채꼴 OAB의 호 AB 위의 점 P에 대하여 PA = PC = PD가 되도록 호 PB 위에 점 C, 선분 OA 위에 점 D를 잡는다. D를 지나고 OP와 평행한 직선이 선분 PA와 만나는 점을 E라 한다. ∠POA = θ일 때 삼각형 CDP의 넓이 f(θ), 삼각형 EDA의 넓이 g(θ)에 대하여 lim_{θ→0+} g(θ)/{θ²f(θ)}는? (0 < θ < π/4)

## 풀이
1. **[L028]** 같은 원에서 현이 같으면 중심각이 같다: PC = PA → ∠COP = θ, C는 각 2θ인 점. PA = 2sin(θ/2).
2. **[L126]** PD = PA인 이등변삼각형 PDA에서 P의 수선의 발 (cosθ, 0)이 DA의 중점 → D = (2cosθ − 1, 0), DA = 2(1 − cosθ).
3. **[L114]** OP = OA = OC인 이등변삼각형에서 ∠OPA = ∠OPC = π/2 − θ/2 → ∠CPA = π − θ. 삼각형 PDA의 밑각 ∠PAD = π/2 − θ/2이므로 꼭지각 ∠DPA = θ, ∠CPD = π − 2θ.
   f(θ) = ½·PA²·sin2θ = 2(1 − cosθ)sinθcosθ.
4. **[L127]** DE ∥ OP → 삼각형 EDA ∽ POA, 닮음비 DA/OA = 2(1 − cosθ). 넓이는 제곱배: g(θ) = 4(1 − cosθ)²·(½sinθ) = 2(1 − cosθ)²sinθ.
5. **[L118]** 1 − cosθ ≈ θ²/2 → f ≈ θ³, g ≈ θ⁵/2. 극한 = (θ⁵/2)/(θ²·θ³) = 1/2. 답 ④.
6. 검산: sympy 좌표 계산으로 f, g 식과 극한 1/2 확인.

## 문제 요약
k>1. y = 2^x + k/2와 y = k(1/2)^x + k − 2의 교점 A. A를 지나고 기울기 −1인 직선이 y = 2^{x−2} − 3과 만나는 점 B.
삼각형 AOB 넓이 16일 때 k + log₂k = q/p, p+q는?

## 풀이
1. 2^x = t → t² + (2 − k/2)t − k = 0 → (t+2)(t − k/2) = 0 → t = k/2. A(log₂k − 1, k). [L005]
2. A는 항상 y = 2^{x+1} 위에 있다. [L006]
3. y = 2^{x−2} − 3은 y = 2^{x+1}을 (3, −3) 이동한 곡선이고, 직선 기울기도 −1이다. 그래서 B = A + (3, −3) = (log₂k + 2, k − 3). [L007]
4. 넓이 = ½|(L−1)(k−3) − (L+2)k| = (3/2)(k + L − 1) = 16 → k + log₂k = 35/3. [L008, L009]
5. p + q = 3 + 35 = 38.

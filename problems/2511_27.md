## 문제 요약
최고차항 계수 1인 삼차함수 f에 대해 g(x) = f(eˣ) + eˣ. 곡선 y = g(x) 위의 점 (0, g(0))에서의 접선이 x축이고 g가 역함수 h를 가질 때, h′(8)은?

## 풀이
1. 접선이 x축 → g(0) = f(1) + 1 = 0, g′(0) = f′(1) + 1 = 0.
2. **[N7E2]** g는 미분가능하고 역함수를 가지므로 단조다. x → ∞에서 g → ∞이므로 증가함수이고, 모든 x에서 g′(x) = eˣ{f′(eˣ) + 1} ≥ 0 → t > 0에서 f′(t) + 1 ≥ 0.
3. **[L019]** f′(t) + 1은 t > 0에서 0 이상인 이차식이고 t = 1에서 0 → t = 1은 극소, 이차식이므로 f′(t) + 1 = 3(t − 1)².
4. f(t) = (t − 1)³ − t + C, f(1) = −1 → C = 0. g(x) = (eˣ − 1)³.
5. **[L082]** g(x) = 8 ⇔ eˣ = 3. g′(ln3) = 3(3 − 1)²·3 = 36 → h′(8) = 1/36.

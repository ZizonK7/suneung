## 문제 요약
모든 항이 양수인 등비수열 {a_n}의 첫째항부터 제n항까지의 합을 S_n이라 하자. a₂ = 1, Σ_{k=1}^{6} (−1)^k S_k = 21일 때 S₂ + S₇의 값은?

## 풀이
1. **[L037]** 이웃한 두 항씩 묶으면 (S₂ − S₁) + (S₄ − S₃) + (S₆ − S₅) = a₂ + a₄ + a₆ = 21.
2. 공비 r > 0: 1 + r² + r⁴ = 21 → r² = 4 → r = 2, a₁ = 1/2.
3. S₂ = 3/2, S₇ = (1/2)(2⁷ − 1) = 127/2 → S₂ + S₇ = 65.

## 문제 요약
f(x) = (1/9)x(x − 6)(x − 9)와 실수 t (0 < t < 6)에 대하여 g(x) = f(x) (x < t), −(x − t) + f(t) (x ≥ t)이다. y = g(x)의 그래프와 x축으로 둘러싸인 영역의 넓이의 최댓값은?

## 풀이
1. (0, 6)에서 f > 0이므로 영역은 0~t의 곡선 아래와, (t, f(t))에서 기울기 −1로 내려가 x = t + f(t)에서 x축과 만나는 직각이등변삼각형이다.
2. **[N3B1]** 넓이를 t의 함수로 쓴다: S(t) = ∫_0^t f(x)dx + f(t)²/2.
3. **[L069]** S′(t) = f(t) + f(t)f′(t) = f(t){1 + f′(t)}. f(t) > 0이므로 부호는 1 + f′(t)가 정한다.
4. f′(t) = (1/9)(3t² − 30t + 54) = −1 → t² − 10t + 21 = 0 → t = 3 (또는 7). (0, 3)에서 S′ > 0, (3, 6)에서 S′ < 0 → t = 3에서 최대.
5. f(3) = 6, ∫_0^3 f = (1/9)(81/4 − 135 + 243) = 57/4. S(3) = 57/4 + 18 = 129/4. 수치 검산도 t ≈ 3에서 최대 32.25.

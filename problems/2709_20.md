## 문제 요약
f = sin x, g = −k cos x (k > 1, [0, 2π]). 제1사분면 교점 A, 제4사분면 교점 B. A, B를 지나는 수평선이 g와 다시 만나는 점 C, D. 넓이 CDB : AOD = 14 : 5. 빈칸 추론: B(p(α), ·), D(q(α), ·), α = (다). 3p(α)/q(α)는?

## 풀이
1. **[L033]** tan x = −k → A의 x좌표 α ∈ (π/2, π), B = (α + π, −sin α). p(α) = α + π.
2. **[L034]** g는 x = π에 대해 대칭 → D의 x좌표 = 2π − (α + π) = π − α. q(α) = π − α.
3. CDB = ½ · DB · 2 sin α = 2α sin α. **[L008]** AOD = ½|α(−sin α) − (π − α)sin α| = (π/2)sin α.
4. 2α : π/2 = 14 : 5 → α = 7π/10. 3 × (17π/10)/(3π/10) = 17.

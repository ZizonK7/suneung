## 문제 요약
x(t) = t(t − 1)(at + b) (a ≠ 0), ∫_0^1 |v| dt = 2. ㄱ. ∫_0^1 v = 0 ㄴ. |x(t₁)| > 1인 t₁ ∈ (0, 1)이 있다 ㄷ. [0, 1]에서 |x| < 1이면 x(t₂) = 0인 t₂ ∈ (0, 1)이 있다.

## 풀이
1. **[L067]** ㄱ: ∫_0^1 v = x(1) − x(0) = 0. 참.
2. **[NF4]** ∫_0^1 |v|는 움직인 거리. x가 (0, 1)에서 근이 없으면 한쪽 부호로 나갔다 돌아오므로 거리 = 2·max|x| → max|x| = 1.
3. ㄴ: b = 0, x = at²(t − 1), a = 27/4이면 max|x| = (27/4)(4/27) = 1, 거리 2. |x| > 1인 점이 없다. 거짓.
4. ㄷ: 근이 없으면 2에서 max|x| = 1이 되어 |x| < 1에 모순. 참.

## 문제 요약
[0, 1]에서 연속인 f가 f(0) = 0, f(1) = 1, ∫_0^1 f(x)dx = 1/6을 만족한다. 실수 전체에서 정의된 g가 (가) −1 < x < 0이면 g(x) = −f(x + 1) + 1, 0 ≤ x ≤ 1이면 g(x) = f(x), (나) 모든 실수 x에 대하여 g(x + 2) = g(x)를 만족할 때 ∫_{−3}^{2} g(x)dx는?

## 풀이
1. (−1, 0)의 조각은 f를 평행이동·대칭한 것이라 적분도 f의 적분으로 옮긴다: ∫_{−1}^{0} {1 − f(x + 1)}dx = ∫_0^1 {1 − f(u)}du = 1 − 1/6 = 5/6. f의 식은 몰라도 된다.
2. 한 주기 [−1, 1]의 적분 = 5/6 + 1/6 = 1.
3. **[L027]** 주기 2이므로 [−3, 1]은 두 주기로 2, 남은 [1, 2]는 [−1, 0]과 같아 5/6. 합 17/6. 답 ②.
4. 검산: f(x) = x⁵(조건 만족)로 직접 적분해 17/6.

## 문제 요약
등비수열 {aₙ}이 2(a₁ + a₄ + a₇) = a₄ + a₇ + a₁₀ = 6을 만족할 때 a₁₀의 값은? (① 22/7 ② 24/7 ③ 26/7 ④ 30/7 ⑤ 32/7)

## 풀이
1. **[N6B1]** a₄ + a₇ + a₁₀은 a₁ + a₄ + a₇의 각 항을 첨자 3만큼 민 합이므로 공비를 r라 하면 a₄ + a₇ + a₁₀ = r³(a₁ + a₄ + a₇).
2. a₁ + a₄ + a₇ = 3, a₄ + a₇ + a₁₀ = 6 → r³ = 2.
3. a₁(1 + r³ + r⁶) = 7a₁ = 3 → a₁ = 3/7. a₁₀ = a₁·r⁹ = (3/7)·8 = 24/7.

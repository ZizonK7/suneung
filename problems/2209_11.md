## 문제 요약
xf(x) = 2x³ + ax² + 3a + ∫_1^x f(t)dt, f(1) = ∫_0^1 f(t)dt일 때 a + f(3)은?

## 풀이
1. **[L026]** x = 1을 넣으면 적분이 0 → f(1) = 2 + 4a.
2. x = 0을 넣으면 0 = 3a − ∫_0^1 f → ∫_0^1 f = 3a. 조건에서 f(1) = 3a → 2 + 4a = 3a → a = −2, f(1) = −6.
3. **[L069]** 양변 미분: f + xf′ = 6x² + 2ax + f → f′ = 6x − 4 → f = 3x² − 4x + C. f(1) = −6 → C = −5.
4. f(3) = 27 − 12 − 5 = 10. a + f(3) = 8. (확인: ∫_0^1 f = 1 − 2 − 5 = −6 = 3a ✓)

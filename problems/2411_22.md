## 문제 요약
최고차항 계수 1인 삼차함수 f에 대해 f(k − 1)f(k + 1) < 0을 만족시키는 정수 k가 존재하지 않는다. f′(−1/4) = −1/4, f′(1/4) < 0일 때 f(8)은?

## 풀이
1. **[L174]** 조건은 간격 2인 두 정수의 함숫값이 반대 부호가 아니라는 것이다. 짝수점 수열 f(2m)과 홀수점 수열 f(2m + 1)로 나누면, 각 수열에서 부호가 바뀌려면 중간에 0인 항을 거쳐야 한다. f는 −∞에서 음, +∞에서 양이므로 f는 짝수 근 e와 홀수 근 o를 가진다. 짝수점에서는 e보다 왼쪽은 모두 음, 오른쪽은 모두 양이어야 한다(홀수점도 o 기준으로 같다).
2. f = (x − e)(x − o)(x − r)로 두고 부호 구간을 맞춘다. e와 o 사이에 같은 쪽 부호가 어긋나는 점이 생기지 않으려면 두 정수근은 이웃한 정수 n, n + 1이고, 셋째 근 r도 그 가까이(n − 1 ≤ r ≤ n + 2)에 있어야 한다. 예: r < n이면 (r, n)에 정수가 없어야 하므로 n − 1 ≤ r.
3. f′(1/4) < 0이면 1/4은 두 임계점 사이, 즉 근들 사이 범위 안이다. f = (x − n)(x − n − 1)(x − r)에 f′(−1/4) = −1/4를 넣으면 r은 n에 대한 일차식이고, n = −1이면 r = −1/8이지만 f′(1/4) > 0, n = 0이면 r = −5/8 ∈ (−1, 0), f′(1/4) = −5/8 < 0으로 맞다. n = 1이면 r = −9/8로 범위 밖이다.
4. f = x(x − 1)(x + 5/8) → f(8) = 8·7·69/8 = 483. (정수근 e, o를 −10~10에서 모두 대입해 조건을 만족하는 경우가 이것 하나뿐임을 검산했다.)

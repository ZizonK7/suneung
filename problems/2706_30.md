## 문제 요약
최고차항 계수 1인 삼차 f, g(x) = ∛(x·f(x)²)가 실수 전체에서 미분가능하고 x = 19/7, x = 3에서 극값. f(5)는?

## 풀이
1. **[NH7]** ∛P가 P의 근 r에서 미분가능하려면 r의 중복도가 3 이상이어야 한다(|x − r|^{k/3}, k = 1, 2는 뾰족·수직).
2. P = x·f²에서 0이 아닌 f의 실근은 중복도 2k라 k ≥ 2, 0은 중복도 1 + 2·(f에서 0의 중복도) → f(0) = 0 필수.
   - f = x(x − a)²: g = x(x − a)^{4/3}, 극점은 a와 3a/7뿐 → {19/7, 3}이 될 수 없음.
   - f = x·Q(x), Q = x² + px + q는 실근 없음: g = x·Q^{2/3}.
3. **[L060]** g′ = Q^{−1/3}·(7x² + 5px + 3q)/3. 극점 19/7, 3이 7x² + 5px + 3q의 두 근 → 7x² − 40x + 57 → p = −8, q = 19 (판별식 64 − 76 < 0 확인).
4. f(5) = 5(25 − 40 + 19) = 20.

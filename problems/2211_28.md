## 문제 요약
f(x) = 6π(x − 1)²에 대해 g(x) = 3f(x) + 4cos f(x). 0 < x < 2에서 g가 극소가 되는 x의 개수는?

## 풀이
1. **[L065]** g = h∘f, h(t) = 3t + 4cos t, g′ = f′(x)·(3 − 4sin f(x)). f는 (0, 1)에서 6π → 0으로 감소, (1, 2)에서 0 → 6π로 증가한다(6π는 닿지 않음).
2. h′ = 3 − 4sin t는 sin t = 3/4에서 부호가 바뀐다. α = arcsin(3/4)이면 t = π − α + 2kπ에서 h′이 − → +(h의 극소), t = α + 2kπ에서 + → −(h의 극대).
3. **[L020]** sin의 한 주기에 h의 극소가 하나, 극대가 하나다. (1, 2)에서 f가 증가하므로 h의 극소 ↔ g의 극소: t = π − α, 3π − α, 5π − α의 3개.
4. (0, 1)에서 f가 감소하므로 h의 극대 ↔ g의 극소: t = α, 2π + α, 4π + α의 3개. (t ∈ (0, 6π)에서 각각 3개)
5. x = 1에서 f(1) = 0, h′(0) = 3 ≠ 0이므로 g′의 부호는 f′을 따라 − → + → 극소.
6. 합 3 + 3 + 1 = 7.

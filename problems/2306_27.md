## 문제 요약
첫째항이 4인 등차수열 {a_n}에 대하여 급수 Σ_{n=1}^{∞} (a_n/n − (3n + 7)/(n + 2))가 실수 S에 수렴할 때 S의 값은?

## 풀이
1. 공차를 d라 하면 a_n/n = d + (4 − d)/n.
2. **[L083]** 급수가 수렴하므로 일반항 → 0: d − 3 = 0 → d = 3. a_n/n = 3 + 1/n.
3. 일반항 = 3 + 1/n − (3n + 7)/(n + 2) = 1/n − 1/(n + 2).
4. **[L016]** 간격 2인 망원합이라 앞쪽 두 항이 남는다: S = 1 + 1/2 = 3/2.

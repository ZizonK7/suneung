## 문제 요약
{a_n}은 등비수열이고 b_n = −1 (a_n ≤ −1), a_n (a_n > −1)이다. (가) Σ_{n=1}^∞ b_{2n−1}은 수렴하고 합은 −3, (나) Σ_{n=1}^∞ b_{2n}은 수렴하고 합은 8. b₃ = −1일 때 Σ_{n=1}^∞ |a_n|은?

## 풀이
1. b₃ = −1 → a₃ ≤ −1. a_n = a₁rⁿ⁻¹.
2. **[L083]** 두 급수가 수렴하므로 b_n → 0. |r| ≥ 1이면 a₃과 같은 부호인 항(r ≥ 1이면 n ≥ 3 전부, r ≤ −1이면 홀수항)이 계속 −1 이하라 b_n = −1이 무한히 나온다. 따라서 |r| < 1이고, −1 이하인 항은 유한 개다.
3. **[N3E2]** 홀수항은 공비 r²으로 a₃과 같은 음의 부호다. r > 0이면 짝수항도 음수라 (나)의 합 8 > 0이 불가능 → r < 0, 짝수항은 모두 양수라 b_{2n} = a_{2n}. (나) a₁r/(1 − r²) = 8.
4. **[N3E3]** 홀수항은 |a_{2n−1}|이 줄어들므로 앞쪽 m개(m ≥ 2, a₃ ≤ −1)만 −1이고 나머지는 a_{2n−1}이다. (가) −m + a₁r^{2m}/(1 − r²) = −3.
5. (나)에서 a₁/(1 − r²) = 8/r, 대입하면 −m + 8r^{2m−1} = −3. r < 0이라 8r^{2m−1} < 0 → m < 3, m = 2: r³ = −1/8 → r = −1/2, a₁ = 8(1 − 1/4)/(−1/2) = −12.
6. 확인: a₁ = −12, a₃ = −3, a₅ = −3/4 > −1이라 m = 2와 맞다.
7. Σ|a_n| = 12/(1 − 1/2) = 24. 수치 계산으로 (가) −3, (나) 8 확인.

## 문제 요약
두 상수 a, b(1 < a < b)에 대하여 두 점 (a, log₂a), (b, log₂b)를 지나는 직선의 y절편과 두 점 (a, log₄a), (b, log₄b)를 지나는 직선의 y절편이 같다. f(x) = a^{bx} + b^{ax}에 대하여 f(1) = 40일 때 f(2)의 값은? (① 760 ② 800 ③ 840 ④ 880 ⑤ 920)

## 풀이
1. **[L077]** log₄x = (1/2)log₂x이므로 y = log₄x는 y = log₂x를 세로로 1/2배 줄인 곡선이다. 대응하는 두 점을 지나는 직선도 1/2배로 줄어 y절편도 1/2배가 된다. 두 y절편이 같으면 y절편은 0이다.
2. 따라서 원점, (a, log₂a), (b, log₂b)가 한 직선 위에 있다: (log₂a)/a = (log₂b)/b → b·log₂a = a·log₂b.
3. **[N6B4]** 로그 등식을 지수로 올린다: log₂a^b = log₂b^a → a^b = b^a.
4. f(1) = a^b + b^a = 2a^b = 40 → a^b = 20. f(2) = (a^b)² + (b^a)² = 2·400 = 800.

## 문제 요약
(가) a₁ = a₃, (나) 모든 자연수 n에 대하여 (a_{n+1} − a_n + 3)(a_{n+1} − 2a_n) = 0을 만족하는 모든 수열 {a_n}에 대하여 a₄의 최댓값은?

## 풀이
1. **[L107]** a_{n+1} = a_n − 3 또는 2a_n. a₁ = x로 두면 a₂ = x − 3 또는 2x, a₃ = x − 6, 2x − 6, 2x − 3, 4x.
2. a₃ = x: x − 6 = x는 불가, 2x − 6 = x → x = 6, 2x − 3 = x → x = 3, 4x = x → x = 0. 따라서 a₃ ∈ {6, 3, 0}.
3. a₄ = 2a₃ 또는 a₃ − 3이므로 최댓값은 a₃ = 6일 때 12(수열 6, 3, 6, 12).

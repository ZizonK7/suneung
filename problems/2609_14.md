## 문제 요약
양수 k에 대하여 집합 {x | 0 ≤ x < 3kπ/2, x ≠ kπ/2}에서 정의된 f(x) = tan(x/k). 점 P(0, p)(p > 0)를 지나고 x축에 평행한 직선이 y = f(x)와 만나는 두 점을 A, B(PA < PB), 직선 y = −p가 y = f(x)와 만나는 점을 C라 하자. AB = 3PA이고 삼각형 OCB의 넓이가 5π/3일 때 k + p는? (O는 원점)

## 풀이
1. f의 주기는 kπ이고, 그래프는 [0, kπ/2)와 (kπ/2, 3kπ/2)의 두 가지로 이루어진다.
2. **[N4D1]** A가 첫째 가지 위의 x = a이면 B는 한 주기 옮긴 x = a + kπ이므로 AB = kπ. AB = 3PA → a = kπ/3, p = tan(π/3) = √3, B(4kπ/3, √3).
3. **[N4D1]** 둘째 가지는 점 (kπ, 0)에 대해 점대칭이므로 y = −√3과의 교점은 B의 대칭점 C(2kπ/3, −√3).
4. **[L008]** 넓이 = ½|x_C·y_B − x_B·y_C| = ½(2kπ/3 + 4kπ/3)√3 = √3kπ = 5π/3 → k = 5√3/9.
5. k + p = 5√3/9 + √3 = 14√3/9.

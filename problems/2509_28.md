## 문제 요약
f는 실수 전체에서 연속인 이계도함수를 갖고, g(x) = f′(2x)sinπx + x는 역함수 g⁻¹를 갖는다. ∫_0^1 g⁻¹(x)dx = 2∫_0^1 f′(2x)sinπx dx + 1/4일 때 ∫_0^2 f(x)cos(πx/2)dx의 값은?

## 풀이
1. sinπx는 정수에서 0이므로 g(0) = 0, g(1) = 1. 역함수가 있으니 g는 증가한다.
2. **[L051]** I = ∫_0^1 f′(2x)sinπx dx라 하면 ∫_0^1 g⁻¹ = 1·g(1) − 0·g(0) − ∫_0^1 g = 1 − (I + 1/2) = 1/2 − I.
3. 조건: 1/2 − I = 2I + 1/4 → I = 1/12.
4. **[N6D1]** 부분적분: I = [f(2x)sinπx/2]_0^1 − (π/2)∫_0^1 f(2x)cosπx dx = −(π/2)∫_0^1 f(2x)cosπx dx. 경계항은 sinπx 때문에 0이다. 따라서 ∫_0^1 f(2x)cosπx dx = −1/(6π).
5. x = 2u로 치환: ∫_0^2 f(x)cos(πx/2)dx = 2∫_0^1 f(2u)cosπu du = −1/(3π). ③.

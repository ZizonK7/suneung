## 문제 요약
모든 항이 자연수이고 (가) a₇ = 40, (나) 모든 자연수 n에 대하여 a_{n+2} = a_{n+1} + a_n (a_{n+1}이 3의 배수가 아닌 경우), a_{n+2} = a_{n+1}/3 (a_{n+1}이 3의 배수인 경우)를 만족시키는 모든 수열 {a_n}에 대하여 a₉의 최댓값과 최솟값을 각각 M, m이라 할 때 M + m의 값은?

## 풀이
1. a₇ = 40은 3의 배수가 아니므로 a₈ = a₆ + 40. a₉는 a₈이 3의 배수이면 a₈/3, 아니면 a₈ + 40. 따라서 a₆의 후보를 구하면 된다.
2. **[L107]** a₇ = 40에서 거꾸로 올라간다. a₆이 3의 배수이면 a₇ = a₆/3 → a₆ = 120(앞항은 자유라 항상 이어진다). a₆이 3의 배수가 아니면 a₅ = 40 − a₆ ≥ 1.
   - a₅가 3의 배수이면 a₆ = a₅/3 → a₆ = 10, a₅ = 30.
   - a₅가 3의 배수가 아니면 a₄ = a₆ − a₅ = 2a₆ − 40 ≥ 1 → a₆ ≥ 21. 한 단계 더: a₄가 3의 배수이면 a₅ = a₄/3 → a₆ = 32(a₄ = 24, a₅ = 8). 아니면 a₃ = 80 − 3a₆ ≥ 1, a₂ = 5a₆ − 120 등으로 자연수 조건이 계속 범위를 좁혀 남는 갈래가 없다.
3. a₆ = 120: a₈ = 160 → a₉ = 200. a₆ = 10: a₈ = 50 → a₉ = 90. a₆ = 32: a₈ = 72 → a₉ = 24.
4. M + m = 200 + 24 = 224.
5. 검산: a₁, a₂ = 1~399 전수 탐색에서 a₇ = 40인 수열의 a₉는 24, 90, 200뿐.

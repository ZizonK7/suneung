## 문제 요약
f(x) = (x − a − 2)²eˣ (x ≥ a), e^{2a}(x − a) + 4eᵃ (x < a). 실수 t에 대하여 f(x) = t를 만족시키는 x의 최솟값을 g(t)라 하자. g(t)가 t = 12에서만 불연속일 때, g′(f(a + 2))/g′(f(a + 6))의 값은? (a는 상수)

## 풀이
1. x ≥ a에서 f′ = eˣ(x − a − 2)(x − a) → [a, a + 2]에서 감소, x ≥ a + 2에서 증가. f(a) = 4eᵃ(극대), f(a + 2) = 0(극소). x < a에서는 기울기 e^{2a} > 0인 직선이고 x → a−에서 4eᵃ로 이어진다.
2. **[L151]** 가장 작은 근은 t가 극댓값 4eᵃ 이하이면 x ≤ a의 직선 위에 있다가, t > 4eᵃ이 되는 순간 x > a + 2의 가지로 건너뛴다. 다른 곳에서는 연속이므로 불연속점은 t = 4eᵃ 하나 → 4eᵃ = 12, eᵃ = 3.
3. **[L082]** f(a + 2) = 0 < 12 → g는 직선 부분의 역함수, g′(0) = 1/e^{2a} = 1/9.
   f(a + 6) = 16e^{a+6} = 48e⁶ > 12 → g는 x > a + 2 가지의 역함수, g′ = 1/f′(a + 6) = 1/(24e^{a+6}) = 1/(72e⁶).
4. 비 = (1/9)·72e⁶ = 8e⁶.

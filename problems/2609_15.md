## 문제 요약
최고차항 계수가 양수, f(0) = 0인 삼차함수 f. g(x) = ∫₀ˣ (|f(t)| − |t|)dt. (가) g′(x) = 0의 서로 다른 실근 4개. (나) g는 x = 2, 6에서 극값. f(6)·g(2) < 0일 때 f(8)은?

## 풀이
1. **[L116]** f(0) = 0이므로 f = x·q(x) (q는 아래로 볼록한 이차함수). g′ = |x|(|q(x)| − 1).
2. **[L053, L055]** g′의 부호는 |q| − 1이 정한다(|x| ≥ 0은 x = 0에서 부호를 바꾸지 않는다). 근은 x = 0과 q = 1, q = −1의 근.
   - min q ≥ −1이면 근이 3개 이하이거나, min q = −1일 때 꼭짓점에서 부호가 안 바뀌어 극값 위치가 q = 1의 두 근 2, 6 → q = (x − 4)²/2 − 1. 근 0, 2, 4, 6으로 4개지만 f(6) = 6 > 0, g(2) > 0이라 탈락.
   - min q < −1이면 q = ±1의 근 4개 α < γ < δ < β에서 모두 부호가 바뀐다. 0을 더해 5개가 되면 안 되므로 0이 이 넷 중 하나다.
3. **[L073]** 두 수평선 y = 1, y = −1과 포물선의 교점은 같은 축에 대칭 → α + β = γ + δ. {0, 2, 6, r}에서 가능한 배치:
   - (−4, 0, 2, 6), (0, 2, 4, 6), (0, 2, 6, 8).
4. q = c(x − α)(x − β) + 1 = c(x − γ)(x − δ) − 1 → c(αβ − γδ) = −2.
   - (−4, 0, 2, 6): c = 1/12, (0, 2)에서 |q| > 1 → g(2) > 0, f(6) = 6 > 0. 탈락.
   - (0, 2, 4, 6): α = 0, β = 6, γ = 2, δ = 4, c = 1/4. (0, 2)에서 |q| < 1 → g(2) < 0, f(6) = 6 > 0. ✓
   - (0, 2, 6, 8): c = 1/6, f(6) = −6, g(2) < 0. 탈락.
5. q = x(x − 6)/4 + 1, f(8) = 8·(4 + 1) = 40.

## 문제 요약
두 양수 a, b에 대하여 곡선 y = a sin bπx (0 ≤ x ≤ 3/b)가 직선 y = a와 만나는 서로 다른 두 점을 A, B라 하자. 삼각형 OAB의 넓이가 5이고 직선 OA의 기울기와 직선 OB의 기울기의 곱이 5/4일 때 a + b는? (O는 원점)

## 풀이
1. 주기 2/b. 최댓값 a를 갖는 점은 x = 1/(2b), 5/(2b) → A(1/(2b), a), B(5/(2b), a).
2. **[L008]** AB는 y = a 위의 수평 선분(길이 2/b)이고 O까지 거리가 a → 넓이 (1/2)(2/b)a = a/b = 5.
3. 기울기 곱: 2ab · (2ab/5) = 4a²b²/5 = 5/4 → ab = 5/4.
4. a² = 25/4 → a = 5/2, b = 1/2, a + b = 3.

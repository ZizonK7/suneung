## 문제 요약
AB = 4, AC = 5, cos A = 1/8인 삼각형 ABC. D는 AC 위, E는 BC 위, ∠BAC = ∠BDA = ∠BED. DE는?

## 풀이
1. **[L071]** BC² = 16 + 25 − 2·4·5·(1/8) = 36 → BC = 6.
2. **[NA4]** ∠BAD = ∠BDA → 삼각형 ABD는 BA = BD = 4인 이등변. AD = 2·4·cos A = 1, DC = 4.
3. **[NA4]** BD = DC = 4 → ∠DBC = ∠C. 삼각형 EBD와 ACB에서 ∠E = ∠A, ∠B = ∠C → AA 닮음(E↔A, B↔C, D↔B).
4. DE/AB = BD/BC → DE = 4·4/6 = 8/3.

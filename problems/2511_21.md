## 문제 요약
f(x) = x³ + ax² + bx + 4(a, b 정수). 모든 실수 α에서 lim_{x→α} f(2x + 1)/f(x)가 존재. f(1)의 최댓값은?

## 풀이
1. **[L002, L003]** f(α) = 0이면 분자도 0 → f(2α + 1) = 0. 근 α가 근 2α + 1을 부른다.
2. **[NE1]** 실근은 유한 개인데 α ≠ −1이면 α, 2α + 1, 4α + 3, …이 모두 다르다(−1에서 멀어짐). 따라서 실근은 고정점 −1뿐이다.
   - 중복도: f = (x + 1)^k q(x)이면 f(2x + 1) = 2^k(x + 1)^k q(2x + 1)이라 극한 존재 ✓.
3. f(−1) = 0 → b = a + 3, f = (x + 1)(x² + px + 4), p = a − 1.
4. x² + px + 4는 −1 외의 실근이 없어야 한다: p² < 16(p = ±4는 근 ∓2, p = 5는 근 −4라 탈락).
5. f(1) = 2(5 + p), p = 3에서 최대 16.

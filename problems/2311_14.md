## 문제 요약
다항함수 f에 대해 g(x) = x(x < −1 또는 x > 1), f(x)(−1 ≤ x ≤ 1). h(x) = lim_{t→0+} g(x + t) × lim_{t→2+} g(x + t). ㄱ. h(1) = 3. ㄴ. h는 실수 전체에서 연속이다. ㄷ. g가 [−1, 1]에서 감소하고 g(−1) = −2이면 h는 최솟값을 갖는다. 옳은 것은?

## 풀이
1. **[L149]** lim_{t→0+} g(x + t) = g(x+)(x에서의 우극한), lim_{t→2+} g(x + t) = g((x + 2)+). 우극한이므로 경계점에서는 오른쪽 구간의 식을 따른다: h(x) = g(x+)·g((x + 2)+).
2. ㄱ: g(1+) = 1, g(3+) = 3 → h(1) = 3. 참.
3. **[L004]** ㄴ: h(−1) = g(−1+)·g(1+) = f(−1)·1. x → −1−에서 g(x+) → −1, g((x + 2)+) → f(1) → 좌극한 −f(1). f(−1) = −f(1)이 늘 성립하지 않으므로 거짓(예: f = 1).
4. ㄷ: f는 [−1, 1]에서 감소, f ≤ −2. 구간별로 h = x(x + 2)(x < −3), x·f(x + 2)(−3 ≤ x < −1, 양수), f(x)(x + 2)(−1 ≤ x < 1, 음수), x(x + 2)(x ≥ 1, 양수).
5. **[L123]** 음수 구간 [−1, 1)에서 |f|와 x + 2가 모두 증가하므로 f(x)(x + 2)는 감소한다. 오른쪽 끝 x = 1이 빠진 구간이라 3f(1)에 닿지 않고, h(1) = 3 > 0. 최솟값이 없으므로 거짓.
6. 옳은 것은 ㄱ → ①.

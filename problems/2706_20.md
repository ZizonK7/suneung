## 문제 요약
1보다 큰 실수 b에 대하여 f(x) = bˣ, g(x) = −log_b x의 그래프가 제1사분면에서 만나는 점 P(α, β). αβ³ = 1일 때 직선 OP의 기울기 m에 대하여 g(m)을 구하는 과정의 빈칸 (가) m = β/α, (나) β, (다) g(m)에 알맞은 수를 p, q, r이라 할 때 (p × q × r)²은?

## 풀이
1. β = b^α ⇔ α = log_bβ, 그리고 β = −log_bα.
2. **[L052]** 3α − β = 3log_bβ + log_bα = log_b(αβ³) = log_b1 = 0 → β = 3α, m = 3 (가).
3. β⁴ = mαβ³ = m = 3 → β = 3^{1/4} (나).
4. β = −log_bα → b = α^{−1/β}. g(m) = −log_b m = −1/log_m b = β/log_mα, α = β/m이므로 log_mα = log_mβ − 1 = 1/4 − 1 = −3/4. g(m) = −(4/3)·3^{1/4} (다).
5. pqr = 3 × 3^{1/4} × (−4/3)·3^{1/4} = −4√3, 제곱 48. 수치로 αβ³ = 1과 g(m)을 확인했다.

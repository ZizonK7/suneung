## 문제 요약
최고차항의 계수가 1인 이차함수 f. (가) (x^n − 64)f(x) = 0은 서로 다른 두 실근을 갖고 각각 중근. (나) f의 최솟값은 음의 정수. 이런 f가 존재하는 모든 자연수 n의 합은?

## 풀이
1. (나)에서 최솟값 < 0 → f는 서로 다른 두 실근(단순근)을 갖는다.
2. **[NB6]** x^n = 64의 실근: n이 짝수면 ±2^{6/n} 두 개, 홀수면 2^{6/n} 하나(모두 단순근).
3. **[NB5]** 전체 근이 두 개이고 모두 중근이려면 x^n − 64의 단순근과 f의 단순근이 정확히 겹쳐야 한다. n이 홀수면 f의 다른 근이 단순근으로 남아 불가. n이 짝수면 f = x² − 2^{12/n}.
4. 최솟값 −2^{12/n}이 정수 → 12/n은 자연수, n 짝수 → n = 2, 4, 6, 12 (최솟값 −64, −8, −4, −2).
5. 합 24.

## 풀이
1. **[L008]** A = (√ln(1 + t), t), B = (√ln(1 + 5t), 5t), C = (√ln(1 + 5t), 0). 세로 변 BC = 5t를 밑변, A까지의 가로 거리를 높이로 쓰면 S(t) = (5t/2){√ln(1 + 5t) − √ln(1 + t)}.
2. **[L080]** S(t)/(t√t) = (5/2){√(ln(1 + 5t)/t) − √(ln(1 + t)/t)} → (5/2)(√5 − 1).

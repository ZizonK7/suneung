## 문제 요약
원 C: 중심 O, 반지름 2. A(2, 0), B(0, −2). C 위의 x좌표가 음수인 점 P에 대해 ∠PAB = θ. Q(0, 2cosθ)에서 직선 BP에 내린 수선의 발 R, f(θ) = PR. ∫_{π/6}^{π/3} f(θ)dθ는?

## 풀이
1. **[L028]** 현 PB의 원주각이 θ이므로 PB = 2·2·sinθ = 4sinθ.
2. **[L114]** 중심각 ∠POB = 2θ. 삼각형 OBP는 OB = OP인 이등변삼각형이라 밑각 ∠OBP = π/2 − θ. 즉 직선 BP와 y축(BO 방향)이 이루는 각이 π/2 − θ다.
3. Q는 y축 위에 있고 BQ = 2 + 2cosθ. R은 Q에서 BP에 내린 수선의 발이므로 BR = BQ·cos(π/2 − θ) = (2 + 2cosθ)sinθ.
4. f(θ) = PB − BR = 2sinθ − sin2θ (= 2sinθ(1 − cosθ) ≥ 0).
5. ∫_{π/6}^{π/3} (2sinθ − sin2θ)dθ = (√3 − 1) − 1/2 = (2√3 − 3)/2. (sympy 확인)

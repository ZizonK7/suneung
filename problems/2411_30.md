## 문제 요약
f′(x) = |sin x|cos x. 곡선 y = f(x) 위의 점 (a, f(a))에서의 접선을 y = g(x)라 하고 h(x) = ∫_0^x {f(t) − g(t)}dt. h가 x = a에서 극값을 갖게 하는 양수 a를 작은 순서로 a_n이라 할 때 (100/π)(a_6 − a_2)는?

## 풀이
1. **[L053]** h′(x) = f(x) − g(x). h가 a에서 극값 ⇔ f − g의 부호가 a에서 바뀐다.
2. **[L100]** f(x) − g(x) = ∫_a^x {f′(t) − f′(a)}dt. f′ − f′(a)가 a 양쪽에서 같은 부호이면(= f′가 a에서 극값) 적분의 부호가 바뀐다. 아니면 f − g는 a에서 부호를 유지한다(접선이 곡선 한쪽에 있음).
3. f′의 극값 위치: (0, π)에서 f′ = sin2x/2 → π/4(극대), 3π/4(극소). (π, 2π)에서 f′ = −sin2x/2 → 5π/4, 7π/4. x = kπ에서는 f′(kπ) = 0이고 근처에서 f′의 부호가 일정(π 근처 ≤ 0, 2π 근처 ≥ 0) → 극값.
4. a_n: π/4, 3π/4, π, 5π/4, 7π/4, 2π, … → a_2 = 3π/4, a_6 = 2π.
5. (100/π)(2π − 3π/4) = 125.

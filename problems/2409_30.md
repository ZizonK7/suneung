## 문제 요약
길이 10인 선분 AB를 지름으로 하는 원과 선분 AB 위에 AC = 4인 점 C가 있다. 원 위의 점 P를 ∠PCB = θ가 되도록 잡고, P를 지나고 AB에 수직인 직선이 원과 만나는 점 중 P가 아닌 점을 Q라 하자. 삼각형 PCQ의 넓이를 S(θ)라 할 때 −7·S′(π/4)는? (0 < θ < π/2)

## 풀이
1. 원의 중심 O, 반지름 5, OC = 1. CP = r로 둔다.
2. **[L071]** O는 C에서 B 쪽에 있으므로 ∠PCO = θ. 삼각형 OCP에서 25 = r² + 1 − 2r·cosθ → r² − 2r·cosθ − 24 = 0, 양수 근 r = cosθ + √(cos²θ + 24).
3. **[L126]** OP = OQ이고 PQ ⊥ AB이므로 AB가 PQ를 이등분한다. 발을 H라 하면 PH = r·sinθ, CH = r·cosθ → S = ½·2r·sinθ·r·cosθ = r²·sinθ·cosθ = (r²/2)·sin2θ.
4. θ = π/4: r = √2/2 + 7/√2 = 4√2. r′ = −sinθ − sinθ·cosθ/√(cos²θ + 24) = −√2/2 − √2/14 = −4√2/7.
5. S′ = r·r′·sin2θ + r²·cos2θ, θ = π/4에서 cos2θ = 0 → S′(π/4) = 4√2·(−4√2/7) = −32/7. −7·S′(π/4) = 32.

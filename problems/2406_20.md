## 문제 요약
최고차항의 계수가 1인 이차함수 f에 대하여 g(x) = ∫_0^x f(t)dt. x ≥ 1인 모든 실수 x에 대하여 g(x) ≥ g(4)이고 |g(x)| ≥ |g(3)|이다. f(9)는?

## 풀이
1. **[L069]** **[L026]** g′ = f이므로 g는 최고차항 계수 1/3인 삼차함수이고 g(0) = 0.
2. **[L060]** g(4)는 [1, ∞)에서의 최솟값이고 4는 구간 안쪽이므로 g는 x = 4에서 극소, g′(4) = f(4) = 0. f = (x − 4)(x − p), p < 4.
3. **[L019]** g(4) < g(3)이고 g → ∞이므로, g(3) ≠ 0이면 (3이 극점이 아니거나 g(3) < 0인 극대점이어도) [1, ∞)에서 g가 0을 지나 |g|가 |g(3)|보다 작아진다. |g| ≥ 0이 [1, ∞)에서 0이 되는 점을 가지므로 최솟값 |g(3)| = 0, 곧 g(3) = 0.
4. g = (1/3)x(x − 3)(x − c)로 놓고 g′(4) = 0 → 48 − 8(3 + c) + 3c = 0 → c = 24/5.
5. 확인: f = g′ = (x − 4)(x − 6/5)이고 g(1) = 38/15 ≥ g(4) = −16/15. 수치로 두 조건 모두 성립.
6. f(9) = 5 · 39/5 = 39.

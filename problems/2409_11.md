## 문제 요약
두 점 P, Q가 t = 0일 때 각각 A(1), B(8)에서 출발해 수직선 위를 움직이고, 시각 t(t ≥ 0)에서의 속도는 v₁(t) = 3t² + 4t − 7, v₂(t) = 2t + 4이다. 출발한 시각부터 두 점 사이의 거리가 처음으로 4가 될 때까지 P가 움직인 거리는?

## 풀이
1. x_P = 1 + t³ + 2t² − 7t, x_Q = 8 + t² + 4t.
2. **[L096]** 상대위치 x_Q − x_P = 7 + 11t − t² − t³. 처음 7에서 증가하다 감소하므로 거리가 처음 4가 되는 것은 x_Q − x_P = 4일 때다: t³ + t² − 11t − 3 = 0 → (t − 3)(t² + 4t + 1) = 0 → t = 3. (−4가 되는 t = √11은 그 뒤.)
3. **[L067]** v₁ = (3t + 7)(t − 1)은 t = 1에서 부호가 바뀐다. [0, 1]에서 |x_P(1) − x_P(0)| = 4, [1, 3]에서 |x_P(3) − x_P(1)| = 28. 움직인 거리 32.

## 문제 요약
두 실수 a, b(a > 1, b > 1)가 lim_{n→∞} (3ⁿ + a^{n+1})/(3^{n+1} + aⁿ) = a, lim_{n→∞} (aⁿ + b^{n+1})/(a^{n+1} + bⁿ) = 9/a를 만족할 때 a + b는?

## 풀이
1. **[L061]** 첫 극한을 a와 3의 대소로 나눈다. a < 3이면 극한 1/3, a = 3이면 1, a > 3이면 aⁿ으로 나눠 a. 극한이 a(> 1)이므로 a > 3.
2. **[L061]** 둘째 극한을 a와 b의 대소로 나눈다. b < a이면 1/a ≠ 9/a. b > a이면 bⁿ이 지배해 극한 b = 9/a < 3인데 b > a > 3에 모순. b = a이면 (1 + a)/(a + 1) = 1 = 9/a → a = 9.
3. a = b = 9, a + b = 18.

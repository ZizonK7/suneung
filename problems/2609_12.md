## 문제 요약
상수 a (a > 1)와 양수 t에 대하여 곡선 y = aˣ과 두 직선 x = t, x = 2t가 만나는 점을 각각 A, B라 하고, B에서 x축에 내린 수선의 발을 C라 하자. AB = AC이고 삼각형 ACB의 넓이가 8일 때 a × t는?

## 풀이
1. **[L126]** AB = AC이고 B, C는 직선 x = 2t 위 → A에서 그 직선에 내린 수선의 발이 BC의 중점. aᵗ = a^{2t}/2 → aᵗ = 2, BC = a^{2t} = 4.
2. **[L008]** 밑변 BC = 4(직선 x = 2t 위), 높이는 A에서 그 직선까지 거리 t → 넓이 2t = 8, t = 4.
3. a⁴ = 2 → a = 2^{1/4}, a·t = 4·2^{1/4} = 2^{9/4}.

## 문제 요약
x₁ = 4t³ − t² − 11t, x₂ = 2t² + 7t + 3 (t ≥ 0). 두 점의 속도가 같아지는 순간의 가속도 p, q에 대해 p − q는?

## 풀이
1. v₁ = 12t² − 2t − 11, v₂ = 4t + 7. 같으면 12t² − 6t − 18 = 0 → (2t − 3)(t + 1) = 0 → t = 3/2.
2. a₁ = 24t − 2 = 34, a₂ = 4 → p − q = 30.
   - sympy로 검산: t = 3/2, p − q = 30.

## 문제 요약
최고차항 계수 1인 삼차함수 f에 대하여 곡선 y = f(x) 위의 점 (−2, f(−2))에서의 접선과 점 (2, 3)에서의 접선이 점 (1, 3)에서 만날 때, f(0)의 값은?

## 풀이
1. (2, 3)에서의 접선이 (1, 3)을 지나므로 이 접선은 y = 3, f′(2) = 0.
2. **[L015]** y = 3이 x = 2에서 접하므로 f(x) − 3 = (x − 2)²(x − k)로 놓는다.
3. **[L048]** (−2, f(−2))에서의 접선이 (1, 3)을 지난다: 3 − f(−2) = f′(−2)·(1 − (−2)). h = f − 3으로 쓰면 h(−2) + 3h′(−2) = 0.
   h(−2) = 16(−2 − k), h′(−2) = −8(−2 − k) + 16 = 32 + 8k → 64 + 8k = 0, k = −8.
4. f(0) = 3 + 4·8 = 35. 검산: f = x³ + 4x² − 28x + 35.

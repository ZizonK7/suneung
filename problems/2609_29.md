## 문제 요약
첫째항이 양수이고 공비가 유리수인 등비수열 {a_n}에 대하여 Σa_n이 수렴하고, (가) a₁ + a₂ < 10, (나) {a_n}의 정수인 항의 개수는 3이고 이 세 항의 곱은 216이다. Σa_n = q/p(p, q 서로소인 자연수)일 때 p + q는?

## 풀이
1. **[L169]** 공비를 기약분수 r = p/q(|p| < q)로 두면 a_n = a₁pⁿ⁻¹/qⁿ⁻¹. 분자에는 p의 거듭제곱이 쌓이고 분모에는 q의 거듭제곱이 쌓이므로 정수인 항은 연속한 한 구간을 이룬다. 세 정수 항은 이웃한 세 항 a_{m−1}, a_m, a_{m+1}이다.
2. **[L030]** 이웃한 세 항의 곱은 가운데 항의 세제곱 → a_m³ = 216, a_m = 6.
3. **[L169]** 6/r = 6q/p, 6r = 6p/q가 정수 → p | 6, q | 6. 바깥 항 6p²/q², 6q²/p²(있으면)는 정수가 아니다.
   - m ≥ 3(a_{m−2}가 있음): 6q²/p²이 정수가 아니려면 |p| ≥ 2 → p = ±2, q = 3. r = ±2/3.
   - m = 2(a₁부터 정수): a₁ = 6/r > 0이라 r > 0. r = 1/2, 1/3, 2/3, 1/6에서 a₁ + a₂ = 18, 24, 15, 42로 (가)에 모순.
4. **[L134]** r = 2/3이면 a₁ = 6(3/2)^{m−1} ≥ 13.5라 a₁ + a₂ > 10. r = −2/3이면 a_m = 6 > 0과 a₁ > 0이 같은 부호 → m은 홀수. m = 3: a₁ = 27/2, a₁ + a₂ = 9/2 < 10. m ≥ 5는 a₁ ≥ 30.375로 (가)에 모순.
5. a_n = (27/2)(−2/3)ⁿ⁻¹(정수 항 −9, 6, −4). Σa_n = (27/2)/(5/3) = 81/10 → 91.
6. 검산: 공비 분모 39 이하, m ≤ 11을 전수 탐색해 해가 하나뿐임을 확인.

## 문제 요약
원점을 지나 y = e^{−x} + e^t에 접하는 직선의 기울기 f(t). f(a) = −e√e일 때 f′(a)는?

## 풀이
1. **[L048]** 접점 s: e^{−s} + e^t = −s·e^{−s} → e^t = −e^{−s}(s + 1), f = −e^{−s}.
2. f(a) = −e^{3/2} → s = −3/2.
3. **[L049]** df/ds = e^{−s}. 관계식을 미분하면 e^t dt = s·e^{−s} ds → ds/dt = e^t/(s·e^{−s}) = −1/3.
   f′(a) = e^{3/2} × (−1/3) = −(1/3)e√e.

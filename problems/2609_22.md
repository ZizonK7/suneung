## 문제 요약
곡선 y = log₂x 위에 서로 다른 두 점 A, B가 있다. A에서 직선 y = x에 내린 수선의 발을 P, B를 y = x에 대해 대칭이동한 점을 Q라 한다. (가) (직선 AP의 y절편) − (직선 BQ의 y절편) = 13/2. (나) 직선 AB의 기울기는 6/7. 사각형 APQB의 넓이가 q/p(서로소인 자연수)일 때 p + q는?

## 풀이
1. **[L152]** AP와 BQ는 모두 y = x에 수직이라 기울기 −1이고, y절편은 지나는 점의 좌표 합이다. A(a, log₂a), B(b, log₂b)이면 (가)는 (a + log₂a) − (b + log₂b) = 13/2.
2. (나)에서 log₂a − log₂b = (6/7)(a − b). (가)에 넣으면 (13/7)(a − b) = 13/2 → a − b = 7/2, log₂(a/b) = 3 → a = 8b. b = 1/2, a = 4. A(4, 2), B(1/2, −1), P(3, 3), Q(−1, 1/2).
3. **[L092]** APQB는 AP ∥ BQ인 사다리꼴이다. 기울기 −1 위의 길이는 |Δx|·√2: AP = √2, BQ = (3/2)√2. 높이는 두 평행선 x + y = 6, x + y = −1/2 사이 거리 (13/2)/√2.
4. 넓이 = (1/2)(√2 + (3/2)√2)·(13/2)/√2 = 65/8 → p + q = 73. 검산: 신발끈 공식 65/8.

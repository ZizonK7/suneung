## 문제 요약
자연수 a, b. f(x) = a·sin bx + 8 − a. (가) f ≥ 0, (나) [0, 2π)에서 f = 0의 서로 다른 실근 4개. a + b는?

## 풀이
1. 최솟값 8 − 2a. 근이 있으므로 최솟값 = 0 → a = 4. [L019]
2. sin bx = −1의 해가 [0, 2π)에서 b개 → b = 4. [L020]

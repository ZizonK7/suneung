## 문제 요약
시각 t (π/2 < t < 3π/2)에서 점 P의 위치가 x = at + tan t, y = 1 + sec t이다. t = 3π/4에서의 속력과 t = π에서의 속력이 같을 때 실수 a의 값은?

## 풀이
1. **[L175]** dx/dt = a + sec²t, dy/dt = sec t·tan t. 속력² = (a + sec²t)² + sec²t·tan²t로 비교한다.
2. **[L057]** t = 3π/4(제2사분면): sec t = −√2, tan t = −1. t = π: sec t = −1, tan t = 0.
3. (a + 2)² + 2 = (a + 1)² → 2a + 5 = 0 → a = −5/2.

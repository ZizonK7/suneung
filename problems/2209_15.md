## 문제 요약
|a₁| ≤ 1, a_{n+1} = −2a_n − 2 (−1 ≤ a_n < −1/2), 2a_n (|a_n| ≤ 1/2), −2a_n + 2 (1/2 < a_n ≤ 1). a₅ + a₆ = 0이고 Σ_{k=1}^5 a_k > 0인 모든 a₁의 합은?

## 풀이
1. a₆ = −a₅: 가운데 식에서만 가능(2a₅ = −a₅) → a₅ = 0. 바깥 식은 a₅ = ±2라 범위 밖.
2. **[L107]** 끝에서 거꾸로 직전 항 후보를 적는다. 0 ← {0, 1, −1}, 1 ← {1/2}, −1 ← {−1/2}, 1/2 ← {1/4, 3/4}, −1/2 ← {−1/4, −3/4}, …
3. 점화식이 a ↦ −a에 대해 대칭이라 음수 가지는 양수 가지의 부호 반전이고 합이 음수다. a₁ = 0은 합 0. 합 > 0은 0 이상 쪽 가지뿐.
4. 양수 후보: 1, 1/2, 1/4, 3/4, 1/8, 3/8, 5/8, 7/8 → 합 9/2.
   - 확인: 거꾸로 전개한 a₁ 17개를 모두 대입해 확인.

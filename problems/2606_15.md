## 문제 요약
상수 k와 f′(0) = 6인 삼차함수 f에 대하여 g(x) = f(x) + k (|x| > 1), −f(x) (|x| ≤ 1). (가) 모든 실수 a에 대하여 lim_{x→a+} {g(x) − g(a)}/(x − a)의 값이 존재하고 그 값은 0 이하이다. (나) 방정식 g(x) = t의 서로 다른 실근의 개수가 2가 되도록 하는 실수 t의 최댓값은 13이다. k + f(1/2)의 값은?

## 풀이
1. **[L157]** 우미분계수가 존재하려면 각 점에서 오른쪽으로 연속이어야 한다. x = −1은 g(−1) = −f(−1)이고 오른쪽도 −f라 자동으로 성립하고, x = 1에서는 g(1) = −f(1) = f(1) + k가 필요하다 → k = −2f(1). x = −1의 왼쪽에서는 끊겨도 된다.
2. **[L089]** 우미분계수 ≤ 0이므로 |x| > 1에서 f′ ≤ 0, −1 < x < 1에서 −f′ ≤ 0(f′ ≥ 0). f′가 연속이라 경계에서 f′(1) = f′(−1) = 0. f′ = c(x² − 1), f′(0) = −c = 6 → f′ = −6(x² − 1), f(x) = −2x³ + 6x + d.
3. f(1) = d + 4, f(−1) = d − 4, k = −2d − 8. g는 x < −1에서 +∞부터 f(−1) + k = −d − 12(닿지 않음)까지 감소, x = −1에서 4 − d로 뛰어오른 뒤 [−1, ∞)에서 연속으로 −∞까지 감소한다.
4. **[L064]** 수평선 y = t와 그래프의 교점을 센다. 두 가지가 모두 지나는 높이는 −d − 12 < t ≤ 4 − d일 때뿐이고 이때 근이 2개, 밖에서는 1개.
5. **[L014]** 범위의 끝은 근이 x = −1(가지의 끝값)에 닿는 순간이다. 최댓값 4 − d = 13 → d = −9, k = 10.
6. f(1/2) = −1/4 + 3 − 9 = −25/4, k + f(1/2) = 15/4. 수치로 t = 13에서 2개, 13.1에서 1개 확인.

## 문제 요약
첫째항이 자연수인 수열 {a_n}이 모든 자연수 n에 대해 a_{n+1} = 2^{a_n}(a_n 홀수), a_n/2(a_n 짝수)를 만족한다. a₆ + a₇ = 3이 되도록 하는 모든 a₁의 값의 합은?

## 풀이
1. a₆가 홀수면 a₇ = 2^{a₆}, 합 3 → a₆ = 1(a₇ = 2). a₆가 짝수면 a₇ = a₆/2, 3a₆/2 = 3 → a₆ = 2. 따라서 a₆ ∈ {1, 2}.
2. **[L107]** 끝 조건에서 거꾸로 올라간다. x의 직전 항은 짝수 2x(항상 가능)와, 2^m = x인 홀수 m(x가 2의 홀수 제곱일 때만)이다. 갈래마다 홀짝 조건을 확인한다.
   - a₆ = 1 ← a₅ = 2 / a₆ = 2 ← a₅ = 4 또는 1(2 = 2¹). a₅ ∈ {1, 2, 4}.
   - a₄ ∈ {1, 2, 4, 8}(4 = 2²은 지수가 짝수라 홀수 직전 항 없음), a₃ ∈ {1, 2, 3, 4, 8, 16}(8 = 2³ ← 3).
   - a₂ ∈ {1, 2, 3, 4, 6, 8, 16, 32}, a₁ ∈ {1, 2, 3, 4, 5, 6, 8, 12, 16, 32, 64}(32 = 2⁵ ← 5).
3. 합 = 153. a₁ ≤ 2000 전수 검사로 같은 집합 확인.

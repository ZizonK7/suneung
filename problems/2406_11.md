## 문제 요약
0 < t < 1. y = x² 위에서 직선 y = 2tx − 1과의 거리가 최소인 점 P, 직선 OP와 y = 2tx − 1의 교점 Q. lim_{t→1−} PQ/(1 − t)는?

## 풀이
1. **[NH6]** 거리가 최소인 점은 접선 기울기가 2t인 점 → 2x = 2t, P(t, t²).
2. 직선 OP: y = tx. tx = 2tx − 1 → Q(1/t, 1).
3. PQ = √((1/t − t)² + (1 − t²)²) = (1 − t²)√(1/t² + 1). 1 − t로 나누면 (1 + t)√(1/t² + 1) → 2√2.

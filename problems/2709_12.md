## 문제 요약
AB = 4, AC = 5, cos A = 1/8인 삼각형 ABC의 외접원에서 A를 포함하지 않는 호 BC 위의 점 D. sin(∠BCD) = √14/4일 때 BD는?

## 풀이
1. **[L071]** BC² = 16 + 25 − 2·4·5·(1/8) = 36 → BC = 6.
2. sin A = 3√7/8 → 2R = BC/sin A = 16/√7.
3. **[L028]** BD는 같은 외접원의 현이고 원주각이 ∠BCD → BD = 2R·sin(∠BCD) = (16/√7)(√14/4) = 4√2.
   - 검산: ∠BCD ≈ 69.3° < ∠A ≈ 82.8°라 호 BC 위에 D가 존재. numpy로 원 위의 D를 훑어 BD ≈ 5.657 = 4√2 확인.

## 문제 요약
{a_n}은 등비수열, b_n = a_n − a₁(|a_n| ≥ 10), (a_n)²(|a_n| < 10). (가) (b₂)² = 36b₃. (나) Σ_{n=1}^∞ b_n은 수렴하고 합은 12. a₁ > 0, a₂ < 0일 때 36 × a₄ × a₆의 값은?

## 풀이
1. a_n = a·rⁿ⁻¹(a > 0, r < 0). **[L083]** 급수가 수렴하므로 b_n → 0. |r| > 1이면 결국 |a_n| ≥ 10이라 b_n = a_n − a는 0으로 가지 않는다. r = −1이면 b_n이 a² 또는 (0, −2a 반복)이라 역시 안 된다. 따라서 −1 < r < 0이고 |a_n|은 감소한다.
2. **[L135]** |a_n| ≥ 10인 항은 앞쪽 몇 개뿐이다. 개수에 따라 나눈다.
   - a < 10(하나도 없음): b_n = a²r^{2(n−1)}, (가)에서 a⁴r⁴ = 36a²r⁴ → a = 6. 합 36/(1 − r²) = 12 → r² = −2, 불가.
   - |a₁| ≥ 10 > |a₂|: b₂ = a²r², b₃ = a²r⁴ → a = 6, a ≥ 10에 모순.
   - |a₃| ≥ 10: b₂ = a(r − 1) ≠ 0, b₃ = a(r² − 1) < 0이라 (b₂)² = 36b₃ 불가.
   - |a₂| ≥ 10 > |a₃|: b₂ = a(r − 1), b₃ = a²r⁴. a²(1 − r)² = 36a²r⁴ → 1 − r = 6r² → r = −1/2. 범위 a/2 ≥ 10 > a/4 → 20 ≤ a < 40.
3. **[L168]** n ≥ 3에서 b_n = (a_n)²은 첫째항 a²r⁴, 공비 r²인 등비수열. 합 = b₁ + b₂ + a²r⁴/(1 − r²) = 0 − 3a/2 + a²/12 = 12 → a² − 18a − 144 = 0 → a = 24(범위 만족).
4. a₄ = 24·(−1/8) = −3, a₆ = 24·(−1/32) = −3/4. 36 × (−3) × (−3/4) = 81.
5. 검산: 분수로 b₁~b₂₀₀ 계산, (가) 성립, 합 12.0.

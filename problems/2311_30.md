## 문제 요약
최고차항의 계수가 양수인 삼차함수 f와 g(x) = e^{sin πx} − 1에 대하여 h(x) = g(f(x))가 (가) x = 0에서 극댓값 0을 갖고, (나) 열린구간 (0, 3)에서 방정식 h(x) = 1의 서로 다른 실근의 개수가 7이다. f(3) = 1/2, f′(3) = 0일 때 f(2) = q/p. p + q는? (p, q는 서로소인 자연수)

## 풀이
1. **[L065]** h(0) = 0 → sin(πf(0)) = 0 → f(0) = n(정수). 겉함수 g의 y = n에서 기울기 π(−1)ⁿ·e⁰ ≠ 0이므로, h가 x = 0에서 극값을 가지려면 f가 x = 0에서 극값을 가져야 한다(f′(0) ≠ 0이면 h도 부호가 바뀌는 단조).
2. **[L060]** f′(0) = f′(3) = 0, 최고차항 양수 → x = 0 극대, x = 3 극소. f(x) = k(2x³ − 9x²) + n (k > 0).
   - **[L065]** f가 극대인 점에서 h가 극대이려면 g가 y = n에서 증가 → n은 짝수.
   - f(3) = −27k + n = 1/2 → k = (n − 1/2)/27 > 0 → n ≥ 2.
3. **[L020]** (0, 3)에서 f는 n에서 1/2로 감소하는 일대일이라, h = 1의 근 수 = (1/2, n)에서 sin πy = ln 2 (0 < ln 2 < 1)의 해 수. 해는 각 (2m, 2m + 1)에 2개, (2m + 1, 2m + 2)에 0개이고, (0, 1) 안의 두 해 중 1/2보다 큰 것은 하나.
   - 개수 = 1 + 2(n/2 − 1) = n − 1 = 7 → n = 8.
4. k = (15/2)/27 = 5/18, f(2) = (5/18)(16 − 36) + 8 = 22/9 → p + q = 31.
5. 검산: (0, 3)에서 h − 1의 부호 변화를 수치로 세어 7개, h는 x = 0 근처에서 음수(극댓값 0) 확인.

## 문제 요약
최고차항 계수가 양수인 삼차함수 f와 실수 t에 대해 g(x) = −f(x) (x < t), f(x) (x ≥ t)가 실수 전체에서 연속. (가) 모든 실수 a에 대해 lim_{x→a+} g(x)/{x(x − 2)}가 존재. (나) 이 극한이 음수가 되는 자연수 m의 집합이 {g(−1), −(7/2)g(1)}. g(−5)는? (단, g(−1) ≠ −(7/2)g(1))

## 풀이
1. **[L040]** x = t에서 연속 → −f(t) = f(t) → f(t) = 0. t는 f의 근이다.
2. **[L002]** (가)에서 a = 0, 2일 때 분모 → 0이므로 g(0) = g(2) = 0 → f(0) = f(2) = 0. f(x) = kx(x − 2)(x − c) (k > 0), t ∈ {0, 2, c}.
3. **[L044]** m = 2에서는 g(2) = 0이라 우극한 = (g의 우미분계수)/2. m ≠ 2이면 부호는 g(m)/{m(m − 2)}의 부호.
4. t와 c의 위치로 경우를 나눠 (나)의 집합을 구하면, 원소 두 개이고 조건을 만족하는 경우는 t = 2, 3 < c < 4뿐이다.
   - m = 1: g(1) = −f(1) = −k(c − 1) < 0, 분모 −1 → 양수. m = 2: f′(2) = 2k(2 − c) < 0 → 음수. m = 3: f(3) = 3k(3 − c) < 0 → 음수. m ≥ 4: 양수. 집합 {2, 3}.
5. g(−1) = −f(−1) = 3k(1 + c), −(7/2)g(1) = (7/2)k(c − 1). 3k(1 + c) = 2, (7/2)k(c − 1) = 3이면 c = −8로 모순. 3k(1 + c) = 3, (7/2)k(c − 1) = 2 → c = 11/3, k = 3/14.
6. g(−5) = −f(−5) = −k(−5)(−7)(−5 − 11/3) = (3/14)·35·(26/3) = 65.
7. 검산: c를 1/4 간격으로 훑고 t ∈ {0, 2, c}마다 집합을 구해 연립한 결과 위 해 하나만 일관됨.

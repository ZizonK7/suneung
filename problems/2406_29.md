## 문제 요약
A(a, a + k), B(b, b + k)가 곡선 C: x² − 2xy + 2y² = 15 위에 있고, A, B에서의 접선이 수직. a + 2k ≠ 0, b + 2k ≠ 0일 때 k²은?

## 풀이
1. 음함수 미분: y′ = (x − y)/(x − 2y). A에서 기울기 k/(a + 2k), B에서 k/(b + 2k).
   수직 → k² = −(a + 2k)(b + 2k).
2. **[NE3]** A가 C 위: a² + 2ak + 2k² = 15. b도 같은 식 → a, b는 t² + 2kt + 2k² − 15 = 0의 두 근.
   a = b이면 (a + 2k)² = −k² → k = 0, a = 0, 조건 a + 2k ≠ 0에 모순. 따라서 a ≠ b.
3. **[L074]** a + b = −2k, ab = 2k² − 15 → (a + 2k)(b + 2k) = ab + 2k(a + b) + 4k² = 2k² − 15.
4. 2k² − 15 = −k² → k² = 5.

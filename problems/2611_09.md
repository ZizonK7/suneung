## 문제 요약
a > 0, f(x) = x³ + 3ax² − 9a²x + 4. 직선 y = 5가 곡선 y = f(x)에 접할 때 f(2)는?

## 풀이
1. **[L060]** f′ = 3(x + 3a)(x − a). 극대 x = −3a, 극소 x = a.
2. **[L014]** 수평선 y = 5가 접하면 접점은 극점이고 5는 극값이다.
   - f(a) = −5a³ + 4 = 5 → a < 0, 불가.
   - f(−3a) = 27a³ + 4 = 5 → a = 1/3.
3. f(x) = x³ + x² − x + 4, f(2) = 8 + 4 − 2 + 4 = 14.

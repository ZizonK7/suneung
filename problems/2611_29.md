## 문제 요약
첫째항과 공차가 같은 등차수열 a_n, 등비수열 b_n. 어떤 자연수 k에 대해 b_{k+i} = 1/a_i − 1 (i = 1, 2, 3). 0 < Σ(b_n − 1/(a_n a_{n+1})) < 30일 때 a_2 × Σ b_{2n} = q/p, p + q는?

## 풀이
1. a_n = na (a = 첫째항 = 공차). b_{k+1} = 1/a − 1, b_{k+2} = 1/(2a) − 1, b_{k+3} = 1/(3a) − 1.
2. **[L030]** b_{k+2}² = b_{k+1}·b_{k+3}. u = 1/a로 두면 (u/2 − 1)² = (u − 1)(u/3 − 1) → u = 4, a = 1/4. b_{k+1} = 3, b_{k+2} = 1, 공비 1/3.
3. **[L016]** 1/(a_n a_{n+1}) = 16/(n(n + 1)) → 합 16 (망원합).
4. b_1 = 3^{k+1}, Σ b_n = 3^{k+2}/2. 0 < 3^{k+2}/2 − 16 < 30 → 32 < 3^{k+2} < 92 → k = 2, b_1 = 27.
5. Σ b_{2n} = 9/(1 − 1/9) = 81/8, a_2 = 1/2 → 81/16. p + q = 97.

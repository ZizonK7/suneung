## 문제 요약
두 양수 a, b(b > 3)와 최고차항의 계수가 1인 이차함수 f에 대하여 g(x) = (x + 3)f(x) (x < 0), (x + a)f(x − b) (x ≥ 0)가 실수 전체에서 연속이다. lim_{x→−3} {√(|g(x)| + {g(t)}²) − |g(t)|}/(x + 3)²의 값이 존재하지 않는 실수 t의 값은 −3과 6뿐이다. g(4)는?

## 풀이
1. **[L088]** 유리화: 식 = |g(x)| / [(x + 3)²{√(|g(x)| + g(t)²) + |g(t)|}].
2. **[N5C1]** g(t)의 값이 0인지로 나눈다.
   - g(t) ≠ 0: 분모의 괄호 → 2|g(t)|이므로 극한은 lim |g(x)|/(x + 3)² = lim |f(x)|/|x + 3|에 달려 있다.
   - g(t) = 0: 식 = √|g(x)|/(x + 3)²이고 g(x)는 −3 근처에서 많아야 (x + 3)³ 크기라 발산한다. 따라서 g(t) = 0인 t에서는 항상 존재하지 않는다.
3. **[L002]** g(t) ≠ 0인 t에서 존재해야 하므로 |f(x)|/|x + 3|이 수렴 → f(−3) = 0. 그러면 극한이 존재하지 않는 t는 정확히 g의 근이다. g의 근 집합 = {−3, 6}.
4. **[L013]** f = (x + 3)(x − c). x < 0: g = (x + 3)²(x − c), x ≥ 0: g = (x + a)(x − b + 3)(x − b − c).
   - x ≥ 0에서 x = b − 3 > 0은 근 → b − 3 = 6, b = 9. x = −a < 0은 구간 밖.
   - x = 9 + c: 0 이상이면 6이어야 하고(c = −3), 음수(c < −9)이면 x < 0 쪽 근 c가 −3이 아닌 새 근이 된다. c ≥ 0이면 9 + c ≥ 9로 새 근. 따라서 c = −3, f = (x + 3)².
5. **[L040]** x = 0에서 연속: 3f(0) = a f(−9) → 27 = 36a → a = 3/4.
6. g(4) = (4 + 3/4)f(−5) = (19/4)·4 = 19.

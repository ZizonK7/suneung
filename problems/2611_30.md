## 문제 요약
실수 전체에서 증가하는 연속함수 f의 역함수 f⁻¹가 (가) |x| ≤ 1일 때 4{f⁻¹(x)}² = x²(x² − 5)², (나) |x| > 1일 때 |f⁻¹(x)| = e^{|x|−1} + 1을 만족한다. 기울기가 m이고 점 (1, 0)을 지나는 직선과 곡선 y = f(x)의 교점 개수를 g(m)이라 하자. g가 m = a, m = b (a < b)에서 불연속일 때 g(a) × lim_{m→a+} g(m) + g(b) × (ln b / b)²은? (단, lim_{x→∞} ln x / x = 0)

## 풀이
1. **[L101]** f⁻¹도 증가하는 연속함수다. |x| ≤ 1에서 f⁻¹ = ±x(x² − 5)/2인데 x(x² − 5)/2는 [−1, 1]에서 감소하므로 f⁻¹ = x(5 − x²)/2, f⁻¹(±1) = ±2. 이어서 x > 1에서 f⁻¹ = e^{x−1} + 1, x < −1에서 f⁻¹ = −(e^{−x−1} + 1). f⁻¹는 홀함수.
2. **[N7D2]** 곡선 y = f(x) 위의 점을 (f⁻¹(t), t)로 쓴다. 직선 y = m(x − 1)과 만날 조건은 t = m(f⁻¹(t) − 1).
3. **[L064]** m을 분리: m = h(t) = t/(f⁻¹(t) − 1). f⁻¹(t) = 1인 t₀ = √2 − 1에서 h는 ±∞로 갈라진다. g(m) = (h(t) = m의 해 개수).
4. h의 개형: t > t₀에서 h는 +∞에서 0⁺으로 감소(t > 1에서 h = t·e^{1−t}, 감소). −1 ≤ t < t₀에서 1/3에서 −∞로 감소(t = 0에서 0). t < −1에서 h = −t/(e^{−t−1} + 2)는 1/3에서 올라가 최댓값 M을 찍고 0⁺으로 간다.
5. M: h′ = 0 ⇔ u = −(t + 1)에 대해 ue^u = 2이고, 이때 M = (1 + u)/(e^u + 2) = u/2.
6. **[L093]** 개수표: m ≤ 0이면 1, 0 < m < M이면 3, m = M이면 2, m > M이면 1. 불연속점 a = 0, b = M. g(a) = 1, lim_{m→0+} g = 3, g(b) = 2.
7. **[L009]** b는 구하지 않는다. u = 2b를 ue^u = 2에 넣으면 be^{2b} = 1 → ln b = −2b → (ln b / b)² = 4.
8. 1 × 3 + 2 × 4 = 11.

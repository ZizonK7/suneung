## 문제 요약
최고차항 계수 1인 삼차함수 f가 있다. 실수 t에 대해 f(α) = f′(t) − 4t² + 4를 만족하는 실수 α의 최댓값을 g(t)라 하자. g가 t = 3에서만 불연속이고 g(3) = 1일 때 f(2)는?

## 풀이
1. **[L064]** h(t) = f′(t) − 4t² + 4로 두면 g(t)는 곡선 y = f(x)와 수평선 y = h(t)의 교점 중 가장 오른쪽 x좌표다. f = x³ + ax² + bx + c이면 h(t) = −t² + 2at + b + 4, 위로 볼록한 포물선이다.
2. **[L151]** f가 극값을 갖지 않으면 가장 큰 근은 높이에 대해 연속이라 g가 불연속점을 갖지 않는다. f가 극대 M, 극소 m(극소점 q)을 가지면 가장 큰 근은 높이 k가 m 이상일 때 q 이상의 가지에 있고, k가 m보다 작아지는 순간 왼쪽 가지로 건너뛴다. 따라서 g는 h(t)가 m 위(또는 m)에서 m 아래로 넘어가는 t에서만 끊긴다.
3. **[L093]** 포물선 h가 m을 가로지르면 불연속점이 두 개 생긴다. t = 3 하나에서만 끊기려면 h가 t = 3에서 m에 한 순간만 닿아야 한다: h의 꼭짓점이 t = 3이고 최댓값 = m. 그때 g(3) = q, 다른 t에서는 g가 왼쪽 가지 위에서 연속이다.
4. **[L060]** h의 꼭짓점 t = a = 3. g(3) = q = 1이므로 f′(1) = 3 + 6 + b = 0 → b = −9. f′ = 3(x + 3)(x − 1)이라 x = 1은 극소점이 맞다.
5. h(3) = 9 + b + 4 = 4 = f(1) = 1 + 3 − 9 + c → c = 9. f(2) = 8 + 12 − 18 + 9 = 11.
6. 검산: 수치로 g(t)를 계산하면 t = 3에서만 −5 → 1 → −5로 끊긴다.

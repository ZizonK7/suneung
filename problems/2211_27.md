## 문제 요약
f(x) = 6π(x − 1)², g(x) = 3f(x) + 4cos f(x). 0 < x < 2에서 g가 극소가 되는 x의 개수는?

## 풀이
1. h(y) = 3y + 4cos y라 하면 g = h∘f, g′ = h′(f(x))·f′(x), h′(y) = 3 − 4sin y. [L023]
2. 0 < x < 2에서 f는 6π → 0(x = 1) → 6π. 따라서 y는 (0, 6π)를 감소하며 한 번, 증가하며 한 번 지난다.
3. **[L020]** sin y = 3/4의 해는 (0, 6π)에서 주기마다 2개씩 6개다. h는 y = α + 2kπ에서 극대, π − α + 2kπ에서 극소다(α = arcsin(3/4), k = 0, 1, 2).
4. **[L065]** 1 < x < 2(f 증가): h의 극소 3개 → g의 극소 3개. 0 < x < 1(f 감소): h의 극대 3개 → g의 극소 3개.
5. x = 1: h′(0) = 3 > 0이고 f′이 − → +로 바뀌므로 g도 극소.
6. 합계 3 + 3 + 1 = 7.

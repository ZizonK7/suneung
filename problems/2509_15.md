## 문제 요약
두 다항함수 f, g가 모든 실수 x에 대하여 (가) ∫_1^x t·f(t)dt + ∫_{−1}^x t·g(t)dt = 3x⁴ + 8x³ − 3x², (나) f(x) = x·g′(x)를 만족한다. ∫_0^3 g(x)dx의 값은?

## 풀이
1. **[L069]** (가)를 미분하면 x·f(x) + x·g(x) = 12x³ + 24x² − 6x, 다항식이므로 f + g = 12x² + 24x − 6.
2. **[L110]** (나)를 넣으면 x·g′ + g = (x·g)′ = 12x² + 24x − 6 → x·g = 4x³ + 12x² − 6x + C. g가 다항식이므로 C = 0, g = 4x² + 12x − 6.
3. **[L026]** 미분으로 잃은 상수를 확인한다: (가)에 x = 1을 넣으면 첫 적분이 0이라 ∫_{−1}^1 t·g(t)dt = 8이어야 한다. ∫_{−1}^1 (4t³ + 12t² − 6t)dt = 8로 성립.
4. ∫_0^3 g = 36 + 54 − 18 = 72.

## 문제 요약
최고차항의 계수가 1인 이차함수 f. 모든 실수 a에 대하여 lim_{x→a} (2x + 1)f(x) / {f(x) + f(x − t)}의 값이 존재하도록 하는 양수 t의 집합이 {t | t ≥ 3/2}이다. f(2)는?

## 풀이
1. **[L043]** f(x) = (x − m)² + n이라 하면 D(x) = f(x) + f(x − t)는 x = m + t/2에서 최솟값 t²/2 + 2n.
   n ≥ 0이면 모든 t > 0에서 D > 0이라 집합이 (0, ∞)가 되므로 n < 0.
2. t > t₀ = 2√(−n)이면 D > 0이라 극한이 늘 존재한다. 집합이 정확히 [3/2, ∞)이므로 t₀ = 3/2 → n = −9/16.
3. **[L042, L002]** t = 3/2에서 D는 x = m + 3/4에서 중근을 가지므로 분자 (2x + 1)f(x)도 거기서 중근이어야 한다. f(m + 3/4) = 0은 저절로 성립하고(f의 근이 m ± 3/4) 단근이므로 2x + 1도 거기서 0 → m + 3/4 = −1/2, m = −5/4.
4. t < 3/2에서는 D의 서로 다른 두 근(합 2m + t)이 모두 분자의 근 {−1/2, −2}여야 하는데 합이 −5/2 + t ≠ −5/2라 불가능. 조건과 맞는다.
5. f(2) = (13/4)² − 9/16 = 10.
6. 검산: sympy로 t = 1/2, 1, 7/5에서 극한이 없는 a가 있고 t = 3/2, 2에서는 모든 근에서 극한이 존재함을 확인.

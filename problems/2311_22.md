## 문제 요약
최고차항 계수 1인 삼차 f, 연속함수 g. (가) f(x) = f(1) + (x − 1)f′(g(x)) (나) g의 최솟값 5/2 (다) f(0) = −3, f(g(1)) = 6. f(4)는?

## 풀이
1. f(x) = x³ + ax² + bx − 3. x ≠ 1에서 f′(g(x)) = (f(x) − f(1))/(x − 1) = h(x) = x² + (1 + a)x + (1 + a + b) (x = 1에서도 연속성으로 성립).
2. **[NH4]** f′(y) = 3(y − c)² + m (c = −a/3, m = b − a²/3)은 축 c에 대해 대칭인 이차식. 그래서 g(x) = c ± √((h(x) − m)/3).
3. h(x) − m = x² + (1 + a)x + 1 + a + a²/3의 최솟값은 (a + 3)²/12 ≥ 0.
4. **[L022]** a ≠ −3이면 h − m > 0이라 g는 값 c를 지나지 못한다. 연속인 g는 한 가지에 머물고, 최솟값이 있으므로 + 가지: 최솟값 c + |a + 3|/6 = 5/2.
   - a ≥ −3이면 (3 − a)/6 = 5/2 → a = −12 (모순). a < −3이면 (−3a − 3)/6 = 5/2 → a = −6, c = 2. (a = −3이면 최솟값이 c = 1이라 탈락.)
5. g(1)은 f′(g(1)) = f′(1)이고 g(1) ≥ c = 2이므로 g(1) = 2c − 1 = 3. f(3) = 3b − 30 = 6 → b = 12.
6. f(x) = (x − 2)³ + 5 → f(4) = 13.

## 문제 요약
길이 2인 선분 AB를 지름으로 하는 반원의 호 위에 점 P, AB의 중점 O. B를 지나고 AB에 수직인 직선이 직선 OP와 만나는 점 Q, ∠OQB의 이등분선이 직선 AP와 만나는 점 R. ∠OAP = θ일 때 삼각형 OAP의 넓이 f(θ), 삼각형 PQR의 넓이 g(θ). lim_{θ→0+} g(θ)/(θ⁴ f(θ))는? (0 < θ < π/4)

## 풀이
1. **[L114]** ∠POB = 2θ. f(θ) = (1/2)·1·1·sin(π − 2θ) = (1/2)sin2θ. OQ = sec2θ이므로 PQ = sec2θ − 1, ∠OQB = π/2 − 2θ.
2. **[L094]** OA = OP라 ∠OPA = θ, 맞꼭지각으로 ∠QPR = θ. ∠PQR = π/4 − θ, 따라서 ∠PRQ = 3π/4.
3. **[L070]** 사인법칙 PR = PQ·sin(π/4 − θ)/sin(3π/4), g = (1/2)PQ·PR·sinθ = (√2/2)PQ²·sin(π/4 − θ)·sinθ.
4. **[L118]** PQ = sec2θ − 1 ≈ 2θ², sin(π/4 − θ) → √2/2, sinθ ≈ θ → g ≈ (√2/2)(4θ⁴)(√2/2)θ = 2θ⁵, f ≈ θ. 극한 = 2.

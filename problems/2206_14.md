## 문제 요약
p, q > 0, f(x) = x³ − 3x² − 9x − 12. 연속함수 g가 (가) xg(x) = |xf(x − p) + qx|, (나) g가 미분가능하지 않은 점이 1개. p + q는?

## 풀이
1. **[NA1]** h(x) = f(x − p) + q로 두면 xg(x) = |x|·|h(x)| → x ≠ 0에서 g(x) = (x/|x|)·|h(x)|. 연속이려면 g(0+) = |h(0)|, g(0−) = −|h(0)|가 같아야 하므로 h(0) = 0.
2. **[NA1]** x = 0에서는 h(0) = 0이면 (x/|x|)|h|가 항상 미분가능(단순근이면 |c|x, 중근이면 |c|x|x|).
3. **[L025]** x ≠ 0에서는 h의 근 중 부호가 바뀌는(홀수 중근) 근에서만 미분 불가능. 삼차 h가 0을 근으로 가지면서 이런 근이 정확히 1개 → 0이 중근이고 나머지 근이 단순근.
4. h(0) = 0, h′(0) = 0 → f′(−p) = 0, f′(x) = 3(x − 3)(x + 1), p > 0 → p = 1. q = −f(−1) = 7.
5. p + q = 8.

## 문제 요약
f = −x² (x < 0), x² − x (x ≥ 0). g = a(x + 1) (x < −1), 0 (−1 ≤ x < 1), a(x − 1) (x ≥ 1). h(x) = ∫_0^x (g − f)가 극값을 하나만 갖는 a의 최댓값 k. k + h(3)은?

## 풀이
1. **[L053]** h′ = g − f를 구간별로 본다.
   - x < −1: x² + ax + a
   - [−1, 0): x² > 0
   - [0, 1): x − x² ≥ 0
   - x ≥ 1: (x − 1)(a − x)
2. **[L055]** x = 0에서는 양쪽이 모두 양수라 극값이 아니다. x ≥ 1 쪽에서는 a > 1이면 x = a, a ≤ 1이면 x = 1에서 부호가 바뀐다. 따라서 극값은 항상 하나 있다.
3. **[L054]** x < −1에서 q(−1) = 1 > 0이고, a > 4이면 근 두 개가 모두 x < −1에 있어 극값이 2개 추가된다. a = 4는 중근이라 부호가 바뀌지 않는다 → k = 4.
4. h(3) = ∫_0^1 (x − x²) + ∫_1^3 (x − 1)(4 − x) = 1/6 + 10/3 = 7/2 → 15/2.

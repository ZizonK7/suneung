## 문제 요약
모든 항이 자연수인 등차수열 {aₙ}의 첫째항부터 제n항까지의 합을 Sₙ이라 하자. a₇이 13의 배수이고 Σ_{k=1}^{7} S_k = 644일 때, a₂는?

## 풀이
1. **[L062]** 첫째항 a, 공차 d이면 S_k = ka + k(k − 1)d/2. Σk = 28, Σk(k − 1) = 140 − 28 = 112 → ΣS_k = 28a + 56d = 644 → a + 2d = 23, 즉 a₃ = 23.
2. **[L072]** a₇ = a₃ + 4d = 23 + 4d.
3. **[L173]** 모든 항이 자연수 → d는 0 이상의 정수, a = 23 − 2d ≥ 1 → 0 ≤ d ≤ 11. 이 범위에서 23 + 4d ∈ {23, 27, …, 67}의 13의 배수는 39뿐 → d = 4, a = 15.
4. a₂ = 19.

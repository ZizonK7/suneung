## 문제 요약
실수 전체에서 미분가능한 f. (가) [0, 1]에서 f(x) = x. (나) [0, ∞)에서 f(x + 1) − xf(x) = ax + b. 60∫_1^2 f(x)dx는?

## 풀이
1. **[NC8]** x ∈ [0, 1]이면 f(x + 1) = x·x + ax + b, 즉 [1, 2]에서 f(x) = (x − 1)² + a(x − 1) + b.
2. **[L040]** x = 1에서 이어짐: 값 f(1) = 1 = b, 기울기 1 = a.
3. ∫_1^2 f = ∫_0^1 (u² + u + 1)du = 1/3 + 1/2 + 1 = 11/6. 60 × 11/6 = 110.

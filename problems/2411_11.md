## 문제 요약
공차가 0이 아닌 등차수열 {a_n}에 대하여 |a₆| = a₈, Σ_{k=1}^{5} 1/(a_k a_{k+1}) = 5/96일 때 Σ_{k=1}^{15} a_k의 값은?

## 풀이
1. **[L035]** d ≠ 0이므로 a₆ ≠ a₈, |a₆| = a₈ → a₆ + a₈ = 0 → a₇ = 0. a_n = (n − 7)d이고 a₆ = −d < 0이어야 하니 d > 0.
2. **[L016]** Σ 1/(a_k a_{k+1}) = (1/d)(1/a₁ − 1/a₆) = (1/d)(−1/(6d) + 1/d) = 5/(6d²) = 5/96 → d² = 16, d = 4.
3. Σ_{k=1}^{15} a_k = 15·a₈ = 15·4 = 60.

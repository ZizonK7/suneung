## 문제 요약
|a_1| = 2, |a_{n+1}| = 2|a_n|, Σ_{n=1}^{10} a_n = −14일 때 a_1 + a_3 + a_5 + a_7 + a_9는?

## 풀이
1. |a_n| = 2^n이고 부호만 모른다.
2. **[L102]** 2^10 = 1024 > 2 + 4 + … + 512 = 1022이므로 합의 부호는 a_10이 정한다 → a_10 = −1024. 나머지 아홉 항의 합 = 1010.
3. 1022 − 1010 = 12 = 2 × (음수 항 절댓값 합) → 음수 항 절댓값 합 6 = 2 + 4 (이진 표현이 유일) → a_1 = −2, a_2 = −4, 나머지 양수.
4. a_1 + a_3 + a_5 + a_7 + a_9 = −2 + 8 + 32 + 128 + 512 = 678.

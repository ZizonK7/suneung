## 문제 요약
최고차항 계수 1인 사차함수 f, (0, ∞)에서 g ≥ 0. (가) x ≤ −3이면 f(x) ≥ f(−3). (나) x > −3이면 g(x + 3){f(x) − f(0)}² = f′(x). ∫₄⁵ g(x)dx = q/p일 때 p + q는?

## 풀이
1. (나)에서 x > −3이면 x + 3 > 0이라 g(x + 3) ≥ 0 → f′(x) ≥ 0. x = 0을 넣으면 f′(0) = 0.
2. **[L019]** (−3, ∞)에서 f′ ≥ 0인데 f′(0) = 0이므로 0은 f′의 중근 → f′ = 4x²(x − a), a ≤ −3.
3. (가): a < −3이면 f는 (a, −3)에서 증가해 f(a) < f(−3)이 된다. 그러므로 a = −3, f′ = 4x²(x + 3), f(x) − f(0) = x⁴ + 4x³.
4. **[L115]** F(x) = f(x) − f(0)이라 하면 F′ = f′이므로 g(x + 3) = F′/F². 
   ∫₄⁵ g(x)dx = ∫₁² F′(x)/F(x)² dx = [−1/F]₁² = 1/F(1) − 1/F(2) = 1/5 − 1/48 = 43/240.
5. p + q = 240 + 43 = 283.

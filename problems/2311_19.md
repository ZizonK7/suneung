## 문제 요약
2x³ − 6x² + k = 0의 서로 다른 양의 실근이 2개가 되는 정수 k의 개수는?

## 풀이
1. k = −2x³ + 6x² = h(x)로 분리한다. [L064]
2. h′(x) = −6x(x − 2) → 극소 h(0) = 0, 극대 h(2) = 8.
3. x > 0에서 y = k와 두 번 만나려면 0 < k < 8 → 정수 7개.

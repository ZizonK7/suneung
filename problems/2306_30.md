## 문제 요약
양수 a에 대하여 f(x) = (x² − ax)/eˣ. 실수 t에 대하여 x에 대한 방정식 f(x) = f′(t)(x − t) + f(t)(곡선 위 x = t에서의 접선과의 교점)의 서로 다른 실근의 개수를 g(t)라 하자. g(5) + lim_{t→5} g(t) = 5일 때, lim_{t→k−} g(t) ≠ lim_{t→k+} g(t)인 모든 실수 k의 값의 합은 q/p이다. p + q는? (p, q는 서로소인 자연수)

## 풀이
1. f′ = −{x² − (a + 2)x + a}e^{−x}, f″ = {x² − (a + 4)x + 2a + 2}e^{−x}. f″의 판별식 a² + 8 > 0이라 변곡점 p₁ < p₂가 있고, 임계점 c₁ < c₂는 x² − (a + 2)x + a = 0의 두 근(c₁ + c₂ = a + 2). x → −∞에서 f → ∞, x → ∞에서 f → 0⁺.
2. **[L100]** 접선은 변곡점에서만 곡선을 뚫고 지나간다. t가 변곡점 근처이면 접점 가까이에 교점이 하나 더 있다가 t = 변곡점에서 접점과 합쳐져 삼중근이 된다. 그래서 변곡점에서 g는 좌우극한보다 1 작다.
3. **[L093]** lim_{t→5} g(t)가 존재하는데 g(5) + lim g = 5(홀수)이면 g는 t = 5에서 연속일 수 없다. 좌우극한이 같고 함숫값만 다른 고립 불연속점이므로 t = 5는 변곡점이고 g(5) = 2, lim g = 3. f″(5) = 0 → 25 − 5(a + 4) + 2a + 2 = 0 → a = 7/3(p₁ = 4/3, p₂ = 5).
4. **[L014]** 접선의 기울기 f′(t)의 부호가 바뀌는 임계점 c₁, c₂에서는 x → ∞ 쪽 끝 행동이 바뀐다. 기울기가 음이면 접선은 −∞로, 양이면 +∞로 가므로 점근선 y = 0에 다가가는 f와 먼 곳에서 새로 만나는지가 달라진다. 수치 확인: t < c₁에서 1, c₁ < t < c₂에서 2(p₁ = 4/3에서만 1), t > c₂에서 3(p₂ = 5에서만 2).
5. 좌우극한이 다른 k는 c₁, c₂뿐이고(변곡점은 좌우극한이 같다) 합은 a + 2 = 13/3. p + q = 3 + 13 = 16.
6. 검산: a = 7/3에서 접선과의 차를 (x − t)²로 나눈 식의 부호 변화를 [−30, 10⁹]에서 세어 위 표를 확인했다.

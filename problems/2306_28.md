## 문제 요약
최고차항의 계수가 1/2인 삼차함수 f에 대하여 g(x) = ln|f(x)| (f(x) ≠ 0), g(x) = 1 (f(x) = 0). (가) g는 x ≠ 1인 모든 실수에서 연속. (나) g는 x = 2에서 극대이고, |g(x)|는 x = 2에서 극소. (다) 방정식 g(x) = 0의 서로 다른 실근은 3개. g의 극솟값은? (① ln(13/27) ② ln(16/27) ③ ln(19/27) ④ ln(22/27) ⑤ ln(25/27))

## 풀이
1. **[N6B2]** f의 근 c에서는 ln|f(x)| → −∞이므로 g는 c에서 불연속이다. (가)에서 f의 실근은 x = 1 하나뿐이다(삼차함수라 실근이 반드시 있다). 그래서 x > 1에서 f > 0.
2. **[N6B3]** g가 x = 2에서 극대인데 |g|가 x = 2에서 극소이므로 g(2) ≤ 0, 곧 0 < f(2) ≤ 1. 또 |f|가 x = 2에서 극대이고 x > 1에서 |f| = f이므로 f′(2) = 0이고 x = 2는 f의 극대점이다.
3. **[L014]** g(x) = 0 ⇔ f(x) = ±1. f = −1의 근은 x < 1에서 하나. f = 1이 두 근을 가져야 하는데 f의 극댓값 f(2) ≤ 1이므로 f(2) = 1(수평선 y = 1이 극대점에서 접함)일 때만 가능하다. 이때 근은 x = 2와 극소점 뒤의 하나.
4. **[L015]** f − 1은 (x − 2)²을 인수로 가지므로 f(x) = (1/2)(x − 2)²(x − k) + 1. f(1) = 0 → (1 − k)/2 + 1 = 0 → k = 3.
5. **[L060]** f′(x) = (1/2)(x − 2)(3x − 8)이므로 다른 극점은 x = 8/3(극소). f(8/3) = 1 − 2/27 = 25/27 > 0이라 실근이 1 하나라는 조건과도 맞다.
6. g의 극솟값은 ln f(8/3) = ln(25/27). 검산: f = 1의 근 2, 3과 f = −1의 근 하나로 g = 0의 실근 3개.

## 문제 요약
최고차항 계수 1인 삼차함수 f. (가) f(x) = 0의 서로 다른 실근은 2개. (나) g(x) = −f(x)(f(x) ≥ 0), 7f(x)(f(x) < 0)일 때, 어떤 실수 a에 대하여 h(x) = g(x) + |(x − 1)(x − a)(x − 4 + a)|가 실수 전체에서 미분가능. f(0)의 최댓값과 최솟값의 곱은?

## 풀이
1. **[L147]** 서로 다른 실근 2개인 삼차식은 중근 하나와 단순근 하나: f = (x − α)²(x − β), α ≠ β.
2. g는 f의 부호가 바뀌지 않는 α에서는 미분가능하고, 단순근 β에서만 꺾인다. β 근처 f의 부호는 x − β와 같아 g′(β−) = 7f′(β), g′(β+) = −f′(β). 꺾임(우미분 − 좌미분) = −8f′(β) = −8(β − α)² < 0.
3. **[L025]** p(x) = (x − 1)(x − a)(x − 4 + a)라 하면 |p|는 p의 단순근 r에서만 꺾이고 꺾임은 +2|p′(r)| > 0, 중근·삼중근에서는 미분가능.
4. **[L148]** h가 미분가능하려면 꺾이는 점이 모두 상쇄되어야 한다: |p|의 꺾이는 점은 β 하나뿐이고 2|p′(β)| = 8(β − α)².
   - p의 근 1, a, 4 − a 중 둘이 같아야 한다(세 근이 다르면 꺾임이 셋, 삼중근은 불가).
   - a = 1 또는 3: p = (x − 1)²(x − 3), β = 3, p′(3) = 4 → (3 − α)² = 1 → α = 2, 4.
   - a = 2: p = (x − 1)(x − 2)², β = 1, p′(1) = 1 → (1 − α)² = 1/4 → α = 1/2, 3/2.
5. f(0) = −α²β: −12, −48, −1/4, −9/4. 최댓값 −1/4, 최솟값 −48, 곱 12.
6. 검산: 네 경우 모두 h의 좌우 차분몫이 일치함을 수치로 확인.

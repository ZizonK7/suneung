## 문제 요약
최고차항 계수 1인 삼차함수 f가 0이 아닌 모든 실수 x에 대해 f′(x)/2 + x² − 2 ≤ {f(2x) − f(0)}/(2x) ≤ x⁴를 만족할 때 f′(10)은?

## 풀이
1. f(x) = x³ + ax² + bx + c이면 가운데 = 4x² + 2ax + b, 왼쪽 = (5/2)x² + ax + b/2 − 2. 부등식은
   (ⅰ) (3/2)x² + ax + b/2 + 2 ≥ 0, (ⅱ) x⁴ − 4x² − 2ax − b ≥ 0.
2. **[L140]** 양변이 다항식이라 x → 0으로 보내면 x = 0에서도 성립한다. (ⅰ)에서 b ≥ −4.
3. **[L139]** (ⅱ)에 x와 −x를 넣고 더해 2로 나누면 x⁴ − 4x² − b ≥ 0. 홀수차항 a가 사라진다.
4. **[L041]** b ≤ x⁴ − 4x²의 최솟값 = −4 (x = ±√2). 2와 합쳐 b = −4.
5. b = −4이면 (ⅱ)는 (x² − 2)² − 2ax ≥ 0. x = √2, −√2를 넣으면 −2√2a ≥ 0, 2√2a ≥ 0 → a = 0. (ⅰ)은 (3/2)x² ≥ 0으로 성립.
6. f′(10) = 300 + 20a + b = 296. 검산: a = 0, b = −4에서 두 부등식을 수치로 확인.

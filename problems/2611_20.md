## 문제 요약
a₁ = 7, n ≥ 2에서 Σ_{k=1}^n a_k = (2/3)a_n + n²/6 − n/6 + 10. 빈칸 (가) f(n), (나) p, (다) q를 채워 pq/f(12)를 구한다.

## 풀이
1. **[L037]** a_{n+1} = S_{n+1} − S_n = (2/3)(a_{n+1} − a_n) + {(n+1)² − n²}/6 − 1/6 → (가) = n/3. 정리하면 2a_n + a_{n+1} = n (n ≥ 2). f(12) = 4.
2. n = 2 대입: 7 + a₂ = (2/3)a₂ + 1/3 + 10 → a₂ = 10 = p.
3. **[L106]** Σ_{k=1}^{12} a_k + Σ_{k=1}^5 a_{2k+1} = a₁ + a₂ + Σ_{k=1}^5 (2a_{2k+1} + a_{2k+2})로 묶으면 각 묶음이 2k + 1.
4. q = 17 + (3 + 5 + 7 + 9 + 11) = 52. pq/f(12) = 520/4 = 130.

## 문제 요약
첫째항과 공비가 각각 0이 아닌 두 등비수열 {a_n}, {b_n}에 대하여 Σa_n, Σb_n이 각각 수렴하고 Σa_nb_n = (Σa_n)(Σb_n), 3Σ|a_{2n}| = 7Σ|a_{3n}|이다. Σ(b_{2n−1} + b_{3n+1})/b_n = S일 때 120S는?

## 풀이
1. a_n = a·r^{n−1}, b_n = b·s^{n−1}(|r|, |s| < 1)로 둔다.
2. **[L168]** a_nb_n은 첫째항 ab, 공비 rs인 등비수열 → ab/(1 − rs) = ab/{(1 − r)(1 − s)} → 1 − rs = 1 − r − s + rs → r + s = 2rs.
3. **[L168]** |a_{2n}|은 첫째항 |a||r|, 공비 r², |a_{3n}|은 첫째항 |a|r², 공비 |r|³. t = |r|로 3t/(1 − t²) = 7t²/(1 − t³) → 3(1 + t + t²) = 7t(1 + t) → 4t² + 4t − 3 = 0 → t = 1/2.
4. s(2r − 1) = r에서 r = 1/2이면 0 = 1/2로 모순 → r = −1/2, s = 1/4.
5. **[L168]** b_{2n−1}/b_n = s^{n−1}, b_{3n+1}/b_n = s^{2n+1} → S = 1/(1 − s) + s³/(1 − s²) = 4/3 + 1/60 = 81/60. 120S = 162.

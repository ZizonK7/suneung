## 문제 요약
삼각형 ABC: (가) 3sinA = 2sinB, (나) cosB = cosC. 외접원 넓이 9π일 때 삼각형 넓이는?

## 풀이
1. R = 3. **[L028]** 변 = 2R·sin(대각) → (가)는 3a = 2b.
2. (나) B = C → b = c. b = c = 3t, a = 2t로 두면 cosB = (a/2)/c = 1/3, sinB = 2√2/3.
3. b = 2R·sinB = 4√2, a = 8√2/3, 높이 = √(32 − 32/9) = 16/3.
4. 넓이 = (1/2)(8√2/3)(16/3) = 64√2/9.

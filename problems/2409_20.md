## 문제 요약
AB = 2, AD = 1, ∠DAB = 2π/3, ∠BCD = 3π/4인 사각형 ABCD. 삼각형 BCD의 외접원의 반지름 R₁, 삼각형 ABD의 외접원의 반지름 R₂. 빈칸 풀이: R₁ = (√2/2)·BD, R₂ = (가)·BD, BD² = 2² + 1² − ((나)), R₁R₂ = (다). (가), (나), (다)를 p, q, r라 할 때 9(pqr)²은?

## 풀이
1. **[L028]** 두 삼각형이 현 BD를 공유하므로 각 외접원에서 BD = 2R·sin(BD의 맞은각). R₁ = BD/(2sin(3π/4)) = (√2/2)BD, R₂ = BD/(2sin(2π/3)) = (√3/3)BD → p = √3/3.
2. **[L071]** BD² = 2² + 1² − 2·2·1·cos(2π/3) = 5 − (−2) = 7 → q = −2.
3. R₁R₂ = (√2/2)(√3/3)·7 = 7√6/6 = r. pqr = −7√2/3, 9(pqr)² = 9·98/9 = 98.

## 문제 요약
원에 내접하는 ABCD, AB : CD = 1 : 3, 직선 AB와 CD의 교점 P. PB : PC : BC = 7 : 5 : √14, AD = 4√13일 때 삼각형 BPC의 외접원 반지름을 구하는 빈칸 (가) l = p·k, (나) 닮음비 1 : q, (다) R = r. p + q + r은?

## 풀이
1. cosθ = (49 + 25 − 14)/70 = 6/7 (문제에 주어짐).
2. **[L029]** ∠PBC = π − ∠ABC = ∠ADC, 공통각 P → △PBC ∽ △PDA. PB : PC = PD : PA.
3. PB = 7k, PC = 5k, PA = 7k + l, PD = 5k + 3l. 7k(7k + l) = 5k(5k + 3l) → l = 3k. p = 3.
4. 닮음비 PB : PD = 7k : 14k = 1 : 2. q = 2. BC = AD/2 = 2√13.
5. **[L028]** sinθ = √13/7, 2R = BC/sinθ = 14 → R = 7. r = 7.
6. p + q + r = 12.

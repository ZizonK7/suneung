## 문제 요약
최고차항 계수 1인 삼차함수 f, g(x) = |f(2/(1 + e^{−x}))|가 실수 전체에서 미분가능. (가) g는 x = 0에서 극소, g(0) > 0. (나) g′(ln3) < 0, |g′(−ln3)| = (3/8)g(−ln3). g(0)의 최솟값 q/p, p + q는?

## 풀이
1. **[NE4]** t = h(x) = 2/(1 + e^{−x})는 증가, 치역 (0, 2). h(0) = 1, h(ln3) = 3/2, h(−ln3) = 1/2, h′ = h(2 − h)/2 > 0 → h′(−ln3) = 3/8. 그래서 g는 t ∈ (0, 2)에서 |f(t)|를 보는 문제다.
2. **[L025]** |f|가 미분가능하려면 (0, 2) 안의 f의 근은 접하는 근이어야 한다.
3. **[L060]** (가) |f(t)|가 t = 1에서 극소, f(1) ≠ 0 → f′(1) = 0. f′ = 3(t − 1)(t − α).
   - f(1) > 0(f 극소)이면 (0, 2)에서 f > 0이고 t = 3/2에서 f′ > 0 → g′(ln3) > 0, (나)에 모순.
   - 따라서 f(1) < 0, t = 1은 f의 극대, α > 1. (0, 2)에서 f < 0이어야 한다(근이 생기면 단순근).
4. (나) g′(ln3) < 0 ⇔ −f′(3/2) < 0 → α < 3/2. |f′(1/2)| = |f(1/2)| → f(1/2) = −(3/2)(α − 1/2).
   f = t³ − (3/2)(1 + α)t² + 3αt + c에서 c = 1 − 21α/8, f(1) = 1/2 − 9α/8.
5. (0, 2)에서 f < 0: α < 2이므로 f(2) = 3 − 21α/8 ≤ 0 → α ≥ 8/7(t = 2는 치역 밖이라 등호 허용).
6. g(0) = −f(1) = 9α/8 − 1/2는 α = 8/7에서 최소 11/14 → 25.

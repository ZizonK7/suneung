## 문제 요약
수열 {a_n}의 첫째항부터 제m항까지의 합 S_m이 모든 자연수 m에 대해 S_m = Σ_{n=1}^{∞} (m + 1)/{n(n + m + 1)}일 때 a₁ + a₁₀ = q/p(서로소인 자연수)이다. p + q는?

## 풀이
1. **[L016]** (m + 1)/{n(n + m + 1)} = 1/n − 1/(n + m + 1). 분자가 두 분모 인수의 차라 역수의 차로 쪼갠다.
2. **[L016]** 간격이 m + 1인 망원합이라 부분합 Σ_{n=1}^{N}에서 앞쪽 1/1, …, 1/(m + 1)이 남고 뒤쪽 m + 1개 항 1/(N + 1), …, 1/(N + m + 1)이 빠진다.
3. **[L021]** N → ∞이면 뒤쪽 m + 1개 항이 0으로 가서 S_m = 1 + 1/2 + … + 1/(m + 1).
4. **[L037]** a₁ = S₁ = 3/2, a₁₀ = S₁₀ − S₉ = 1/11. 합 35/22 → p + q = 57.

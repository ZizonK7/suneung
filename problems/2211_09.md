## 문제 요약
직선 y = 2x + k가 두 함수 y = (2/3)^{x+3} + 1, y = (2/3)^{x+1} + 8/3의 그래프와 만나는 점을 각각 P, Q라 하자. PQ = √5일 때 상수 k는? (그림에서 Q가 P의 오른쪽 위)

## 풀이
1. **[L092]** P, Q는 기울기 2인 직선 위에 있으므로 PQ = √5 = |Δx|·√(1 + 2²) → Δx = 1, Δy = 2. Q = P + (1, 2).
2. **[L005]** P의 x좌표를 p라 하면 (2/3)^{p+3} + 1 + 2 = (2/3)^{p+2} + 8/3. t = (2/3)^{p+2}로 놓으면 (2/3)t + 3 = t + 8/3 → t = 1 → p = −2.
3. P(−2, 5/3) → k = 5/3 + 4 = 17/3. Q(−1, 11/3)도 직선 위에 있다.

## 문제 요약
f(x) = x²/2 − x + ln(1 + x)와 양수 t에 대하여, 점 (s, f(s)) (s > 0)에서 y축에 내린 수선의 발과 곡선 y = f(x) 위의 점 (s, f(s))에서의 접선이 y축과 만나는 점 사이의 거리가 t가 되도록 하는 s의 값을 g(t)라 하자. ∫_{1/2}^{27/4} g(t)dt의 값은?

## 풀이
1. **[L048]** 접점 (s, f(s))의 접선의 y절편은 f(s) − s·f′(s), 수선의 발은 (0, f(s)). 거리 = s·|f′(s)|.
2. f′(s) = s − 1 + 1/(1 + s) = s²/(1 + s) > 0 → t = h(s) = s³/(1 + s). h는 s > 0에서 증가하므로 g = h⁻¹.
3. **[L051]** h(1) = 1/2, h(3) = 27/4. ∫_{1/2}^{27/4} g = 3·(27/4) − 1·(1/2) − ∫_1^3 h(s)ds.
4. **[L079]** s³/(1 + s) = s² − s + 1 − 1/(1 + s) → ∫_1^3 = 26/3 − 4 + 2 − ln2 = 20/3 − ln2.
5. 81/4 − 1/2 − 20/3 + ln2 = 157/12 + ln2. 수치 적분으로 13.7765 확인.

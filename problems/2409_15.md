## 문제 요약
최고차항 계수 1인 삼차함수 f. g(x) = f(x+3){f(x)+1}/f(x) (f(x)≠0), 3 (f(x)=0).
lim_{x→3} g(x) = g(3) − 1일 때 g(5)는?

## 풀이
1. f(3)≠0이면 g는 x=3 근처에서 연속이라 극한값 = 함숫값이 되어 모순이다. 그래서 f(3)=0, g(3)=3, 극한값 2. [L001]
2. 분모 f(x)→0이므로 f(6)·{f(3)+1} = f(6) = 0. [L002, L003]
3. f = (x−3)(x−6)(x−a) → 극한 = 3(6−a)/(−3(3−a)) = 2 → a = 4. (a=3이면 발산)
4. g(5) = f(8)(f(5)+1)/f(5) = 40·(−1)/(−2) = 20.

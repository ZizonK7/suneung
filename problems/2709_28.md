## 문제 요약
중심 O, 반지름 2인 원 C와 OA = 5인 점 A, 선분 OA와 C의 교점 B. A를 지나고 O를 지나지 않는 직선이 C와 두 점 P, Q(AP < AQ)에서 만난다. Q를 포함하지 않는 호 BP와 선분 AB, AP로 둘러싸인 도형의 넓이를 t, ∠OPQ = f(t)라 하면 f는 미분가능하다. tan f(k) = 3/2인 k에 대해 f′(k)는?

## 풀이
1. θ = ∠POB를 매개변수로 둔다. O를 원점, A = (5, 0)이면 P = (2cosθ, 2sinθ).
2. **[L143]** 넓이 = 삼각형 OPA − 부채꼴 OBP: t = 5sinθ − 2θ, dt/dθ = 5cosθ − 2.
3. **[L142]** ∠OPQ는 삼각형 OPA에서 P의 외각이므로 f = θ + α, α = ∠OAP, tanα = 2sinθ/(5 − 2cosθ).
4. **[L124]** tan(θ + α)를 펼치면 tan f = 5sinθ/(5cosθ − 2). 이 값이 3/2 → 10sinθ = 15cosθ − 6, 325cos²θ − 180cosθ − 64 = 0 → cosθ = 4/5, sinθ = 3/5(tanθ = 3/4, tanα = 6/17로 확인).
5. **[L049]** f′(t) = (df/dθ)/(dt/dθ). dα/dθ = (10cosθ − 4)/(29 − 20cosθ) = 4/13 → df/dθ = 17/13. dt/dθ = 2 → f′(k) = 17/26. 수치 미분으로 검산.

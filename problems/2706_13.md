## 문제 요약
두 다항함수 f, g가 모든 실수 x에서 f(x) > g(x)이고 f(1) = g(1) + 1이다. 양수 t에 대하여 두 곡선 y = f(x), y = g(x)와 두 직선 x = 0, x = t로 둘러싸인 도형의 넓이를 S(t)라 할 때 S′(t) = t² − 2t + a(a는 상수)이다. ㄱ. a = 1 ㄴ. S(3) = 6 ㄷ. 두 곡선과 두 직선 x = −2, x = 2로 둘러싸인 도형의 넓이는 S(4)와 같다. 옳은 것만 고르면?

## 풀이
1. **[L078]** h = f − g > 0이므로 절댓값 없이 S(t) = ∫_0^t h(x)dx.
2. **[L069]** 미분하면 S′(t) = h(t) = t² − 2t + a (t > 0).
3. **[N3A1]** h는 다항식이고 t > 0인 모든 t에서 t² − 2t + a와 같으므로 실수 전체에서 h(x) = x² − 2x + a.
4. h(1) = f(1) − g(1) = 1 → a − 1 = 1, a = 2. ㄱ 거짓.
5. S(3) = ∫_0^3 (x² − 2x + 2)dx = 9 − 9 + 6 = 6. ㄴ 참.
6. ㄷ의 넓이는 ∫_{−2}^{2} h = 2(8/3 + 4) = 40/3, S(4) = 64/3 − 16 + 8 = 40/3. 참. (h = (x − 1)² + 1은 x = 1에 대칭이고 [−2, 2]를 x = 1에 대칭이동하면 [0, 4]라서 계산 없이도 같다.) 답 ⑤.

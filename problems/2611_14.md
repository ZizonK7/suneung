## 문제 요약
AB = 3, BC = 4, ∠B = π/2. AD = 2인 원(중심 A)이 AC와 만나는 점 E, 호 EF 위의 G를 CG = 2√6이 되게 잡는다. 세 점 C, E, G를 지나는 원 위의 H가 ∠HCG = ∠BAC일 때 GH는?

## 풀이
1. AC = 5, AE = AG = 2, CE = 3. sin∠BAC = 4/5.
2. **[L071]** 삼각형 ACG에서 cos∠CAG = (25 + 4 − 24)/(2·5·2) = 1/4. 이등변 AEG에서 EG² = 4 + 4 − 8·(1/4) = 6 → EG = √6.
3. **[L071]** 삼각형 CEG(3, √6, 2√6)에서 cos∠CEG = (9 + 6 − 24)/(2·3·√6) = −3/(2√6) → sin∠CEG = √15/(2√6).
4. **[L028]** 원 CEG의 2R = CG/sin∠CEG = 24/√15. 같은 원의 현 GH의 원주각이 ∠HCG(사인 4/5)이므로 GH = 2R·(4/5) = 96/(5√15) = 32√15/25.

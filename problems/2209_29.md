## 문제 요약
이차함수 f에 대하여 g(x) = {f(x) + 2}e^{f(x)}가 (가) f(a) = 6인 a에 대하여 x = a에서 최댓값을 갖고, (나) x = b, x = b + 6에서 최솟값을 갖는다. f(x) = 0의 서로 다른 두 실근 α, β에 대하여 (α − β)²은? (a, b는 실수)

## 풀이
1. **[L065]** g = h(f(x)), h(t) = (t + 2)e^t로 보고 f의 치역에서 h를 읽는다. h′(t) = (t + 3)e^t → t = −3에서 최소 −e^{−3}, t > −3에서 증가, t → −∞이면 h → 0⁻, t → ∞이면 h → ∞.
2. f가 위로 볼록(최고차 계수 양수)이면 치역이 위로 열려 g에 최댓값이 없다. 따라서 f는 아래로 볼록, 치역 (−∞, M]. h(6) > 0이고 t ≥ −3에서 h가 증가하므로 g의 최댓값은 h(M)이고, f(a) = 6에서 최대 → M = 6, a는 꼭짓점.
3. 치역에 −3이 들어 있으므로 g의 최솟값은 h(−3)이고, 최소점은 f(x) = −3인 x다 → f(b) = f(b + 6) = −3.
4. **[L073]** 수평선 y = −3과 포물선의 두 교점은 축에 대칭 → 꼭짓점 a = b + 3. f(x) = 6 − k(x − a)², f(a + 3) = 6 − 9k = −3 → k = 1.
5. f = 0의 근 a ± √6 → (α − β)² = 24.

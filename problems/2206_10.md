## 문제 요약
n ≥ 2인 자연수 n에 대해 y = log_n x와 y = −log_n(x + 3) + 1의 교점의 x좌표가 1과 2 사이가 되게 하는 모든 n의 합은?

## 풀이
1. **[L052]** log_n x + log_n(x + 3) = 1 → x(x + 3) = n (x > 0).
2. **[L064]** n을 분리: y = x(x + 3)은 x > 0에서 증가하므로 교점은 하나이고, 1 < x < 2 ⇔ 4 < n < 10.
3. n = 5, 6, 7, 8, 9 → 합 35.

## 문제 요약
첫째항이 자연수, a_{n+1} = a_n + 1(a_n 홀수), a_n/2(a_n 짝수). a₂ + a₄ = 40이 되는 모든 a₁의 합은?

## 풀이
1. **[L107]** a₂를 문자로 두고 홀짝으로 갈라 a₄를 쓴다.
   - a₂ 홀수: a₃ = a₂ + 1(짝수), a₄ = (a₂ + 1)/2 → 3a₂ + 1 = 80, 자연수 아님.
   - a₂ 짝수, a₃ = a₂/2 홀수: a₄ = a₂/2 + 1 → a₂ = 26(a₃ = 13 홀수 ✓).
   - a₂ 짝수, a₃ 짝수: a₄ = a₂/4 → a₂ = 32(a₃ = 16 ✓).
2. 거꾸로 a₁: a₂ = 26 ← a₁ = 25(홀수) 또는 52(짝수). a₂ = 32 ← a₁ = 31 또는 64.
3. 합 25 + 52 + 31 + 64 = 172 (전수 확인 일치).

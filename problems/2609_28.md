## 문제 요약
삼차함수 f, 미분가능한 g. f(x) = g(x) − tan g(x).
(가) f(0) = 0, f″(π) = 0. (나) sin g(π) = 0, lim_{x→∞} g(x) = 3π/2. g′(0)·{g(0)}²은?

## 풀이
1. **[L022]** tan g(x)가 늘 정의되므로 g는 π/2 + nπ를 지나지 못한다. lim g = 3π/2이므로 치역은 (π/2, 3π/2) 또는 (3π/2, 5π/2)이다.
   h(y) = y − tan y는 각 구간에서 감소하는 일대일 함수다(h′ = −tan²y).
2. sin g(π) = 0 → g(π) = π(첫 구간) 또는 2π(둘째 구간).
3. **[L023]** h′(g(π)) = 0이므로 f′(π) = 0. 여기에 f″(π) = 0을 더하면 **[L024]** f(x) = f(π) + a(x − π)³이다.
4. 구간 판정:
   - 첫 구간이면 f(π) = π이고, f(0) = 0에서 a = 1/π² > 0이다. 그러면 x→∞에서 f→∞, g→π/2가 되어 모순이다.
   - 둘째 구간이면 f(π) = 2π, a = 2/π² > 0이고, x→∞에서 f→∞, g→3π/2로 맞는다.
5. **[L009]** g(0) = y₀는 y₀ = tan y₀를 만족해 구할 수 없지만, g′(0) = f′(0)/h′(y₀) = −f′(0)/y₀²이다.
   따라서 g′(0)·y₀² = −f′(0) = −3a·π² = −6.

## 문제 요약
실수 전체에서 연속인 f와 최고차항 계수 1인 삼차함수 g가 g(x) = −∫_0^x f(t)dt (x < 0), ∫_0^x f(t)dt (x ≥ 0)를 만족한다. <보기> ㄱ. f(0) = 0 ㄴ. f는 극댓값을 갖는다. ㄷ. 2 < f(1) < 4이면 f(x) = x의 서로 다른 실근은 3개. 옳은 것은?

## 풀이
1. **[L026]** 두 식 모두 x = 0에서 0 → g(0) = 0.
2. **[L069]** 양변을 미분하면 g′(x) = −f(x) (x < 0), f(x) (x > 0).
3. **[L091]** f가 x = 0에서 연속이므로 f(0) = lim_{x→0+} g′(x) = g′(0), f(0) = lim_{x→0−} (−g′(x)) = −g′(0) → g′(0) = 0 = f(0). ㄱ 참.
4. g(x) = x³ + ax², f(x) = 3x² + 2ax (x ≥ 0), −3x² − 2ax (x < 0).
5. ㄴ: a = 0이면 f(x) = 3x|x|로 증가함수, 극댓값이 없다. 거짓(a ≠ 0이면 x = 0에서 극대).
6. **[L013]** ㄷ: f(1) = 3 + 2a ∈ (2, 4) → −1/2 < a < 1/2. f(x) = x를 구간별로 푼다. x = 0은 근. x > 0: 3x + 2a = 1 → x = (1 − 2a)/3 > 0. x < 0: −3x − 2a = 1 → x = −(1 + 2a)/3 < 0. 각 근이 자기 구간 안에 있으므로 3개. 참.
7. 답 ㄱ, ㄷ. a 몇 값에서 수치로 근 3개 확인.

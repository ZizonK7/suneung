## 문제 요약
수직선 위를 움직이는 점 P의 시각 t(t ≥ 0)에서의 속도 v(t)와 가속도 a(t)가 (가) 0 ≤ t ≤ 2일 때 v(t) = 2t³ − 8t, (나) t ≥ 2일 때 a(t) = 6t + 4를 만족한다. 시각 t = 0에서 t = 3까지 P가 움직인 거리는?

## 풀이
1. **[L058]** (가)에서 v(2) = 16 − 16 = 0. t ≥ 2에서 v(t) = v(2) + ∫_2^t (6s + 4)ds = 3t² + 4t − 20 = (t − 2)(3t + 10).
2. **[L067]** 0 ≤ t ≤ 2에서 v = 2t(t − 2)(t + 2) ≤ 0, 2 < t ≤ 3에서 v > 0. t = 2에서 끊는다.
   - ∫_0^2 (8t − 2t³)dt = 16 − 8 = 8.
   - ∫_2^3 (3t² + 4t − 20)dt = 19 + 10 − 20 = 9.
3. 움직인 거리 = 8 + 9 = 17.

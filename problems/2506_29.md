## 문제 요약
f(x) = x³/3 − x² + ln(1 + x²) + a. 양수 b, c에 대해 g = f(x)(x ≥ b), −f(x − c)(x < b)가 실수 전체에서 미분가능. a + b + c = p + q·ln2일 때 30(p + q)는?

## 풀이
1. f′ = x² − 2x + 2x/(1 + x²) = x²(x − 1)²/(1 + x²) ≥ 0, f′ = 0은 x = 0, 1.
2. **[L040]** x = b에서 f(b) = −f(b − c), f′(b) = −f′(b − c).
3. **[L122]** f′ ≥ 0이므로 f′(b) = −f′(b − c)이면 둘 다 0 → b, b − c ∈ {0, 1}. b > 0, c > 0 → b = 1, b − c = 0, c = 1.
4. f(1) = −f(0): 1/3 − 1 + ln2 + a = −a → a = 1/3 − (ln2)/2.
5. a + b + c = 7/3 − (1/2)ln2 → p + q = 11/6, 30(p + q) = 55.

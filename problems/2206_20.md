## 문제 요약
실수 a와 f(x) = x³ − 12x² + 45x + 3에 대하여 g(x) = ∫_a^x {f(x) − f(t)}·{f(t)}⁴ dt가 오직 하나의 극값을 갖도록 하는 모든 a의 값의 합은?

## 풀이
1. **[L069]** 피적분함수의 f(x)는 t와 무관하므로 적분 밖으로 뺀다. g(x) = f(x)∫_a^x {f(t)}⁴dt − ∫_a^x {f(t)}⁵dt.
2. **[L069]** 곱의 미분과 함께 미분하면 g′(x) = f′(x)∫_a^x {f(t)}⁴dt + {f(x)}⁵ − {f(x)}⁵ = f′(x)∫_a^x {f(t)}⁴dt.
3. **[L026]** F(x) = ∫_a^x {f(t)}⁴dt는 F(a) = 0이고, {f(t)}⁴ ≥ 0(0이 되는 점은 고립점)이라 증가한다. 그래서 F의 부호는 x − a의 부호와 같다.
4. **[L053]** f′(x) = 3(x − 3)(x − 5)이므로 g′의 부호는 (x − 3)(x − 5)(x − a)의 부호와 같다. a ≠ 3, 5이면 부호가 세 번 바뀌어 극점이 셋(극대 하나와 극소 둘, 또는 반대)이고, 극댓값과 극솟값은 다르므로 극값이 하나가 아니다.
5. **[L055]** a = 3이면 g′ ∝ (x − 3)²(x − 5)라 x = 3에서 부호가 바뀌지 않아 극값은 x = 5의 하나뿐이다. a = 5도 같다. 합 3 + 5 = 8.
6. 검산: sympy로 g′ = f′(x)F(x) 확인, 수치로 a = 0, 4, 7에서 부호 변화 3번, a = 3, 5에서 1번.

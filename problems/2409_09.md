## 문제 요약
0 ≤ x ≤ 2π일 때 부등식 cos x ≤ sin(π/7)을 만족시키는 x의 범위가 α ≤ x ≤ β이다. β − α는?

## 풀이
1. **[L099]** sin(π/7) = cos(π/2 − π/7) = cos(5π/14). 우변을 cos 값으로 바꿔 교점을 바로 쓴다.
2. **[L034]** y = cos x와 수평선의 두 교점은 x = π에 대해 대칭: α = 5π/14, β = 2π − 5π/14. 그 사이에서 cos x가 더 작다.
3. β − α = 2π − 5π/7 = 9π/7.

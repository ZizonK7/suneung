## 문제 요약
최고차항의 계수가 1/2인 삼차함수 f와 실수 t에 대하여 방정식 f′(x) = 0이 닫힌구간 [t, t + 2]에서 갖는 실근의 개수를 g(t)라 하자. (가) 모든 실수 a에 대하여 lim_{t→a+} g(t) + lim_{t→a−} g(t) ≤ 2. (나) g(f(1)) = g(f(4)) = 2, g(f(0)) = 1. f(5)는?

## 풀이
1. **[N6C1]** (나)에서 g가 2가 되므로 f′는 서로 다른 두 근 α < β를 갖는다. β − α < 2이면 [β − 2, α]에서 g = 2이고, t = β − 2에서 우극한 2, 좌극한 1로 합 3 → (가)에 모순. β − α > 2이면 g ≤ 1이라 (나)에 모순. 따라서 β = α + 2.
   - 이때 g(t) = 2는 t = α 하나뿐이고(좌우극한은 모두 1, 합 2), g(t) = 1 ⇔ t ∈ [α − 2, α + 2], t ≠ α.
2. (나) → f(1) = f(4) = α, f(0) ∈ [α − 2, α + 2]이고 f(0) ≠ α.
3. **[N6C2]** f(1) = f(4) = α이므로 f(x) − α = (1/2)(x − 1)(x − 4)(x − c).
4. **[L074]** f′ = 0의 두 근의 합 2(5 + c)/3, 곱 (4 + 5c)/3. (β − α)² = (합)² − 4(곱) = 4 → c² − 5c + 4 = 0 → c = 1 또는 4.
   - c = 1: f − α = (1/2)(x − 1)²(x − 4), f′의 근 1, 3 → α = 1. f(0) = 1 − 2 = −1 ∈ [−1, 3], ≠ 1. 적합.
   - c = 4: f − α = (1/2)(x − 1)(x − 4)², f′의 근 2, 4 → α = 2. f(0) = 2 − 8 = −6 ∉ [0, 4]. 부적합.
5. f(x) = 1 + (1/2)(x − 1)²(x − 4), f(5) = 1 + 8 = 9.

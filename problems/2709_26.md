## 풀이
1. y = 2/(x² + x)에서 y′ = −2(2x + 1)/(x² + x)², y′(1) = −3/2. 접선 l: y = 1 − (3/2)(x − 1).
2. **[L078]** 곡선은 아래로 볼록이라 [1, 2]에서 l보다 위. 넓이 = ∫_1^2 {2/(x² + x) − l}dx.
3. **[N11E1]** 2/(x² + x) = 2{1/x − 1/(x + 1)} → ∫_1^2 = 2[ln x − ln(x + 1)]_1^2 = 2ln(4/3).
4. ∫_1^2 l dx = 1 − (3/2)(1/2) = 1/4(사다리꼴). 넓이 = 2ln(4/3) − 1/4.

## 문제 요약
공차가 3인 등차수열 {aₙ}이 (가) a₅ × a₇ < 0, (나) Σ_{k=1}^{6} |a_{k+6}| = 6 + Σ_{k=1}^{6} |a_{2k}|를 만족할 때 a₁₀은?

## 풀이
1. **[L036]** 공차 > 0과 (가)에서 a₅ < 0 < a₇. a₇ 이후는 양수, a₄ 이전은 음수이고 a₆만 부호가 정해지지 않는다.
2. 좌변 a₇ + … + a₁₂, 우변 6 − a₂ − a₄ + |a₆| + a₈ + a₁₀ + a₁₂. 공통인 a₈, a₁₀, a₁₂를 지우면 a₇ + a₉ + a₁₁ = 6 − a₂ − a₄ + |a₆|.
3. **[L072]** 모두 a₆로 쓴다: a₇ + a₉ + a₁₁ = 3a₆ + 27, a₂ + a₄ = 2a₆ − 18.
   - a₆ ≥ 0: 3a₆ + 27 = 24 − a₆ → a₆ = −3/4, 모순.
   - a₆ < 0: 3a₆ + 27 = 24 − 3a₆ → a₆ = −1/2 (a₅ = −7/2, a₇ = 5/2로 (가) 만족).
4. a₁₀ = a₆ + 12 = 23/2.

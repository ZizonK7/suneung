## 문제 요약
f(x) = (k − |x|)e^{−x} (k > 0). 미분가능하고 모든 x에서 F′ = f, F ≥ f인 F에 대해 F(0)의 최솟값 g(k). g(1/4) + g(3/2) = pe + q일 때 100(p + q)는?

## 풀이
1. 구간별 원시함수: x ≥ 0에서 F = (x − k + 1)e^{−x} + C₁, x < 0에서 F = −(x + k + 1)e^{−x} + C₂.
2. **[L040]** x = 0에서 값 일치 → C₂ = C₁ + 2. F(0) = 1 − k + C₁이므로 C₁의 최솟값을 구하면 된다.
3. **[NH5]** F − f ≥ 0을 상수에 대한 조건으로 바꾼다.
   - x ≥ 0: φ = (2x − 2k + 1)e^{−x}는 x = k + ½까지 증가 후 0으로 감소 → 하한 min(1 − 2k, 0). C₁ ≥ max(2k − 1, 0).
   - x < 0: ψ = −(2x + 2k + 1)e^{−x}, ψ′ = (2x + 2k − 1)e^{−x}. k > ½이면 x = ½ − k에서 최소 −2e^{k−½} → C₁ ≥ 2e^{k−½} − 2. k ≤ ½이면 감소라 하한 ψ(0⁻) = −(2k + 1) → C₁ ≥ 2k − 1.
4. k = 1/4: C₁ = 0 → g = 3/4. k = 3/2: C₁ = max(2, 2e − 2) = 2e − 2 → g = 2e − 5/2.
5. 합 2e − 7/4 → p + q = 1/4 → 25.

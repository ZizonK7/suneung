## 문제 요약
정수 a ≠ 0, f(x) = x³ − 2ax². 조건 "{f(x₁) − f(x₂)}/(x₁ − x₂) × {f(x₂) − f(x₃)}/(x₂ − x₃) < 0인 x₁, x₂, x₃이 (k, k + 3/2)에 존재"를 만족하는 정수 k의 곱이 −12일 때 f′(10)은?

## 풀이
1. **[ND5]** 기울기가 양인 할선과 음인 할선이 구간 안에 함께 있다 ⇔ f가 그 구간에서 단조가 아니다 ⇔ 극점이 열린구간 안에 있다.
2. **[L060]** f′ = x(3x − 4a). 극점 x = 0, 4a/3 (a ≠ 0이라 둘 다 부호가 바뀐다).
3. 0 ∈ (k, k + 3/2) → k = −1. 4a/3 ∈ (k, k + 3/2) → k ∈ (4a/3 − 3/2, 4a/3)인 정수 1~2개(연속).
4. 곱이 −12 → 나머지 정수의 곱이 12. 연속 정수로 {12}, {−12}, {3, 4}, {−4, −3}을 따지면 정수 a가 나오는 것은 {−4, −3}뿐: −3 < 4a/3 < −5/2 → a = −2 (4a/3 = −8/3, 구간 (−25/6, −8/3)).
5. f′(x) = 3x² + 8x, f′(10) = 300 + 80 = 380.

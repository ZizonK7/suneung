## 문제 요약
f(x) = e^x + x. 양수 t에 대해 점 (t, 0)과 (x, f(x)) 사이 거리가 x = s에서 최소일 때 g(t) = f(s). g의 역함수 h에 대해 h′(1)은?

## 풀이
1. **[NG2]** 거리² = (x − t)² + f(x)²의 도함수가 x = s에서 0: (s − t) + f(s)f′(s) = 0. 즉 (t, 0)은 (s, f(s))에서의 법선 위. → t = s + f(s)f′(s).
2. **[L049]** t와 g를 모두 s로 쓴다: t(s) = s + f f′, g = f(s).
3. **[L082]** h(1) = t ↔ g(t) = 1 ↔ f(s) = 1 ↔ s = 0, t = 0 + 1·2 = 2. h′(1) = dt/dg = (dt/ds)/(dg/ds).
4. dt/ds = 1 + f′² + f f″ = 1 + 4 + 1 = 6, dg/ds = f′(0) = 2 → h′(1) = 3.

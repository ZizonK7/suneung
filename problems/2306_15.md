## 문제 요약
a₁ = 0, a_n ≤ 0이면 a_{n+1} = a_n + 1/(k+1), a_n > 0이면 a_{n+1} = a_n − 1/k. a₂₂ = 0이 되는 모든 자연수 k의 합은?

## 풀이
1. **[NC1]** 단위를 1/(k(k+1))로 바꾸면 0 이하일 때 +k, 양수일 때 −(k+1)인 정수 수열이다.
2. 0으로 돌아오려면 (+k 횟수)·k = (−(k+1) 횟수)·(k+1) → 최소 k+1번 더하고 k번 뺀다. 값은 −k, …, k의 2k+1개를 한 번씩 돈다.
3. **[L018]** 따라서 주기는 2k + 1이고, a_n = 0 ⇔ (2k+1) | (n − 1).
4. a₂₂ = 0 ⇔ (2k+1) | 21 → 2k+1 = 3, 7, 21 → k = 1, 3, 10. 합 14 (직접 반복 계산으로 확인).

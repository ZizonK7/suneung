## 문제 요약
길이가 2인 선분 AB를 지름으로 하는 반원의 호 위의 점 P에 대하여 ∠BAP = θ (π/4 < θ < π/2). P를 지나고 AB에 평행한 직선이 호와 만나는 점 중 P가 아닌 점을 Q라 한다. 사각형 ABQP의 넓이를 f(θ), AP : BP = 1 : 3이 되는 θ를 α라 할 때 f′(α)는?

## 풀이
1. **[L028]** 반지름 1이므로 AP = 2sin(∠ABP) = 2cosθ, BP = 2sinθ. AP : BP = 1 : 3 → tanα = 3.
2. **[L114]** 중심 O를 원점, B = (1, 0)으로 두면 원주각 ∠PAB = θ의 중심각 ∠POB = 2θ → P = (cos2θ, sin2θ). θ > π/4라 cos2θ < 0, P는 왼쪽 위.
3. **[L045]** ABQP는 등변사다리꼴이고 Q는 P의 y축 대칭점 (−cos2θ, sin2θ). PQ = −2cos2θ.
4. f(θ) = (2 − 2cos2θ)/2 · sin2θ = (1 − cos2θ)sin2θ.
   f′(θ) = 2sin²2θ + 2cos2θ(1 − cos2θ).
5. **[L158]** tanα = 3 → cos2α = (1 − 9)/(1 + 9) = −4/5, sin2α = 2·3/(1 + 9) = 3/5.
6. f′(α) = 18/25 − (8/5)(9/5) = 18/25 − 72/25 = −54/25.

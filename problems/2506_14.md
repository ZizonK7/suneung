## 문제 요약
자연수 k에 대해 log₂√(−n² + 10n + 75) − log₄(75 − kn)의 값이 양수가 되도록 하는 자연수 n의 개수가 12이다. 이를 만족하는 모든 k의 합은?

## 풀이
1. **[L090]** log₂√A = log₄A로 밑을 4로 통일한다. 양수 조건은 log₄(−n² + 10n + 75) > log₄(75 − kn), 밑 4 > 1이라 진수의 대소로 바뀐다. 진수 조건 −n² + 10n + 75 > 0, 75 − kn > 0도 함께 건다.
2. 세 조건을 n에 대해 정리한다.
   - −n² + 10n + 75 > 75 − kn ⇔ n(10 + k − n) > 0 ⇔ n < 10 + k.
   - (n − 15)(n + 5) < 0 ⇔ n ≤ 14.
   - n < 75/k.
3. **[L172]** 개수는 세 상한 중 가장 작은 것이 정한다. k에 따라 묶이는 상한이 바뀐다.
   - k = 1, 2, 3, 4: n < 10 + k가 가장 세다(75/k ≥ 10 + k) → 개수 9 + k = 10, 11, 12, 13. k = 3.
   - k = 5: 세 상한 모두 n ≤ 14 → 14개.
   - k ≥ 6: n < 75/k가 가장 세다 → k = 6이면 n ≤ 12로 12개, k = 7이면 10개, 이후 더 줄어든다. k = 6.
4. k = 3, 6 → 합 9.

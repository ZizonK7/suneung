## 문제 요약
최고차항 계수 1이고 f(0) = 0, f(1) = 0인 삼차함수 f에 대해 g(t) = ∫_t^{t+1} f(x)dx − ∫_0^1 |f(x)|dx. ㄱ. g(0) = 0이면 g(−1) < 0. ㄴ. g(−1) > 0이면 f(k) = 0인 k < −1이 존재한다. ㄷ. g(−1) > 1이면 g(0) < −1. 옳은 것은?

## 풀이
1. f(x) = x(x − 1)(x − a)로 둔다. (0, 1)에서 x(x − 1) < 0이므로 f의 부호는 x − a의 반대, (−1, 0)에서 x(x − 1) > 0이므로 x − a와 같다.
2. **[L133]** ㄱ: g(0) = ∫_0^1 f − ∫_0^1 |f| = 0이면 (0, 1)에서 f ≥ 0 → a ≥ 1. 그러면 (−1, 0)에서 f < 0이므로 g(−1) = ∫_{−1}^0 f − ∫_0^1 |f| < 0. 참.
3. ㄴ: a ≥ 0이면 (−1, 0)에서 f ≤ 0이라 g(−1) < 0. 따라서 a < 0인 경우만 본다. 이때 (0, 1)에서 f < 0이므로 ∫_0^1 |f| = −∫_0^1 f = (1 − 2a)/12, ∫_{−1}^0 f = −(7 + 10a)/12 → g(−1) = −2(1 + a)/3. g(−1) > 0 ⇔ a < −1이고 f(a) = 0. 참.
4. **[L133]** ㄷ: g(−1) > 1 → a < −5/2 (a < 0 구간). (0, 1)에서 f의 부호가 일정(음)하므로 ∫_0^1 |f| = −∫_0^1 f, g(0) = 2∫_0^1 f = (2a − 1)/6 < −1. 참.
5. ㄱ, ㄴ, ㄷ 모두 옳다 → ⑤.

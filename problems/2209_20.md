## 문제 요약
f(x) = ½x³ − (9/2)x² + 10x에 대해 x에 대한 방정식 f(x) + |f(x) + x| = 6x + k의 서로 다른 실근이 4개가 되도록 하는 모든 정수 k의 합은?

## 풀이
1. **[L038]** A = f(x) + x로 두면 좌변 = (A + |A|) − x. A ≥ 0이면 2A − x, A < 0이면 −x.
2. A = (x/2)(x² − 9x + 22)이고 x² − 9x + 22의 판별식이 음수라 항상 양수 → A ≥ 0 ⇔ x ≥ 0.
3. **[L013]** x ≥ 0: 2f(x) + x = 6x + k → h(x) = x³ − 9x² + 15x = k. x < 0: −x = 6x + k → x = −k/7, k > 0일 때만 구간 안에 든다.
4. **[L064]** h′ = 3(x − 1)(x − 5), h(0) = 0, h(1) = 7, h(5) = −25. x ≥ 0에서 y = k와의 교점: 0 < k < 7이면 3개, k = 0이면 3개(x = 0 포함), 나머지 k는 2개 이하.
5. 4개가 되려면 k > 0(음수 근 하나)이고 x ≥ 0에서 3개 → 0 < k < 7 → k = 1, …, 6, 합 21.

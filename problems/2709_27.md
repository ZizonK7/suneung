## 문제 요약
f(x) = (ln x)³ − 3ln x. x ≥ −2에서 정의된 g는 x > −2에서 미분가능하고, t ≥ e인 모든 실수 t에 대해 g(f(t)) = t². x > 1/e에서 정의된 h(x) = g(f(x))에 대해 h′(1)은?

## 풀이
1. u = ln x로 두면 f = u³ − 3u. t ≥ e(u ≥ 1)에서 f는 −2부터 증가하므로 g(y)는 y ≥ −2 전체에서 이 가지로 정해진다.
2. h′(1) = g′(f(1))·f′(1) = g′(0)·(−3). x = 1(u = 0)은 t ≥ e 가지 밖이므로 g′(0)은 다른 점에서 읽어야 한다.
3. **[L082]** 속값부터 찾는다: f(t) = 0, t ≥ e → u³ = 3u, u = √3, t = e^{√3}. g(f(t)) = t²을 미분하면 g′(f(t))·f′(t) = 2t, f′(t) = (3u² − 3)/t = 6/t → g′(0) = 2t²/6 = e^{2√3}/3.
4. h′(1) = (e^{2√3}/3)·(−3) = −e^{2√3}. sympy로 검산.

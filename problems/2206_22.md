## 문제 요약
삼차함수 f. (가) f(x) = 0의 서로 다른 실근 2개. (나) f(x − f(x)) = 0의 서로 다른 실근 3개. f(1) = 4, f′(1) = 1, f′(0) > 1일 때 f(0) = q/p, p + q는?

## 풀이
1. (가) f = a(x − α)²(x − β).
2. **[L076]** (나) ⇔ f(x) = x − α, f(x) = x − β의 서로 다른 근이 모두 3개. 두 직선은 기울기 1이고 각각 (α, 0), (β, 0)을 지난다.
3. **[L015, L014]** f(1) = 4, f′(1) = 1이므로 (1, 4)에서의 접선이 y = x + 3이다. 개수가 3이 되려면 이 접선이 두 직선 중 하나여야 한다 → −3 ∈ {α, β}.
4. α = −3(중근)이면 f = a(x + 3)²(x − β), f(1) = 16a(1 − β) = 4, f′(1) = 2 + 16a = 1 → a = −1/16, β = 5. f′(0) = 21/16 > 1 ✓.
   - 확인: f − (x + 3) = −(x + 3)(x − 1)²/16 → 근 −3, 1. f − (x − 5) = (x − 5)(−(x + 3)²/16 − 1) → 근 5. 합 3개 ✓.
   - β = −3(단순근)인 경우 f = a(x − α)²(x + 3)은 f(1) = 4, f′(1) = 1을 동시에 만족시키는 실수 a, α가 없다(sympy 확인).
5. f(0) = 45/16 → 61.

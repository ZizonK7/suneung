## 문제 요약
t = 0에서 출발하여 수직선 위를 움직이는 점 P의 시각 t(t ≥ 0)에서의 위치가 x = t³ − t² − t + 1이다. ㄱ. t = 1일 때 위치는 1이다. ㄴ. t = 1일 때 속도는 0이다. ㄷ. 출발한 후 운동 방향이 바뀌는 시각에 가속도는 4이다. 옳은 것만을 고르면?

## 풀이
1. ㄱ: x(1) = 1 − 1 − 1 + 1 = 0. 거짓.
2. ㄴ: v = 3t² − 2t − 1 = (3t + 1)(t − 1) → v(1) = 0. 참.
3. **[L067]** t ≥ 0에서 v는 t = 1에서만 0이고 부호가 −에서 +로 바뀐다 → 방향이 바뀌는 시각 t = 1. a = 6t − 2 → a(1) = 4. 참.
4. 답 ㄴ, ㄷ.

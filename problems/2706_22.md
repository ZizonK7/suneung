## 문제 요약
수열 {a_n}은 a₁ = 1, a₃ = 4이고 모든 자연수 n에 대하여 a_{2n} = a_n + 1, a_{4n+3} = a_{4n+1} = a_n + 4를 만족한다. a_k = 10을 만족하는 자연수 k의 개수는?

## 풀이
1. 모든 k ≥ 2는 짝수(2n), 4n + 1(n ≥ 1), 4n + 3(n ≥ 1) 중 정확히 하나라서 a₁, a₃만 주어지면 모든 항이 정해진다. a₂ = 2, a₄ = 3, a₅ = a₇ = 5, a₈ = 4, ….
2. **[L177]** c_m = (a_k = m인 k의 개수)로 둔다. a_k = m인 k는 a_n = m − 1인 n에서 k = 2n으로, a_n = m − 4인 n에서 k = 4n + 1, 4n + 3으로 나온다(나머지가 달라 겹치지 않는다). 따라서 m ≥ 5에서 c_m = c_{m−1} + 2c_{m−4}.
3. 초기값: c₁ = 1(k = 1), c₂ = 1(k = 2), c₃ = 1(k = 4), c₄ = 2(k = 3, 8. k = 3은 점화식이 아니라 주어진 값).
4. c₅ = 2 + 2 = 4, c₆ = 4 + 2 = 6, c₇ = 6 + 2 = 8, c₈ = 8 + 4 = 12, c₉ = 12 + 8 = 20, c₁₀ = 20 + 12 = 32.
5. 검산: k ≤ 2¹⁶까지 직접 계산해 a_k = 10인 k가 32개(최대 k = 512, k > 2¹⁵에서 a_k ≥ 16).

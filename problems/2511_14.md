## 문제 요약
삼각형 ABC의 변 AB 위에 AD : DB = 3 : 2인 점 D, A를 중심으로 D를 지나는 원 O, 원 O와 선분 AC의 교점 E. sinA : sinC = 8 : 5, 넓이 비 (△ADE) : (△ABC) = 9 : 35, 외접원 반지름 7, AB < AC. 원 O 위의 점 P에 대해 △PBC의 넓이의 최댓값은?

## 풀이
1. **[L028]** 변은 2R·sin(대각)이므로 BC : AB = sinA : sinC = 8 : 5. AD = 3k, DB = 2k로 두면 AB = 5k, BC = 8k, 원의 반지름 AD = AE = 3k.
2. **[L070]** △ADE와 △ABC는 각 A를 공유하므로 넓이 비 = (3k·3k) : (5k·AC) = 9 : 35 → AC = 7k.
3. **[L071]** 코사인법칙: 49k² = 25k² + 64k² − 80k²·cosB → cosB = 1/2, B = 60°. **[L028]** AC = 2R·sinB → 7k = 14·(√3/2) → k = √3.
4. **[L141]** P가 원 O 위를 움직일 때 직선 BC까지 거리의 최댓값 = (A에서 BC까지 거리) + 반지름 = AB·sin60° + 3√3 = 15/2 + 3√3.
5. 최대 넓이 = (1/2)·8√3·(15/2 + 3√3) = 36 + 30√3.

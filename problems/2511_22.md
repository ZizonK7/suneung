## 문제 요약
모든 항이 정수. a_{n+1} = a_n − 3 (|a_n| 홀수), a_n/2 (a_n = 0 또는 |a_n| 짝수). |a_m| = |a_{m+2}|인 m의 최솟값이 3인 모든 수열의 |a₁|의 합은?

## 풀이
1. 먼저 |a| = |a의 두 칸 뒤|인 a를 모두 찾는다(집합 G).
   - a 홀수: a → a − 3 → (a − 3)/2. |(a − 3)/2| = |a| → a = −3, 1.
   - a 짝수, a/2 홀수: a/2 − 3. |a/2 − 3| = |a| → a = −6, 2. a/2 짝수: a/4 → a = 0.
   - G = {−6, −3, 0, 1, 2}. 조건: a₃ ∈ G, a₁, a₂ ∉ G.
2. **[L107]** a₃에서 거꾸로 직전 항: x의 앞은 2x 또는 (x + 3이 홀수일 때) x + 3.
   - a₃ = −3: 앞은 −6 ∈ G뿐 ✗. a₃ = 1: 앞은 2 ∈ G뿐 ✗.
   - a₃ = −6: a₂ = −12 (−3은 G) → a₁ = −24, −9.
   - a₃ = 2: a₂ = 4 → a₁ = 8, 7. a₂ = 5 → a₁ = 10.
   - a₃ = 0: a₂ = 3 (0은 G) → a₁ = 6.
3. |a₁|의 합 = 24 + 9 + 8 + 7 + 10 + 6 = 64.
   - 확인: |a₁| ≤ 5000 전수 대입으로 같은 6개.

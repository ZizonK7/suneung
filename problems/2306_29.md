## 문제 요약
반지름 1, 중심각 π/2인 부채꼴 OAB. 호 AB 위의 점 P에서 선분 OA에 내린 수선의 발 H. ∠OAP의 이등분선이 선분 HP, OP, OB와 만나는 점을 Q, R, S라 한다. ∠APH = θ일 때 삼각형 AQH의 넓이 f(θ), 삼각형 PSR의 넓이 g(θ). lim_{θ→0+} θ³g(θ)/f(θ) = k일 때 100k는? (0 < θ < π/4)

## 풀이
1. **[L114]** ∠HAP = π/2 − θ이고 OA = OP이므로 ∠OAP = ∠OPA = π/2 − θ, ∠AOP = 2θ. 따라서 AH = 1 − cos2θ, 이등분선이 AO와 이루는 각은 π/4 − θ/2.
2. f(θ) = ½·AH·AH·tan(π/4 − θ/2) = ½(1 − cos2θ)²tan(π/4 − θ/2).
3. **[L008]** R, S가 모두 이등분선 위에 있으므로 g(θ) = ½·RS·d, d는 P에서 이등분선까지의 거리 = AP·sin(π/4 − θ/2), AP = 2sinθ. AS = 1/cos(π/4 − θ/2), 삼각형 AOR에서 AR = sin2θ/sin(π/4 + 3θ/2)(→ 0)이므로 RS = AS − AR.
4. **[L118]** θ → 0에서 f ≈ ½(2θ²)²·1 = 2θ⁴, RS → √2, d ≈ 2θ·(√2/2) = √2θ → g ≈ θ. θ³g/f → θ⁴/(2θ⁴) = 1/2, 100k = 50.
5. 검산: 좌표로 Q, R, S를 구해 θ = 10⁻⁷에서 100k ≈ 49.99999.

## 문제 요약
0 < a < 2. f(x) = 2|sin 4x| (x < 0), −sin ax (x ≥ 0). g(x) = |∫_{−aπ}^{x} f(t)dt|가 실수 전체에서 미분가능할 때 a의 최솟값은?

## 풀이
1. **[L026, L025]** F(x) = ∫_{−aπ}^{x} f라 하면 F(−aπ) = 0이므로 f(−aπ) = 2|sin 4aπ| = 0이어야 한다 → 4a는 정수.
2. x < 0에서 f ≥ 0이므로 F는 증가한다. 그래서 (−aπ, 0]에서 F > 0이고 x < −aπ에서 F < 0이다(그 사이 근은 −aπ뿐).
3. **[L027]** F(0) = 2 × (4a개 주기 × 1/2) = 4a. x > 0에서 F(x) = 4a − (1 − cos ax)/a.
4. **[L019, L025]** x > 0에서 F가 부호를 바꾸면 안 된다. 최솟값 4a − 2/a ≥ 0 → a ≥ 1/√2.
   등호일 때 F = 0인 점은 cos ax = −1, 즉 f = 0인 점이라 괜찮다.
5. 4a가 정수이고 a ≥ 0.707… → a = 3/4.

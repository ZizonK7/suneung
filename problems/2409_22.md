## 문제 요약
다항함수 f, g와 부정적분 F, G. (가) ∫₁ˣ f(t)dt = xf(x) − 2x² − 1. (나) f(x)G(x) + F(x)g(x) = 8x³ + 3x² + 1. ∫₁³ g(x)dx는?

## 풀이
1. **[L069]** (가) 양변 미분: f = f + xf′ − 4x → f′ = 4 → f = 4x + c.
2. **[L026]** x = 1: 0 = f(1) − 3 → f(1) = 3 → f = 4x − 1.
3. **[ND6]** (나)의 좌변은 (FG)′이다 → F(x)G(x) = 2x⁴ + x³ + x + C.
4. F = 2x² − x + d, G = x² + px + q로 놓고 계수 비교: x³에서 p = 1, x²·x에서 2q − 1 + d = 0, dp − q = 1 → q = 0, d = 1. G = x² + x.
5. g = 2x + 1, ∫₁³ g = G(3) − G(1) = 12 − 2 = 10.

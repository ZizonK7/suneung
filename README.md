# suneung

평가원 기출 문항에서 풀이 논리를 모아, 그 논리들을 랜덤으로 조합해 새로운 수능 수학 문항을 만드는 작업 저장소입니다.

기본 생각은 "수능 수학은 평가원의 논리에서 나온다"는 것입니다. 기출을 풀어 논리 카드로 정리하고, 카드를 무작위로 뽑아 과목의 경계 없이 엮어 문항을 만든 뒤, 피드백을 제작 원칙으로 쌓아갑니다.

## 현황 (2026-10-19)
- 기출 정리: 534문항 중 41문항 (미적분 9문항)
- 논리 카드: 66장 (L001~L066, 미적분 영역 9장)
- 제작 문항: 8개

| 문항 | 과목 | 완성도 | 난이도 | 한 줄 |
|---|---|---|---|---|
| [D001](drafts/D001.md) | 공통(수2) | 2 | – | 쓸데없이 주어진 조건이 많았다 |
| [D002](drafts/D002.md) | 공통(수2) | 3 | 쉬운 준킬러 | 왼쪽에서도 접한다는 낯선 논리 |
| [D003](drafts/D003.md) | 공통(수1 도형) | 4 | 준킬러 | 실력에 따라 짧게/길게 풀리는 원 위의 점 개수 |
| [D004](drafts/D004.md) | 공통(수1) | 5 | 중하 | 삼각함수 교점이 만드는 삼각형 넓이 수열 |

## 구성
| 경로 | 내용 |
|---|---|
| `exams/` | 평가원 문제지 PDF (2022학년도 6월 ~ 2027학년도 9월, 17회) |
| `pool.csv` | 문항 인덱스 (공통·미적분·확률과 통계 534문항) |
| `answers.csv` | 문항별 정답 |
| `problems/` | 기출 문항 노트: 풀이, 정답 검증, 사용한 논리 |
| `logics/` | 논리 카드 (영역·수준·출처 포함) |
| `drafts/` | 제작한 문항: 추출 기록, 풀이, 자체 검수, 피드백 |
| [`LESSONS.md`](LESSONS.md) | 제작 원칙, 자체 검수 체크리스트, 평가 기록 |
| [`WORKFLOW.md`](WORKFLOW.md) | 작업 절차와 명령어 |
| `tools/` | 인덱스 생성, 정답 추출, 문항 렌더링, 랜덤 추출 스크립트 |
| `draws.log` | 모든 랜덤 추출의 시드와 결과 |

## 사용
```
pip install pymupdf sympy numpy
python tools/draw.py problems 5                             # 정리할 기출 5문항 추출
python tools/show.py 2611_21                                 # 문제 페이지 렌더링 + 정답
python tools/draw.py logics 1 --target 공통                   # 목표 문항에 쓸 논리 카드 추출
python tools/draw.py logics 1 --target 미적분 --area 미적분    # 미적분 카드에서만 추출
```

## 저작권
`exams/`의 문제지 저작권은 한국교육과정평가원에 있습니다. 해설 자료는 포함하지 않으며, `answers.csv`의 정답만 정리해 두었습니다.

**내용**: f(x)와 f(φ(x))가 함께 있는 항등식은 양변을 미분해 f′(x)와 f′(φ(x))φ′(x)의 관계를 얻는다. 묻는 점 a에서 φ(a)의 f′가 필요하면, φ(b) = b인 고정점이나 φ(a)에서 다시 대입해 연립한다.
**트리거**: f(x) + f(φ(x)) = (식) 꼴에서 특정 점의 f′를 물음.
**예** (2509_27): x = 0(φ(0) = 0) → f′(0) = 2/3, x = π(φ(π) = 0) → f′(π) = −1 + f′(0)/2 = −2/3.

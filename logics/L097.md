name: 실수인 n제곱근의 개수는 n의 홀짝과 부호로 정한다
area: [수1]
level: 기초
sources: [2309_11(핵심), 2206_21(핵심), 2311_13(핵심)]
---
**내용**: n이 짝수이면 a > 0일 때 ±a^{1/n} 두 개(합 0, 곱 −a^{2/n}), a = 0일 때 0 하나, a < 0일 때 없다. n이 홀수이면 a^{1/n} 하나다. n이 미지수이면 홀짝으로 경우를 나눈다.
**트리거**: "a의 n제곱근 중 실수인 것"의 개수·합·곱 조건, x^n − a가 든 방정식에서 n이 미지수.
**예** (2309_11): N > 0의 네제곱근 중 실수의 곱 −√N = −9 → N = 81. (2206_21): x^n = 64의 실근은 n이 짝수면 ±2^{6/n} 두 개, 홀수면 2^{6/n} 하나.

**내용**: log_a x + log_a y = log_a xy. k·log_a x = log_a x^k.
**거듭제곱 등식** (2211_13): b·log a = a·log b 꼴의 등식은 계수를 지수로 올려 a^b = b^a로 바꾼다. 묻는 식이 거듭제곱이면 바로 쓰인다. 예: (log₂a)/a = (log₂b)/b → a^b = b^a → f(1) = 2a^b = 40.

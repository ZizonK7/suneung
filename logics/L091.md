id: L091
name: x·g(x) = |x·h(x)|이면 g = (x/|x|)·|h|로 쓰고, g가 연속이려면 h(0) = 0이다
area: [수2]
level: 도구
sources: [2206_14(핵심)]
---
**내용**: x ≠ 0에서 g(x) = (x/|x|)|h(x)|. g(0+) = |h(0)|, g(0−) = −|h(0)|이므로 연속이면 h(0) = 0이다. 이때 x = 0에서는 부호 인수 x/|x|가 꺾임을 상쇄해 g가 항상 미분가능하다(단순근이면 |c|x, 중근이면 |c|x|x|). 미분 불가능점은 0이 아닌 h의 근 중 부호가 바뀌는 근뿐이다(L025).
**트리거**: "xg(x) = |x·(식)|", "(x − a)g(x) = |…|"처럼 g가 일차식으로 나눈 꼴로만 주어지고 g가 연속.
**예** (2206_14): h = f(x − p) + q, 미분 불가능점이 1개 → 0이 h의 중근 → f′(−p) = 0.

**내용**: (A)(B) = 0 꼴이나 부호·첨자 조건으로 갈리는 점화식은 분기마다 두 식을 모두 적고, 중간 조건(a₂a₃ < 0, a_n > 0)으로 가지를 친다. 끝 조건(a₅ = 0)은 거꾸로 올라가 직전 항의 후보를 먼저 적으면 갈래가 줄어든다. 각 갈래에서 나온 값이 그 갈래의 범위 조건을 만족하는지 확인한다.
**트리거**: "a_n = …이 되도록 하는 모든 a₁(또는 k)", 두 갈래 점화식.
**예** (2506_22): 분기가 n = 4, 9에서만 생겨 t의 범위 4가지로 끝난다. (2509_22): a₅ = 0에서 거꾸로 a₄ = 2k/3 또는 0을 먼저 적는다.

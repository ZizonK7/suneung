---
id: L158
name: tan 값으로 2배각의 sin·cos을 바로 쓴다
area: [미적분]
level: 도구
sources: [2606_27(핵심)]
---
**내용**: 각이 변의 비(tanθ = k)로 정해지고 식에 sin2θ, cos2θ가 나오면 θ를 구하거나 sinθ, cosθ를 따로 구하지 않고 sin2θ = 2k/(1 + k²), cos2θ = (1 − k²)/(1 + k²)로 바로 넣는다. 부호는 2θ의 범위로 확인한다.
**트리거**: "AP : BP = 1 : 3이 되는 θ", 지름 위 직각삼각형의 두 변 비, 중심각 2θ로 좌표가 (cos2θ, sin2θ)인 점.
**예** (2606_27): tanα = 3 → cos2α = −4/5, sin2α = 3/5 → f′(α) = 2sin²2α + 2cos2α(1 − cos2α) = −54/25.

id: L180
name: Σ의 극한은 k/n을 x로 읽어 정적분으로 바꾼다
area: [미적분]
level: 기초
sources: [2311_24(핵심), 2211_26(핵심)]
---
**내용**: lim (1/n)Σ_{k=1}^{n} f(a + (b − a)k/n)·(b − a) = ∫_a^b f(x)dx. 1/n을 Δx, k/n을 x로 읽고 적분 구간은 k/n의 범위(0~1)에서 정한다. 속의 계수(3k/n 등)는 f에 넣거나 x를 늘려 구간을 바꾼다.
분모·분자를 n의 거듭제곱으로 나눠 (1/n)·g(k/n) 꼴을 먼저 만든다(차수를 세서 1/n이 하나 남게). 예 (2211_26): (k² + 2kn)/(k³ + 3k²n + n³) → ∫_0^1 (x² + 2x)/(x³ + 3x² + 1)dx = ln5/3.
**트리거**: lim_{n→∞} (1/n)Σ f(k/n) 꼴, 항마다 k/n이 들어간 합의 극한.
**예** (2311_24): lim (1/n)Σ√(1 + 3k/n) = ∫_0^1 √(1 + 3x)dx = 14/9.

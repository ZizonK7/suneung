name: x와 −x를 넣어 더하면 홀수차항이 지워진다
area: [기초]
level: 도구
sources: [2609_21(핵심)]

**내용**: 모든 x에서 P(x) ≥ 0이면 P(x) + P(−x) ≥ 0도 모든 x에서 성립한다. 모르는 계수가 홀수차항에만 있으면 이것으로 그 계수를 지워 남은 계수만의 조건을 얻는다. 지운 계수는 따로, 등호가 걸리는 점(x = ±p)을 넣어 정한다.
**트리거**: "모든 실수 x에 대하여" 다항 부등식(또는 등식)에 미지 계수가 두 개 이상이고, 하나는 홀수차항에 있음.
**예** (2609_21): x⁴ − 4x² − 2ax − b ≥ 0 → x⁴ − 4x² − b ≥ 0 → b ≤ −4. 이후 x = ±√2에서 −2√2a ≥ 0, 2√2a ≥ 0 → a = 0.

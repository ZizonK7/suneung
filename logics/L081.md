**내용**: f′(x) = 3x² + 2ax + b ≥ 0이 모든 x에서 성립 ⇔ 판별식 ≤ 0. 등호(중근)일 때도 증가함수다.
**역함수** (2511_27): 연속함수가 역함수를 가지면 일대일이라 단조다. 미분가능하면 g′ ≥ 0 또는 g′ ≤ 0이 모든 x에서 성립하고, 끝 행동으로 어느 쪽인지 정한다. g′ = 0인 점이 있으면 그 점이 g′의 최솟값(최댓값) 지점이다(L019). 예: g′(0) = 0이고 g는 증가 → f′(t) + 1 ≥ 0, t = 1에서 0 → f′(t) + 1 = 3(t − 1)².
**트리거**: "실수 전체에서 증가", "g가 역함수를 가질 때", "일대일대응".

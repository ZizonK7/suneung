**내용**: 구간별로 정의된 함수와 수평선 y = t의 교점 수는 조각별 교점 수의 합이다. 합의 최댓값이 (각 조각 최대의 합)이 되려면 각 조각이 최대 개수를 갖는 t의 범위가 겹쳐야 한다. 단조함수에 절댓값을 씌운 조각은 0에서 꺾여 최대 2개이고, 그 범위는 (0, 양 끝값 중 작은 쪽)이며 끝이 닫혔는지 열렸는지 따진다.
**트리거**: 조각마다 식이 다른 함수(특히 |지수 − n|, |로그 − n|)에서 "f(x) = t의 실근 개수 g(t)의 최댓값이 k".
**예** (2311_21): x < 0 조각은 t ∈ (0, min(n, 9 − n))에서 2개, x ≥ 0 조각은 t ∈ (0, n − 2]에서 2개 → 두 범위가 모두 존재하는 3 ≤ n ≤ 8에서 최댓값 4.

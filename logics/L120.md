**내용**: 모든 x(또는 모든 정수)에서 L(x) ≤ Q(x) ≤ U(x)이면 U − L = 0인 점에서 Q = L = U이다. 모르는 계수 수만큼 이런 점을 찾으면 Q가 정해지고, 나머지 점에서 부등식이 성립하는지 확인한다.
**트리거**: 모르는 함수(식)가 두 식 사이에 끼어 있는 "모든 x(정수)에 대하여 … ≤ … ≤ …".
**예** (2509_21): U − L = 4(k + 1)(k + 2) → Q(−1) = −10, Q(−2) = −12로 이차식 Q(k) = 3k² + 11k − 2 결정.

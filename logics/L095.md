name: 주기함수가 낀 방정식의 n번째 근은 주기 간격으로 늘어선다
area: [수1, 미적분]
level: 도구
sources: [2606_20(핵심), 2506_30(핵심)]
---
**내용**: 주기가 p이고 한 주기 [0, p)의 근이 r₁ < … < r_k이면 a_{k(n−1)+i} = r_i + (n − 1)p. 첨자를 k로 나눈 나머지별로 공차 p인 등차수열이다. L020은 구간의 해 개수를 세고, 이 카드는 n번째 근을 쓴다.
**트리거**: f(x + p) = f(x)인 함수의 방정식 근을 작은 것부터 a_n으로 나열. 커지는 곡선과 주기함수의 교점 x좌표를 a_n으로 나열하고 n → ∞ 극한을 물음.
**예** (2606_20): 근 0, 1, 3, 주기 4 → a_{3n−2}, a_{3n−1}, a_{3n}은 공차 4. a_20 + a_21 + a_22 = 80.
**점근적으로** (2506_30): 주기함수와 커지는 곡선의 교점(tan x = √x/10)은 정확한 등차수열은 아니지만 주기(가지)마다 하나씩 있고, n → ∞에서 점근선 쪽에 붙는다 → a_n ≈ (n − 1)π + π/2, a_{n+1} − a_n → π. 이 근사로 극한의 지배항을 정한다.

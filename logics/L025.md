**내용**: F가 미분가능할 때 |F|는 F ≠ 0인 곳에서 미분가능하다. F(x₀) = 0인 점에서는 F′(x₀) = 0이어야 미분가능하다(부호가 바뀌며 뚫고 지나가면 꺾인다).
**트리거**: |F(x)|나 |∫f|의 미분가능성 조건. ∛(다항식) 같은 유리지수 함수가 실수 전체에서 미분가능.
**결과**: F의 모든 근이 접하는 근이어야 한다 → F ≥ 0(또는 ≤ 0) 꼴 조건으로 바뀐다.
**n제곱근** (2706_30): ⁿ√F(n 홀수)는 근 r 근처에서 (x − r)^{k/n}(k = 중복도) 꼴이라 k ≥ n이어야 미분가능하다(k < n이면 뾰족점·수직 접선). 예: ∛(x·f²)가 미분가능 → f의 0 아닌 실근은 중복 2 이상, f(0) = 0.

---
id: L161
name: g가 극대인 점에서 |g|가 극소이면 그 점의 g값은 0 이하다
area: [수2]
level: 도구
sources: [2306_28(핵심)]
---
**내용**: g(a) > 0이면 a 근처에서 |g| = g라 극대와 극소가 동시에 될 수 없다(상수 제외). 따라서 g가 a에서 극대이고 |g|가 a에서 극소이면 g(a) ≤ 0이다(g(a) < 0이면 |g| = −g가 극소, g(a) = 0이면 |g| ≥ 0의 최소). 마찬가지로 g가 극소이고 |g|가 극대이면 g(a) < 0이다.
**트리거**: 한 점에서 g의 극값 종류와 |g|의 극값 종류가 함께 주어짐.
**예** (2306_28): g = ln|f|가 x = 2에서 극대, |g|가 x = 2에서 극소 → ln f(2) ≤ 0 → f(2) ≤ 1. 근 개수 조건과 합쳐 f(2) = 1.

---
id: L122
name: 0 이상인 두 값의 합이 0이면 둘 다 0이다
area: [기초]
level: 도구
sources: [2506_29(핵심)]
---
**내용**: A ≥ 0, B ≥ 0이고 A + B = 0(또는 A = −B)이면 A = B = 0. 등식 하나가 두 개의 조건이 되어 미지수의 위치가 정해진다.
**트리거**: 제곱·절댓값·f′ ≥ 0처럼 부호가 정해진 두 값이 합 0이거나 서로 −1배라는 조건(이어 붙이기의 미분가능 조건, 대칭 조건).
**예** (2506_29): f′ = x²(x − 1)²/(1 + x²) ≥ 0인데 이어 붙이는 점에서 f′(b) = −f′(b − c) → 둘 다 0 → b, b − c ∈ {0, 1}.

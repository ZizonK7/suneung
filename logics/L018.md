**내용**: 홀짝으로 나뉜 점화식 등은 a_1을 문자로 두고 몇 항 전개하면 주기(예: a_{n+4} = a_n)가 드러난다. 뒤쪽 항이 주어지면 주기를 이용해 앞쪽 항으로 끌어온다.
**트리거**: 경우별 점화식 + 멀리 떨어진 항(a_12 등)의 값.
**앞쪽 항** (2611_16): 앞쪽 항 하나를 물으면 일반항을 구하지 않고 n = 1, 2, …를 차례로 넣는다. 계수에 n이 있으면 각 단계의 n을 정확히 넣는다. 예: a_{n+1} = n²a_n + 1 → a_2 = 2, a_3 = 9.
**예**: a_{n+1} = 1/a_n (n 홀수), 8a_n (n 짝수) → a_4 = a_1/8, a_5 = a_1.

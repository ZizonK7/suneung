**내용**: 도함수와 원함수가 엇갈려 곱해진 합은 곱의 미분법(L068)을 거꾸로 읽은 것이다. (FG)′로 묶으면 적분해서 FG를 바로 얻는다. e^f(1 + xf′) = (xe^f)′처럼 한쪽이 x, 다른 쪽이 e^f인 꼴도 같다.
**트리거**: f, F, g, G가 교차로 곱해진 항등식, f와 f′가 섞인 함수방정식, e^f·(…) 또는 f + xf′ 꼴.
**예** (2409_22): fG + Fg = 8x³ + 3x² + 1 → FG = 2x⁴ + x³ + x + C → 계수 비교로 G = x² + x. (2609_30): e^f(1 + xf′) = g → h = xe^f로 두면 h′ = g.

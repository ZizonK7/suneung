---
**내용**: 연속함수 f가 모든 t > 0에서 f(x) = t의 근을 정확히 n개 갖고, 아는 가지가 이미 각 t를 몇 번 가졌는지 알면, 모르는 구간이 각 t를 가질 횟수가 정해진다. 한 번씩이면 그 구간에서 양수인 부분은 단조로 치역을 덮고, 양수 값을 가질 수 없는 부분(f ≥ 0이면)은 f = 0이다.
**트리거**: 일부 구간에서만 식이 주어진 연속함수, "모든 양수 t에 대하여 f(x) = t의 서로 다른 실근은 n개".
**예** (2411_28): x < 0 가지가 감소해 각 t > 0을 한 번 가지므로 x ≥ 0 쪽도 한 번씩 → x > k에서 증가, [0, k]에서 f = 0.

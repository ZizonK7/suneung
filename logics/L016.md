**내용**: (a_{k+1} − a_k)/(a_k·a_{k+1}) = 1/a_k − 1/a_{k+1}. 등차수열이면 1/(a_k·a_{k+1}) = (1/d)(1/a_k − 1/a_{k+1}).
두 수열의 곱이 나오면 b_n = a_{n+1}처럼 한 수열이 다른 수열을 한 칸 민 것인지 먼저 본다.
**트리거**: 분모가 두 항의 곱, 분자가 두 항의 차(또는 상수)인 시그마.
**결과**: Σ = 1/a_1 − 1/a_{n+1}. 합 조건에서 일반항을 거꾸로 얻는다.
**간격 k** (2509_29): Σ_{n=1}^{N} {b_n − b_{n+k}}는 앞쪽 b_1 + … + b_k에서 뒤쪽 b_{N+1} + … + b_{N+k}를 뺀 값이다. 급수에서 b_n → 0이면 앞쪽 k개 항만 남는다. 1/{n(n + k)}처럼 두 인수의 차가 1이 아닌 상수·문자일 때 쓴다. 예: Σ (m + 1)/{n(n + m + 1)} = 1 + 1/2 + … + 1/(m + 1).

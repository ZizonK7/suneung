**내용**: f(x) + k = 0 → k = −f(x). 고정된 그래프 y = −f(x)와 움직이는 수평선 y = k의 교점으로 센다. 극값이 경계가 되고, "양의 실근"이면 x > 0 부분만 본다.
**트리거**: 매개변수가 상수항에만 있는 방정식의 실근 개수 조건. "방정식 f(x) = f(t)의 실근 개수가 n인 모든 t".
**f(x) = f(t)** (2509_20): 높이 k = f(t)에 대한 개수표로 조건을 만족하는 k를 먼저 고르고, f(t) = k인 t를 정의역에서 모두 찾는다. 같은 k에 t가 여럿 대응하는 것을 빠뜨리지 않는다. 예: 실근 3개인 높이 k = −1, 0 → t = 0, π, 2π와 π/2, 5π/4, 7π/4.

name: f의 다항식 = G(x) 꼴이면 양변을 미분하고 f = 0인 점을 넣어 G, G′, G″의 공통근을 얻는다
area: [미적분]
level: 아이디어
sources: [2606_28(핵심)]
---
**내용**: f⁵ + f³ = G를 미분하면 (5f⁴ + 3f²)f′ = G′, 한 번 더 미분하면 (20f³ + 6f)f′² + (5f⁴ + 3f²)f″ = G″. f(c) = 0에서 계수가 모두 0이므로 G(c) = G′(c) = G″(c) = 0이다. f의 다항식에서 최저차가 높을수록 더 높은 도함수까지 0이 된다.
**트리거**: f에 대한 다항식(최저차가 2차 이상) = 알려진 함수, f가 이계도함수를 가짐, f의 근이 존재(사잇값 정리).
**예** (2606_28): G″ = 0에서 c = −2, 1. G′(c) = 0에서 a를 구하고 f′(2) > 0으로 하나를 고른다.

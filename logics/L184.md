name: 등비수열 rⁿ은 −1 < r ≤ 1일 때만 수렴한다
area: [미적분]
level: 기초
sources: [2709_25(핵심)]
---
**내용**: 등비수열 {rⁿ}의 수렴 조건은 −1 < r ≤ 1(r = 1이면 1로, |r| < 1이면 0으로 수렴). 등비급수의 수렴 조건 −1 < r < 1과 달리 r = 1을 포함한다. 공비가 매개변수 식이면 이 부등식을 풀어 매개변수 범위를 얻는다.
**트리거**: "수열 {aⁿ}(또는 {(식)ⁿ})이 수렴하도록 하는 …", 공비에 매개변수가 든 등비수열의 수렴.
**예** (2709_25): ((k² − 20)/16)ⁿ 수렴 → −16 < k² − 20 ≤ 16 → 4 < k² ≤ 36 → 정수 k 8개.

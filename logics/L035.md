**내용**: d ≠ 0이면 a_m ≠ a_n이므로 |a_m| = |a_n| ⟺ a_m + a_n = 0. 첫째항과 공차가 정수 조건과 결합해 약수 문제가 된다. 예: (2m + 1)d = 90 → d는 90의 (홀수 ≥ 3)분의 1 꼴.
**트리거**: 등차수열 + 절댓값 같음 + 자연수 공차. 절댓값 적분 함수의 극값 조건 |f(a)| = |f(b)|.
**이차함수** (2306_20): |f(a)| = |f(b)|이면 f(a) = f(b)(축이 (a + b)/2) 또는 f(a) + f(b) = 0. 이런 조건이 둘 이상이면 축은 하나뿐이라 대부분 합이 0인 쪽으로 정해진다. f(a) + f(a + 1) = 0이 여러 a에서 성립하면 f(x) + f(x + 1)의 근으로 묶는다. 예: |f(1)| = |f(2)|, |f(4)| = |f(5)| → f(x) + f(x + 1) = 4(x − 1)(x − 4).

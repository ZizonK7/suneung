id: L156
name: 처음 만족하는 n이 m이면 m − 1번째는 만족하지 않는다
area: [수1]
level: 도구
sources: [2306_13(핵심)]
---
**내용**: 수열이 단조이면 "aₙ < c를 만족하는 n의 최솟값이 m"은 aₘ < c ≤ aₘ₋₁과 같다. 상수 c의 범위가 두 이웃 항 사이로 정해지고, 등호는 부등식의 엄격/비엄격을 그대로 따른다.
**트리거**: "…를 만족시키는 n의 최솟값이 m이 되도록 하는 k의 개수(범위)".
**예** (2306_13): x₆ < 1/k ≤ x₅ → 1/64 < 1/k ≤ 1/16 → 16 ≤ k < 64, 48개.

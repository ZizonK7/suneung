**내용**: 두 넓이(또는 끝 하나를 공유하는 두 정적분)가 같다는 조건은 따로 계산하지 않고 빼서, 부호 있는 정적분 하나가 0이라고 쓴다. 교점처럼 지저분한 값을 구하지 않아도 되고, 0부터 적분하면 상수항이 사라져 인수분해가 쉽다.
넓이의 차(B − A = c)가 주어져도 같은 방법으로 부호 있는 정적분 하나 = c로 쓴다(2506_13).
**트리거**: "A = B일 때", "B − A = …", 교점 하나를 사이에 두고 위아래가 바뀌는 두 넓이, ∫_p^a f = ∫_p^b f 꼴의 등식.
**예** (2311_10): 교점 α 양쪽 넓이 A = B → ∫_0^2 {(−x² + k) − (x³ + x²)}dx = 0 → k = 14/3. α는 구하지 않는다.
**예** (2511_09): ∫_{−2}^a f = ∫_{−2}^0 f → ∫_0^a f = 0 → a(a − 10)(a + 2) = 0 → a = 10.

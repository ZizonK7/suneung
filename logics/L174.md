**내용**: f(k − 1)f(k + 1) < 0인 정수 k가 없다는 조건은 짝수점 수열 f(2m)과 홀수점 수열 f(2m + 1) 각각에서 이웃한 항이 반대 부호가 아니라는 뜻이다. 그래서 각 부분수열이 부호를 바꾸려면 0인 항(같은 홀짝의 정수근)을 거쳐야 한다. 끝 행동이 반대 부호인 다항함수는 짝수 근과 홀수 근을 하나씩 가지고, 근의 위치가 이웃한 정수 근처로 좁혀진다.
**트리거**: f(k − 1)f(k + 1), f(k)f(k + 2) 같은 간격 2의 곱의 부호 조건, "만족하는 정수 k가 존재하지 않는다".
**예** (2411_22): 짝수 근·홀수 근 → 이웃한 정수근 n, n + 1과 그 가까이의 셋째 근. f′ 조건으로 n = 0, r = −5/8 → f(8) = 483.

name: 삼각함수가 정해진 점에서 최대이면 값 조건과 위치 조건으로 나눈다
area: [수1]
level: 도구
sources: [2511_10(핵심)]
---
**내용**: a·cos bx + c(a > 0)가 정해진 점 p에서 최댓값 M을 가지면 (1) 최댓값은 a + c = M(구간이 cos = 1인 점을 품으면), (2) 그 점에서 cos bp = 1 → bp = 2kπ. 값 조건과 위치 조건을 따로 써서 a와 b를 각각 정한다. sin이면 bp = π/2 + 2kπ, 최솟값이면 cos bp = −1.
**트리거**: "x = p에서 최댓값(최솟값) M을 갖도록 하는 a, b", 진폭·주기 계수가 모두 미지수.
**예** (2511_10): 최댓값 a + 3 = 13 → a = 10, cos(bπ/3) = 1 → b = 6k → a + b 최솟값 16.

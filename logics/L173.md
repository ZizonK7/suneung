---
**내용**: 모든 항이 자연수(정수)이면 a₁과 d가 정수이고, 항이 음수로 내려가지 않으므로 d ≥ 0이다. 첫째항과 공차 사이의 일차 관계가 하나 주어지면 a₁ ≥ 1에서 d의 상한이 나와 경우가 유한해지고, 배수·약수 조건으로 하나를 고른다.
**트리거**: "모든 항이 자연수인 등차수열", 합 조건 하나와 배수 조건이 함께 주어짐.
**예** (2409_21): a + 2d = 23, a ≥ 1, d ≥ 0 → 0 ≤ d ≤ 11. a₇ = 23 + 4d가 13의 배수인 것은 d = 4뿐.

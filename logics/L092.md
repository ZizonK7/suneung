**내용**: 기울기가 같은 직선 위에서 길이는 가로 거리(세로 거리)에 비례한다. 축 위의 점과 곡선 위의 점이 섞여도 좌표의 차만 비교하면 된다.
기울기 m인 직선 위 두 점 사이 거리는 |Δx|·√(1 + m²)이라 길이 하나가 주어져도 좌표 차가 바로 정해진다.
**트리거**: AB = k·PB 같은 선분 비 조건, 평행한 두 직선 위의 선분 비, 기울기를 아는 직선 위 선분의 길이.
**예** (2309_21): B(x = 0), P(x = a), AB = 4PB → A의 x좌표 4a. 평행선에서 CQ = 3AB → 가로 거리도 3배 → 2^b = 4·2^a.
**예** (2211_09): 기울기 2인 직선 위 PQ = √5 → Δx = 1, Δy = 2 → Q = P + (1, 2).

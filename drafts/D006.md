## 문항
함수 f(x) = e^{2x} − 3e^x + 2와 양수 c에 대하여 함수

  H(x) = ∫_0^x f(t)·f(t − c) dt

가 x = α에서 극값을 갖는 서로 다른 실수 α의 개수가 2이다. 함수 H(x)의 극솟값이 a + b ln 2일 때, 16(a + b)의 값을 구하시오. (단, a, b는 유리수이다.) [4점]

## 정답: 35

## 풀이
1. f(t) = (e^t − 1)(e^t − 2)이므로 f의 근은 0과 ln 2이고 둘 다 단근이다.
2. **[L053]** H′(x) = f(x)·f(x − c)이다. H의 극값은 이 곱의 부호가 바뀌는 점에서만 생긴다.
3. **[L003]** f(t − c)의 근은 c와 c + ln 2이다(f의 근을 c만큼 민 것). c > 0이면 두 근 집합이 겹치는 경우는 c = ln 2뿐이다(c = ln 2이면 ln 2가 겹친다).
   - 겹치지 않으면 서로 다른 단근 4개 → 부호 변화 4번 → 극값 4개.
4. **[L015]** c = ln 2이면 t = ln 2가 곱의 중근이 되어 부호가 바뀌지 않는다. 극값은 t = 0, 2 ln 2 두 곳뿐이다 → c = ln 2.
5. 부호를 보면 t = 0 앞뒤로 + → −(극대, H(0) = 0), t = 2 ln 2 앞뒤로 − → +(극소)이다.
6. e^t = u라 하면 f(t)·f(t − ln 2) = (u − 1)(u − 2)²(u − 4)/4 = (u⁴ − 9u³ + 28u² − 36u + 16)/4이다.
   극솟값 H(2 ln 2) = (1/4)[e^{4t}/4 − 3e^{3t} + 14e^{2t} − 36e^t + 16t]_0^{2 ln 2} = −93/16 + 8 ln 2.
7. 16(a + b) = 16(−93/16 + 8) = 35.

검증(sympy, numpy):
- c ∈ {0.3, ln 2, 0.9, 2 ln 2, 1.5, 3}에서 부호 변화 수는 4, 2, 4, 4, 4, 4다. c = ln 2일 때만 2다.
- H(2 ln 2) = −93/16 + 8 ln 2 ≈ −0.267이다.
- t = ln 2에서는 양쪽 부호가 모두 음수라 극값이 아니다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - "양수"를 빼면 c = −ln 2도 극값 2개가 되어(0이 겹침) 극솟값이 달라진다.
  - "극값 2개"를 빼면 c가 결정되지 않는다.
  - 모두 필요하다.
- **해석을 대신해주지 않았는지(원칙 2):**
  - f를 인수분해하지 않은 꼴로 줬다.
  - "근이 겹쳐야 한다"는 사실은 문장에 없다.
- **조건이 만든 대상을 쓰는지(원칙 7):**
  - 겹치는 근 ln 2는 c를 정하는 데 쓰인다.
  - 극값의 위치 0, 2 ln 2는 극솟값 계산의 적분 구간으로 쓰인다.
- **없는 단계 확인(원칙 6):** c > 0의 경우만 보면 되고, c = 0은 "양수"로 빠진다.
- **풀이 갈래(원칙 4):**
  - 지름길: e^t = u로 바꿔 부호표를 u의 다항식으로 그린다.
  - 정공법: f(t)와 f(t − c)의 그래프를 따로 그려 부호를 맞춘다.
- **난이도(한 단계 낮춰 봄):** 핵심 발상은 "평행이동한 근이 겹쳐야 극값이 줄어든다" 하나이고, 적분 계산이 조금 길다. 예상: 중.

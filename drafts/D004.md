## 문항
0이 아닌 실수 k에 대하여 x > 0에서 두 곡선 y = sin πx, y = k cos πx가 만나는 점을 x좌표가 작은 것부터 차례로 P₁, P₂, P₃, …이라 하자.
자연수 n에 대하여 삼각형 OPₙPₙ₊₁의 넓이를 Sₙ이라 하자. S₁ : S₂ = 5 : 11일 때,

  Σ_{n=1}^{10} 1/(Sₙ·Sₙ₊₁) = q/p

이다. p + q의 값을 구하시오. (단, O는 원점이고, p와 q는 서로소인 자연수이다.) [4점]

## 정답: 161

## 풀이
1. **[L033]** sin πx = k cos πx ⟺ tan πx = k. 가장 작은 양의 해를 c라 하면 교점의 x좌표는 xₙ = c + (n − 1)이다(tan의 주기 1).
   y좌표는 sin π(c + n − 1) = (−1)^{n−1} sin πc로, 크기 h = |sin πc|가 같고 부호가 번갈아 바뀐다.
2. **[L008]** O, Pₙ, Pₙ₊₁은 x축 양쪽에 있으므로 Sₙ = ½|xₙyₙ₊₁ − xₙ₊₁yₙ| = (h/2)(xₙ + xₙ₊₁) = (h/2)(2c + 2n − 1).
   즉 {Sₙ}은 공차 h인 등차수열이다.
3. S₁ : S₂ = (2c + 1) : (2c + 3) = 5 : 11 → c = 1/3.
   - k > 0이면 c ∈ (0, 1/2)이므로 성립한다.
   - k < 0이면 c ∈ (1/2, 1)이므로 모순이다.
   - 따라서 k = √3, h = √3/2이다.
4. Sₙ = (√3/12)(6n − 1), Sₙ·Sₙ₊₁ = (6n − 1)(6n + 5)/48.
5. **[L016]** Σ 48/((6n−1)(6n+5)) = 8 Σ (1/(6n−1) − 1/(6n+5)) = 8(1/5 − 1/65) = 96/65 → p + q = 161.

검증(sympy, numpy):
- 실제 교점은 x = 0.333…, 1.333…, 2.333…이다.
- S₁ : S₂ = 5/11이 맞고, c ∈ ℝ에서 해는 1/3 하나다.
- 합은 96/65이다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - 비율 조건을 빼면 c가 결정되지 않는다.
  - "0이 아닌"을 빼면 k = 0일 때 넓이가 0이 되어 비율이 정의되지 않는다(이 조건은 정의를 위한 최소 조건이다).
  - 처음엔 "양수 k"로 쓰려 했지만, k < 0이 비율 조건만으로 배제되므로 "양수"는 쓸모없는 조건이었다. 그래서 바꿨다.
- **해석을 대신해주지 않았는지(원칙 2):**
  - "x좌표가 등차수열", "넓이가 등차수열"은 문장에 없다. 학생이 tan의 주기와 y좌표의 부호 교대를 보고 스스로 찾아야 한다.
  - Σ 1/(SₙSₙ₊₁)의 망원합 구조도 넓이 수열이 등차임을 알아야 드러난다.
- **그림:** 없음(그림을 주면 교점의 간격과 부호 교대가 바로 보인다).
- **풀이 갈래(원칙 4):**
  - 지름길: c, h를 구한 뒤 넓이 공식을 쓰지 않고 S₁, S₂, S₃을 직접 계산해서 등차임을 귀납적으로 확인할 수 있다.
  - 정공법: 일반항을 넓이 공식으로 유도한다.
  - 둘 다 같은 답에 닿는다.
- **경우 배제(원칙 5):** k < 0 배제는 "가장 작은 양의 해 c의 범위"라는 비교 대상이 자연스럽게 있다.
- **난이도(원칙 3, 한 단계 낮춰 봄):**
  - 단계는 다섯 개지만 각 단계가 익숙한 도구다.
  - 낯선 점은 "넓이 수열이 등차"라는 관찰 하나다.
  - 예상: 쉬운 준킬러(12~13번 자리).

## 자체 평가 (Claude)
- 삼각함수 교점의 주기성(L033)이 수열(L016)의 재료를 만드는 구조라서, 수1 안에서 두 단원이 이어진다.
- **걱정 1:** 발상이 "넓이가 등차" 하나라 목표(준킬러)보다 쉬울 수 있다. D002처럼 빨리 끝나는 느낌이 날 수 있다.
- **걱정 2:** 단답형으로 만들려고 "q/p, p + q"를 붙였다. 5지선다로 96/65를 묻는 것도 가능하다.

## 사용자 피드백 (2026-10-19) — 완성도 5/5, 난이도 중하
- **첫인상:** 신박하다. 뭘 하라는 건지 전혀 모르겠다.
- **사용자 풀이:** k가 양수일 때부터 그려봤는데 답이 나왔다. k가 음수여도 식은 똑같다. 사실 가정 자체가 필요 없었다.
  → 맞다. c를 "가장 작은 양의 해"로 두면 Sₙ = (h/2)(2c + 2n − 1)이 k의 부호와 무관하게 성립한다. 비율 조건에서 c = 1/3이 바로 나오므로 k > 0은 결과로 따라온다.
- **좋았던 점:** 삼각형 넓이를 생각하는 방식이 좋았다. 깔끔한 문제다. 교대수열을 쓴 것도 좋았다.
- **난이도 중하인 이유:** k를 가정하기 쉽고, 식도 무난하고, 교대수열도 자연스럽게 떠오른다. 과정이 짧지만은 않아서 "중"이지만, 중 치고는 쉬워서 "중하"다.

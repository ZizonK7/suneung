## 문항
자연수 n과 실수 k에 대하여 −4 ≤ x ≤ 3에서 정의된 함수

  f(x) = { |2^{x+4} − n|   (−4 ≤ x < 0)
         { sin(πx) + k     (0 ≤ x ≤ 3)

이 있다. 실수 t에 대하여 x에 대한 방정식 f(x) = t의 서로 다른 실근의 개수를 g(t)라 하자. g(t)의 최댓값이 6이 되도록 하는 자연수 n이 오직 하나일 때, k의 값은? [4점]

① 6  ② 13/2  ③ 7  ④ 15/2  ⑤ 8

## 정답
③ 7

## 풀이
1. **[L034] 사인 조각:** 0 ≤ x ≤ 3에서 y = sin(πx) + k는 봉우리 [0, 1]과 그것을 주기 2만큼 옮긴 [2, 3], 골짜기 [1, 2]로 이루어진다.
   - k < t < k + 1이면 직선 y = t는 두 봉우리에서 각각 2번 만난다(x₀, 1 − x₀, 2 + x₀, 3 − x₀). 그래서 4개다.
   - t = k이면 x = 0, 1, 2, 3에서 만나 역시 4개다. 양 끝점 0과 3이 모두 정의역에 들어 있기 때문이다.
   - 그 밖의 t에서는 2개 이하다. 따라서 이 조각의 교점은 최대 4개이고, 4개가 되는 t의 범위는 **k ≤ t < k + 1**이다(아래 끝이 닫혀 있다).
2. **지수 조각:** −4 ≤ x < 0에서 2^{x+4}는 1(포함)부터 16(미포함)까지 증가한다.
   - 2 ≤ n ≤ 15일 때 |2^{x+4} − n|은 x = −4에서 n − 1로 시작해 0까지 내려갔다가, x → 0⁻일 때 16 − n으로 다가간다. 이 값에 닿지는 않는다.
   - 교점 2개인 t의 범위는 두 끝값 중 작은 쪽까지다. 닫혔는지 열렸는지는 그 끝값이 어느 쪽에서 왔는지가 정한다.
     - n ≤ 8이면 n − 1 < 16 − n이다. 범위는 0 < t ≤ n − 1이다(x = −4가 포함되어 닫힘).
     - n ≥ 9이면 16 − n < n − 1이다. 범위는 0 < t < 16 − n이다(x = 0은 이 조각이 아니므로 열림).
   - n = 1 또는 n ≥ 16이면 단조라서 교점은 많아야 1개다.
3. **[L137] 동시에 최대:** 두 조각의 정의역은 겹치지 않는다. 그래서 g(t)는 두 조각의 교점 수를 더한 것이고, 4 + 2 = 6이 최댓값의 상한이다.
   - g(t)의 최댓값이 6이려면 두 조각이 **같은 t에서** 동시에 최대여야 한다.
   - 사인 조각의 범위 [k, k + 1)과 지수 조각의 범위가 겹쳐야 한다. 지수 조각의 범위는 0 근처에서 시작하므로 k > 0일 때 조건은 다음과 같다.
     - n ≤ 8: k ≤ n − 1
     - n ≥ 9: k < 16 − n
   - k ≤ 0이면 2 ≤ n ≤ 15가 모두 되거나(−1 < k ≤ 0) 하나도 안 된다(k ≤ −1).
4. **n이 하나뿐인 k:** 지수 조각의 위 끝값은 n − 1(n ≤ 8)과 16 − n(n ≥ 9)이다. 가장 큰 값은 7이고, n = 8(닫힘)과 n = 9(열림)가 함께 가진다.
   - k < 7이면 n = 8, 9가 모두 조건을 만족시켜 2개 이상이다.
   - k > 7이면 하나도 없다.
   - k = 7이면 n = 8만 된다. t = 7에서 x = −4, log₂15 − 4, 0, 1, 2, 3으로 6개다.
   - n = 9는 t = 7에서 지수 조각의 근이 x = −3 하나뿐이다. 2^{x+4} = 16의 근 x = 0은 사인 조각의 점이다. 그래서 최댓값이 5다.
   - 따라서 k = 7.

**지름길:** n과 17 − n은 위 끝값이 같다(n − 1 = 16 − (17 − n)). 차이는 닫힘(n ≤ 8)과 열림(n ≥ 9)뿐이다. "n이 오직 하나"이려면 k가 가장 높은 위 끝값 7에 정확히 놓여, 닫힌 쪽 n = 8만 남아야 한다. 이렇게 보면 3단계의 일반 조건을 다 쓰지 않아도 된다.

**정공법:** 0 < k < 7에서 조건을 만족시키는 n의 개수를 세면 (8 − ⌈k⌉) + (7 − ⌊k⌋) = 15 − ⌈k⌉ − ⌊k⌋다. 이 값은 정수 k에서만 홀수(15 − 2k)이고, 1이 되는 것은 k = 7뿐이다. k ≥ 7 쪽은 직접 확인한다.

6. **경우 나누기 필요성:** n ≤ 8과 n ≥ 9는 위 끝이 닫히느냐 열리느냐가 달라 실제로 다른 부등식(≤, <)이 나온다. 가정 없이 한 식으로 쓸 수 없다.
7. **버려지는 대상:**
   - 사인 조각의 위 끝 k + 1은 쓰이지 않는다. 지수 조각의 범위가 늘 0 근처부터라 겹침의 위쪽은 자동이다.
   - 근 log₂15 − 4는 존재 확인에만 쓰인다.
   - 나머지(n − 1, 16 − n, 0·1·2·3)는 모두 판단에 쓰인다.
8. (미적분 아님)

- **난이도:** 판단은 지수 조각 위 끝의 닫힘·열림(두 종류), 사인 조각 아래 끝의 닫힘, 동시 최대(L137), 개수가 1이 되는 k를 거꾸로 찾기다. 첫 예상은 중상이다. 지름길이 짧아 한 단계 내려 중으로 적는다.

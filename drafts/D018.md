## 문항
양수 a, b와 실수 c에 대하여 함수

  f(x) = a sin bx + c

가 다음 조건을 만족시킨다.

(가) 모든 실수 x에 대하여 f(x) + f(x + π) = 6이다.
(나) 닫힌구간 [0, t]에서 함수 f(x)의 최솟값이 −1이 되도록 하는 양수 t의 최솟값은 π/4이다.

a × b의 값은? [4점]

① 20  ② 24  ③ 28  ④ 20√2  ⑤ 24√2

## 정답
④ 20√2 (a = 4√2, b = 5, c = 3)

## 풀이
1. **[L059] (가) 읽기:** f(x) + f(x + π) = a{sin bx + sin(bx + bπ)} + 2c = 6이 모든 x에서 성립한다.
   - x = 0을 넣으면 a sin bπ + 2c = 6이고, 상수항을 비교하면 2c = 6이다. 그래서 c = 3이고 sin(bx + bπ) = −sin bx가 모든 x에서 성립해야 한다.
   - 각을 π의 정수배만큼 옮길 때 부호만 바뀌는 것은 홀수배일 때다. bπ = π, 3π, 5π, … 이므로 **b는 홀수**다(b = 1, 3, 5, 7, …).
   - b = 2만 떠올리기 쉽다. 그런데 b = 1은 (나)에서 바로 막히고, 다음 단계에서 b의 후보 전체가 필요하다.
2. **[L160] (나) 읽기: 최솟값은 값 조건과 위치 조건으로 나뉜다.**
   - f(0) = c = 3이고 a, b > 0이라 f는 처음에 올라간다. 그래서 [0, t]의 최솟값은 bt ≤ π인 동안 3에 머문다.
   - π < bt ≤ 3π/2이면 최솟값은 끝점 값 f(t) = a sin bt + 3이고, 계속 작아진다.
   - bt ≥ 3π/2이면 최저점을 품으므로 최솟값은 c − a로 고정된다.
   - "−1에 처음 닿는 t가 π/4"이다. 그러면 π/4는 최솟값이 작아지는 구간에 있어야 한다. 즉 π < bπ/4 ≤ 3π/2이므로 4 < b ≤ 6이다.
3. **분기:** 학생이 L160을 그대로 쓰면 "x = π/4에서 최솟값 −1 → c − a = −1, bπ/4 = 3π/2 → b = 6, a = 4"로 간다(선지 ② 24).
   - 이 길은 (가)의 "b는 홀수"와 부딪힌다.
   - 그래서 π/4는 최저점이 아니다. [0, π/4]가 최저점을 품지 않고, 최솟값이 끝점 값인 경우다.
   - 4 < b < 6이고 b는 홀수이므로 b = 5이다.
4. bπ/4 = 5π/4이므로 f(π/4) = a sin(5π/4) + 3 = 3 − (√2/2)a = −1이고, a = 4√2이다.
   - 확인: 최솟값은 t = π/5(bt = π)까지 3이다. 그 뒤 t = π/4에서 처음 −1에 닿고, t = 3π/10에서 c − a = 3 − 4√2까지 내려간다.
5. a × b = 4√2 × 5 = **20√2**.

**지름길:** 2단계에서 경우를 나누지 않는다. "누적 최솟값이 바뀌는 것은 각이 (π, 3π/2]에 있을 때뿐"이라는 것만 보면 4 < b ≤ 6이다. 여기에 (가)의 홀수 조건을 더하면 b = 5가 바로 나온다.
**정공법:** b = 1, 3, 5, 7, …을 차례로 넣어 본다.
- b = 1, 3이면 bπ/4 ≤ π라서 [0, π/4]의 최솟값이 3이다.
- b ≥ 7이면 최저점 t = 3π/(2b)가 π/4보다 앞에 있어, 처음 닿는 t가 π/4보다 작다.
- 남는 b = 5에서 a를 구한다.

## LESSONS 자체 검수
1. **조건 빼기:** 위 검사대로 (가)의 6과 홀수 정보, a > 0, b > 0, "t의 최솟값", −1, π/4가 모두 필요하다. 군더더기 조건은 없다.
2. **카드가 단계를 결정하는가:** L059는 (가)에서 b가 홀수라는 것을 정한다. 이 정보가 없으면 b ∈ (4, 6]의 연속체가 남는다. L160은 (나)에서 "최저점을 품는가(값 c − a, 각 3π/2) / 품지 않아 끝점 값인가"를 가르는 분기점이다. 둘 다 답을 바꾼다.
3. **해석을 대신해주지 않는가:** "누적 최솟값", "b는 홀수", "π/4는 최저점이 아니다"는 문장에 없다. 새 함수 g(t)도 정의하지 않았다(D010 교훈). 학생이 "[0, t]의 최솟값이 처음 −1"을 번역해야 한다.
4. **지름길:** 각의 범위 (π, 3π/2]만 보면 4 < b ≤ 6 → b = 5다. 정공법(b를 차례로 대입)도 짧게 끝까지 간다. 둘 다 20√2다.
5. **배제의 비교 대상:** b = 6(최저점 가정)을 지우는 근거는 (가)에서 얻은 "b는 홀수"다. 문제 안에 있고 바로 앞 단계에서 얻은 것이다. b ≥ 7을 지우는 근거도 문장의 "최솟값(처음)"이다.
6. **경우 나누기가 필요한가:** 지름길처럼 4 < b ≤ 6으로 한 번에 쓰면 "최저점인가/끝점인가"를 나눌 필요가 없다. 그래서 이 분기는 난이도 근거로 세지 않았다. L160을 그대로 쓰는 학생에게는 함정이 되는 자리일 뿐이다.
7. **조건이 만든 대상이 쓰이는가:** c = 3은 a를 구하는 데 쓰이고, b = 5와 a = 4√2는 답에 들어간다. 버려지는 것이 없다.
8. (미적분 해당 없음)
9. **답이 준 값을 다시 쓰는가:** 답 a × b의 a = 4√2, b = 5는 모두 조건을 풀어야 나온다. 문제의 6, −1, π/4는 답 식에 그대로 들어가지 않는다.
- **난이도:** 판단은 두 가지다. (가)에서 b를 홀수 전체로 잡는 것과 (나)를 누적 최솟값으로 번역하는 것이다. 첫 예상은 중이고, 한 단계 내려 중하로 적는다. 경계 종류가 많지 않으므로(최솟값이 줄기 시작하는 각 π, 최저점 각 3π/2) 내리는 규칙을 그대로 따랐다.

## 문항
삼차함수 f(x)와 실수 k에 대하여 함수

  f(|x − k|) − |f(x)|

가 실수 전체의 집합에서 미분가능하다. f(2) = 0일 때, 가능한 모든 k의 값의 합은? [4점]

① 2  ② 6  ③ 8  ④ 10  ⑤ 16

## 정답
④ 10

## 풀이
1. **[L148] 꺾이는 점 찾기:**
   - f(|x − k|)는 x = k에서만 꺾일 수 있다. 우미분계수는 f′(0), 좌미분계수는 −f′(0)이므로 꺾임(우 − 좌)은 2f′(0)이다.
   - |f(x)|는 f의 단순근 r에서만 꺾이고 꺾임은 2|f′(r)|이다. 이중근·삼중근에서는 미분가능하다. 따라서 −|f(x)|의 꺾임은 −2|f′(r)|로 항상 음수다.
   - 합이 미분가능하려면 꺾임이 모두 상쇄되어야 한다. −|f|의 꺾임을 지울 수 있는 것은 x = k의 꺾임 하나뿐이다. 그래서 다음 둘 중 하나다.
     - (i) 꺾임이 하나도 없다: f′(0) = 0이고 f가 단순근을 갖지 않는다. 그러면 f = A(x − d)³이고 f′(0) = 3Ad² = 0이므로 f = Ax³이다. f(2) ≠ 0이라 맞지 않는다.
     - (ii) f의 단순근은 k 하나이고, 2f′(0) = 2|f′(k)|이다. 나머지 두 근은 이중근이거나 허근이다.
2. **부호 판단:** f = A(x − k)Q(x)로 두면 Q는 x축 아래로 내려가지 않는다(이중근 또는 허근).
   - f′(k) = A·Q(k)이고 f′(0) = |f′(k)| > 0이다.
   - A < 0이면 f′(k) < 0이므로 f′(0) = −f′(k), 즉 f′(0) + f′(k) = 0이어야 한다. 그런데 Q = (x − u)² + w²로 두고 계산하면 f′(0) + f′(k) = A(k² + 2u² + 2w²)이고, 이것이 0이면 k = u = w = 0, 곧 f = Ax³라 단순근 k가 없다. 그래서 A < 0은 불가능하다.
   - 따라서 A > 0이고 f′(0) = f′(k)이다.
3. **도함수의 대칭:** k ≠ 0이면 f′(0) = f′(k)에서 0과 k가 f′의 축, 즉 변곡점의 x좌표에 대해 대칭이다. 변곡점의 x좌표는 k/2이다.
   - Q의 꼭짓점을 u라 하면 변곡점은 (k + 2u)/3이다. (k + 2u)/3 = k/2에서 k = 4u이다.
   - k = 0이면 f′(0) = f′(k)는 저절로 성립한다(f(|x|)와 |f|가 x = 0에서 같은 크기로 꺾인다).
4. **f(2) = 0 읽기:** 2는 단순근(= k)이거나 Q의 근(이중근 u)이다.
   - 2가 단순근: k = 2, Q의 꼭짓점 u = 1/2. 예: f = (x − 2)(x − 1/2)². Q가 허근을 가져도 된다((x − 2){(x − 1/2)² + 3}도 성립).
   - 2가 이중근: u = 2이므로 k = 4u = 8, 또는 k = 0. f = (x − 8)(x − 2)² 또는 x(x − 2)².
5. 가능한 k는 0, 2, 8이고 합은 10이다. → ④

**지름길:** 이중근 꼴 f = (x − k)(x − s)²를 바로 놓고 f′(0) = f′(k)를 쓰면 k(k − 4s) = 0이다. 2가 이중근(s = 2)이면 k = 0, 8이고, 2가 단순근이면 k = 2(s = 1/2)이다. 허근 경우와 A < 0을 따지지 않아도 같은 k가 나온다.

**정공법:** 1~2단계로 f = A(x − k)Q(x), A > 0을 얻은 뒤 f′(0) = f′(k)를 계산한다. 이중근 꼴이면 f′(0) = A(s² + 2ks), f′(k) = A(k − s)²에서 4ks = k²이다. 허근 꼴 Q = (x − u)² + w²이면 같은 계산으로 4ku = k²이다(w는 지워진다). 2가 단순근이면 k = 2를 넣어 u = 1/2를 얻는다.

## 검증
verify.py (sympy, numpy):
- **기호 계산:** f = (x − k)(x − s)²에서 f′(0) − f′(k) = k(4s − k). Q가 허근일 때도 f = (x − k){(x − u)² + w²}에서 k(4u − k)로 w와 무관하다. 계수가 음수일 때 필요한 f′(0) + f′(k) = 0은 k² + 2s² (또는 k² + 2u² + 2w²) = 0이라 불가능하다.
- **전수 탐색:** f = A(x − 2)(x² + px + q)에서 A ∈ {1, 2, −1, −2}, p ∈ [−12, 12], q ∈ [−20, 20], k ∈ [−20, 20]을 0.25 간격으로 훑었다. x = k와 f의 실근마다 좌우 미분계수 차를 수치로 계산했다.
  - A > 0: k = 0 (x(x − 2)²), k = 2 (p = −1, q ≥ 1/4 전부), k = 8 ((x − 8)(x − 2)²).
  - A < 0: 해가 없다.
  - 가능한 k = {0, 2, 8}, 합 10.
- **해의 직접 확인:** 네 해에서 좌우 미분계수 차가 10⁻⁵ 수준이다. 반례 (x − 2)x(x − 1), k = 2에서는 4이다.
- **조건 빼기 검사:**
  - f(2) = 0을 빼면 f = x³이 모든 k에서 성립해 k가 정해지지 않는다.
  - 미분가능 조건을 빼면 k가 자유다.
  - "최고차항의 계수가 1"은 처음에 넣었다가 뺐다. 양수 계수는 같은 k 집합을 주고 음수 계수는 해가 없어서 쓸모없었다(D014 교훈). 빼면 학생이 계수의 부호를 판단해야 한다.
  - k = 0 갈래는 합에 영향을 주지 않는다. "0이 아닌 k" 같은 조건은 쓸모없어 넣지 않았다.
- **선지:**
  - ① 2: 2를 단순근으로만 본다(k = 2만).
  - ② 6: 이중근을 변곡점 쪽으로 잘못 두어 k = 2s = 4, 4 + 2.
  - ③ 8: 2를 이중근으로만 본다(k = 0, 8).
  - ④ 10: 정답.
  - ⑤ 16: k = 8을 두 번 센다.

## LESSONS 자체 검수
1. **조건 빼기:** f(2) = 0, 미분가능 조건 모두 필요하다. 쓸모없던 "최고차항의 계수가 1"은 지웠다.
2. **카드 사용:** L148이 1단계의 분기(꺾임이 없는 경우 / k에서 상쇄되는 경우)를 결정한다. 나머지 네 장은 억지라서 뺐고, 이유는 추출 기록에 적었다. 한 장만 쓴 것이 약점이다.
3. **번역을 대신하지 않는지:** 문장에는 "단순근은 k 하나", "f′(0) = f′(k)", "변곡점 k/2"가 없다. 학생이 꺾임 상쇄에서 끌어내야 한다.
4. **지름길:** 이중근 꼴을 바로 놓고 k(k − 4s) = 0을 얻는다. 정공법(허근·음수 계수까지 따짐)도 끝까지 간다.
5. **배제의 비교 대상:** f = Ax³ 배제는 f(2) = 0과 바로 비교한다. 2가 단순근인지 이중근인지는 "f(2) = 0"이 직접 묻는 갈래라 비교 대상이 문제 안에 있다.
6. **필요 없는 경우 나누기:** 허근 경우와 A < 0은 엄밀한 풀이에서 확인할 것이다. 지름길에서는 필요 없다. 난이도 근거로 세지 않았다.
7. **버려지는 대상:** 단순근 k, 이중근 s = k/4는 모두 답(k의 합)에 쓰인다. k = 0 갈래는 풀이에서 k(k − 4s) = 0의 근으로 자연스럽게 나오지만 합에는 0을 더한다. 장치가 버려졌다고 볼 수도 있다(걱정 2).
8. (미적분 아님)
9. **준 값 재사용:** 답 10 = 2 + 8에서 2는 문제에 준 근이다. 단, k = 2는 "2가 단순근일 수도 있다"는 판단을 거쳐야 나오고, 8은 k = 4s를 풀어야 나온다. 경계 사례로 기록한다.
- **난이도:** 판단은 셋이다. 꺾임 상쇄(핵심), 부호 판단(f′(0) = +f′(k)), 2의 역할 갈래. 첫 예상 중상에서 한 단계 내려 중으로 적는다.

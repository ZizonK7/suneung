## 문항
공비가 0이 아닌 등비수열 {aₙ}의 첫째항부터 제n항까지의 합을 Sₙ이라 할 때, 다음 조건을 만족시킨다.

  (가) x에 대한 방정식 x² − (a₂ + a₅)|x| + a₁a₆ = 0의 서로 다른 실근의 개수는 2이다.
  (나) S₄ − S₂ = 12, S₈ − S₆ = 3/4

a₁의 값을 구하시오. [4점]

## 정답: 96

## 풀이
1. **[L037]** S₄ − S₂ = a₃ + a₄, S₈ − S₆ = a₇ + a₈ = r⁴(a₃ + a₄)이므로 r⁴ = 1/16, r = ±1/2.
   a₃ + a₄ = a₁r²(1 + r) = 12에서:
   - r = 1/2이면 a₁ = 32
   - r = −1/2이면 a₁ = 96
2. **[L030]** 1 + 6 = 2 + 5이므로 a₁a₆ = a₂a₅이다.
3. **[L013]** 근은 x와 −x가 짝을 이루므로 x ≥ 0 쪽만 보면 된다. x ≥ 0에서 방정식은 x² − (a₂ + a₅)x + a₂a₅ = (x − a₂)(x − a₅) = 0이므로, 실근은 a₂, a₅ 중 양수인 것과 그 부호를 바꾼 것이다.
   - r = 1/2: a₂ = 16, a₅ = 2(둘 다 양수) → 실근 ±16, ±2로 4개 ✗
   - r = −1/2: a₂ = −48, a₅ = 6(부호가 다름) → 실근 ±6으로 2개 ✓
4. a₁ = 96.

검증(sympy):
- (나)의 실수해는 (a₁, r) = (32, 1/2), (96, −1/2) 두 개다.
- 각각 (가)의 서로 다른 실근은 4개, 2개다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - (가)를 빼면 a₁이 32와 96 두 개다.
  - (나)의 두 식 중 하나라도 빼면 r 또는 a₁이 결정되지 않는다.
  - "공비가 0이 아닌"은 등비수열 정의상 자연스러운 최소 조건이다.
- **해석을 대신해주지 않았는지(원칙 2):**
  - a₁a₆ = a₂a₅라서 인수분해된다는 사실은 숨겼다. 일부러 a₃a₄가 아니라 a₁a₆으로 써서 잘 안 보이게 했다.
  - "실근 2개 → a₂, a₅의 부호가 다르다 → r < 0"도 학생이 번역해야 한다.
- **풀이 갈래(원칙 4):**
  - 지름길: L030을 보고 바로 인수분해한다.
  - 정공법: a₁, r로 전부 전개한 뒤 판별식이나 근의 공식으로 근을 따진다.
  - 둘 다 같은 답에 닿는다.
- **경우 배제(원칙 5):** r = 1/2을 배제할 때의 비교 대상은 "근의 개수 2"라는 조건 자체라서 자연스럽다.
- **없는 단계 확인(원칙 6):** r = ±1/2 경우 나누기는 (나)만으로 실제로 두 해가 나오므로 진짜 필요한 단계다.
- **난이도(한 단계 낮춰 봄):** 각 단계가 짧다. 핵심 발상은 "a₁a₆ = a₂a₅로 인수분해"와 "근 2개 → 부호 반대" 두 개다. 예상: 중하.

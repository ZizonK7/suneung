## 문항
최고차항의 계수가 1인 삼차함수 f(x)가 f(0) = 0이고 극값을 갖는다. 상수 s에 대하여 함수

  g(x) = { f(x) (x ≥ 0), f(x − 4) + s (x < 0) }

가 실수 전체에서 미분가능하고 증가할 때, g(1) − g(−1)의 값이 될 수 있는 정수의 개수를 구하시오. [4점]

## 정답: 24

## 풀이
1. **구조:** x < 0 부분은 f의 그래프를 (4, s)만큼 평행이동한 것이다. x = 0에서 이어지려면 s = f(0) − f(−4)이다. 그래서 이동 벡터 (4, s)는 두 점 (−4, f(−4)), (0, f(0))을 잇는 현의 방향이다 **[L007]**.
   - 즉 g는 f의 그래프에서 [−4, 0] 부분을 잘라 내고 양쪽을 붙인 것이다.
2. **미분가능:** f′(−4) = f′(0). f′은 이차함수이므로 −4와 0은 f′의 축에 대해 대칭이다 → 축 x = −2.
   - f(x) = x³ + ax² + bx라 하면 −a/3 = −2 → a = 6이다.
3. **[L089] 증가:** g′ ≥ 0이어야 한다.
   - x ≥ 0에서 f′의 최솟값은 f′(0) = b이고(축이 −2), x < −4에서도 f′(x)의 최솟값은 f′(−4) = b다. → b ≥ 0.
   - f가 감소하는 구간은 축 −2를 가운데로 하므로 잘라 낸 [−4, 0] 안에 들어간다.
4. **극값:** f′ = 3x² + 12x + b의 판별식 > 0 → b < 12.
5. g(1) − g(−1) = f(1) − {f(−5) + s} = (7 + b) − {(25 − 5b) + (4b − 32)} = 14 + 2b ∈ [14, 38).
6. 정수 14, 15, …, 37 → 24개.

검증(sympy, numpy):
- f′(−4) = f′(0)에서 a = 6이다. g(1) − g(−1) = 2b + 14이다.
- b = −1이면 g가 증가하지 않는다. b = 0, 5, 11.9이면 증가하고 극값이 있다. b = 12, 15이면 증가하지만 f의 극값이 없다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - "극값을 갖는다"를 빼면 b의 상한이 없어 정수가 무한하다.
  - "증가"를 빼면 b의 하한이 없다.
  - "미분가능"을 빼면 a가 정해지지 않는다.
  - f(0) = 0이 없으면 상수항이 남지만 g(1) − g(−1)에서 지워진다. 그래서 f(0) = 0은 사실 필요 없다(원칙 1). 남겨 둔 이유는 f를 x³ + ax² + bx로 놓기 쉽게 하려는 것뿐이라, 빼는 쪽이 맞을 수 있다.
- **해석을 대신해주지 않았는지(원칙 2):** "감소 구간을 잘라 낸다"는 문장에 없다. 미분가능 조건을 f′의 대칭으로 읽는 것도 학생 몫이다.
- **답이 준 값을 다시 쓰는지(원칙 9):** 답은 b의 범위에서 나온다. 준 값 4는 축 −2와 a를 정하는 데만 쓰인다.
- **풀이 갈래(원칙 4):** 지름길은 f′의 대칭(축 −2)이다. 정공법은 f′(−4) = f′(0)을 바로 계산하는 것이다(48 − 8a = 0). 둘 다 짧다.
- **난이도(한 단계 낮춰 봄):** 판단은 "잘라 붙인 그래프"를 읽는 것, 증가 조건을 경계에서 보는 것, 극값 조건을 상한으로 쓰는 것 셋이다. 각 단계가 짧아 첫 예상 중에서 한 단계 내려 중하로 적는다.

## 자체 평가 (Claude)
- **좋은 점:** 삼차함수의 감소 구간을 잘라 내고 붙이면 증가함수가 된다는 그림이 낯설다. 미분가능 조건이 f′의 대칭으로 바뀌는 것도 깔끔하다.
- **걱정 1:** f(0) = 0이 필요 없는 조건일 수 있다(위 검수).
- **걱정 2:** 답이 "범위 안 정수 개수"라 마지막 단계가 기계적이다.

## 사용자 피드백 (2026-10-19) — 완성도 3/5, 난이도 중하
- f(0) = 0이라는 조건은 필요가 없다. 이것만 빼면 더 괜찮을 것 같다.
- 극값(감소 구간)만 없애면 되기 때문에 그리 복잡하지 않다.
- 난이도: 변곡점의 x좌표가 −2라는 것과 극솟점의 x좌표가 0 이하라는 것만 쓰면 되므로 중하. 하를 주기에는 생각할 게 있다.

## 수정본 (f(0) = 0을 뺌)
최고차항의 계수가 1인 삼차함수 f(x)가 극값을 갖는다. 상수 s에 대하여 함수

  g(x) = { f(x) (x ≥ 0), f(x − 4) + s (x < 0) }

가 실수 전체에서 미분가능하고 증가할 때, g(1) − g(−1)의 값이 될 수 있는 정수의 개수를 구하시오. [4점]

- 답은 그대로 24다. f(x) = x³ + ax² + bx + c로 놓으면 s = f(0) − f(−4)라서 g(1) − g(−1) = f(1) − f(−5) − f(0) + f(−4)이고, c가 지워져 2b + 14가 된다(sympy 확인).

## 돌아보기 (Claude)
- 자체 검수에서 f(0) = 0이 쓸모없다는 것을 찾고도 "f를 놓기 쉽게" 하려고 남겼다. 찾았으면 지웠어야 했다(LESSONS 원칙 1에 추가).
- 사용자 풀이는 "변곡점 x = −2, 극솟점 x ≤ 0" 두 줄이다. 내 풀이(f′의 최솟값을 양쪽에서 비교)보다 짧다. 증가 조건을 "감소 구간이 잘라 낸 [−4, 0] 안에 든다"로 바로 읽으면 극솟점 하나만 보면 된다.
- 난이도는 중하로 예상했고 실제도 중하였다. 처음으로 한 단계 내린 값이 그대로 맞았다.

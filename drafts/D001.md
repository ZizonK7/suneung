## 문항
함수 y = h(x)의 그래프가 그림과 같다.

> [그림] h(x) = x + 2 (x < 0), h(x) = x − 1 (x ≥ 0)
> x < 0에서 기울기 1인 반직선, (0, 2)는 빈 점.
> x ≥ 0에서 기울기 1인 반직선, (0, −1)은 채운 점.

곡선 y = f(x)가 원점을 지나는 최고차항의 계수가 1인 삼차함수 f(x)와 양수 c에 대하여 함수 G(x)를

  G(x) = h(x) × f(x + c) / f(x)  (f(x) ≠ 0)
  G(x) = 0                        (f(x) = 0)

이라 하자. 함수 G(x)는 x = 0에서 연속이다.
곡선 y = f(x)의 극대점을 A, 극소점을 B라 할 때, 삼각형 OAB의 넓이가 6이다.
G(4)의 값을 구하시오. (단, O는 원점이다.) [4점]

## 정답: 84

## 풀이
1. **[L004]** 그래프에서 lim_{x→0−} h(x) = 2, lim_{x→0+} h(x) = −1이다. h는 x=0에서 끊긴다.
2. **[L003]** r = lim_{x→0} f(x+c)/f(x)라 하면, 좌극한 2r과 우극한 −r이 같고 G(0)=0이어야 하므로 r = 0이다.
   f(0)=0이므로 분모는 x=0에서 0이다. r = 0이려면 f(x+c)가 x=0에서 f(x)보다 높은 차수의 근을 가져야 한다.
   f(x+c)의 x=0에서의 근 차수는 f의 x=c에서의 근 차수와 같다.
   f의 근 차수 합은 3이므로, x=0에서 1차, x=c에서 2차일 수밖에 없다. 따라서 f(x) = x(x − c)².
   - 확인: f(x+c)/f(x) = x(x+c)/(x−c)² → 0.
3. f′(x) = (x − c)(3x − c). 극대점 A(c/3, 4c³/27), 극소점 B(c, 0).
4. **[L008]** 넓이 = ½·|x_A·y_B − x_B·y_A| = 2c⁴/27 = 6 → c = 3.
5. G(4) = h(4)·f(7)/f(4) = 3 × 112 / 4 = **84**.

검증: sympy로 c=3일 때 G(±10⁻⁶) → 0, G(4) = 84 확인.

## 자체 평가 (Claude)
- **L003이 사실상 핵심이 됐다.** 메인으로 뽑힌 L004는 "x=0에서 좌·우극한이 다르다"를 읽는 데만 쓰였다. 메인이 기초 카드일 때 메인답게 쓰는 방법을 정해야 한다.
- **2409_15와 구조가 닮았다.** G(x)를 "f(x+c)/f(x), 근에서는 예외값"으로 정의한 틀이 L003의 출처 문항에서 거의 그대로 왔다. 대신 2409_15는 "극한 존재 → 근 하나 추가"였고, D001은 "점프 × 비율 → 비율이 0 → 중근"으로 한 단계를 비틀었다.
- **L008이 가볍게 쓰였다.** B가 x축 위에 있어서 사실상 ½·밑변·높이 계산이다.
- **"원점을 지난다"를 조건으로 직접 줬다.** 이 조건이 없으면 f(0)≠0, f(c)=0인 경우도 x=0에서 연속이 되어 f가 결정되지 않는다. 동시에 삼각형 OAB의 O와 이어지도록 의도했다.
- 예상 난이도: 4점 단답 중간(14~15번 또는 20번).

## 사용자 피드백 (2026-10-19)
요지: **쓸데없이 주어진 것이 많다.**
- h(x)가 의미 없이 쓰였다. G(0)=0으로 정의했으므로, x=0에서 연속이려면 h와 무관하게 극한이 0이어야 한다. 그래서 비율 극한이 0이라는 결론이 h 없이도 나온다. h의 점프는 풀이에 아무 역할을 하지 않는다.
- 같은 이유로 h(x)의 식도 사실상 필요 없었다.
- h(x)를 그림으로 줄 필요도 없었다. 그림을 해석하는 문제가 아니기 때문이다.

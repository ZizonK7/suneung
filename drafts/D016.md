## 문항
두 수열 {aₙ}, {bₙ}이 모든 자연수 n에 대하여

  aₙbₙ = 0,  |aₙ| + |bₙ| = 2ⁿ⁻¹

을 만족시킨다. Σ_{n=1}^{7} aₙ = 40, Σ_{n=1}^{7} bₙ = −65일 때, Σ_{n=1}^{7} |aₙ|의 값은? [4점]

① 40  ② 48  ③ 56  ④ 62  ⑤ 71

## 정답
③ 56

## 풀이
0. **번역:** aₙbₙ = 0이므로 각 n에서 둘 중 하나는 0이고, 나머지 하나는 2ⁿ⁻¹ 또는 −2ⁿ⁻¹이다. 경우는 n마다 네 가지다: (aₙ, bₙ) = (±2ⁿ⁻¹, 0), (0, ±2ⁿ⁻¹).
1. **[L102] 가장 큰 항부터 정한다:** 1 + 2 + ⋯ + 2ⁿ⁻² = 2ⁿ⁻¹ − 1 < 2ⁿ⁻¹이다. 그래서 앞의 n − 1개 항은 아무리 모아도 n번째 항을 넘지 못한다.
   - Aₘ = Σ_{n≤m} aₙ, Bₘ = Σ_{n≤m} bₙ이라 하면 |Aₘ| + |Bₘ| ≤ 2ᵐ − 1이다.
   - 이 부등식이 n = 7부터 거꾸로 한 항씩 정하는 비교 기준이다.
2. **n = 7:** (A₇, B₇) = (40, −65)이다. 7번째 항을 빼서 (A₆, B₆)의 후보 넷을 만든다.
   - a₇ = ±64이면 (−24, −65), (104, −65)이다.
   - b₇ = ±64이면 (40, −129), (40, −1)이다.
   - |A₆| + |B₆| ≤ 63인 것은 (40, −1)뿐이다 → b₇ = −64.
3. **n = 6:** 한계는 31이다. (40, −1)에서 a₆ = 32만 통과한다 → (8, −1).
4. **n = 5:** 한계는 15다. a₅ = 16만 통과한다 → (−8, −1).
   - 여기서 Σaₙ = 40인데 a₅, a₆이 둘 다 양수라 그 합이 48이다. 40보다 커서 음수 항이 필요하다는 것이 드러난다.
5. **n = 4:** 한계는 7이다. a₄ = −8만 통과한다 → (0, −1).
6. **n = 3, 2, 1:** b₃ = −4 → (0, 3), b₂ = 2 → (0, 1), b₁ = 1 → (0, 0)이다.
7. 따라서 a = (0, 0, 0, −8, 16, 32, 0), b = (1, 2, −4, 0, 0, 0, −64)이다. Σ|aₙ| = 8 + 16 + 32 = **56**.

**지름길 (두 번의 2211_21):** cₙ = aₙ + bₙ, dₙ = aₙ − bₙ으로 두면 |cₙ| = |dₙ| = 2ⁿ⁻¹이고, 부호만 모른다.
- Σcₙ = 40 − 65 = −25이다. 127 − 2 × (음수 항 절댓값 합) = −25 → 음수 항의 합 76 = 64 + 8 + 4 → c₃, c₄, c₇만 음수.
- Σdₙ = 40 + 65 = 105이다. 음수 항 절댓값 합 11 = 8 + 2 + 1 → d₁, d₂, d₄만 음수.
- **[L102]** 위 두 해독에서 이진 표현이 유일하므로 부호가 하나로 정해진다.
- aₙ ≠ 0 ⟺ cₙ = dₙ이다(bₙ ≠ 0이면 cₙ = −dₙ). 부호가 같은 n은 4, 5, 6 → Σ|aₙ| = 8 + 16 + 32 = 56.

**함정:** |Σaₙ| = 40을 이진수 32 + 8로 읽고 a₄, a₆만 0이 아니라고 하면, 남은 {1, 2, 4, 16, 64}의 부호로 −65를 만들 수 없다. aₙ에도 음수가 섞여 있다는 것을 알아야 한다.

## LESSONS 자체 검수
1. **조건 빼기:** 네 조건이 모두 필요하다(위 검증). 군더더기 조건은 없다.
2. **카드 사용:** L102가 정공법(마지막 항부터)과 지름길(두 번의 이진 해독) 모두에서 분기점이다. 나머지 네 장은 장식이 되어 뺐다.
3. **해석을 대신해 주는지:** "둘 중 하나만 ±2ⁿ⁻¹", "cₙ, dₙ으로 바꾸면 부호만 모르는 2의 거듭제곱", "앞 항의 합은 다음 항을 못 넘는다"는 문장에 없다.
4. **지름길:** cₙ, dₙ 변환으로 2211_21형 두 번에 끝난다. 정공법(n = 7부터 후보 넷 비교)도 끝까지 간다. 둘이 같은 답에 닿는다.
5. **배제의 비교 대상:** 후보를 지울 때 비교 대상은 |Aₘ| + |Bₘ| ≤ 1 + 2 + ⋯ + 2ᵐ⁻¹이다. 조건 |aₙ| + |bₙ| = 2ⁿ⁻¹을 더하기만 하면 나오는 값이라 문제 안에 있다.
6. **경우 나누기 필요성:** 정공법의 후보 비교는 실제로 후보를 지운다. 단, 지름길에서는 경우 나누기가 없다. 그래서 정공법의 7단계를 난이도 근거로 세지 않았다.
7. **조건이 만든 대상:** 해독된 bₙ의 위치가 aₙ = 0인 n을 정한다. 버려지는 것은 bₙ의 부호뿐이고, 이것도 해독 과정에서 쓰인다.
8. (미적분 아님)
9. **준 값의 재사용:** 답 56 = 8 + 16 + 32는 해독해야 나온다. 문제의 40, −65는 답 계산에 들어가지 않는다. 56 − 16 − 32 = −8처럼 Σaₙ 확인용으로만 쓰인다.
- **난이도:** 첫 예상은 중상이다. 메인 카드를 2차원으로 확장하는 판단(어느 수열에 들어가는지)과 부호 판단이 겹친다. 한 단계 내려 중으로 적는다. 판단의 종류는 "번역"과 "큰 항부터" 둘이고, 후보 비교는 반복이라 내렸다.

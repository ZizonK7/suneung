## 문항
시각 t = 0일 때 원점을 출발하여 수직선 위를 움직이는 점 P의 시각 t (t ≥ 0)에서의 속도 v(t)가

  v(t) = lim_{n→∞} { t^{2n}(t − 1)(t − a) + (t − 1)(t − b) } / ( t^{2n} + 1 )

이다. 점 P가 다음 조건을 만족시킬 때, a + b의 값을 구하시오. (단, a, b는 상수이다.) [4점]

(가) 점 P는 출발한 후 운동 방향을 한 번만 바꾼다.
(나) 점 P가 운동 방향을 바꾸는 시각에서의 점 P의 위치는 −2이고, 시각 t = 4에서의 점 P의 위치는 −2/3이다.

## 정답: 2

## 풀이
1. **[L061] 속도 읽기:**
   - 0 ≤ t < 1이면 t^{2n} → 0이므로 v = (t − 1)(t − b)이다.
   - t > 1이면 분모·분자를 t^{2n}으로 나누어 v = (t − 1)(t − a)이다.
   - t = 1이면 v(1) = 0이고, v는 t = 1에서 연속이다.
2. **[L067] 방향이 바뀌는 곳:** 방향 전환은 v의 부호 변화다.
   - (1, ∞): a > 1이면 t = a에서 바뀐다.
   - (0, 1): 0 < b < 1이면 t = b에서 바뀐다.
   - **t = 1:** v(1) = 0이고 (t − 1)은 단순 인수다. 하지만 다른 인수가 t − b에서 t − a로 갈아타므로 부호 변화는 1 − b와 1 − a의 부호에 달려 있다. 왼쪽 부호는 −(1 − b)의 부호, 오른쪽 부호는 (1 − a)의 부호다. 따라서 **a, b가 1의 같은 쪽에 있을 때만** t = 1에서 방향이 바뀐다.
3. **(가) 한 번만:** 가능한 경우는 둘이다.
   - (A) a ≤ 1, b ≤ 0: t = 1에서만 바뀐다.
   - (B) a > 1, b ≤ 0: t = a에서만 바뀐다. 이때 t = 1에서는 v = 0이지만 방향이 바뀌지 않는다.
   - 0 < b < 1이거나 b ≥ 1이면 두 번 이상 바뀌거나 한 번도 안 바뀐다.
4. **[L060] (A) 배제:** 바뀌는 시각이 1이므로 x(1) = ∫_0^1 (t − 1)(t − b)dt = −1/6 + b/2 = −2 → b = −11/3이다.
   그런데 x(4) = −2 + ∫_1^4 (t − 1)(t − a)dt = 7 − 9(a − 1)/2 = −2/3 → a = 1 + 46/27 > 1이 되어 a ≤ 1에 어긋난다.
5. **[L060] (B):** 위치가 극소인 시각 a에서 v(a) = 0이다(오른쪽 식의 나머지 근).
   - x(a) = (−1/6 + b/2) − (a − 1)³/6 = −2.
   - a < 4이면 x(4) − x(a) = ∫_a^4 (t − 1)(t − a)dt = (4 − a)²(a + 5)/6 = 4/3이다. 즉 (4 − a)²(a + 5) = 8이다. 왼쪽은 (1, 4)에서 감소하므로 a = 3이다.
   - a ≥ 4이면 x(a) = −2에서 b = (a − 1)³/3 − 11/3 ≥ 16/3 > 0이 되어 b ≤ 0에 어긋난다.
   - a = 3 → b = −1.
6. a + b = 2.

검증(numpy, scipy):
- 극한식을 n = 2000으로 직접 계산해 구간별 식과 맞는지 확인했다(t = 0.5, 0.99, 1, 1.01, 2.5).
- a = 3, b = −1이면 방향 전환은 t = 3 한 번이다. x(3) = −2, x(4) = −2/3이다.
- a ∈ [−3, 6], b ∈ [−6, 3]을 0.05 간격으로 훑었다. (가)와 (나)를 만족시키는 것은 a = 3, b = −1뿐이다(허용 오차로 이웃한 b ± 0.05가 함께 잡혔다).

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - (가)를 빼면 "운동 방향을 바꾸는 시각"이 하나로 정해지지 않는다.
  - (나)의 두 위치 −2와 −2/3은 각각 빼 보면 1변수 족이 남는다.
  - 값 하나하나도 빼 봤다(원칙 1, D008 교훈).
- **답이 준 값을 다시 쓰는지(원칙 9):** 답 a + b는 조건을 풀어야 나온다. −2, −2/3은 답 계산에 들어가지 않는다.
- **해석을 대신해주지 않았는지(원칙 2):** "t = 1에서 v = 0이지만 방향이 바뀌지 않을 수 있다"는 문장에 없다. 극한식을 구간별로 풀어야 보인다.
- **경우 배제의 비교 대상(원칙 5):** (A)는 (나)의 두 위치로 a를 계산하면 a > 1이 나와 스스로 모순이다. 비교 대상(a ≤ 1)이 경우 설정 안에 있다.
- **조건이 만든 대상(원칙 7):** 방향 전환 시각 3은 a가 되고, 위치 −2는 b를 정한다. t = 1의 0은 방향 전환이 아니라는 판단에 쓰인다.
- **미적분 논리가 분기점에 있는지(원칙 8):** t = 1의 행동(속도 0인데 방향이 안 바뀜)은 수열의 극한으로 정의된 함수의 경계에서 생긴다. 이 판단이 (A)와 (B)를 가른다.
- **풀이 갈래(원칙 4):**
  - 지름길: 방향 전환을 "a에서"라고 놓고 바로 a = 3, b = −1을 구한 뒤, t = 1이 전환이 아님을 확인한다. 다만 (A)를 배제하지 않으면 풀이가 완결되지 않는다.
  - 정공법: 3단계의 경우를 모두 나눈다.
- **난이도:** 판단할 경계가 t = 1의 부호, (A)/(B), b의 범위로 여럿이다. D008 보정 기록(판단할 경계가 많으면 낮추지 않는다)에 따라 첫 예상 중상을 그대로 적는다.

## 자체 평가 (Claude)
- **좋은 점:** t = 1에서 v = 0이고 (t − 1)이 단순 인수인데도 방향이 바뀌지 않는다. "단순근이면 부호가 바뀐다"는 반사를 극한 함수의 경계가 깨뜨린다.
- **걱정 1:** 카드가 모두 기초 수준이라 각 단계의 계산은 쉽다. 볼륨은 경우 판단에서만 나온다.
- **걱정 2:** a ≥ 4 배제와 (A) 배제는 계산으로 끝나는 확인 단계라, 학생이 건너뛰고 답만 맞힐 수 있다.
- **걱정 3:** 답이 2로 작아서 찍기 쉬워 보일 수 있다.

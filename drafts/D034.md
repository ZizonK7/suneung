## 문항
최고차항의 계수가 1인 삼차함수 f(x)가 다음 조건을 만족시킨다.

(가) 모든 양수 α에 대하여 lim_{x→α} f(x − 5)/f(x)의 값이 존재한다.
(나) ∫_0^5 f(x)dx = ∫_0^{11} f(x)dx

f(10)의 값을 구하시오. [4점]

## 정답: 66

## 풀이
1. **[L121]** (나)에서 빼면 ∫_5^{11} f(x)dx = 0이다. f가 [5, 11]에서 늘 양수이거나 늘 음수일 수는 없으므로, f는 (5, 11)에서 근 β를 갖는다.
2. **[L003] 근의 연쇄:** (가)에서 양수 α가 f의 근이면 분모 → 0이므로 분자도 0, 즉 f(α − 5) = 0이다(중복도도 α − 5 쪽이 α 이상).
   - β > 5이므로 β − 5 > 0도 근이고, 다시 β − 10도 근이다.
   - β − 10 > 0이면 β − 15도 근이어야 해서 근이 넷이 된다. 따라서 β − 10 ≤ 0, 즉 5 < β ≤ 10이다.
   - 연쇄는 양수를 벗어나는 곳에서 끊긴다. "양수 α에 대하여"가 없으면 연쇄가 끝없이 이어져 이런 f가 없다.
3. 근이 β − 10, β − 5, β로 정해진다. c = β − 5 (0 < c ≤ 5)로 두면 f(x) = (x − c)³ − 25(x − c)이다.
4. u = x − c로 바꾸면 ∫_{5−c}^{11−c} (u³ − 25u)du = 0이다. F(u) = u⁴/4 − 25u²/2는 우함수이므로 F(11 − c) = F(5 − c)이다.
   - F(s) − F(t) = (s² − t²)(s² + t² − 50)/4이다.
   - s² = t²이면 11 − c = c − 5 → c = 8 (범위 밖)이다.
   - (11 − c)² + (5 − c)² = 50이면 c² − 16c + 48 = 0 → c = 4 (c = 12는 범위 밖)이다.
5. f(x) = (x + 1)(x − 4)(x − 9) → f(10) = 11 × 6 × 1 = 66.

검증(sympy):
- 근 c − 5, c, c + 5인 f에 대해 ∫_5^{11} f = 0의 해는 c = 4, 8, 12이고, 0 < c ≤ 5인 것은 4뿐이다.
- c = 8(근 3, 8, 13)은 근 3에서 −2가 근이 아니라 (가)에 어긋난다.
- f = (x + 1)(x − 4)(x − 9)에서 ∫_0^5 f = ∫_0^{11} f = 495/4이고, f(10) = 66이다.

- **조건 빼기 검사:**
  - (가)를 빼면 ∫_5^{11} f = 0을 만족하는 삼차함수가 무수히 많다.

- **해석을 대신해주지 않았는지(원칙 2):** "근이 연쇄한다", "연쇄는 양수를 벗어나면 끊긴다", "(5, 11)에 근이 있다"는 문장에 없다.

- **경우가 합쳐지는지 먼저 보기(D015 교훈):** 근이 양수가 아닌 경우와 양수 근이 (0, 5]에만 있는 경우는 따로 따질 필요가 없다. 둘 다 "(5, 11)에 근이 있다"는 한 문장으로 한꺼번에 빠진다.
- **난이도(한 단계 낮춰 봄):** 판단은 셋이다. (나)를 "(5, 11)에 근이 있다"로 읽는 것, 연쇄가 양수 경계에서 끊기는 것, 적분 방정식에서 범위 밖 해를 거르는 것이다. 첫 예상 중상에서 한 단계 내려 중으로 적는다.

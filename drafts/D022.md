## 문항
수열 {a_n}의 첫째항부터 제n항까지의 합을 S_n이라 하자. 수열 {a_n}이 모든 자연수 n에 대하여

  2S_n = a_n² + a_n

을 만족시키고,

  Σ_{k=11}^{20} a_k = 0

이다. 다음은 a₂₀의 최솟값을 구하는 과정이다.

┌──────────────────────────────────
함수 h(x) = ½x(x + 1)이라 하면, 모든 자연수 n에 대하여 S_n = h(a_n)이다.
S_{n+1} − a_{n+1} = S_n이고 h(x) − x = h(x − 1)이므로

  h(a_{n+1} − 1) = h(a_n)

이다. 곡선 y = h(x) 위의 두 점의 y좌표가 같으면 두 점은 일치하거나 직선 x = −½에 대하여 대칭이므로

  a_{n+1} = a_n + 1 또는 a_{n+1} = (가)  …… ㉠

이다. 또 2a₁ = a₁² + a₁에서 a₁ = 0 또는 a₁ = 1이므로, ㉠에 의하여 모든 자연수 n에 대하여

  −n + 1 ≤ a_n ≤ n

이다.
한편 Σ_{k=11}^{20} a_k = 0이므로

  a₂₀ = a₁₀ 또는 a₂₀ = (나)

이다. 따라서 a₂₀의 최솟값은 (다)이다.
└──────────────────────────────────

위의 (가), (나)에 알맞은 식을 각각 f(a_n), g(a₁₀)이라 하고, (다)에 알맞은 수를 p라 할 때, f(p) × g(p)의 값을 구하시오. [4점]

## 풀이
1. **[L037] 첫째 관계:** S_{n+1} − S_n = a_{n+1}이다. 그래서 h(a_{n+1}) − a_{n+1} = h(a_n)이다. h(x) − x = ½x(x − 1) = h(x − 1)이므로 h(a_{n+1} − 1) = h(a_n)이다.
2. **[L155] (가):** 이 관계를 그림으로 읽는다.
   - 점 P_n(a_n, S_n)은 곡선 y = h(x) 위에 있다.
   - 점 (a_{n+1}, S_n)은 곡선 y = h(x − 1) 위에 있다(1단계).
   - 그러므로 P_n에서 수평으로 곡선 y = h(x − 1)까지 갔다가, 수직으로 y = h(x)까지 올라가면 P_{n+1}이다. 수직으로 올라간 길이 h(x) − h(x − 1) = x가 a_{n+1}이고, 높이가 S_n에서 S_{n+1}로 바뀐다.
   - y = h(x − 1)의 대칭축은 x = ½이다. 수평선 y = S_n과의 두 교점은 a_n + 1과 1 − (a_n + 1) = −a_n이다. 따라서 **(가) = −a_n**이다.
   - 대수로 풀어도 같다: (a_{n+1} + a_n)(a_{n+1} − a_n − 1) = 0.
3. **범위:** a₁ ∈ {0, 1}이다. a_{n+1}은 a_n + 1이나 −a_n이므로 귀납적으로 −n + 1 ≤ a_n ≤ n이다(본문에 주어짐).
4. **[L037] (나), 메인 판단:** Σ_{k=11}^{20} a_k = S₂₀ − S₁₀이므로, 조건은 S₂₀ = S₁₀, 즉 h(a₂₀) = h(a₁₀)이다.
   - 같은 높이의 두 점은 일치하거나 x = −½에 대하여 대칭이다.
   - 따라서 a₂₀ = a₁₀ 또는 **a₂₀ = −a₁₀ − 1**이다.
   - 중간 열 개 항의 합이 양 끝 항 a₁₀, a₂₀만으로 정해진다는 것이 이 문항의 핵심이다.
5. **(다) 두 갈래 비교:**
   - a₂₀ = a₁₀이면 a₂₀ ≥ −9이다(a₁₀ ≥ −9).
   - a₂₀ = −a₁₀ − 1이면 a₂₀ ≥ −11이다(a₁₀ ≤ 10).
   - −11은 실제로 된다. 예: a_k = k (k ≤ 12) 뒤에 −12, 12, −12, 12, −12, 12, −12, −11이 오는 수열. S₁₀ = S₂₀ = 55이다.
   - 따라서 **(다) = −11**이다.
6. f(t) = −t, g(t) = −t − 1, p = −11 → f(p) × g(p) = 11 × 10 = **110**이다. 이 값은 p(p + 1) = 2S₂₀이다.

**지름길:** 갈래를 나누지 않아도 된다.
- S₂₀ = S₁₀ = h(a₁₀)이고, a₁₀ ∈ [−9, 10]이므로 h(a₁₀) ≤ h(10) = 55이다.
- h(a₂₀) ≤ 55를 만족하는 정수 중 가장 작은 것은 −11이다(h(−11) = 55, h(−12) = 66).
- 그래서 바로 a₂₀ ≥ −11이다.

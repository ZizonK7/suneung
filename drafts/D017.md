## 문항
최고차항의 계수가 1인 삼차함수 f(x)와 자연수 n에 대하여 0 ≤ x < 2π에서 정의된 함수

  g(x) = f(5 sin nx)

가 다음 조건을 만족시킨다.

(가) 방정식 f(x) = 0의 서로 다른 실근의 개수는 2이다.
(나) 함수 g(x)의 최댓값은 108이고, 방정식 g(x) = 108의 서로 다른 실근의 개수는 12이다.
(다) 함수 g(x)의 최솟값을 m이라 할 때, 방정식 g(x) = m의 서로 다른 실근의 개수는 8이다.

n + f(0)의 값은? [4점]

① 28  ② 30  ③ 32  ④ 34  ⑤ 36

## 정답
③ 32

## 풀이
u = 5 sin nx로 두면, x가 0 ≤ x < 2π를 움직일 때 u는 [−5, 5]를 n번 왕복한다(n주기). g의 최댓값·최솟값은 f의 [−5, 5]에서의 최댓값·최솟값이다.

1. **[L020] 주기 수로 세기:**
   - 한 주기에 u = v의 해는 −5 < v < 5이면 2개, v = ±5이면 1개다.
   - [−5, 5]에서 f가 최댓값을 갖는 u는 내부의 극대점(많아야 하나)과 끝점뿐이다. 그래서 g = (최댓값)의 해는 한 주기에 1, 2, 3개 중 하나다. 최솟값도 같다.
   - 12 = n × (1~3), 8 = n × (1~3)을 함께 만족시키는 것은 n = 4뿐이다. 한 주기에 최댓값은 3번, 최솟값은 2번이다.
2. **3과 2의 번역:**
   - 3 = 2 + 1: 내부 극대점 p에서 2번, 끝점에서 1번이다. 최고차항의 계수가 양수라 f는 p 왼쪽에서 증가하므로 f(−5) < f(p)다. 따라서 그 끝점은 u = 5이고, f(p) = f(5) = 108이다.
   - 2: 끝점 5는 최대점이므로 "양 끝점에서 같은 최솟값"은 아니다. 따라서 최솟값은 내부 극소점 q(p < q < 5) 한 곳에서만 갖는다.
3. **[L147] (가):** f(x) = (x − α)²(x − β) (α ≠ β)이고, 중근 α는 극값이 0인 극점이다.
   - 극댓값은 108이므로 α는 극대점이 아니다. 따라서 α = q이고 m = 0, f(x) = (x − q)²(x − β) (β < q)이다.
4. **비율:** f(x) − 108 = (x − p)²(x − 5)이고 f(x) = (x − q)²(x − β)이다. 두 식에서 f′의 근을 비교하면 q = (p + 10)/3, p = (q + 2β)/3이다.
   - 따라서 네 점 β, p, q, 5의 간격은 k : 2k : k다.
   - 108 = f(5) − f(q) = (5 − q)²(5 − β) = k² · 4k = 4k³이므로 k = 3이다.
   - q = 2, p = −4, β = −7, 즉 f(x) = (x − 2)²(x + 7)이다.
   - 확인: p = −4는 (−5, 5) 안에 있다. f(−5) = 98 > 0이므로 최솟값 0은 u = 2에서만 갖는다(한 주기 2번 → 8개).
5. f(0) = 4 × 7 = 28이므로 n + f(0) = 4 + 28 = 32다.

**지름길:** 삼차함수의 비율 관계를 아는 학생은 (가)(나)를 읽자마자 "중근 q, 극대점 p, 극댓값과 같은 값을 갖는 점 5"의 간격을 2 : 1로 놓는다. 그러면 f(5) − f(q) = 4k³ = 108에서 바로 k = 3을 얻는다.
**정공법:** f(x) = (x − q)²(x − β)로 두고 f(5) = f((q + 2β)/3) = 108을 연립한다. 해는 (q, β) = (2, −7), (11, 2)이다. 둘째는 극대점이 u = 5라 내부 극대가 아니므로 버린다.

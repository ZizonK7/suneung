## 문항
삼차함수 f(x)에 대하여 수열 {a_n}을

  a_n = ∫_{n−1}^{n} f(x)dx

라 하자. 세 수 f(2), f(5), f(8)이 이 순서대로 등차수열을 이루고 a₃ + a₈ = 6일 때, Σ_{k=1}^{10} a_k의 값을 구하시오. [4점]

## 정답: 30

## 풀이
1. **[L072] 등차수열 읽기:** f(5) − f(2) = f(8) − f(5)이다. 간격이 같고 평균변화율이 같으니 세 점 (2, f(2)), (5, f(5)), (8, f(8))은 한 직선 y = l(x) 위에 있다.
2. **f의 꼴:** f(x) − l(x)는 2, 5, 8을 근으로 갖는 삼차식이므로 f(x) = c(x − 2)(x − 5)(x − 8) + l(x)이다.
   - (x − 2)(x − 5)(x − 8)은 (5, 0)에 대해 대칭이다. 그래서 f는 점 (5, l(5))에 대해 대칭이다(변곡점 x = 5).
   - c와 l의 기울기는 정해지지 않는다.
3. **[L017] 짝짓기:** 구간 [k − 1, k]와 [10 − k, 11 − k]는 x = 5에 대해 대칭이다. 그래서 a_k + a_{11−k}에서 대칭인 부분이 지워져 a_k + a_{11−k} = 2l(5)로 k에 관계없다.
   - (나)의 a₃ + a₈ = 6은 이 짝 하나다 → 모든 짝의 합이 6이다.
4. Σ_{k=1}^{10} a_k = Σ_{k=1}^{5} (a_k + a_{11−k}) = 5 × 6 = 30.

**정공법:** f(x) = c(x − 2)(x − 5)(x − 8) + mx + d로 두고 a₃ + a₈ = 10m + 2d = 6, Σa_k = ∫_0^{10} f = 50m + 10d = 30. c는 저절로 지워진다.

검증(sympy):
- 일반 삼차함수 px³ + qx² + rx + s에서 "f(2), f(5), f(8)이 등차"는 q = −15p, 즉 변곡점 x = 5와 같다.
- p ∈ {1, 3}, r을 바꿔 가며 a₃ + a₈ = 6을 맞추면 합은 항상 30이다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - 등차 조건을 빼면 일반 삼차함수에서 합이 정해지지 않는다.
  - a₃ + a₈ = 6을 빼면 수치가 없다.
  - "최고차항의 계수"는 답과 무관해서 처음부터 주지 않았다.
- **해석을 대신해주지 않았는지(원칙 2):** "변곡점", "대칭"은 문장에 없다. 학생이 "등차수열 → 일직선 → 대칭"을 번역해야 한다.
- **답이 준 값을 다시 쓰는지(원칙 9):** 답 30 = 5 × 6이라 준 값 6을 그대로 쓴다. 다만 "짝의 합이 모두 같다"는 구조를 찾아야 6이 다섯 번 쓰인다. f를 끝까지 정할 수 없다는 점이 이 구조의 핵심이라 그대로 두었다. 경계 사례로 기록한다.
- **풀이 갈래(원칙 4):** 지름길은 대칭 짝짓기, 정공법은 미정계수 계산이다. 정공법에서도 c가 저절로 지워진다.
- **조건이 만든 대상(원칙 7):** 직선 l은 l(5)로 답에 쓰인다. c는 정해지지 않는 것 자체가 의미다.
- **난이도(한 단계 낮춰 봄):** 판단은 "대칭을 보느냐" 하나이고, 못 봐도 정공법이 짧다. 첫 예상 중에서 한 단계 내려 중하로 적는다.

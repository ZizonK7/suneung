## 문항
함수 f(x) = (e^x + e^{−x})/2와 양수 a에 대하여, 곡선 y = f(x)와 직선 y = f(a)로 둘러싸인 부분의 넓이를 S(a)라 하고, 이 부분의 경계 중 곡선 y = f(x) 위에 있는 부분의 길이를 L(a)라 하자.

  S(a) + L(a) = (17/2) ln 2

일 때, 4L(a)의 값을 구하시오. [4점]

## 정답: 15

## 풀이
1. **[L075] 길이:** 1 + {f′(x)}² = 1 + {(e^x − e^{−x})/2}² = {f(x)}²이다. 그래서 L(a) = ∫_{−a}^{a} f(x)dx.
2. **[L078] 넓이:** S(a) = ∫_{−a}^{a} {f(a) − f(x)}dx = 2a·f(a) − ∫_{−a}^{a} f(x)dx.
3. **핵심:** 곡선 아래 넓이와 곡선의 길이가 같다(∫f = L). 그래서 S(a) + L(a) = 2a·f(a), 즉 가로 2a, 세로 f(a)인 직사각형의 넓이다.
4. 2a·f(a) = a(e^a + e^{−a})는 a > 0에서 증가한다. a = 2 ln 2이면 2 ln 2 × (4 + 1/4) = (17/2) ln 2이므로 a = 2 ln 2다.
5. L(a) = e^a − e^{−a} = 4 − 1/4 = 15/4 → 4L(a) = 15.

검증(sympy, scipy):
- S(a) + L(a) − 2a·f(a) = 0이 기호 계산으로 성립한다.
- a = 2 ln 2에서 수치 적분으로 S + L = 5.8918 = (17/2) ln 2, L = 3.75를 확인했다.
- 2a·f(a)가 증가함수라 a는 하나다.

## LESSONS 자체 검수
- **조건 빼기 검사:** 조건이 S + L 하나뿐이고 a를 정하는 데 필요하다.
- **해석을 대신해주지 않았는지(원칙 2):** "넓이 + 길이 = 직사각형"은 문장에 없다. 각각 계산해 더하면 자연스럽게 보인다.
- **답이 준 값을 다시 쓰는지(원칙 9):** 답은 a를 구한 뒤 L로 계산한다. 준 값 (17/2) ln 2는 a를 정하는 데만 쓰인다.
- **미적분 논리가 분기점에 있는지(원칙 8):** 곡선의 길이와 e^x 적분이 풀이의 중심이다. 다만 분기(경우 나누기)는 없다.
- **두세 번만 쓰이는 대상(원칙 1, D010):** S(a), L(a)는 조건과 답에만 쓰인다. 하지만 각각이 "넓이", "길이"라는 의미라 정적분식으로 직접 쓰는 것보다 정의가 자연스럽다고 판단했다.
- **난이도(한 단계 낮춰 봄):** 판단은 "S와 L을 더하면 지워진다" 하나이고, 각각 계산해도 짧다. a = 2 ln 2를 찾는 데 ln 2가 힌트다. 첫 예상 중하에서 한 단계 내려 하상으로 적는다.

## 문항
모든 항이 양수인 등비수열 {a_n}이 있다. 양수 x에 대하여 수열 {b_n}을

  b_n = { x    (a_n ≥ x)
        { a_n  (a_n < x)

이라 하자. 급수 Σ_{n=1}^∞ b_n은 모든 양수 x에 대하여 수렴하고, 이 급수의 합을 f(x)라 할 때, 함수 f(x)가 다음 조건을 만족시킨다.

(가) 직선 y = kx + 3이 곡선 y = f(x)와 만나도록 하는 실수 k의 값의 범위는 k ≤ 5/2이다.
(나) f(4) = 12

f(1/3) = q/p일 때, p + q의 값을 구하시오. (단, p와 q는 서로소인 자연수이다.) [4점]

## 풀이
a_n = a·rⁿ⁻¹ (a > 0, r > 0)이라 하자.

0. **수렴:** r ≥ 1이면 n이 충분히 클 때 a_n ≥ x(r > 1)이거나 b_n = min(a, x)로 일정(r = 1)하다. 그러면 b_n이 0으로 가지 않으므로 0 < r < 1이다.
1. **[L135] f를 읽기:** a_n은 감소하므로 x 이상인 항은 앞쪽 몇 개뿐이다. 그 개수를 m이라 하면, 즉 a_{m+1} ≤ x ≤ a_m이면
   f(x) = m·x + (a_{m+1} + a_{m+2} + ⋯) = m·x + a_{m+1}/(1 − r)
   이다. 따라서 f는 항 a₁, a₂, a₃, …을 꺾이는 점으로 갖는 꺾은선이다. [a_{m+1}, a_m]에서 기울기는 m이고, 오른쪽으로 갈수록 기울기가 1씩 줄어든다(위로 볼록). 또 x → 0+이면 f(x) → 0이고, x ≥ a₁이면 f(x) = a/(1 − r)로 일정하다.
2. **[L042] (가) 번역:** f는 위로 볼록하고 f(0+) = 0 < 3이다. 그래서 (0, 3)을 지나는 직선은 기울기가 작으면 곡선과 만나고, 기울기를 키우면 어느 순간부터 만나지 않는다. 범위가 닫힌 끝 k = 5/2에서 끝나므로 이때 직선은 곡선에 닿기만 한다(특수 상황).
   - 꺾은선의 선분 기울기는 모두 정수다. 5/2는 정수가 아니므로 직선은 선분을 품지 못하고 꼭짓점 하나에서 닿는다.
   - 그 꼭짓점의 왼쪽 기울기는 3, 오른쪽 기울기는 2이다. 즉 x 이상인 항이 3개에서 2개로 바뀌는 점이고, x = a₃이다.
   - a₃ = v라 하면 [a₃, a₂]에서 f(x) = 2x + v/(1 − r)이다. 따라서 f(v) = 2v + v/(1 − r) = (5/2)v + 3, 즉 v(1 + r)/(2(1 − r)) = 3이다.
     → a₃ = 6(1 − r)/(1 + r), 그리고 [a₃, a₂]에서 f(x) = 2x + 3 + a₃/2이다.
3. **[L135] (나) 경우 나누기:** 4 이상인 항의 개수를 k라 하자. a_{k+1} = a₃r^{k−2}이므로 f(4) = 4k + a₃r^{k−2}/(1 − r) = 4k + 6r^{k−2}/(1 + r) = 12이다.
   - k ≥ 3: 4k ≥ 12이고 둘째 항이 양수라 모순이다.
   - k = 2 (a₃ ≤ 4 ≤ a₂): 8 + 6/(1 + r) = 12 → r = 1/2. a₃ = 2, a₂ = 4라 4 ∈ [2, 4]로 맞다.
   - k = 1 (a₂ ≤ 4 ≤ a₁): 4 + 6/(r(1 + r)) = 12 → r(1 + r) = 3/4 → r = 1/2. 같은 수열이다(4 = a₂가 꼭짓점이라 두 식이 모두 성립한다).
   - k = 0 (4 ≥ a₁): f(4) = a₁/(1 − r) = 12이므로 a₁ = 12(1 − r) ≤ 4, 즉 r ≥ 2/3이어야 한다. 그런데 식은 r²(1 + r) = 1/2이고, r ≥ 2/3이면 r²(1 + r) ≥ (4/9)(5/3) = 20/27 > 1/2이다. 모순이다.
   - 따라서 r = 1/2, a₃ = 2, a₁ = 8이다.
4. **[L135] f(1/3):** 1/3 이상인 항은 8, 4, 2, 1, 1/2의 5개이고, 나머지는 1/4 + 1/8 + ⋯ = 1/2이다. f(1/3) = 5/3 + 1/2 = 13/6 → p + q = 19.

**지름길:** 2단계에서 얻은 "[a₃, a₂]에서 f(x) = 2x + 3 + a₃/2"를 바로 쓴다. 4가 이 구간에 있다고 놓으면 8 + 3 + a₃/2 = 12에서 a₃ = 2이다. a₃/(1 − r) = 4에서 r = 1/2이고, a₂ = 4라 가정과 맞는다. 다른 구간이 안 되는 이유는 3단계에서 확인한다(시험장에서는 일치하는 것을 찾고 넘어갈 학생이 많을 것이다).

**정공법:** 3단계처럼 k = 0, 1, 2, 3 이상을 모두 확인한다. k = 0 배제가 가장 길다. 비교 대상은 "4가 a₁ 이상이어야 한다"는 구간 조건이다.

## LESSONS 자체 검수
1. **조건 빼기:** (가), (나), 각 수치, 수렴 조건이 모두 필요하다. "모든 항이 양수"는 빼도 답이 같다(검증 참고). 대상 설정으로 남기고 걱정에 적었다.
2. **뽑힌 논리:** L135는 f의 식(1단계), 꼭짓점이 a₃라는 판단(2단계), (나)의 경우 나누기(3단계)에서 쓰인다. L042는 (가)의 닫힌 끝을 "닿는 순간"으로 읽는 데 쓰인다. L149, L074, L035는 뺐다.
3. **해석을 대신해주는지:** "꺾은선", "기울기는 x 이상인 항의 개수", "꼭짓점 a₃"는 문장에 없다. (가)도 접한다고 말하지 않고 k의 범위로만 준다.
4. **지름길:** 꼭짓점 오른쪽 선분의 식 2x + 3 + a₃/2를 쓰면 (나)가 한 줄이다. 정공법(k 경우 나누기)도 끝까지 갈 수 있다.
5. **배제의 비교 대상:** k = 0 배제는 "4 ≥ a₁"과 a₁ = 12(1 − r)의 비교다. 구간 조건 자체가 비교 대상이다. k ≥ 3은 4k ≥ 12로 바로 빠진다.
6. **경우 나누기가 필요한지:** 4가 어느 구간에 있는지 모르면 f(4)의 식을 쓸 수 없다. 가정 없이 하나의 식으로 쓸 방법이 없다. k = 1과 k = 2는 같은 해(꼭짓점)라 실제로 갈리는 것은 "2 이하 / 0 / 3 이상"이다.
7. **조건이 만든 대상:** (가)의 꼭짓점 a₃ = 2는 a₁ = 8과 답의 항 목록에 쓰인다. (나)의 해 r = 1/2도 답에 쓰인다. 버려지는 것은 없다.
8. **(미적분) 분기점:** 급수를 x에서 자른 항의 개수가 곧 기울기라는 판단(급수 → 함수)이 (가)와 (나) 양쪽의 분기점이다. 미적분 부분이 결과값만 넘겨주는 앞단계가 아니다.
9. **답이 준 값을 다시 쓰는지:** 답 f(1/3)은 a = 8, r = 1/2를 구해야 나온다. 문제의 3, 5/2, 4, 12는 답 계산에 들어가지 않는다.
- **난이도:** 판단은 셋이다. f가 꺾은선이고 기울기가 항의 개수임을 읽기, 정수가 아닌 기울기 → 꼭짓점 a₃, 4의 위치 경우 나누기. 첫 예상은 중상이고, 한 단계 내려 중이다. 미적분 규칙대로 두 단계 내리면 중하다. 경계의 종류가 많은 문항은 아니라 내리는 규칙을 그대로 적용했다.

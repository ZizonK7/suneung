## 문항
최고차항의 계수가 1인 이차함수 f(x)와 상수 a에 대하여 함수

  g(x) = { f(x)      (x < 0)
         { f(x) + a  (x ≥ 0)

가 다음 조건을 만족시킨다.

(가) 함수 |g(x)|는 실수 전체의 집합에서 연속이다.
(나) 실수 k에 대하여 x에 대한 방정식 g(x) = k의 서로 다른 실근의 개수를 h(k)라 할 때, h(k) = 3을 만족시키는 실수 k의 값의 범위는 −1 < k ≤ 3이다.

g(−3) + g(5)의 값은? [4점]

① 20  ② 26  ③ 32  ④ 38  ⑤ 42

## 정답
② 26

## 풀이
f(0) = q, f의 꼭짓점을 (v, m)이라 하자.

1. **[L035] (가) 읽기:** 두 조각은 각각 연속이므로 x = 0만 보면 된다.
   - 좌극한은 f(0) = q이고 함숫값은 q + a이다. |q| = |q + a|이므로 a = 0이거나 (q + a) + q = 0이다.
   - a = 0이면 g = f는 이차함수라 h(k) ≤ 2이다. (나)의 h(k) = 3과 맞지 않는다.
   - 따라서 a = −2q (q ≠ 0)이다. g는 x = 0에서 q에서 −q로 뛴다. 오른쪽 조각은 f(x) − 2q이고, 꼭짓점 값은 m − 2q이다.
2. **[L013] 구간별로 풀고 근이 구간에 드는지 본다:**
   - x < 0에서는 f(x) = k를, x ≥ 0에서는 f(x) = k + 2q를 푼다. 두 식 모두 근은 v ± s 꼴이다.
   - 한 조각에서 근은 많아야 2개이므로 h(k) = 3은 2 + 1이다.
   - x < 0 조각에 두 근이 다 들려면 v + s < 0, 곧 v < 0이어야 한다. x ≥ 0 조각에 두 근이 다 들려면 v − s ≥ 0, 곧 v > 0이어야 한다.
   - **v < 0인 경우:**
     - 오른쪽 조각은 −q에서 출발해 증가하므로 근이 1개다(k ≥ −q일 때).
     - 왼쪽 조각에 근이 2개이려면 m < k < q이다. k = q이면 근 하나가 x = 0이 되어 x < 0에 들지 않는다.
     - 그래서 범위의 위쪽 끝 q는 열려 있다. (나)의 "k ≤ 3"과 맞지 않는다.
   - **v > 0인 경우:**
     - 왼쪽 조각은 감소하며 q에 다가가므로, 근이 1개인 것은 k > q일 때다(x = 0은 들지 않는다).
     - 오른쪽 조각에 근이 2개인 것은 m − 2q < k ≤ −q일 때다. k = −q이면 근 하나가 x = 0이고, 이 점은 x ≥ 0에 든다.
     - 위쪽 끝이 닫혀 있으므로 −q = 3, 곧 q = −3, a = 6이다.
   - v = 0이면 어느 조각에도 근이 2개 들지 않는다.
3. **[L172] 아래쪽 끝:** k > q와 k > m − 2q가 함께 걸린다. 그래서 아래끝은 max(q, m − 2q) = max(−3, m + 6)이다. 이 값이 −1이므로 m + 6 = −1, m = −7이다.
4. f(0) = v² + m = −3이므로 v² = 4이고, v > 0이므로 v = 2이다. 따라서 f(x) = (x − 2)² − 7 = x² − 4x − 3이고 a = 6이다.
   - 확인: g(x) = x² − 4x − 3 (x < 0), x² − 4x + 3 = (x − 1)(x − 3) (x ≥ 0)이고, h(k) = 3인 범위는 −1 < k ≤ 3이다.
5. g(−3) = f(−3) = 18, g(5) = f(5) + 6 = 2 + 6 = 8이므로 g(−3) + g(5) = 26이다.

**지름길:**
- 닫힌 끝 3은 어떤 조각의 닫힌 끝값에서만 나온다. 그런 점은 x = 0(오른쪽 조각)뿐이다. 그래서 g(0) = q + a = 3이고, (가)에서 |q| = 3, a ≠ 0이므로 q = −3, a = 6이다.
- 아래끝 −1이 q(= −3)가 아니므로, −1은 오른쪽 조각 f(x) + 6의 최솟값이다. 따라서 m = −7이다.
- v = ±2 중 오른쪽 조각이 꺾여야 근이 두 개 생기므로 v = 2이다.

**함정 (거울상):**
- 괄호를 보지 않고 3을 왼쪽 조각의 끝값 q로 읽으면 f(x) = x² + 4x + 3, a = −6이 나온다.
- 이 함수는 정답 g의 좌우를 뒤집은 것이고, h(k) = 3인 범위는 −1 < k < 3이다.
- 두 후보를 가르는 것은 "≤" 하나뿐이다. 이 경로로 가면 답은 42가 된다.

## LESSONS 자체 검수
1. **조건 빼기:** (가), 계수 1, 위끝 3, 아래끝 −1, 괄호 "≤"를 하나씩 빼거나 바꿨다. 모두 답이 갈린다. 끝값도 하나씩 따로 뺐다(D008 교훈). f(0) ≠ 0이나 "a ≠ 0" 같은 편의 조건은 처음부터 넣지 않았다(D014 교훈).
2. **카드가 단계를 결정하는가:**
   - L013은 "x = 0의 근이 어느 조각에 드는가"로 위끝의 괄호와 v의 부호를 정한다. 분기점이다.
   - L035는 a = 0인 갈래를 (나)로 버리고 a = −2f(0)을 얻는다. 판단 단계다.
   - L172는 아래끝이 두 하한 중 센 쪽이라는 판단이다. 무게는 작다.
3. **해석을 대신해주지 않는가:** "g는 x = 0에서 f(0)에서 −f(0)으로 뛴다", "닫힌 끝은 오른쪽 조각의 x = 0에서 나온다", "3 = 2 + 1"은 문장에 없다.
4. **지름길:** 닫힌 끝 → g(0) = 3 → q = −3으로 바로 가는 풀이가 있다. 정공법(경우 분석)도 끝까지 간다.
5. **배제의 비교 대상:**
   - a = 0 배제는 (나)의 "h(k) = 3"과 비교한다(이차함수는 근이 2개 이하).
   - v < 0 배제는 (나)의 "≤" 괄호와 비교한다. 비교 대상은 모두 문제 안에 있다.
6. **경우 나누기가 필요한가:**
   - v의 부호를 나누지 않으면 거울상 함수와 구별할 수 없다. 지름길도 결국 "닫힌 끝은 x = 0에서만"이라는 같은 판단을 쓴다.
   - a = 0 갈래는 한 줄로 끝나는 확인이라 난이도 근거로 세지 않았다.
7. **만든 대상이 버려지는가:**
   - q = −3과 a = 6은 g(5)에 쓰인다.
   - m = −7과 v = 2는 f를 정한다.
   - 왼쪽 조각의 근 등 계산 중간값은 답에 필요 없다. 다만 조건이 "만든" 대상은 아니다.
8. (미적분 아님)
9. **답이 준 값을 다시 쓰는가:** 답 g(−3) + g(5) = f(−3) + f(5) + a는 계수와 a를 구해야 나온다. 3, −1이 식에 그대로 들어가지 않는다. 거울상 함수에서는 답이 달라지도록 비대칭인 두 점을 골랐다(g(−3) + g(3) 같은 대칭인 질문은 거울상에서도 18이라 괄호가 쓸모없어진다).
- **난이도:**
  - 판단은 셋이다: 뛰는 값의 부호(L035), 닫힌 끝이 어느 조각인가(L013), 아래끝이 어느 하한인가(L172).
  - 이차함수라 계산은 짧다.
  - 첫 예상 중에서 한 단계 내려 중하로 적는다. 경계의 종류(꼭짓점, 열린 끝값, 닫힌 끝값)는 셋이다. 하지만 지름길로 가면 괄호 판단 하나로 대부분 풀려 내리는 쪽을 택했다.

## 자체 평가
- **좋은 점:**
  - 문장이 짧다. 답이 될 수 있는 두 함수가 서로 좌우 거울상이고, 둘을 가르는 것이 범위의 괄호 "≤" 하나다. 이 괄호가 메인 카드 L013("근이 그 구간에 드는지")을 그대로 묻는다. x = 0이 x ≥ 0 쪽에 든다는 사실이 문제 전체의 열쇠다.
  - |g| 연속(L035)이 만든 "f(0)에서 −f(0)으로의 점프"가 열린 끝값과 닫힌 끝값을 한 쌍(−3과 3)으로 만들어, 두 장치가 맞물린다.

- **제안 자리와 이유:**
  - 13번(중하~중, 수2): 판단 셋에 계산이 짧아 13번 난이도에 맞는다.

- **버린 구상:**

  - 삼차함수판(h(k) = 4인 범위): 미지수가 하나 남아 함수가 정해지지 않았다.

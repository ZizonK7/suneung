- **L036을 뺀 이유:** 등차수열의 부분합을 교점 개수 문항에 넣으려면 수평선 y = a_n이나 y = S_n을 억지로 세워야 했다. 이때 수열은 교점 개수의 경계값을 나열하는 장식이 되거나, 답이 수열의 첨자만으로 정해져 함수 쪽 조건이 쓸모없어졌다(원칙 1).
- **D007 피드백 반영:** 속함수 u(x) = 4^x − 2^{x+2}에 최솟값(x = 1)과 점근선(y = 0)을 줬다. 그래서 개수가 바뀌는 경계가 세 종류가 된다: 겉함수의 극값(접함), 속함수의 최솟값, 속함수의 점근선 값.

## 문항
최고차항의 계수가 1인 삼차함수 f(x)에 대하여 함수

  g(x) = f(4^x − 2^{x+2})

가 다음 조건을 만족시킨다.

(가) 모든 실수 x에 대하여 g(x) ≥ 0이고, 방정식 g(x) = 0의 서로 다른 실근의 개수는 2이다.
(나) 실수 k에 대하여 방정식 g(x) = k의 서로 다른 실근의 개수를 h(k)라 할 때, h(k) = 5를 만족시키는 k의 값의 범위는 16 < k < 32이다.

Σ_{k=1}^{40} h(k)의 값을 구하시오. [4점]

## 정답: 150

## 풀이
1. **[L005] 속함수 읽기:** 2^x = t (t > 0)로 두면 u = 4^x − 2^{x+2} = t² − 4t = (t − 2)² − 4이다.
   - u = v를 만족시키는 x의 개수 n(v):
     - v < −4: 0개
     - v = −4: 1개 (t = 2, x = 1)
     - −4 < v < 0: 2개 (t = 2 ± √(4 + v) 모두 양수)
     - v ≥ 0: 1개. 특히 v = 0이면 t(t − 4) = 0에서 t = 0은 버리고 t = 4 하나다. 그래서 0은 x → −∞일 때 다가가기만 하는 값이다.
   - h(k) = Σ n(v) (f(v) = k인 v에 대한 합)이다.
2. **[L014] (나) 번역:** 근 하나가 x를 많아야 2개 만들고 f(v) = k의 근은 많아야 3개다. 그래서 5 = 2 + 2 + 1이다.
   - (−4, 0)에 근 두 개, [0, ∞)에 근 하나가 있어야 한다. 따라서 f는 (−4, 0)에서 극대이고, 그 극댓값에서 수평선이 접할 때 개수가 줄어든다 → 극댓값 = 32.
   - 아래쪽 경계 16은 접하는 순간이 아니다. (−4, 0)의 양 끝값 중 큰 값, 즉 max(f(−4), f(0)) = 16이다.
3. **[L019] (가) 번역:** u의 치역은 [−4, ∞)이므로 (가)는 "[−4, ∞)에서 f ≥ 0이고 최솟값이 0"이다.
   - 0이 되는 곳은 둘 중 하나다. 하나는 f의 극소점이다(중근). 다른 하나는 v = −4, 즉 x = 1이다. 이 점은 속함수의 최소점이라 f가 중근이 아니어도 g가 극소가 된다.
4. **경우 나누기:** v₂ > v₁을 극소점이라 하자(v₁은 극대점).
   - **f(−4) = 16인 경우:** 0이 되는 곳은 v₂뿐이다. f(v) = (v − v₂)²(v − q)이고 극댓값 4(v₂ − q)³/27 = 32에서 v₂ − q = 6이다.
     - (v₂ + 4)²(2 − v₂) = 16을 풀면 v₂ = −2 또는 2√3 − 2다.
     - v₂ = −2이면 극대점이 −6이라 (−4, 0) 밖이다.
     - v₂ = 2√3 − 2 > 0이면 g(x) = 0의 근이 1개라 (가)에 어긋난다.
   - **f(0) = 16인 경우:**
     - v₂ < 0에서 0이 되면 같은 계산으로 v₂ = 2 − 2√3이다. 그런데 극대점이 (−4, 0) 밖이다.
     - f(−4) = 0이고 극솟값이 양수이면 g(x) = 0의 근은 x = 1 하나다.
     - 남는 것은 f(−4) = 0과 극소 f(v₂) = 0이 함께 성립하는 경우다. f(v) = (v + 4)(v − v₂)², f(0) = 4v₂² = 16 → v₂ = 2다.
   - 따라서 f(v) = (v + 4)(v − 2)² = v³ − 12v + 16이다. 극댓값 f(−2) = 32로 (나)와 맞는다.
5. **개수 표:**
   - f − 16 = v(v² − 12)이고 f − 32 = (v + 2)²(v − 4)이다.
   - h(0) = 2, 0 < k < 16이면 4, h(16) = 4(v = −2√3, 0, 2√3), 16 < k < 32이면 5, h(32) = 3(v = −2, 4), k > 32이면 1이다.
6. Σ_{k=1}^{40} h(k) = 4 × 15 + 4 + 5 × 15 + 3 + 1 × 8 = 150.

검증(numpy, sympy):
- h(k)를 v 공간(근과 n(v))과 x 공간(g(x) − k의 부호 변화) 양쪽에서 세어 일치를 확인했다.
- (나)를 만족시키는 삼차함수 족을 극대점 v₁ ∈ (−4, 0) 전체로 훑었다. (가)까지 만족시키는 것은 v₁ = −2(목표)뿐이다.
  - "g ≥ 0"을 빼면 50개 이상의 다른 해가 나온다.
  - "근의 개수 2"를 빼면 f(−4) = 16 쪽 해(v₂ = 2√3 − 2)가 남는다.
- 극댓값 32를 빼고 "16 < k < a"로만 주면, f(−4) = 16이고 (−4, 0)에 중근을 갖는 해가 생긴다(예: v₂ = −0.5, a ≈ 16.45).

## LESSONS 자체 검수
- **조건 빼기 검사:** 위 검증대로 g ≥ 0, 근의 개수 2, 하한 16, 상한 32가 모두 필요하다. 상한 32는 f(−4) = 16 쪽의 중근 해를 막는다.
- **해석을 대신해주지 않았는지(원칙 2):**
  - "5 = 2 + 2 + 1"은 문장에 없다.
  - "16은 접하는 값이 아니라 끝값"이라는 사실도 문장에 없다.
  - 속함수의 점근선과 최솟값도 학생이 치환으로 찾아야 한다.
- **경우 배제의 비교 대상(원칙 5):** 16이 f(0)인지 f(−4)인지는 (−4, 0) 구간의 두 끝값 비교다. 두 끝은 u의 최솟값과 점근선이고, 1단계에서 이미 찾은 값이다.
- **조건이 만든 대상을 쓰는지(원칙 7):**
  - f(−4) = 0은 x = 1이라는 근으로 쓰인다.
  - 중근 2와 16, 32의 근(0, ±2√3, −2, 4)은 모두 개수 표에 쓰인다.
  - 버려지는 것은 t = 0뿐이다. 이것은 점근선이 생기는 이유로 쓰인다.
- **없는 단계 확인(원칙 6):** 경우 나누기는 "16이 어느 끝값인가"와 "0이 어디서 생기는가" 두 축이다. 각 경우에서 실제로 다른 삼차함수가 나오고, 조건 하나씩으로 탈락한다. 필요 없는 가정은 없다.
- **풀이 갈래(원칙 4):**
  - 지름길: (가)에서 g(1) = 0인 경우를 먼저 의심한다. 그러면 f = (v + 4)(v − p)²로 바로 놓고 f(0) = 4p² = 16을 얻는다.
  - 정공법: 4단계의 경우를 모두 나눈다.
- **난이도(한 단계 낮춰 봄):** 첫 예상은 준킬러다. 한 단계 내려 쉬운 준킬러로 적는다.

## 자체 평가 (Claude)
- **좋은 점:** h가 바뀌는 경계가 접함(32), 점근선(f(0) = 16), 속함수 최솟값(f(−4) = 0) 세 종류다. L014("접하는 순간을 고른다")만 믿으면 16을 접하는 값으로 오해한다.
- **좋은 점:** L019의 "≥ 0이고 근이 있으면 극소"가 여기서는 겉함수의 중근이 아니라 속함수의 최소점(x = 1)에서 성립한다. 학생이 "중근"으로 바로 가면 막힌다.
- **걱정 1:** 경우 나누기 중 두 갈래는 무리수 계산(2 ± 2√3)에서 끝난다. 학생이 이 갈래를 끝까지 계산하지 않고 감으로 넘길 수 있다.
- **걱정 2:** 마지막 Σ_{k=1}^{40}이 개수 표를 정확히 만들었는지 확인하는 장치라, 계산 실수형 감점 요소가 크다.

## 사용자 피드백 (2026-10-19)
- **같은 논리가 다시 나왔다:** "0 이상이고 0이 되는 점은 극소"가 D007에 이어 다시 쓰였다. exam_grader 수업 노트에 이 문항을 추가했다.
- **실제로 쓰이는 것은 미적분 수업의 '합성함수의 극대·극소' 내용이다:** 값이 0이 되려면 x → −∞(점근선)가 아니라 실제로 도달해야 한다. 겉·속함수가 모두 미분가능하므로 다음 두 경우로 나뉜다.
  - 겉함수가 α에서 극소이면 속함수에 y = α를 그어 교점 개수만큼 근이 생긴다.
  - 속함수가 극점을 가지면 그 점은 속함수의 극소이고, 겉함수가 그 값에서 증가해야 한다.
  - 그래서 "y = α가 속함수와 두 점에서 만나는 경우"와 "속함수 극소(−4)에서 하나, y ≥ 0에서 하나"인 경우가 있다.
- **(나)의 5 = 2 + 2 + 1:** 접하는 순간은 k 하나에서만 일어나므로 범위의 안쪽이 될 수 없다. 범위가 끝나는 곳은 근이 줄어드는 순간(극댓값에서 두 근이 합쳐짐)이거나 근이 끝값(0)에 닿는 순간이다.
- **아쉬운 점:** 답을 구할 때 16~32가 그대로 들어간다. 문제에서 준 값을 다시 세게 하는 구조다.

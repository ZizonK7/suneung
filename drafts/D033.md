## 문항
실수 전체의 집합에서 도함수가 연속인 함수 f(x)와 삼차함수 g(x)가 모든 실수 x에 대하여

  |f(g(x))| = (x − 1)⁴(x + 2)²

이고 다음 조건을 만족시킬 때, f(3) − f(−3)의 값은? [4점]

(가) f(0) = 0, f′(4) = 8
(나) g(−1) = 4, f(g(−3)) < 0

① 0  ② 9  ③ 18  ④ 27  ⑤ 36

## 정답: ③ 18 (g(x) = (x − 1)²(x + 2), f(x) = x|x|)

## 풀이
h(x) = f(g(x)), p(x) = (x − 1)⁴(x + 2)²라 하자. h는 미분가능하고 |h| = p.
1. **부호는 영점에서만 뒤집힌다.** p > 0인 구간에서 h = p 또는 h = −p로 부호가 일정하다. 부호가 바뀔 수 있는 곳은 p = 0인 x = 1, −2뿐이다.
2. **(가) f(0) = 0 → g의 영점.** g(x) = 0이면 h(x) = f(0) = 0이라 p(x) = 0. 따라서 g의 실근은 1 또는 −2뿐이다.
3. **(나) g(−1) = 4와 f′(4) = 8 → g′(−1) = 0.** h′(−1) = f′(g(−1))·g′(−1) = 8g′(−1). 한편 h = ±p이므로 h′(−1) = ±p′(−1)이고, p′(x) = 6(x − 1)³(x + 1)(x + 2)라 p′(−1) = 0. ∴ g′(−1) = 0. **[L023 방향: 바깥 함수의 미분이 0이 아니면 안쪽 함수의 미분이 0]**
4. **g′의 다른 근.** g′(x) = 3c(x + 1)(x − m)으로 두면 g′ ≠ 0인 곳에서
   f′(g(x)) = h′(x)/g′(x) = ±p′(x)/g′(x) = ±2(x − 1)³(x + 2) / {c(x − m)}.
   f′이 연속이라 x → m에서 이 값이 유한해야 한다 → (x − m)이 (x − 1)³(x + 2)의 인수: m = 1 또는 m = −2. (m = −1이면 분모의 (x + 1)²에 분자는 (x + 1)¹뿐이라 발산.) 즉 g는 단조가 아니다.
5. **m = −2는 한 칸 k로 배제.** 극점이 −2, −1이면 한 칸 k = 1/2. 극점 x = −1을 지나는 수평선은 곡선과 x = −1 − 3k = −5/2에서 다시 만난다: g(−5/2) = g(−1). 그러면 |f(g(−5/2))| = |f(g(−1))|, 곧 p(−5/2) = p(−1)이어야 하는데 p(−1) = 16, p(−5/2) = (7/2)⁴·(1/2)² = 2401/64. 모순.
6. **m = 1 → g 결정.** g′ = 3c(x + 1)(x − 1) → g(x) = c(x³ − 3x) + d. g(1) = g(−2) = d − 2c이고, 2에서 g의 실근은 1 또는 −2이므로 d = 2c. g(−1) = 2c + d = 4c = 4 → c = 1.
   g(x) = x³ − 3x + 2 = (x − 1)²(x + 2).
7. **f의 모양.** p = {g(x)}²이므로 |f(g(x))| = {g(x)}². g의 치역은 실수 전체이니 |f(t)| = t². 부호: t > 0는 x > −2 (x ≠ 1)에서 나오는데, x = 1 양쪽에서 g가 같은 값을 가지므로 x = 1에서는 부호가 뒤집힐 수 없다(1에서는 뒤집히는 것처럼 보여도 f가 함수가 아니게 된다). 뒤집힐 수 있는 곳은 x = −2, 즉 t = 0뿐이다.
   f(t) = s₊t² (t ≥ 0), s₋t² (t < 0). f′(4) = 8s₊ = 8 → s₊ = 1. f(g(−3)) = f(−16) = −256·s₋ … (−16)²s₋ < 0 → s₋ = −1.
   f(x) = x|x|, f′(x) = 2|x|로 연속이다.
8. f(3) − f(−3) = 9 − (−9) = 18 → ③.

검증(numpy·sympy): g = (x − 1)²(x + 2), f = t|t|가 항등식을 [−4, 4]에서 만족(오차 10⁻¹²), f(0) = 0, g(−1) = 4, f′(4) = 8, f(g(−3)) = −256. 삼차 g = cx³ + dx² + ex + k를 격자(계수 −3~3, 간격 0.5)에서 훑어 g(−1) = 4, g′(−1) = 0, "같은 g값이면 같은 p값", "g = 0이면 p = 0"을 모두 만족하는 것은 (1, 0, −3, 2) 하나. m = −2 경우는 sympy로 g(−5/2) = g(−1) = 4를 확인(p는 다름).

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - f(0) = 0을 빼면 d가 안 정해진다(g = c(x³ − 3x) + d는 어느 d든 수준집합이 같아 항등식과 맞는다).
  - f′(4) = 8을 빼면 g′(−1) = 0을 못 얻는다. 값 8은 s₊를 정하고, 답 f(3)에 쓰인다. 값을 "≠ 0"으로만 주고 f(−3)만 물으면 8이 하는 일이 없어진다. 그래서 f(3) − f(−3)을 물었다.
  - g(−1) = 4를 빼면 c가 안 정해지고, 28번처럼 f′ 조건을 걸 점도 사라진다.
  - f(g(−3)) < 0을 빼면 s₋가 안 정해진다. g(−3) = −16을 계산해야 쓸 수 있는 조건이라 g를 구한 뒤에 쓰인다.
- **해석을 대신해주지 않았는지(원칙 2):** "g′(−1) = 0", "g는 단조가 아니다", "우변은 g²"는 문장에 없다.
- **경우 배제의 비교 대상(원칙 5):** m = −2 배제는 "g값이 같은 두 점에서 p값도 같아야 한다"는 항등식 자체가 비교 대상이다. m = −1 배제는 f′의 유한성.
- **버려지는 대상(원칙 7):** 배제된 m들은 조건이 만든 대상이 아니다. 조건이 만든 값 g(−3) = −16, g′(−1) = 0, 영점 1·−2는 모두 뒤에서 쓰인다.
- **답(원칙 9):** 18은 g와 f의 부호 둘을 다 정해야 나온다. 준 값 4, 8이 그대로 들어가지 않는다.
- **풀이 갈래(원칙 4):** 짧은 길 = 우변이 {(x − 1)²(x + 2)}²임을 보고 g = (x − 1)²(x + 2)를 바로 두고 (가)·(나)로 확인. 긴 길 = 위 풀이(g′(−1) = 0 → m 후보 → 한 칸 k → g). 짧은 길도 "|f(g)| = g²이면 f = ±t²"라는 생각을 해야 하고, 부호 배정(x = 1에서 못 뒤집힘)은 똑같이 해야 한다.
- **자연스럽게 세운 식이 풀리는지(원칙 10):** 모두 일차·인수분해.
- **난이도(한 단계 낮춰 봄):** 판단은 다섯이다. 영점에서만 부호 뒤집힘, f′ ≠ 0 → g′ = 0, f′ 유한 → m 후보, 한 칸 k 배제, x = 1에서 못 뒤집힘. 첫 예상 중상 → 중으로 적는다. 짧은 길을 보면 중하.

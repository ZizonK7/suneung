## 문항
매개변수 t로 나타낸 곡선

  C : x = e^t(3 + sin²πt), y = e^t(t² + at + b − cos²πt)

가 있다. 실수 k에 대하여 직선 y = x + k와 곡선 C가 만나는 점의 개수를 f(k)라 할 때, 함수 f(k)와 곡선 C는 다음 조건을 만족시킨다.

(가) f(k) = 2를 만족시키는 실수 k는 오직 하나뿐이다.
(나) 곡선 C는 점 (3e³, 3e³)을 지난다.

조건 (가)를 만족시키는 실수 k를 α라 하자. 직선 y = x + α가 곡선 C에 접하는 점의 좌표를 (p, q)라 할 때, p + q의 값은? (단, a, b는 상수이다.) [4점]

① 7e  ② 8e  ③ 9e  ④ 10e  ⑤ 11e

## 풀이
1. **[L150] 결합식으로 삼각항 지우기:** 직선 y = x + k와 만나는 점은 y − x = k인 점이다.
   - y − x = e^t(t² + at + b − cos²πt − 3 − sin²πt) = e^t(t² + at + b − 4).
   - φ(t) = e^t·Q(t), Q(t) = t² + at + b − 4라 하면 f(k)는 방정식 φ(t) = k의 서로 다른 실근의 개수다.
   - x′(t) = e^t(3 + sin²πt + π sin 2πt) > 0이라 x(t)가 증가한다. 그래서 서로 다른 t는 서로 다른 점을 준다. (학생은 보통 이 확인 없이 넘어가도 같은 답에 닿는다.)
2. **(가) 번역 — 점근선 0은 닿지 않는 값이다:** t → −∞이면 φ(t) → 0⁺(e^t가 이긴다)이고, t → ∞이면 φ(t) → ∞이다.
   - φ′ = e^t(Q + Q′)의 부호가 바뀌지 않으면 φ는 0에서 ∞까지 증가한다. f(k)는 0 또는 1이라 (가)에 어긋난다.
   - φ가 극대 M(t = c₁), 극소 m(t = c₂)을 가지면 그래프는 0⁺ → M → m → ∞이다.
     - m < 0이면 m < k ≤ 0에서 f(k) = 2다(왼쪽 가지는 0에 닿지 않는다). k가 무수히 많다.
     - m > 0이면 f(m) = f(M) = 2다. k가 둘이다.
     - m = 0이면 f(k) = 2는 k = M에서만 성립한다. ✓
   - m = 0이고 φ = e^tQ에서 e^t > 0이므로, Q는 극소점에서 중근을 갖는다. Q(t) = (t − c)².
3. **(나):** x(t) = 3e³ ⇔ t = 3이다(x(3) = 3e³, x 증가). 점 (3e³, 3e³)은 직선 y = x 위에 있으므로 φ(3) = 0 → Q(3) = 0 → c = 3.
   - Q = (t − 3)², 즉 a = −6, b = 13이다.
4. **α와 접점:** φ = e^t(t − 3)², φ′ = e^t(t − 1)(t − 3)이다. 극댓값은 φ(1) = 4e이므로 α = 4e다.
   - 직선 y = x + 4e는 t = 1에서 접한다(φ − α가 t = 1에서 중근, x′(1) ≠ 0이라 dy/dx = 1). 다른 한 점(t > 3)에서는 뚫고 지나간다.
   - p = x(1) = e(3 + 0) = 3e, q = p + α = 7e (또는 y(1) = e(1 − 6 + 13 − 1) = 7e).
5. p + q = 10e → ④.

**지름길:**
- (나)의 점이 y = x 위에 있다는 것을 먼저 보면 "직선 y = x가 곡선 C에 접하는 그림"을 바로 의심할 수 있다. 그러면 φ = e^t(t − 3)², 곧 x²e^x 그래프를 오른쪽으로 3만큼 옮긴 꼴이다. 극대점이 극소점보다 2만큼 왼쪽에 있다는 익숙한 사실로 t = 1과 α = 4e가 바로 나온다.
- 답은 p + q = 2p + α로 계산해도 된다. 접점이 직선 y = x + α 위에 있기 때문이다.

**정공법:** (나)에서 3a + b = −5를 얻으면 Q = (t − 3)(t + 3 + a)이다. 두 근 3과 −3 − a가 다르면 2단계의 m < 0 경우라서, 2단계의 분류로 −3 − a = 3이 나온다.

## LESSONS 자체 검수
1. **조건 빼기:** (가), (나) 모두 필요하다(위 검증). "오직 하나"도 필요하다. 군더더기 조건과 정의는 없다.
2. **뽑힌 논리:** L150은 "f(k)를 무엇으로 세나"라는 첫 분기를 결정한다. 결합식이 없으면 삼각·지수 혼합 방정식이라 손을 댈 수 없다. 나머지 네 장은 억지라 빼고 기록했다.
3. **해석을 대신하지 않는지:** "y − x를 보라", "y = x에 접한다", "극솟값이 0"은 문장에 없다. (나)는 점만 주고, 그 점이 y = x 위에 있다는 것은 학생이 알아챈다.
4. **지름길:** "y = x에 접하는 그림"을 의심하면 φ = e^t(t − 3)²가 바로 나온다(x²e^x 평행이동). 정공법(경우 분류 → 중근)으로도 끝까지 간다. 둘 다 10e에 닿는다.
5. **배제의 비교 대상:** m < 0과 m > 0을 지울 때 비교하는 대상은 "f = 2가 되는 k의 개수"다. 이것은 (가)의 문장 자체다. 점근선 0이 "닿지 않는 끝값"이라는 점은 φ의 극한에서 나온다.
6. **경우 나누기가 필요한가:** (나)로 Q = (t − 3)(t + 3 + a)까지 오면, 남는 판단은 "두 근이 다르면 f = 2가 구간"이라는 것 하나다. 학생이 중근을 바로 의심하면 분류를 건너뛴다. 그래서 분류 단계를 난이도 근거로 크게 세지 않았다.
7. **조건이 만든 대상:**
   - (나)의 t = 3(중근)은 φ′의 근이 되어 극대점 t = 1을 정한다.
   - α = 4e와 접점 t = 1은 답에 쓰인다.
   - 오른쪽에서 만나는 셋째 점(t > 3)은 개수로만 쓰이고 좌표는 버려진다. 초월방정식이라 묻지 않았다.
8. **(미적분) 분기점의 논리:** 매개변수 곡선의 결합식(L150), 지수함수의 극한(점근선 0에 닿지 않음), e^t·이차식의 극값이 쓰인다. 이것들이 (가)의 분기를 만든다. 수2로 바꿔 쓸 수 없다. 다만 매개변수 미분 자체는 "접점 ⇔ 중근"으로 대신할 수 있어 비중이 작다.
9. **답이 준 값을 다시 쓰는지:** 답 10e는 극댓값 4e와 접점 t = 1에서 나온다. 문제에 적힌 3e³은 답에 들어가지 않는다.
- **난이도 보정:** 첫 예상은 중이다. 한 단계 내리면 중하, 두 단계 내리면 하상이다. 판단은 (가) 분류 하나와 결합식 하나라서 내리는 규칙을 그대로 적용했다.

- **소재 겹침:** 미적분 미분(매개변수) + 개형. 27번에 매개변수 문항이 오면 세부가 겹친다.

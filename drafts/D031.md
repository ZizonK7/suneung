- 30번의 g(x) = (x − b)² 같은 겉함수는 두지 않았다. (가)를 g′(f)f′로 포장해도 g가 한 번만 쓰여 장식이 된다(D010 교훈). 대신 f f′을 그대로 써서 "(f²)′의 절반"으로 보는 번역을 학생에게 남겼다.

## 문항
양수 a와 상수 b에 대하여 함수 f(x) = a sin x + b가 다음 조건을 만족시킬 때, ab의 값을 구하시오. [4점]

(가) ∫₀^{2π} |f(x)f′(x)| dx = 10
(나) ∫₀^{π/2} f(x) cos x dx = 2

## 정답: 2 (a = 2, b = 1)

## 풀이
1. **(나) 그대로 적분.** sin x를 한 덩어리로 보면 그 미분 cos x가 곱해져 있다 **[L115]**. u = sin x로 두면 x: 0 → π/2일 때 u: 0 → 1.
   ∫₀¹ (au + b) du = a/2 + b = 2. … ①
2. **(가) 절댓값을 ±로.** f f′ = (f²/2)′이므로 ∫|f f′| dx는 f²/2가 움직인 양의 합이다. f = a sin x + b의 그래프를 그려 둔다. b의 크기를 모르니 f가 0을 지나는지 모른다. 일단 지난다고 두고(|b| < a) 그린다.
   - f: b → a + b → b → b − a → b. f²는 b² → (a + b)² → 0 → (a − b)² → 0 → b² (b < 0이어도 합은 같다).
   - 움직인 양: {(a + b)² − b²} + (a + b)² + (a − b)² + (a − b)² + b² = 2(a + b)² + 2(a − b)² = 4(a² + b²).
   - (가): 4(a² + b²)/2 = 10 → a² + b² = 5. … ②
   - (지나지 않는 경우 |b| ≥ a) f의 부호가 고정이라 f²는 (a + b)²와 (a − b)² 사이만 오간다: 움직인 양 2|(a + b)² − (a − b)²| = 8a|b| → a|b| = 5/2. … ②′
3. **연립.** ①에서 b = 2 − a/2.
   - ②: a² + (2 − a/2)² = 5 → 5a² − 8a − 4 = 0 → (5a + 2)(a − 2) = 0 → a = 2 (양수), b = 1. |b| = 1 < 2라 가정과 맞는다.
   - ②′: b ≥ a이면 a(2 − a/2) = 5/2 → a² − 4a + 5 = 0, 실근 없음. b ≤ −a이면 a(a/2 − 2) = 5/2 → a² − 4a − 5 = 0 → a = 5, b = −1/2인데 b ≤ −a가 아니다. 모순.
4. ab = 2.

검증(scipy 수치 적분): (a, b) = (2, 1)에서 (가) = 10.000, (나) = 2.000. 움직인 양 공식(|b| < a → 4(a² + b²), |b| ≥ a → 8a|b|)을 다섯 쌍에서 확인. b = 2 − a/2 위에서 a ∈ (0, 6]을 훑어 (가) = 10이 되는 점은 a = 2 하나.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - (가)를 빼면 a/2 + b = 2만 남는다. (나)를 빼면 원 a² + b² = 5만 남는다.
  - "양수 a"를 빼면 (a, b) = (−1, 5/2)도 두 조건을 만족한다(부호가 고정인 경우, 8|a||b| = 20). ab = −5/2가 되어 답이 갈린다. 필요한 조건이다.
  - 10을 바꾸면 다른 (a, b)가 나오고, 2를 바꿔도 마찬가지다.
- **해석을 대신해주지 않았는지(원칙 2):** "f²의 변화량", "f가 0을 지난다"는 말은 문장에 없다. |f f′|를 (f²)′로 보는 것, sin x·cos x를 치환으로 보는 것이 학생 몫이다.
- **경우 배제의 비교 대상(원칙 5):** f가 0을 지나는지는 |b|와 a의 비교다. f = a sin x + b 자체에 있다.
- **경우 나누기가 필요한지(원칙 6):** 필요하다. 부호가 고정이면 합이 8a|b|로 달라진다. 다만 30번처럼 "일단 그려 두고 계산"하면 첫 경우에서 바로 답이 나오고 사후 확인(|b| < a)으로 끝난다. 둘째 경우를 끝까지 하는 것은 긴 길이다.
- **버려지는 대상(원칙 7):** 이차방정식의 다른 근 a = −2/5가 양수 조건으로 버려진다. D005와 같은 모양이라 걱정되는 점이다. 다만 버려지는 것이 근 하나뿐이고 조건이 만든 '점·대상'은 아니다.
- **답이 준 값을 다시 쓰는지(원칙 9):** ab = 2는 연립을 풀어야 나온다.
- **풀이 갈래(원칙 4):** 짧은 길 = 그려 두고 첫 경우로 계산. 긴 길 = 경우를 둘 다 끝까지.
- **자연스럽게 세운 식이 풀리는지(원칙 10):** 원과 직선의 연립, 이차방정식 하나.
- **난이도(한 단계 낮춰 봄):** 판단은 셋이다. |f f′|를 (f²)′/2로 읽기, 부호가 바뀌는지에 따라 합이 달라짐, (나)의 치환. 첫 예상 중하 → 하상으로 적는다. 민수 기준으로는 30번과 같은 두 지점(절댓값 ±, 식 그대로 쓰기)을 그대로 밟는다.

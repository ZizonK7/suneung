## 문항
최고차항의 계수가 1인 삼차함수 f(x)와 자연수 k가 다음 조건을 만족시킨다.

  (가) lim_{x→1} (x − 1)² / (f(x) − k|x|) = 1/10
  (나) x에 대한 방정식 f(x) = k|x|의 서로 다른 실근의 개수는 3이다.

f(2)의 값을 구하시오. [4점]

## 정답: 43

## 풀이
1. **[L013]** x=1 근처에서는 |x| = x이므로 (가)의 분모는 다항식 f(x) − kx이다.
2. **[L015]** 분자 (x−1)²는 x=1에서 0이고, 극한값이 0이 아닌 유한한 값이다. 그래서 f(x) − kx는 x=1을 정확히 중근으로 갖는다.
   - 단근이면 극한이 0, 삼중근이면 발산한다.
   - 따라서 f(x) − kx = (x−1)²(x−p)이고, 극한 1/(1−p) = 1/10에서 p = −9.
   - 즉 f(x) = kx + (x−1)²(x+9)이다.
3. **[L013]** 실근을 x ≥ 0과 x < 0으로 나눠 센다.
   - **x ≥ 0:** f(x) − kx = (x−1)²(x+9) = 0 → x = 1 하나뿐이다(k와 무관).
   - **x < 0:** f(x) + kx = 0 ⟺ (x−1)²(x+9) = −2kx. 즉 곡선 y = (x−1)²(x+9)와 원점을 지나는 직선 y = −2kx의 교점이다.
4. **[L015, L014]** (나)에서 x < 0 쪽 서로 다른 실근이 정확히 2개여야 한다.
   - x=0에서 좌변이 9 > 0이고 x→−∞에서 −∞이므로, 실근은 중복 포함 홀수 개다. 그래서 서로 다른 실근이 2개인 것은 직선이 곡선에 접할 때뿐이다.
   - 원점에서 그은 접선: c(b) = b·c′(b), c(x) = (x−1)²(x+9) → −(b−1)(b+3)(2b+3) = 0 → b = −3 또는 −3/2.
   - b = −3: 기울기 c′(−3) = −32 = −2k → k = 16.
   - b = −3/2: k = 125/8 (자연수가 아니므로 제외).
5. f(x) = 16x + (x−1)²(x+9) = x³ + 7x² − x + 9 → f(2) = 32 + 11 = **43**.

검증(sympy):
- f − 16x = (x−1)²(x+9), f + 16x = (x+1)(x+3)²이고 극한은 1/10이다.
- 자연수 k ∈ [1, 59] 중 서로 다른 실근이 3개인 경우는 k = 16뿐이다.
- k = 125/8도 실근 3개이므로 "자연수" 조건이 필요하다.

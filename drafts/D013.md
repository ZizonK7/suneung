## 문항
자연수 n에 대하여 곡선 y = 1/√x와 x축 및 두 직선 x = n, x = n + 1로 둘러싸인 부분을 밑면으로 하는 입체도형이 있다. 이 입체도형을 x축에 수직인 평면으로 자른 단면이 모두 정사각형일 때, 이 입체도형의 부피를 V_n이라 하자.

  4 log₆₄ e^{V₁ + V₂ + ⋯ + V_m}

의 값이 자연수가 되도록 하는 1000 이하의 모든 자연수 m의 값의 합을 구하시오. [4점]

## 정답: 581

## 풀이
1. **[L084]** 단면은 한 변 1/√x인 정사각형이므로 넓이 1/x이다. V_n = ∫_n^{n+1} dx/x = ln((n + 1)/n).
2. **[L016]** V₁ + ⋯ + V_m = ln(2/1 · 3/2 ⋯ (m + 1)/m) = ln(m + 1) → e^{…} = m + 1.
3. **[L085]** 4 log₆₄(m + 1) = (2/3)log₂(m + 1) = j (자연수) → m + 1 = 2^{3j/2}.
   - m + 1이 자연수이려면 3j/2가 정수, 즉 j가 짝수다 → m + 1 = 8^i.
   - m = 7, 63, 511 (4095는 1000 초과).
4. 합 581.

검증(sympy, python): V_n = ln((n + 1)/n), 1 ≤ m ≤ 1000 전수 조사로 m = 7, 63, 511.

## LESSONS 자체 검수
- **조건 빼기 검사:** "1000 이하"가 없으면 합이 무한하다. 다른 조건은 하나뿐이다.
- **해석을 대신해주지 않았는지(원칙 2):** e^{ΣV}는 "로그의 합 → 곱"을 사실상 알려 준다. 망원곱을 학생이 찾게 하려면 e^{…}를 빼야 하지만, 그러면 로그 안에 로그가 들어가 식이 어색해진다.
- **답이 준 값을 다시 쓰는지(원칙 9):** 답은 조건을 풀어야 나온다.
- **미적분 논리가 분기점에 있는지(원칙 8):** 부피 적분은 첫 단계 계산일 뿐이고, 분기(j의 짝홀)는 수1 논리다. 원칙 8에 어긋난다.
- **난이도(한 단계 낮춰 봄):** 판단은 "j가 짝수여야 한다" 하나다(2306_21과 같은 구조). 첫 예상 하상에서 한 단계 내려 하로 적는다.

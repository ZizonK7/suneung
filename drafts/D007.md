## 문항
함수 f(x) = ∫_0^x |sin t| dt와 최고차항의 계수가 1인 삼차함수 g(x)에 대하여 함수 h(x) = g(f(x))가 다음 조건을 만족시킨다.

(가) x ≥ 0인 모든 실수 x에 대하여 h(x) ≥ 0이고, h(α) = 0인 양수 α가 존재한다.
(나) 함수 h(x)는 x = π에서 극대이다.

조건을 만족시키는 함수 g(x) 중에서 α의 값이 최소가 되도록 하는 함수 g(x)에 대하여 h(α/2)의 값을 구하시오. [4점]

## 정답: 27

## 풀이
1. **[L027]** |sin t|는 주기가 π이고 한 주기의 적분값이 2다. 그래서 f(nπ + θ) = 2n + (1 − cos θ) (0 ≤ θ ≤ π)이다.
   - f는 증가함수이고, f(π) = 2, f(3π) = 6, f(3π/2) = 3이다.
2. **[L023]** h′(x) = g′(f(x))·|sin x|이다.
   - x = π에서는 |sin x| = 0이라 h′(π) = 0이 저절로 성립한다. 하지만 |sin x|는 부호가 바뀌지 않으므로 이것만으로는 극값이 아니다.
   - π 근처에서 h′의 부호는 g′(f(x))의 부호와 같다. f(x)는 2를 증가하며 지나므로, x = π에서 극대이려면 g′이 y = 2에서 + → −로 바뀌어야 한다.
   - 따라서 g′(y) = 3(y − 2)(y − q) (q > 2)이다. 2는 g의 극대, q는 극소다.
3. **[L019]** x ≥ 0이면 f(x) ≥ 0이므로, (가)는 "y ≥ 0에서 g(y) ≥ 0이고 g(f(α)) = 0"이다.
   - f(α) > 0이므로 g는 y ≥ 0의 안쪽 점에서 최솟값 0을 가진다. 그 점은 극소점 q이다. 따라서 g(q) = 0이고 f(α) = q다.
   - g(y) = (y − q)²(2y + q − 6)/2이다.
   - x = 0에서도 h(0) = g(0) = q²(q − 6)/2 ≥ 0이어야 하므로 q ≥ 6이다.
4. α = f⁻¹(q)이고 f는 증가하므로, α가 최소인 것은 q = 6일 때다. 이때 α = 3π다(f(3π) = 6).
   - 이때 g(y) = y(y − 6)²이다.
5. h(α/2) = h(3π/2) = g(3) = 3 × 9 = 27.

검증(sympy, numpy, scipy):
- g′ = 3(y − 2)(y − q)와 g(q) = 0에서 g(0) = q²(q − 6)/2이고, g(0) ≥ 0 ⇔ q ≥ 6이다.
- q = 5.9이면 [0, 12π]에서 h의 최솟값이 −1.74로 (가)가 깨진다. q = 6, 6.5, 8이면 최솟값이 0이다.
- q = 6일 때 h(π − δ), h(π), h(π + δ)는 31.99988, 32, 31.99988로 x = π에서 극대다.
- f(π/3), f(4π/3), f(3π/2), f(3π), f(7π/3)을 수치 적분과 공식으로 비교해 모두 일치했다.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - (가)를 빼면 α가 정의되지 않는다.
  - (나)를 빼면 g(y) = (y − q)²(y − s) (q > 0, s ≤ 0)만 남아 q를 0 가까이 보낼 수 있다. α의 최솟값이 없다.
  - "최고차항의 계수가 1"을 빼면 답이 배수만큼 달라진다.
  - 모두 필요하다.
- **해석을 대신해주지 않았는지(원칙 2):**
  - g′(2) = 0이라는 사실은 문장에 없다. "x = π에서 극대"를 g′(f(π)) = 0과 f(π) = 2로 번역해야 한다.
  - "g는 중근을 가진다"도 문장에 없다. (가)에서 끌어내야 한다.
- **경우 배제의 비교 대상(원칙 5):** q ≥ 6을 얻는 비교 대상은 x = 0이다. (가)가 "x ≥ 0"이라고 써서 x = 0을 가리키고 있다.
- **조건이 만든 대상을 쓰는지(원칙 7):**
  - f(π) = 2는 g′의 근이 된다.
  - (가)의 α는 최소화 대상이자 답의 입력(α/2)이다.
  - q ≥ 6의 경계 q = 6에서 α = 3π가 다시 f의 평평한 점이 된다. 극대점과 극소점이 모두 f의 평평한 점(π, 3π)에 놓인다.
- **없는 단계 확인(원칙 6):** q < 2인 경우는 2가 극소가 되므로 (나)에서 바로 빠진다. 따로 나눌 필요가 없다.
- **풀이 갈래(원칙 4):**
  - 지름길: g(0) ≥ 0 한 줄로 q ≥ 6을 얻는다.
  - 정공법: g = (y − q)²(y − s)로 놓고 "y ≥ 0에서 g ≥ 0"에서 s ≤ 0, 극대점 (q + 2s)/3 = 2에서 q = 6 − 2s ≥ 6을 얻는다.
- **미적분 논리가 분기점에 있는지(원칙 8):**
  - 합성함수의 미분 h′ = g′(f)·f′에서 "f′ = 0인 점은 극값을 만들지 않고, f가 g′의 근을 지나야 극값"이라는 판단이 풀이의 첫 분기다.
  - |sin t|의 적분을 주기 개수로 세야 f(π), f(3π), f(3π/2)가 나온다.
- **난이도(한 단계 낮춰 봄):** 첫 예상은 쉬운 준킬러다. 한 단계 내려 중으로 적는다.

## 자체 평가 (Claude)
- **좋은 점:** x = π는 f의 평평한 점이라 h′(π) = 0이 공짜로 나온다. 그래서 학생이 "이미 h′ = 0인데 극대라는 조건이 무슨 뜻이지?"에서 멈추게 된다. 이 지점이 L023을 분기점에 놓는다.
- **좋은 점:** 답이 나오는 경계(q = 6)에서 α = 3π가 다시 평평한 점이 된다. 극대·극소가 모두 f의 평평한 점에 놓이는 결말이 깔끔하다.
- **걱정 1:** "α가 최소가 되도록 하는 g"라는 문장이 조금 길다. q의 범위를 끌어내게 하려면 필요했다.
- **걱정 2:** q ≥ 6을 g(0) ≥ 0 한 줄로 얻으면 L019(중근)를 거치지 않을 수도 있다. 다만 g(q) = 0을 세우는 데는 L019가 여전히 필요하다.

## 문항
실수 전체의 집합에서 연속인 함수 f(x)가 모든 실수 x에 대하여

  |f(x)| = |(x² − 1)(x² − 9)|

를 만족시킨다. 함수 f(x)가 다음 조건을 만족시킬 때, 함수 f(x)의 모든 극솟값의 합은? [4점]

(가) 함수 f(x)f(x − t)가 실수 전체의 집합에서 미분가능하도록 하는 양수 t의 개수는 1이다.
(나) 함수 f(x)는 최솟값을 갖는다.

① −48  ② −41  ③ −32  ④ −25  ⑤ −16

## 정답
② −41

## 풀이
p(x) = (x² − 1)(x² − 9)라 하자. 근은 −3, −1, 1, 3이고 모두 단순근이다. 부호는 x < −3에서 +, (−3, −1)에서 −, (−1, 1)에서 +, (1, 3)에서 −, x > 3에서 +이다.

1. **[L101] 부호 놓기:** f는 연속이고 근 사이에서 |f| > 0이므로, 다섯 구간마다 f = s_k·p (s_k = ±1)이다.
2. **[L040] 꺾이는 점:** 근 r에서 f의 좌우 식은 s_k·p와 s_{k+1}·p이다. 값은 0으로 같고, 기울기는 s_k·p′(r)와 s_{k+1}·p′(r)이다. p′(r) ≠ 0이므로
   - 부호를 유지하면(s_k = s_{k+1}) 미분가능하고 x축을 뚫고 지난다.
   - 부호를 뒤집으면 꺾인다(x축에 닿고 되돌아가는 V자).
   - 꺾이는 점의 집합을 C라 하자.
3. **(가) 곱의 미분가능성:** h(x) = f(x)f(x − t)가 깨질 수 있는 곳은 f(x)가 꺾이는 점과 f(x − t)가 꺾이는 점뿐이다.
   - x = c (c ∈ C)에서 f(x)가 꺾인다. 상대 인수 f(x − t)의 값 f(c − t)가 0이 아니면 h도 꺾이고, 0이면 두 인수가 모두 0으로 가므로 h′(c) = 0으로 미분가능하다. → c − t가 근이어야 한다.
   - x = c + t에서는 f(x − t)가 꺾인다. 같은 이유로 c + t가 근이어야 한다.
   - 따라서 C의 모든 점 c에 대하여 c − t와 c + t가 모두 f의 근이다. 꺾이는 점은 간격 t로 놓인 두 근의 한가운데여야 한다.
   - **C가 비어 있으면**(f = ±p) 모든 t에서 h가 미분가능하다. 양수 t가 무수히 많으므로 (가)에 어긋난다. 그래서 꺾이는 점이 반드시 있다.
   - 근 −3, −1, 1, 3 가운데 두 근의 한가운데인 것은 −1(−3과 1, t = 2)과 1(−1과 3, t = 2)뿐이다. −3, 3은 바깥쪽 근이 없어 꺾일 수 없다.
   - 그래서 C는 {−1}, {1}, {−1, 1} 중 하나이고, 어느 경우든 t = 2 하나만 된다.
4. **(나) 양 끝의 부호:** p는 사차식이므로 x → ±∞에서 +∞로 간다. f의 양 끝 부호는 s₁과 s₅다. 연속함수 f가 최솟값을 가지려면 두 끝이 모두 +∞여야 한다(한쪽이라도 −∞면 최솟값이 없다).
   - s₁ = s₅ = 1이어야 한다. 부호는 꺾이는 점에서만 뒤집히므로 꺾이는 점의 개수가 짝수다 → C = {−1, 1}.
   - 반대로 C = {−1, 1}, s₁ = 1이면 f는 양 끝이 +∞인 연속함수라 최솟값을 갖는다.
5. **f 확정:** f(x) = p(x) (|x| ≥ 1), f(x) = −p(x) (|x| < 1). 즉 [−3, 3]에서 f = −|p|이고 바깥에서는 f = p이다.
6. **극솟값:** p′(x) = 4x(x² − 5)이고 u = x²로 두면 p = (u − 1)(u − 9) = (u − 5)² − 16이다.
   - x = ±√5 (|x| ≥ 1인 쪽): f = p, 극솟값 −16 (두 번).
   - x = 0 (|x| < 1인 쪽): p(0) = 9가 p의 극댓값이었는데 f = −p라서 극솟값 −9가 된다.
   - x = ±1: 꺾이는 점은 f가 양쪽에서 음수로 내려가는 극대점(극댓값 0)이다.
   - x = ±3: 부호를 유지하는 근이라 극값이 아니다.
   - 모든 극솟값의 합 = −16 − 16 − 9 = −41 → ②.

**지름길:** (나)부터 본다. 양 끝이 모두 +∞라야 하니 꺾이는 점은 짝수 개다. (가)에서 꺾이는 점은 "양옆으로 같은 거리에 근이 있는 근"(±1)뿐이고 적어도 하나는 있어야 하니 둘 다다. 근이 −3, −1, 1, 3으로 같은 간격이라 t = 2는 보자마자 보인다. f는 [−3, 3]에서 −|p|, 바깥에서 p인 우함수이므로 x ≥ 0만 보고 −16 × 2 − 9를 계산한다.
**정공법:** 부호 32가지를 두고 (가)를 경우마다 확인해도 같은 결론에 닿는다(verify.py가 이 방식).

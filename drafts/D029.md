## 문항
세 상수 a, b, c에 대하여 함수

  f(x) = ae^{2x} + be^x + c

가 f(0) = 1을 만족시킨다. 실수 t에 대하여 두 곡선 y = f(x)와 y = e^{tx}가 만나는 점의 개수를 g(t)라 하자. 함수 g(t)가 t = 1, t = 3/2, t = 2에서 불연속일 때, f(ln 3)의 값은? [4점]

① 4  ② 5  ③ 6  ④ 8  ⑤ 9

## 정답
③ 6  (f(x) = (e^{2x} + e^x)/2)

## 풀이
1. **공통점:** f(0) = 1 = e^{t·0}이므로 모든 t에서 x = 0은 교점이다. x ≠ 0인 교점은 f(x) > 0이고 ln f(x) = tx인 점이다.
   - 곡선 y = ln f(x)는 원점을 지난다. 그래서 g(t) − 1은 "원점을 지나는 직선 y = tx와 이 곡선의, 원점 말고 다른 교점의 개수"다.
   - 같은 말로, g(t) − 1은 m(x) = ln f(x)/x (x ≠ 0)이 t가 되는 x의 개수다.
2. **[L014] 근이 합쳐지는 순간:** t = f′(0)이면 y = e^{tx}가 (0, 1)에서 y = f(x)에 접한다. 그래서 x = 0 근처의 교점이 x = 0과 합쳐진다. 이 t에서 g는 반드시 불연속이다.
   - 다른 점에서 접하는 t도 불연속점이 될 수 있다. 이것은 m의 극값이다.
3. **[L050] 끝에 닿는 순간:** x → ±∞에서는 지수 다항식의 한 항이 지배한다.
   - x → +∞이고 a > 0이면 ln f(x)/x → 2이다.
   - x → −∞에서는 가장 낮은 지수가 지배한다.
     - c > 0이면 ln f(x)/x → 0이다.
     - c = 0이고 b > 0이면 f(x) ≈ be^x이므로 ln f(x)/x → 1이다. 곡선 y = ln f(x)는 점근선 y = x + ln b를 갖는다.
     - c < 0이면 x → −∞에서 f < 0이다. 그래서 왼쪽 끝이 막히고, 이 경우 극한값이 없다.
   - t가 이 극한값을 지나면 먼 곳의 교점 하나가 생기거나 사라진다. 그래서 g가 불연속이다.
4. **분기점: 1은 어디서 왔나.** t = 1이면 방정식은 e^x = s에 대한 이차방정식이 된다.

     as² + (b − 1)s + c = 0, 즉 (s − 1)(as − c) = 0

   - 근은 s = 1(x = 0)과 s = c/a뿐이다. 따라서 x ≠ 0인 점에서 접할 수는 없다.
   - 그러므로 1은 f′(0)이거나, 끝에 닿는 값이다. 끝에 닿는 값이면 c = 0, b > 0으로 −∞쪽 기울기가 1이다.
   - (a = 0이면 +∞쪽 기울기가 1일 수도 있다. 이 경우는 6에서 지운다.)
5. **c = 0인 경우:** a + b = 1이다.
   - t = 3/2에서 방정식은 as² + bs = s^{3/2}이다. u = √s로 두면 au² − u + b = 0 = (u − 1)(au − b)이다.
   - u ≠ 1에서 중근이 생기려면 b/a = 1이어야 한다. 그런데 이것은 u = 1에서의 중근, 즉 f′(0) = 3/2과 같은 말이다. 그래서 3/2은 f′(0)이다.
   - f′(0) = 2a + b = 3/2와 a + b = 1에서 a = b = 1/2이다.
   - 확인: f = (e^{2x} + e^x)/2이면 m은 (−∞, 0)에서 1 → 3/2로, (0, ∞)에서 3/2 → 2로 증가한다.
     - g(t)는 t ≤ 1에서 1, 1 < t < 3/2에서 2, t = 3/2에서 1, 3/2 < t < 2에서 2, t ≥ 2에서 1이다.
     - 불연속점은 정확히 1, 3/2, 2다.
6. **다른 경우는 모두 안 된다 (정공법).** t = 2에서 방정식은 (a − 1)s² + bs + c = 0 = (s − 1)((a − 1)s − c)이다. 그래서 t = 2에서도 x ≠ 0인 점에서는 접하지 않는다.
   - **c < 0:** 왼쪽 끝이 막힌다.
     - a ≠ 0이면 4에 의해 f′(0) = 1이고, f(0) = 1과 합치면 c = a < 0이다. 그러면 오른쪽 끝도 막힌다. 2가 나올 곳은 f′(0) = 2나 t = 2에서 접하는 것뿐인데, 둘 다 안 된다.
     - a = 0이면 f = be^x + c이다. 2가 나오려면 f′(0) = b = 2, c = −1이어야 한다. 그런데 t = 3/2에서 2u² − 1 = u³, 즉 (u − 1)(u² − u − 1) = 0이고, 양의 근이 모두 단순근이다. 그래서 3/2이 나오지 않는다.
   - **c > 0:** −∞쪽 기울기가 0이다. 4에 의해 1은 f′(0)이어야 하고(a = 0이면 2가 나오지 않는다), 그러면 c = a > 0, b = 1 − 2a이다.
     - t = 3/2에서 au⁴ − u³ + (1 − 2a)u² + a = (u − 1)h(u)이고 h(u) = au³ + (a − 1)u² − au − a이다.
     - h(0) = −a < 0이고, h′의 두 근의 곱은 −1/3 < 0이다. 그래서 u > 0에서 h의 근은 하나뿐이고 단순근이다. 3/2이 나오지 않는다.
   - **c = 0, b ≤ 0:** b = 0이면 f = e^{2x}로 퇴화한다. b < 0이면 왼쪽 끝이 막히고 f′(0) = 1 + a > 2이므로 1이 나오지 않는다.
   - **c = 0, a < 0:** 오른쪽 끝이 막히고, t = 2에서 접하지도 않는다. 그래서 2가 나오지 않는다.
7. f(ln 3) = (9 + 3)/2 = **6**.

**지름길:** e^{tx}는 모두 (0, 1)을 지나므로 1, 3/2, 2는 세 가지 중 하나다: (0, 1)에서 접하는 기울기 f′(0), x → +∞쪽 기울기(최고차 지수 2), x → −∞쪽 기울기(최저차 지수).
- 정수가 아닌 3/2은 접하는 기울기다: 2a + b = 3/2.
- 남은 1은 x → −∞쪽 기울기다. 상수항이 없어야 e^x가 최저차 항이 되므로 c = 0이다.
- a + b = 1과 합치면 바로 a = b = 1/2이다.

**φ로 보는 풀이 (L050을 그대로 쓰는 길):** 교점은 φ_t(x) = f(x)e^{−tx} = ae^{(2−t)x} + be^{(1−t)x} + ce^{−tx} = 1의 근이다.
- c ≠ 0이면 x → −∞에서 ce^{−tx}가 지배한다. 그래서 t = 0을 지날 때 φ_t의 끝 행동이 바뀐다.
- c = 0이면 be^{(1−t)x}가 지배한다. 그래서 t = 1을 지날 때 φ_t(−∞)가 0에서 ±∞로 바뀐다.
- "t = 1에서 불연속"은 곧 "−∞에서 e^x 항이 지배"라는 뜻이다.

  - y = f(x) = k의 수평선 교점(지수 다항식의 점근선 쪽 끝): e^x = s로 치환하면 다항식 문제라 수2 겉옷이고(원칙 8), D008과 구조가 같다.
  - ∫_k^x (지수 다항식) ≥ 0 조건(L039 + L050): 상수항이 0일 때 극한이 유한해지는 판단은 있다. 하지만 조건이 f의 계수 부호 하나로 끝나 사이즈가 작다.
  - lim_{x→−∞} f′(x)/f(x)로 최저 지수를 읽게 하는 극한 조건: 판단이 하나뿐이다.
  - f(0) = 1 없이 원점에서 그은 접선을 쓰는 판: 접점이 초월방정식이고 답이 유일하지 않다.

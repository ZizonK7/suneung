## 문항
삼차함수 f(x)에 대하여 함수

  g(x) = ∫_0^x f′(t) sin(π f(t)) dt

가 다음 조건을 만족시킨다.

(가) 함수 g(x)는 x = 0에서 최솟값을 갖고, x = 2에서 최댓값을 갖는다.
(나) f′(0) = f′(2)

∫_0^2 x f′(x) sin(π f(x)) dx의 값은? [4점]

① 1/π  ② 2/π  ③ 3/π  ④ 4/π  ⑤ 6/π

## 정답
② 2/π

## 풀이
1. **[L115] g의 정체:** f를 모르는데 적분해야 한다. 피적분함수가 f′ × (f의 식) 꼴이므로 f(t)로 치환하면
   g(x) = [−cos(πf(t))/π]_0^x = {cos(πf(0)) − cos(πf(x))}/π
   이다. g는 f의 값에만 의존한다(경로와 무관).
2. **(가) 번역:** 삼차함수 f의 치역은 실수 전체이므로 cos(πf(x))는 −1과 1을 모두 갖는다.
   - x = 0에서 최소 ⟺ 모든 x에 대하여 cos(πf(x)) ≤ cos(πf(0)) ⟹ cos(πf(0)) = 1, f(0)은 짝수.
   - x = 2에서 최대 ⟺ cos(πf(x)) ≥ cos(πf(2)) ⟹ cos(πf(2)) = −1, f(2)는 홀수.
   - 따라서 g(x) = {1 − cos(πf(x))}/π, g(2) = 2/π. f 자체는 아직 정해지지 않는다.
3. **(나) 번역(대칭):** 삼차함수의 도함수(이차함수)가 f′(0) = f′(2)이면 f′의 대칭축이 x = 1이다. 그래서 f는 점 (1, f(1))에 대하여 대칭이다: f(1 + u) + f(1 − u) = 2f(1) = f(0) + f(2).
   - f(0) + f(2) = (짝수) + (홀수) = 홀수 N이므로 cos(πf(1 − u)) = cos(πN − πf(1 + u)) = −cos(πf(1 + u)).
   - 즉 cos(πf(x))는 x = 1에 대하여 점대칭이고 ∫_0^2 cos(πf(x)) dx = 0, 따라서 ∫_0^2 g(x) dx = 2/π.
4. **[L111] 부분적분:** 구하는 적분은 ∫_0^2 x g′(x) dx이므로
   ∫_0^2 x g′(x) dx = [x g(x)]_0^2 − ∫_0^2 g(x) dx = 2 × (2/π) − 2/π = 2/π.

**지름길:** 1~3단계를 g로만 본다. f의 점대칭과 f(0) + f(2)가 홀수라는 사실에서 g(1 + u) + g(1 − u) = 2/π, 즉 g는 점 (1, 1/π)에 대하여 대칭이다. 그러면 ∫_0^2 g = 2 × (1/π)가 바로 나오고, 부분적분 한 줄로 끝난다.
**정공법:** f(x) = a(x − 1)³ + b(x − 1) + d로 두고 f(0) = 2m, f(2) = 2n + 1에서 d = (2m + 2n + 1)/2(반정수)를 얻는다. 그다음 x = 1 + u로 치환해 ∫_{−1}^{1} cos(π(au³ + bu + d)) du = cos(πd) × ∫cos(…) − sin(πd) × ∫sin(…)에서 cos(πd) = 0, 둘째 적분은 기함수라 0이다. 길지만 끝까지 간다.

## LESSONS 자체 검수
1. **조건 빼기:** 위 검증대로 최솟값(x = 0), 최댓값(x = 2), f′(0) = f′(2), "삼차"가 각각 필요하다. 주지 않아도 되는 최고차항의 계수는 넣지 않았다(D014 교훈).
2. **뽑힌 논리가 단계를 결정하는가:** L115가 없으면 (가)를 번역할 수 없다. g를 f의 값만의 함수로 바꾸는 것이 모든 판단의 출발점이다. L111은 x가 낀 적분을 ∫g로 옮기는 마지막 단계를 결정한다. L087·L177·L070은 뺐다.
3. **해석을 대신해주는가:** "f(0)은 짝수, f(2)는 홀수", "f는 (1, f(1))에 대하여 대칭", "cos(πf)는 점대칭"은 문장에 없다. (나)는 대칭축만 주는 평범한 조건이다. 학생이 홀짝과 엮어 반정수 f(1)을 찾아야 한다.
4. **지름길·정공법:** 지름길(g의 점대칭 (1, 1/π))과 정공법(f를 a, b, d로 놓고 cos(πd) = 0) 모두 2/π에 닿는다.
5. **배제의 비교 대상:** 경우 배제 단계가 없다. (가)의 "최솟값/최댓값"은 cos의 최댓값 1과 최솟값 −1이라는 자연스러운 비교 대상이 있다. 이 비교는 삼차함수의 치역이 실수 전체라는 사실과 이어진다.
6. **경우 나누기가 필요한가:** 나누지 않는다. f를 끝까지 정하지 않아도 되므로 f(0) = 0 등을 가정하면 안 된다. 가정 없이 홀짝만으로 끝난다.
7. **조건이 만든 대상이 쓰이는가:** f(0)의 짝수성과 f(2)의 홀수성은 f(1)이 반정수라는 데 함께 쓰인다(합이 홀수). g(2) = 2/π는 부분적분 경계항에 쓰인다. (나)의 대칭축 x = 1은 적분 구간 [0, 2]의 중점으로 쓰인다. 버려지는 것이 없다.
8. **미적분 논리가 분기점에 있는가:** 치환적분으로 g를 닫힌 꼴로 바꾸는 단계가 문제를 여는 관문이다. 초월함수 합성 cos(πf)의 대칭과 부분적분이 뒤를 잇는다. 미적분을 빼면 남는 수2 문제가 없다.
9. **답이 준 값을 다시 쓰는가:** 문제에 적힌 수는 0, 2(구간)뿐이다. 답 2/π의 1/π는 홀짝 조건을 풀어서 얻은 평균값이다. 다만 ∫_0^2 g = (길이 2) × (평균 1/π)라 구간 길이 2는 들어간다. 경계 사례로 기록한다. 답이 g(2)와 같은 값이 되는 것은 2g(2) − ∫g의 구조에서 나온 우연이다.
- **난이도:** 첫 예상은 중상이다. 판단은 "치환으로 g의 정체 보기"와 "대칭 + 홀짝 → cos(πf)의 점대칭" 두 개다. 둘 다 미적분 학생에게 익숙한 도구라 한 단계 내려 중, 두 단계 내린 값은 중하로 적는다.

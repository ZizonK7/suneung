## 문항
최고차항의 계수가 1인 삼차함수 f(x)와 실수 t에 대하여 방정식 f(x) = 0이 닫힌구간 [t, t + 2]에서 갖는 서로 다른 실근의 개수를 g(t)라 하자. 함수 f(x)와 g(t)가 다음 조건을 만족시킨다.

(가) 함수 g(t)가 t = a에서 불연속인 실수 a의 개수는 4이고, 이러한 모든 a의 값의 합은 2이다.
(나) ∫_0^4 f(x)dx = 0

f(5)의 값은? [4점]

① 15  ② 20  ③ 30  ④ 50  ⑤ 60

## 정답
④ 50

## 풀이
1. **[L162] g가 끊기는 곳:** 방정식 f(x) = 0의 서로 다른 실근의 집합을 R라 하자. 구간 [t, t + 2]가 오른쪽으로 움직일 때 근 r는 t = r − 2에서 들어오고 t = r에서 나간다. 그래서 g가 불연속일 수 있는 곳은 r − 2와 r(r ∈ R)뿐이다.
   - 두 근의 차가 정확히 2(r′ = r + 2)이면 t = r에서 r가 나가는 순간 r′가 들어온다. 좌극한과 우극한은 같고 g(r)만 1 크다(고립값). 두 후보 r, r′ − 2가 한 점으로 겹친다.
   - 따라서 불연속점의 개수 = 2 × (근의 개수) − (차가 2인 두 근의 쌍의 개수).
2. **[L162] 개수 4의 번역 (분기점):**
   - 근이 1개이면 2개, 근이 2개이면 4개(차가 2이면 3개)다.
   - 근이 3개(간격 p, q)이면 6 − (쌍의 수)다. 쌍이 2개가 되는 것은 p = q = 2뿐이다(p + q = 2와 p = 2는 함께 성립할 수 없다).
   - 그래서 (가)의 "4"는 두 경우다.
     - **A:** 세 근이 m − 2, m, m + 2 (간격 2인 등간격)
     - **B:** 중근 α와 단순근 β, |β − α| ≠ 2
3. **A 확인 [L103]:** 불연속점은 m − 4, m − 2, m, m + 2이고 합 4m − 4 = 2에서 m = 3/2이다.
   - f(x) = (x − 3/2)³ − 4(x − 3/2)는 점 (3/2, 0)에 대해 대칭이다. [0, 3]의 중점이 3/2이므로 ∫_0^3 f(x)dx = 0이다.
   - 그러면 ∫_0^4 f(x)dx = ∫_3^4 f(x)dx = [u⁴/4 − 2u²]_{3/2}^{5/2} = 1/2 ≠ 0이다. (나)에 어긋난다.
   - "개수 4 = 등간격"으로만 읽은 학생은 여기서 막히고, 근의 개수가 줄어드는 B를 다시 떠올려야 한다.
4. **B:** 불연속점은 α − 2, α, β − 2, β이고 합에서 α + β = 3이다. f(x) = (x − α)²(x − β)에 β = 3 − α를 넣어 (나)를 계산한다.
   ∫_0^4 f(x)dx = 64 − (64/3)(2α + β) + 8(α² + 2αβ) − 4α²β = (4/3)α(3α² − 15α + 20) = 0
   - 3α² − 15α + 20의 판별식은 225 − 240 < 0이므로 α = 0, β = 3이다.
   - |β − α| = 3 ≠ 2라 B의 조건도 맞는다.
   - 확인: 근 0, 3에서 불연속점은 −2, 0, 1, 3(4개, 합 2)이다.
5. f(x) = x²(x − 3)이므로 f(5) = 25 × 2 = **50**.

**지름길:**
- A는 계산 없이 L103으로 지운다. [0, 3]의 대칭으로 ∫_0^4 f를 ∫_3^4 f 하나로 줄이면 된다. 일반 m에서는 ∫_0^4 f(x)dx = −4(m − 2)³이므로, (나)를 만족하는 등간격 삼차함수는 m = 2뿐이다. 그런데 m = 2는 합이 6이다.
- B에서 α + β = 3을 얻은 뒤 "0과 3"을 먼저 넣어 보면 ∫_0^4 x²(x − 3)dx = 64 − 64 = 0이 바로 맞는다. 유일성만 이차식의 판별식으로 확인한다.

**정공법:** B에서 (x − α)²(x − 3 + α)를 전개해 적분하면 α에 대한 삼차식이 나오고, α로 묶인다. 끝까지 갈 수 있다.

## 추출 기록
- 랜덤 추출 없음. 사용자 지정(2026-10-25): 10/18(일) 시험 28번과 2026-10 학평 30번의 논리를 메인으로 한 숙제용 문항.
- 30번에서 겉함수 g(x) = (x − b)²는 극점이 하나라 g(f(x))의 꺾이는 점이 "f의 극점"과 "f = b인 점"뿐이었다. 겉함수를 삼차 x³ − 3x로 바꿔 임계값이 둘(±1)이 되게 했다. 그러면 f의 범위가 −1 아래로 내려가는지에 따라 꺾이는 점의 수가 달라진다(D007 교훈: 속함수와 겉함수의 임계점이 섞여야 볼륨이 생긴다).
- 28번의 "f′(−1) ≠ 0이니 g′(0) = 0"은 (가)의 극소 조건에 넣었다: h′(π) = g′(b)·(−a)에서 a ≠ 0이라 g′(b) = 0.

## 문항
양수 a와 상수 b에 대하여 두 함수 f(x) = a sin x + b, g(x) = x³ − 3x가 있다. 함수 h(x) = g(f(x))가 다음 조건을 만족시킬 때, a + b의 값을 구하시오. [4점]

(가) 함수 h(x)는 x = π에서 극솟값을 갖는다.
(나) ∫₀^{2π} |h′(x)| dx = 124

## 정답: 4 (a = 3, b = 1)

## 풀이
1. **(가)에서 b.** h′(x) = g′(f(x))f′(x)이고 f(π) = b, f′(π) = −a ≠ 0이다. h′(π) = 0이어야 하므로 g′(b) = 0 **[L023]** → b = ±1.
   - 극소인지 보기: x = π 근처에서 f는 감소하며 b를 지난다.
   - b = 1: f > 1이면 g′(f) > 0, f < 1이면 g′(f) < 0. f′ < 0을 곱하면 h′는 −에서 +로 바뀐다 → 극소.
   - b = −1: f > −1이면 g′(f) < 0, f < −1이면 g′(f) > 0. h′는 +에서 −로 → 극대. 모순.
   - ∴ b = 1, f(x) = a sin x + 1.
2. **(나)는 h가 움직인 양의 합.** |h′|는 바로 적분할 수 없으니 h = g(f)의 그래프를 그려 두고, 늘어난 양과 줄어든 양을 모두 더한다. h가 꺾이는 곳은 f의 극점(x = π/2, 3π/2)과 f가 g의 임계값 ±1을 지나는 점이다 **[L065]**.
   - f의 범위는 [1 − a, 1 + a]. f = 1은 x = 0, π, 2π에서 지난다. f = −1을 지나는지는 a에 달렸다(1 − a < −1 ⟺ a > 2). a를 모르니 일단 그려 둔다.
   - 값: g(1) = −2, g(−1) = 2, g(1 + a) = a³ + 3a² − 2, g(1 − a) = −a³ + 3a² − 2.
   - **a ≤ 2** (f ≥ −1): h는 −2 → g(1 + a) → −2 → g(1 − a) → −2. [−1, 1]에서 g는 감소하므로 g(1 − a) ≥ −2.
     합 = 2(a³ + 3a²) + 2(3a² − a³) = 12a². 12a² = 124이면 a = √(31/3) > 2. 가정과 어긋난다.
   - **a > 2** (f가 −1 아래로 내려감): x = π에서 3π/2로 갈 때 f는 1 → −1 → 1 − a. h는 −2에서 g(−1) = 2까지 올랐다가 g(1 − a)로 내려온다. 3π/2 → 2π는 거꾸로.
     합 = 2(a³ + 3a²) + 2·4 + 2{2 − g(1 − a)} = 2a³ + 6a² + 8 + 2(a³ − 3a² + 4) = 4a³ + 16.
     4a³ + 16 = 124 → a³ = 27 → a = 3. a > 2에 맞는다.
3. a + b = 4.

검증(scipy): a = 3, b = 1에서 ∫|h′| = 124.000. 공식(a ≤ 2 → 12a², a > 2 → 4a³ + 16)을 a = 1, 1.5, 2, 2.5, 3에서 확인. b = 1, a ∈ (0, 5]를 훑어 124가 되는 a는 3 하나. (가)는 (b, a) = (1, ±3)에서 h(π ± ε) > h(π), (−1, ±3)에서 h(π ± ε) < h(π)로 확인.

## LESSONS 자체 검수
- **조건 빼기 검사:**
  - (가)를 빼면 b가 안 정해진다. (나)를 빼면 a가 안 정해진다.
  - "극솟값"을 "극값"으로 바꾸면 b = −1도 남는다. b = −1이면 h(x; a, −1) = −h(x + π; a, 1)이라 (나)에서 a = 3이 똑같이 나와 a + b = 2가 된다. 극소라는 말이 일한다.
  - "양수 a"를 빼면 a = −3도 (가)·(나)를 만족한다(f를 반 주기 밀어도 움직인 양의 합은 같다). a + b = −2가 되어 필요하다. 대신 h의 최댓값(52)을 물으면 양수 조건이 필요 없어지지만, 최댓값은 (나)를 계산하며 이미 쓴 값(g(4) = 52)이라 묻지 않았다.
  - 124를 바꾸면 a가 바뀐다. 127처럼 첫 경우의 범위에 떨어지는 값(12a² = 27 → a = 3/2)으로 바꾸면 둘째 경우가 사라져 쉬워진다.
- **해석을 대신해주지 않았는지(원칙 2):** "g′(b) = 0", "f가 −1 아래로 내려간다", "꺾이는 점"은 문장에 없다.
- **경우 배제의 비교 대상(원칙 5):** f의 최솟값 1 − a와 g의 임계값 −1의 비교. 두 함수가 문제 안에 있다.
- **없는 단계를 있는 것처럼 쓰지 않았는지(원칙 6):** a ≤ 2인 경우는 12a² = 124가 a > 2를 주어 스스로 무너진다. 실제로 판단이 필요한 경우 나누기다. 30번의 "일단 그려 두고 당당히"로 가면 둘째 경우(그림에 f = −1 통과를 넣은 쪽)부터 시작해 한 번에 끝난다.
- **버려지는 대상(원칙 7):** b = −1(극대라서), a = √(31/3)(범위 모순) 둘 다 배제용이지 조건이 만든 대상은 아니다.
- **미적분 고유 논리가 분기점에 있는지(원칙 8):** 합성함수의 미분 h′ = g′(f)f′과 "속함수가 겉함수의 임계값을 지나는 점"이 (가)·(나) 둘 다의 분기점이다. 다만 피적분함수 자체는 삼각·다항이라 적분 계산은 없다. 적분은 "움직인 양의 합"으로만 쓰인다.
- **답(원칙 9):** 4는 b = ±1 판단과 삼차방정식을 거쳐 나온다.
- **풀이 갈래(원칙 4):** 합에서 3a² 항이 상쇄되어 4a³ + 16으로 떨어진다. 계산을 믿고 밀면 가볍고, 그림 없이 적분하려 들면 막힌다.
- **난이도(한 단계 낮춰 봄):** 판단은 넷이다. g′(b) = 0, 극소·극대 구분, h의 꺾이는 점 찾기(속함수 극점 + 임계값 통과), a의 범위 경우. 첫 예상 중상 → 중으로 적는다. 미적분이라 두 단계 내린 중하도 함께 적어 둔다.

## 자체 평가 (Claude)
- 좋은 점: 28번의 "f′ ≠ 0 → 안쪽 함수 임계점"과 30번의 "절댓값 적분은 ±로"가 각각 (가), (나)의 분기점이다. 겉함수에 임계값이 둘이라 30번보다 그림이 한 단계 더 필요하다.
- 걱정 1: (가)의 극소/극대 구분이 a의 부호(양수)에 기대지 않는지 확인했다. a < 0이어도 b = 1이 나온다.
- 걱정 2: 숙제로는 세 문항 중 가장 무겁다. 3문제 몫.
